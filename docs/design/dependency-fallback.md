# 依赖降级链（Dependency Fallback Chain）
> **版本**：v1.0
> **日期**：2026-08-28
> **性质**：独立设计文档（DNA 防腐化铁律 #6 的实现细则）
> **原则**：所有依赖必须有降级策略。降级是**组件独立性**语义——任一生态组件停摆，其余组件降级继续运行。**Tuck 为可配置硬依赖**：是否启用由用户决定（不能强迫用户，debug 模式可不启用）；**一旦启用，Tuck 不允许停摆**（fail-closed）。CI-144 v2.0 PAL（物理锚定层）特征可更优雅实现此语义（明文锚点硬实时决策）。
> **关联**：ADR-0001（契约对齐 + 触发链路）、PLAN P10a

## 一、降级总则

- **组件独立性**：任一生态组件停摆，仅其自身功能降级，其余组件照常运行。例如 Callosum 失效 → 无 KV 缓存直连推理，Mind 检索与 Tentacle 工具照常；Tentacle 失效 → 仅文本回复，Mind 检索与推理照常。
- **fail-open**：非安全依赖不可用 → 降级功能，保持基本能力（编排/推理不中断）。
- **Tuck 可配置，启用后 fail-closed**：
  - **未启用 Tuck**（debug 模式 / 用户选择，不能强迫用户）→ 无 Tuck 保护正常运行，出网不强制审计（用户知情）。
  - **已启用 Tuck** → **不允许停摆**：不可用时阻断出网/高风险动作，绝不静默放行（唯一运行时硬依赖）。
  - CI-144 v2.0 PAL：启用后 Tuck 通过 PAL 明文锚点（固定偏移头部，含 Risk-Level/Override-Flag）做硬实时决策，无需解密载荷——事件驱动、0 解密，是 fail-closed 的优雅实现（PAL 落地前用现有配置门控）。
- 降级必须**可观测**：每次降级写审计/日志（含 trace_id），不静默。

## 二、依赖降级链

| 依赖 | 不可用表现 | 降级策略 | 模式 |
|---|---|---|---|
| **Helix-Mind** | gRPC 连接失败/超时/服务不可达 | 跳过记忆检索与认知工艺：`NoopMemoryAdapter`（现有默认），Anaphase 直接以熟练模式推理（无记忆增强）。**P10a 必须验证此路径** | fail-open |
| **Callosum** | 缓存服务不可达 | 无 KV 缓存，直连推理（token 成本上升，功能不受影响） | fail-open |
| **FlowModus** | LLM 调度不可达 | 直连 LLM（仅调试模式）或确定性降级（无 LLM 时返回确定性结果） | fail-open |
| **Tentacle** | 工具执行不可达 | 工具动作不可用，仅文本回复（不执行工具） | fail-open |
| **Cellrix** | UI 渲染不可达 | 退化为 CLI 纯文本输出 | fail-open |
| **Tuck** | 安全网关不可达 | **可配置硬依赖**：未启用（debug/用户选择）→ 无 Tuck 正常运行；**启用后不允许停摆** → 阻断出网/高风险动作（fail-closed），凭证标签拒绝签发 | **启用后 fail-closed** |

## 三、Mind 离线降级路径（P10a 验收重点）

```
外部请求 → AgentLoop
    │
    ├── mind 可用 → HelixQuery（记忆检索）→ 认知工艺 → 推理
    │
    └── mind 不可用（连接失败/超时）→ 降级路径：
         ├── 跳过 HelixQuery（NoopMemoryAdapter）
         ├── 跳过认知工艺（无 budget_tier 输入 → 熟练模式直接推理）
         ├── 记录降级事件（含 trace_id，可观测）
         └── 正常返回推理结果（无记忆增强）
```

## 四、降级判定规则

1. **探测**：`mind_endpoint` 连接超时（默认 2s）或 gRPC 返回 Unavailable → 判定不可用。
2. **熔断**：连续失败 N 次（默认 3）进入降级模式，避免每次请求都重试浪费。
3. **恢复**：定期（事件驱动/闲时）重探，恢复后自动回到正常路径。
4. **审计**：每次降级进入/恢复记录到审计日志（含 trace_id、原因、时间）。

## 五、测试要求

- **P10a 集成测试**：起 Mind 服务验证正常闭环；**停 Mind 验证降级闭环**（无记忆直接推理 + 降级事件记录）。
- 断言：Mind 离线时 Anaphase 仍能完成基本对话（fail-open），且降级事件被记录。
