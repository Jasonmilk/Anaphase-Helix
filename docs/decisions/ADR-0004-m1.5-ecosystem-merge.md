# ADR-0004：M1.5 生态合流（真实连通 + 语义定义 + run_cycle 渐进接线）

## 状态
**Active**（2026-09-03，M1.5 候选 D 执行记录）

## 问题
1. M1 的 Tentacle 侧是 mock server（ADR-0003 决策 2）；Tentacle 二进制虽有 grpc crate，但 `--transport` 只支持 stdio/http，从未接线
2. M1 的 fixture 数据内联在测试里（ADR-0003 决策 3）；真实 fixture 插件（manifest+js）需在 M1.5 落地
3. identity_labels / seen_entropy_bloom 语义（ADR-0003 决策 7 明确 M1.5 定义）
4. pipeline 接回 run_cycle（ADR-0003 决策 9 映射表）为 M1.5 必做项

## 决策

### 决策 1：Tentacle `--transport grpc` 接线
- `tentacle --transport grpc --grpc-port <port>`（默认 50051），复用与 http/stdio 相同的 registry 构建（scan_plugins + ProcessTool 实例化），经 `TentacleGrpcService::into_server()` + tonic serve
- tentacle crate 新增 `tentacle-transport-grpc` + `tonic 0.12` 依赖

### 决策 2：fixture 插件（manifest + js 执行体）
- `fixtures/` 目录：`numbers` / `rate`，manifest 携带 SHA-256 完整性校验（scan_plugins 强制）
- **参数化**：默认值走 MET 路径；`params` 覆盖走 UNMET 路径（如 `{"series":[1.0]}` 短序列）
- **M1.5 联调发现（重要）**：fixture 默认值必须满足判据契约，否则真实执行判 UNMET：
  - numbers 原默认 20 序列 → sum=210 超 threshold high=100 → 修正为 1..=10（sum=55，全过）
  - rate 原默认 {10,20} → cross_check(|10-20|=10 > 0.1*20) 失败 → 修正为 {10,10}（与 M1 mock 形状一致）
  - **教训**：真实 fixture 默认值 = M1 mock 形状 + 判据契约的双重约束，fixture-data-shapes.md 是权威锚点

### 决策 3：真实连通测试（跨仓库）
- Anaphase `tests/m1_e2e_live.rs`（#[ignore]，手动联调）：spawn 真实 tentacle 二进制（--transport grpc --plugins-dir fixtures/）→ GrpcTentacleAdapter 连真实 endpoint → pipeline 全链路
- 运行要求：`cargo build -p tentacle`（../helix-tentacle）+ node on PATH；`TENTACLE_BIN` 可覆盖路径
- 验证：m1_5_live_met（默认 fixture → MET）+ m1_5_live_unmet（短序列 → UNMET + retry_due=4600）全绿

### 决策 4：identity_labels / seen_entropy_bloom 语义
- **identity_labels**：调用方身份标签（如 tenant/channel/app），供 Tuck 审计 + 渐进披露。**只传纯标签，绝不传凭证**。Anaphase 经 `PipelineInput.identity_labels`（BTreeMap，确定性）注入，逐 call 转发
- **seen_entropy_bloom**：调用方"已见熵"布隆过滤器，用于重复/重放工具调用检测（Callosum 防重放）。可选：空 = 本调用无重放守卫。Anaphase 当前不启用（传空）
- adapter 新增 `execute_tool_with_labels(tool, params, trace_id, labels, bloom)`；`execute_tool` 保留为空标签入口

### 决策 5：run_cycle 渐进接线（step 1）
- **完整接回（六 stage 映射）是深重构，分步实施**。step 1（本次）：`AgentLoop.tool_command: Option<String>`——配置后 Execution 经 ToolAdapter 派发真实工具名（如 GrpcTentacleAdapter → 真实 Tentacle），未配置保持 echo fallback（向后兼容，现有测试不动）
- `with_tool_command()` builder；测试用 RecordingToolAdapter 证明："numbers" 被解析、未配置时保持 "echo"
- **剩余项（下一里程碑）**：Reasoning 输出结构化（替换 `contains("tool_call")` 字符串匹配）+ suggested_actions 结构化 + pipeline 完整 merge（六 stage ↔ 六状态映射表）

## 影响
- Tentacle：`--transport grpc` 可用，fixtures/ 为可复用示例（其它兼容项目可直接参考 manifest+js 插件模式）
- Anaphase：真实连通验证通过，M1 mock → M1.5 真实无缝切换（fixture 形状一致）
- 测试数：Anaphase 78（lib 46 + integration 16 + m1_e2e 3 + mind 9 + mock 4）；live 测试 2 个 #[ignore] 手动运行
