# ADR-0049：会话收敛 —— 状态 + 骨架 + 按需下钻（`lodestone-spec:ADR-0002` D5/D6 的会话实现）

- **状态**：**Accepted（2026-10-09）**
- **日期**：2026-10-09
- **决策范围**：anaphase-helix（`session_events` 的读取语义 + `run_cycle` 的上下文注入）
- **关联**：**`lodestone-spec:ADR-0002` D5/D6（协议本体，本文不重开）**、`ADR-0047`（period / lineage_path / slice）、`ADR-0048`（join 键）、`ADR-0023`（按需加载）、`ADR-0026`（会话事件流）
- **引用约定**：不带仓名的 `ADR-XXXX` 指 `anaphase:ADR-XXXX`；`lodestone-spec:ADR-0002` 是协议方。

## 一、背景：现在的行为是**截断**，不是收敛

实测（`helix-mind/docs/helixECO/convergence-A-baseline-2026-10-09.json`）：
21 轮链，第 1 轮埋独有事实 `ZEPHYR-7421`，第 21 轮追问。

| 判据 | 实测 | 判定 |
|---|---|---|
| ① 注入**不随链长线性增长** | 第 2 轮 **288** 字符 → 第 21 轮 **288** 字符 | ✅ **真空成立** |
| ② 早期独有事实**可被取回** | 第 21 轮 prompt **不含** `ZEPHYR-7421`；**下钻路径不存在** | ❌ |
| ③ 血缘边**完整** | 路径长度 **21**（r21 → r1） | ✅ |

根因是一行：续接注入 = `read_summary(dir, id, 400)` —— 只取**被续接那一轮**的
「human said + helix answered」，各 400 字。⇒ ① 之所以成立，**代价是链上其余 19 轮全部不可见**。

**这正是"截断"与"收敛"的分界**：截断让信息**变少**且**无处可取**；收敛让信息**变隐**且**仍可取**。

## 二、决策

> **协议不重新发明**：状态机、骨架、沉淀区、下钻指令四条全在 `lodestone-spec:ADR-0002` D5/D6。
> 本文只做**映射**：文档 → 会话链，磁石（lode）→ period。

### D1 每轮 = 一个磁石（lode）

`period` 即 `lode`；链 = 血缘路径（`ADR-0047` 的 `lineage_path`）。**不引入第二套身份**。

### D2 状态：`draft` | `converged`（**先两态**）

- 存储：`<period_id>.state` 侧车，与既有 `.name` 侧车**同构**（一文件一词，append-only 友好）。
- **缺省 = 由龄期派生**，不是存储值：`age >= converge_hide_after_days` ⇒ `converged`，否则 `draft`。
  ⇒ **历史 period 一行不回写**，一律按默认派生。
- 与协议的 `draft → converged → aligned` 对齐：本 ADR 只实现前两态；
  `aligned` 留给 v2.x（**不预造**）。

### D3 骨架 = D6 的 L0（**纯函数**）

`lodes` 的会话形态：对血缘路径**逐轮一行** —— `<period_id> [<status>] <summary 一行>`，
受 `converge_skeleton_max_lines` 与每行字符上限约束。
**纯函数**（输入 period 列表 + 状态，输出行），不做 IO、不看时间 —— 可单测、可变异。

### D4 下钻 = D6 的 L1/L2（**读数指令，复用既有结构分诊**）

- `!lodes` → L0 骨架（也就默认注入的那份）
- `!lode <slug>` → L1：单个磁石的子结构
- `!body <slug>` → L2：该轮**全文**（从事件流读，字节即当年落盘的字节）
- `!sediment` → 沉淀区索引

**实现走既有 `!` 前缀的结构化分诊**（`Perception` 识别 → 0 token → 不调 LLM）。
⇒ **不新增任何「面」**（无新端口 / 无新端点 / 无新协议）：下钻是**读数指令**，不是新入口。

### D5 沉淀区 = 已落盘的事件流本身（**隐性化 ≠ 删除**）

- 会话的全文**从未需要搬移**：一轮一个 `.events.jsonl` 文件，append-only。
  ⇒ D5 的"正文移入沉淀区、字节保留"**在本仓由构造满足**：沉淀 = 从**默认视图**退出，不是搬文件。
- 默认视图（注入）只给骨架；`!body <slug>` 是取回路径。
- **本 ADR 不引入任何删除操作**：`lodestone-spec` 的 `compress` 在这里只压**视图**，不压**字节**。

### D6 默认永不丢失，且**可关**

| 配置 | 默认 | 含义 |
|---|---|---|
| `converge_hide_after_days` | **7** | 超过则默认视图隐性 |
| `converge_compress_after_days` | **180** | 冷区留存阈值（本版只登记，不改字节） |
| `converge_skeleton_max_lines` | `24` | 骨架行上限（有界性的**旋钮**） |
| `converge_enabled` | `true` | **可关**：关掉 = 回到"只注入上一轮" |

全部进 `[anaphase]` 配置，**零硬编码**（DNA 铁律 11）。

### D7 可审查（§③ 四问）

必须能回答：**第几轮 / 因为什么被隐性 / 现在在哪 / 怎么取回**。
⇒ `!lode <slug>` 的回答里**必须**带：`status`、`derived_from`（如果派生）、
`retrievable_via`（取回指令）。**说不出这四句的不算收敛。**

## 三、验收判据（与实验 A 同一套，可证伪）

> 同一段 **20 轮**的链，第 21 轮继续时：
> 1. 注入 token **不随链长线性增长**（骨架有界）
> 2. 第 1 轮的独有事实**仍可被取回** —— 经下钻指令，不靠召回

**反证**：把注入退回 `read_summary(…, 400)` ⇒ 第 21 轮的取回路径消失、事实不可得 ⇒ 判据 ② 红。

## 六、落地实测（2026-10-09）—— 含一处默认值的自我更正

`helix-mind/docs/helixECO/convergence-A-after-2026-10-09.json`（基线见同名 `-baseline-`）。

| 判据 | 基线（改进前） | **落地后（实测）** |
|---|---|---|
| ① 不随链长线性增长 | 288 → 288（**真空**） | 自第 13 轮起骨架**锁定 12 行**；prompt 989 → 1054 后**转平** |
| ② 早期事实可取回 | ❌ 无任何路径 | ✅ `!body <id>` 取回全文含 `ZEPHYR-7421` |
| ③ 血缘边完整 | 21 | 21 |

**防"假绿"的第二条断言**（人类追加）：除字符数有界外，还要断言**注入里含骨架行**。
已加：`skeleton_is_bounded_and_the_elision_is_named` 断言行数 == `max_lines + 1`（含具名省略行），
`skeleton_keeps_the_newest_rounds` 断言留下的是**最新**的（活动区）。

### 6.1 自我更正：`skeleton_max_lines` 默认 **24 → 12**

**24 是错的，且是被实测抓出来的**：链长 21 < 24 ⇒ 骨架**从不触发省略** ⇒ 每轮加一行，
prompt 287 → **1504**（+62/轮）—— **比基线更重**，判据①在它被检验的那个尺度上**失败**。

> **一个从不生效的上界不是上界。**

12 行后骨架绑定，省略具名（`[N earlier round(s) hidden — retrieve with !body <id>]`），
且**第 1 轮的事实因此退出骨架** ⇒ 判据②**确实**由下钻满足，不是骨架顺手带出。

### 6.2 三条零成本确认（人类提问）

1. **撞名**：Tentacle 工具名为 `calc` / `numbers` / `rate` / `weather` / `web_search`
   （`helix-tentacle/fixtures/*.manifest.json`）；读数指令 `lodes` / `lode` / `body` / `sediment`
   **无一重叠**。分支在 `parse_structured_command` 之后、pipeline 之前拦下，撞名的静默降级不可能发生。
2. **显式收敛不在本版范围**：D2 是**纯龄期派生**，本版**没有**"人类说'这段聊明白了，现在收敛'"的入口。
   **这是有意裁剪，不是遗漏** —— `write_state` / `PeriodStatus::parse` 已存在且被测试覆盖，
   为将来的显式入口留好了唯一写入口。
3. **关账档不在任何仓内**：它在工作区根（`~/Developer/Jasonmilk/DSH-关账档-2026-10-11.md`），

## 八、gist 落地后的 D 复判（2026-10-09）

人类给的处置规则是「gist 绿 ⇒ 若 `C 关 + S` 仍假，再做 D」。**实测后必须说：这条规则不能判别。**

`converge_enabled = false` **同时关掉骨架和 gist** ⇒ `C 关 + S` **必然**为假，
与 D 是否必要无关。**这是第 4 条指标陷阱（无效对照比没有对照更危险）的同一形状，只是上了一层。**

**有效对照**（gist 开、预算故意绑死）：`converge_gist_max_chars = 60`，21 轮 ⇒ 17 轮沉底，
第 21 轮追问，人不做任何事 ⇒ **prompt 仍含事实、reply = `旺财`**。

**原因**：gist 按**最旧优先**填充 ⇒ 最早的内容**最后**才被裁（本实现如此，且刻意如此）。

⇒ **D 对当前判据的增量 = 0，且是构造性的。** 建议**不做 D**；若日后要保留它，
必须先给出一个**能判别**的判据（例如 `gist_max_chars` 小于首轮 gist 本身）。

## 九、驳回的落点（2026-10-09）—— 一次**具名用户动作**，不是模型判断

**为什么不自动**：AGM（1985）说得明白 —— 冲突时该放弃哪一条，**逻辑本身决定不了，需要外部标准**；
而所有让模型自任裁判的方法（ToT / LATS / MemGPT）都假定**强模型**，**我们是 3B**。
模型自判会**通过简单测试、在真实使用里才崩** —— 那是装饰性绿灯。

**动作（协议无关，走既有 `!` 分诊，不新增面）**：
- `!reject <period_id> [理由]` → 写 `<id>.rejected`（一行理由；**空理由写具名默认**，因为
  "没有理由"与"没记"必须是两种可分辨的读数）
- `!settle <id>` → 显式写 `converged`（§6.2.2 声明"不在本版范围"的那个入口，至此有了）

**驳回的唯一效果**：退出**注入视图**（不进 gist、不占最近 N 行）。**字节不动**，
`!lodes` 仍**列出**它并带理由与 `!body` 路径，`!body` 仍可取回 —— 隐性化 ≠ 删除。

**端到端实测（四点全过）**：P1(A 主线) → P2(B 支线，驳回) → P3 → P4
- `!reject P2 方向不对，另开一支` ⇒ 回答写明"字节未动 / 不再注入 / 仍可取回"
- `!lodes P3` ⇒ `[1 rejected branch(es) — kept, not injected]` + 理由 + `!body` 路径
- P4 的 prompt ⇒ 含 A 的事实（北极星）**True**；含 B 的行 id / 含 B 的事实（月亮井）**False**
- `!body P2` ⇒ 取回全文

**变异反证**：`skeleton` 去掉 `filter(|r| r.rejected.is_none())` ⇒ 被驳回的内容回到注入 ⇒ 红。

## 十、两个语义问题（人类要求明确）与中间洞的**未闭合**记录

### 10.1 驳回的作用域：**节点级，不含子孙**（现状，明说）

`!reject <id>` 只标记**这一个 period**。它的**子孙不随之被驳回**，仍按原样进入各自的注入。

**为什么现在是这样**：最小实现 + 可测。**但这是不是对的，我没定。**
- 「**另开分支**」的字面意思是**一段**（B 及其后续），那对应**子树级**驳回；
- 而子树级一旦做错方向，会把"读者也看不见后代"和"驳回"混起来 —— 正是 §9 要防的。

⇒ **记为待裁决**：`reject` 是 **branch（子树）** 还是 **node（节点）**。
若定为子树级，实现是 `skeleton` 的过滤改成"祖先里有被驳回者即排除"，**很小但要重测**。

### 10.2 驳回时间：**不记录**（现状，明说）

`<id>.rejected` 只存**一行理由**，**没有时间戳**。

**为什么不记**：与 `.name` / `.state` / `.gist` 同构 —— 这四个侧车都刻意**不含时钟**，
因为写盘时的时钟会让回放不可字节比对（ADR-0003）。
**代价**：可审查四问里的「**为什么**」有答案，「**什么时候**」没有。

⇒ **记为待裁决**：若要时间，唯一的干净落点是**调用方注入的时钟**（`self.clock.now()`），
而不是 `SystemTime::now()`；那会让该侧车不再参与字节级回放（可接受，但必须写明）。

### 10.3 中间洞：**已测，未闭合**（不得记为已补）

人类更正：**驳回 ≠ 中间洞**。证据目录此前**没有中间轮的测量** —— 现已补
（`helix-mind/docs/helixECO/middle-hole-2026-10-09.json`）：

21 轮、`gist_max_chars = 120`（**故意绑死**）、第 1 轮埋「红色灯塔」、第 10 轮埋「蓝色风车」、第 21 轮问第 10 轮那条：

| 项 | 实测 |
|---|---|
| gist 标题 | `gist of 17 earlier round(s) — bounded; originals intact` |
| 最近 N 行 | 3 条，**中间轮不在其中** |
| prompt 含**最旧**事实 | **True**（gist **最旧优先** ⇒ 保护最旧） |
| prompt 含**中间**事实 | **False** ← **洞** |
| 具名余量标记 | **True**（读者知道缺东西） |
| reply | `红色灯塔`（答了最旧的，不是问的中间那条） |
| `!body <中间轮>` | ✅ 出口仍在 |

⇒ **洞的性质**：中间轮**既不在最近 N 行、也不在 gist 前缀**；省略**具名**；取回**需要人或模型主动发起下钻**。
**未闭合**：要闭合它就得让 gist 覆盖中间（那会重新线性增长），或让模型自己发起下钻
（3B 上不可靠 ⇒ **装饰性绿灯**）。**两条都未做。**
