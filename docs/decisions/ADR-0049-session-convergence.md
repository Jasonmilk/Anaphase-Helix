# ADR-0049：会话收敛 —— 状态 + 骨架 + 按需下钻（`lodestone-spec:ADR-0002` D5/D6 的会话实现）

- **状态**：**Accepted（2026-10-09）**
- **日期**：2026-10-09
- **决策范围**：anaphase-helix（`session_events` 的读取语义 + `run_cycle` 的上下文注入）
- **关联**：**`lodestone-spec:ADR-0002` D5/D6（协议本体，本文不重开）**、`ADR-0047`（period / lineage_path / slice）、`ADR-0048`（join 键）、`ADR-0023`（按需加载）、`ADR-0026`（会话事件流）
- **引用约定**：不带仓名的 `ADR-XXXX` 指 `anaphase:ADR-XXXX`；`lodestone-spec:ADR-0002` 是协议方。

---

## 一、背景：现在的行为是**截断**，不是收敛

实测（`helix-mind/docs/helixECO/convergence-A-baseline-2026-10-09.json`）：
21 轮链，第 1 轮埋独有事实 `ZEPHYR-7421`，第 21 轮追问。

| 判据 | 实测 | 判定 |
|---|---|---|
| ① 注入**不随链长线性增长** | 第 2 轮 **288** 字符 → 第 21 轮 **288** 字符 | ✅ **真空成立** |
| ② 早期独有事实**可被取回** | 第 21 轮 prompt **不含** `ZEPHYR-7421`；**下钻路径不存在** | ❌ |
| ③ 血缘边**完整** | 路径长度 **21**（r21 → r1） | ✅ |

根因是一行：续接注入 = `read_summary(dir, id, 400)` —— 只取**被续接那一轮**的
「human said + helix answered」，各 400 字。⇒ ① 之所以成立，**代价是链上其余 19 轮全部不可见**。

**这正是"截断"与"收敛"的分界**：截断让信息**变少**且**无处可取**；收敛让信息**变隐**且**仍可取**。

---

## 二、决策

> **协议不重新发明**：状态机、骨架、沉淀区、下钻指令四条全在 `lodestone-spec:ADR-0002` D5/D6。
> 本文只做**映射**：文档 → 会话链，磁石（lode）→ period。

### D1 每轮 = 一个磁石（lode）

`period` 即 `lode`；链 = 血缘路径（`ADR-0047` 的 `lineage_path`）。**不引入第二套身份**。

### D2 状态：`draft` | `converged`（**先两态**）

- 存储：`<period_id>.state` 侧车，与既有 `.name` 侧车**同构**（一文件一词，append-only 友好）。
- **缺省 = 由龄期派生**，不是存储值：`age >= converge_hide_after_days` ⇒ `converged`，否则 `draft`。
  ⇒ **历史 period 一行不回写**，一律按默认派生。
- 与协议的 `draft → converged → aligned` 对齐：本 ADR 只实现前两态；
  `aligned` 留给 v2.x（**不预造**）。

### D3 骨架 = D6 的 L0（**纯函数**）

`lodes` 的会话形态：对血缘路径**逐轮一行** —— `<period_id> [<status>] <summary 一行>`，
受 `converge_skeleton_max_lines` 与每行字符上限约束。
**纯函数**（输入 period 列表 + 状态，输出行），不做 IO、不看时间 —— 可单测、可变异。

### D4 下钻 = D6 的 L1/L2（**读数指令，复用既有结构分诊**）

- `!lodes` → L0 骨架（也就默认注入的那份）
- `!lode <slug>` → L1：单个磁石的子结构
- `!body <slug>` → L2：该轮**全文**（从事件流读，字节即当年落盘的字节）
- `!sediment` → 沉淀区索引

**实现走既有 `!` 前缀的结构化分诊**（`Perception` 识别 → 0 token → 不调 LLM）。
⇒ **不新增任何「面」**（无新端口 / 无新端点 / 无新协议）：下钻是**读数指令**，不是新入口。

### D5 沉淀区 = 已落盘的事件流本身（**隐性化 ≠ 删除**）

- 会话的全文**从未需要搬移**：一轮一个 `.events.jsonl` 文件，append-only。
  ⇒ D5 的"正文移入沉淀区、字节保留"**在本仓由构造满足**：沉淀 = 从**默认视图**退出，不是搬文件。
- 默认视图（注入）只给骨架；`!body <slug>` 是取回路径。
- **本 ADR 不引入任何删除操作**：`lodestone-spec` 的 `compress` 在这里只压**视图**，不压**字节**。

### D6 默认永不丢失，且**可关**

| 配置 | 默认 | 含义 |
|---|---|---|
| `converge_hide_after_days` | **7** | 超过则默认视图隐性 |
| `converge_compress_after_days` | **180** | 冷区留存阈值（本版只登记，不改字节） |
| `converge_skeleton_max_lines` | `24` | 骨架行上限（有界性的**旋钮**） |
| `converge_enabled` | `true` | **可关**：关掉 = 回到"只注入上一轮" |

全部进 `[anaphase]` 配置，**零硬编码**（DNA 铁律 11）。

### D7 可审查（§③ 四问）

必须能回答：**第几轮 / 因为什么被隐性 / 现在在哪 / 怎么取回**。
⇒ `!lode <slug>` 的回答里**必须**带：`status`、`derived_from`（如果派生）、
`retrievable_via`（取回指令）。**说不出这四句的不算收敛。**

## 三、验收判据（与实验 A 同一套，可证伪）

> 同一段 **20 轮**的链，第 21 轮继续时：
> 1. 注入 token **不随链长线性增长**（骨架有界）
> 2. 第 1 轮的独有事实**仍可被取回** —— 经下钻指令，不靠召回
> 3. 该事实的**血缘边仍完整**

**反证**：把注入退回 `read_summary(…, 400)` ⇒ 第 21 轮的取回路径消失、事实不可得 ⇒ 判据 ② 红。

## 四、影响与边界

- **不碰**：F1（UI 重建仍冻结）、`ADR-0048`（B18 已结案）、C1 的 `model` 腿（仍登记未动）、面板（排在收敛之后）。
- **不引入**：新端口 / 新端点 / 新协议 / 新 crate / 任何删除路径。
- **已知代价**：默认视图从"上一轮全文"变成"骨架一行"，**单轮细节变粗** —— 这是 D5 的
  设计意图（骨架不膨胀），取回路径由 D4 提供。
