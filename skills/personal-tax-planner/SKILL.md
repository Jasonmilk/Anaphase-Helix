# 个人所得税计算与税务规划

## 任务目标

- 本 Skill 用于：中国个人所得税精确计算、多方案税负对比、合规节税建议及风险提示
- 能力包含：综合所得与分类所得计算、年终奖计税方案优化、股权激励税务处理、专项附加扣除规划
- 触发条件：用户询问"我的税怎么算"、"如何少交税"、"年终奖怎么发"、"期权行权税多少"、"税务规划建议"等问题

## 前置准备

- 依赖说明：scripts脚本所需的依赖包及版本
  ```
  无
  ```
- 非标准文件/文件夹准备：无

## 操作步骤

### 步骤 1：收集收入与扣除信息

从用户处收集以下信息，若缺失需主动询问：

**收入信息（至少包含一项）：**

- 工资薪金年收入总额（含奖金、津贴）
- 劳务报酬收入明细（如有）
- 稿酬收入明细（如有）
- 特许权使用费收入明细（如有）
- 年终奖金额（如有）
- 股权激励详情（如有）：类型（期权/限制性股票/股票增值权）、授予价格、行权价格、行权数量、行权日期

**专项扣除（社保公积金）：**

- 社保公积金个人缴费比例（各地不同，参见references/social_insurance.md）
- 月缴费基数（可能受上下限约束）
- 或直接提供月缴费金额

**专项附加扣除信息：**

- 3岁以下婴幼儿照护：婴幼儿数量、扣除方式（父母各50%/父母一方100%）（2000元/月/人）
- 子女教育：子女人数、每个子女每月扣除金额（2000元/月/人）
- 继续教育：教育类型（学历/职业资格）；学历继续教育400元/月（最长48个月）；职业资格继续教育3600元/年（取得证书当年一次性扣除）
- 住房贷款利息：首套住房贷款、扣除月数（1000元/月，最长240个月）
- 住房租金：城市类型（800/1100/1500元/月）、扣除月数
- 赡养老人：赡养人数（独生子女/非独生子女）、扣除方式（独生子女3000元/月，非独生子女分摊3000元/月，每人不超过1500元/月）
- 大病医疗：本人/配偶/未成年子女、医保目录内自付部分（超过15000元部分据实扣除，上限80000元）

**其他扣除：**

- 基本减除费用：5000元/月（默认）
- 企业年金/职业年金个人缴费部分
- 符合规定的商业健康保险
- 个人养老金（12000元/年，当前试点城市）

### 步骤 2：调用计算脚本

根据收入类型选择相应脚本：

**场景 A：仅综合所得（工资+劳务+稿酬+特许权）**

- 调用 `scripts/tax_calculator.py --income-type=综合所得 --salary=<金额> --labor=<金额> --author=<金额> --royalty=<金额> --social-insurance=<社保公积金年合计> --special-deductions=<专项附加扣除总额> --other-deductions=<其他扣除>`

**场景 B：包含年终奖**

- 调用 `scripts/year_end_bonus.py --comprehensive-income=<综合所得应纳税所得额（不含年终奖）> --bonus=<年终奖金额>`
- 该脚本会同时输出年终奖单独计税和并入综合所得两种方案，自动推荐最优方案

**场景 C：股权激励**

- 调用 `scripts/equity_incentive.py --type=<期权/限制性股票> --grant-price=<授予价> --exercise-price=<行权价> --quantity=<数量> --market-price=<行权日市价> --other-income=<其他综合所得>`

**场景 D：复杂综合场景**

- 依次调用上述脚本，汇总所有项目的应纳税额
- 注意：专项附加扣除只能在综合所得中扣除一次，切勿重复计算

### 步骤 3：分析计算结果

智能体根据脚本输出进行分析：

**税负构成分析：**

- 明确各项收入的应纳税额占比
- 识别税负较重的收入类型
- 对比同收入水平下的平均税负率

**方案对比（如有年终奖）：**

- 若年终奖单独计税更优：说明单独计税的节税金额和原因
- 若并入综合所得更优：解释原因（如年终奖金额较低、综合所得处于税率边界）

**税负优化空间评估：**

- 基于当前收入结构，识别可调整的计税方式
- 评估专项附加扣除的配置是否充分利用

### 步骤 4：提供合规节税建议

智能体结合计算结果和税法知识，提供建议：

**收入结构调整建议：**

- 年终奖发放节奏优化：如"建议将X元年终奖单独计税，避免并入综合所得税负增加Y%"
- 股权激励行权时点选择：如"建议在次年3月前行权，避免与当年高收入叠加"
- 劳务报酬拆分：如"单笔劳务报酬超20万元时，考虑拆分为多次申报"

**专项附加扣除配置建议：**

- 充分利用可用的扣除项
- 扣除方式优化：如赡养老人兄弟姐妹间合理分摊、住房贷款利息与租金不可重复扣除等

**税收优惠政策利用：**

- 符合条件的税收优惠（如特定地区津贴、外籍人士免税政策等）
- 提醒用户关注政策变化

### 步骤 5：风险提示与合规提醒

智能体基于知识库进行风险提示：

**常见风险点：**

- 境外收入未申报风险
- 股权激励未按规定期限申报（取得后次月15日内）
- 劳务报酬预扣预缴与汇算清缴差异
- 多处任职时的专项附加扣除重复申报

**合规建议：**

- 强调"合理节税"与"逃税"的界限
- 提醒按时进行年度汇算清缴（次年3月1日至6月30日）
- 建议保留收入凭证和扣除证明材料
- 复杂情况建议咨询专业税务师

## 注意事项

**脚本调用原则：**

- 所有计算通过脚本执行，确保结果精确
- 脚本输出详细的计算过程，便于智能体理解税负构成
- 智能体不进行手工计算，仅负责分析结果和提供建议

**智能体处理范围：**

- 法规解读、政策解释
- 节税建议生成与优化
- 风险识别与合规提醒
- 复杂场景的逻辑判断

**边界限制：**

- 本Skill仅提供中国内地个人所得税相关服务
- 不涉及企业所得税、增值税等其他税种
- 不提供任何逃避税建议，所有方案基于现行有效法规
- 高净值复杂税务规划建议咨询专业税务师

**信息完整性：**

- 计算前必须收集完整收入和扣除信息
- 信息缺失时主动询问用户
- 用户提供的数据需符合格式要求（参照assets中的模板）

## 使用示例

**示例 1：年终奖方案优化**

- 功能说明：对比年终奖单独计税和并入综合所得的税负差异
- 执行方式：调用 year_end_bonus.py 脚本
- 关键参数：综合所得应纳税所得额、年终奖金额
- 示例：用户年收入30万元，年终奖8万元，脚本输出两种方案税负并推荐最优

**示例 2：股权激励税务筹划**

- 功能说明：计算股票期权行权的应纳税额并提供行权时点建议
- 执行方式：调用 equity_incentive.py 脚本
- 关键参数：期权类型、授予价、行权价、数量、市价
- 示例：用户持有10万份期权，授予价5元，当前市价30元，脚本计算行权税负并分析

**示例 3：综合所得税负优化**

- 功能说明：全面计算综合所得各项收入税负，分析优化空间
- 执行方式：调用 tax_calculator.py 脚本
- 关键参数：工资、劳务、稿酬、特许权使用费、专项附加扣除
- 示例：用户工资40万、劳务20万、有2个子女和1位老人需赡养，脚本计算应纳税额并提供扣除配置建议
