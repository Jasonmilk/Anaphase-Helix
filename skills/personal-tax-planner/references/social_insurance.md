# 社保公积金缴费参考（专项扣除）

## 概述
社保公积金个人缴费部分属于"专项扣除"（注意：不同于"专项附加扣除"），可从综合所得中扣除。

## 个人缴费比例（全国通用项目）

| 险种 | 个人缴费比例 | 说明 |
|------|------------|------|
| 养老保险 | 8% | 全国统一 |
| 医疗保险 | 2% | 各地略有差异 |
| 失业保险 | 0.5%（多数地区） | 部分地区为0.3%-1% |
| 工伤保险 | 0%（个人不缴） | 单位承担 |
| 生育保险 | 0%（个人不缴） | 已并入医疗保险 |
| 住房公积金 | 5%-12% | 各地不同，单位自主确定 |

**个人社保合计（不含公积金）**：约10.5%（养老8% + 医疗2% + 失业0.5%）

## 主要城市缴费基数上下限（2025年度）

| 城市 | 缴费基数下限 | 缴费基数上限 | 个人社保比例 | 公积金比例范围 | 数据来源 |
|------|------------|------------|------------|-------------|---------|
| 上海 | 7,460元/月 | 37,302元/月 | 10.5% | 5%-7% | 沪人社规〔2025〕 |
| 北京 | 7,162元/月 | 35,811元/月 | 10.5%+3元 | 5%-12% | 京人社发〔2025〕11号 |

> 注意：缴费基数上下限每年7月调整（以上一年度社平工资为基准）。
> 个人月薪超过上限的，按上限作为缴费基数；低于下限的，按下限缴费。

## 计算示例

**上海，月薪30,000元，公积金7%**：
```
社保个人缴费 = 30,000 × 10.5% = 3,150元/月
公积金个人缴费 = 30,000 × 7% = 2,100元/月
合计 = 5,250元/月
年合计 = 5,250 × 12 = 63,000元/年（可作为专项扣除）
```

**上海，月薪50,000元（超上限），公积金7%**：
```
社保缴费基数按上限 37,302元
社保个人缴费 = 37,302 × 10.5% = 3,916.71元/月
公积金缴费基数也按上限 37,302元
公积金个人缴费 = 37,302 × 7% = 2,611.14元/月
合计 = 6,527.85元/月
年合计 = 78,334.20元/年
```

## 使用注意
1. 当用户提供月薪时，需确认是否超过当地缴费基数上限
2. 公积金比例因单位而异，需向用户确认具体比例
3. 社保公积金属于"专项扣除"，在计算应纳税所得额时与"专项附加扣除"并列扣除
4. 计算公式：应纳税所得额 = 收入额 - 基本减除(60000) - **专项扣除(社保公积金)** - 专项附加扣除 - 其他扣除

## 政策依据
- 《个人所得税法》第六条："专项扣除，包括居民个人按照国家规定的范围和标准缴纳的基本养老保险、基本医疗保险、失业保险等社会保险费和住房公积金等"
- 上海社保基数：上海市人力资源和社会保障局公告（rsj.sh.gov.cn）
- 北京社保基数：京人社发〔2025〕11号
