## 个人所得税法核心条款

### 纳税义务人

- **居民个人**：在中国境内有住所，或者无住所而在一个纳税年度内在中国境内居住满一年的个人
  - 承担无限纳税义务：就其全球所得在中国纳税
- **非居民个人**：在中国境内无住所且不居住，或者无住所而在一个纳税年度内在中国境内居住不满一年的个人
  - 承担有限纳税义务：仅就来源于中国境内的所得纳税

### 征税范围

1. **综合所得**：工资薪金、劳务报酬、稿酬、特许权使用费
2. **经营所得**：个体工商户生产经营所得、承包承租经营所得
3. **分类所得**：利息股息红利、财产租赁、财产转让、偶然所得

### 税率适用

- 综合所得：3%-45%七级超额累进税率
- 经营所得：5%-35%五级超额累进税率
- 分类所得：20%比例税率

### 减除费用

- 基本减除费用：60,000元/年（5,000元/月）
- 专项附加扣除：子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人
- 其他扣除：企业年金、职业年金、商业健康保险、个人养老金

### 政策依据

- 《中华人民共和国个人所得税法》第二条、第三条、第六条

## 综合所得计税规则

### 预扣预缴制度

工资薪金按月累计预扣预缴，劳务报酬、稿酬、特许权使用费按次或按月预扣预缴。

### 劳务报酬预扣预缴

```
劳务报酬收入不超过4000元：
应预扣预缴税额 = (收入 - 800) × 预扣率 - 速算扣除数

劳务报酬收入超过4000元：
应预扣预缴税额 = 收入 × (1 - 20%) × 预扣率 - 速算扣除数

预扣预缴税率：20%、30%、40%
```

预扣预缴适用的预扣率与速算扣除数（以扣除费用后的“应纳税所得额”为计税基础）：

| 扣除费用后的应纳税所得额（元） | 预扣率 | 速算扣除数（元） |
| ------------------------------ | ------ | ---------------- |
| 不超过 20,000                  | 20%    | 0                |
| 超过 20,000 至 50,000          | 30%    | 2,000            |
| 超过 50,000                    | 40%    | 7,000            |

### 稿酬预扣预缴

```
稿酬收入不超过4000元：
应预扣预缴税额 = (收入 - 800) × 70% × 20%

稿酬收入超过4000元：
应预扣预缴税额 = 收入 × (1 - 20%) × 70% × 20%
```

### 年度汇算清缴

居民个人应在次年3月1日至6月30日内进行汇算清缴：

```
应补或应退税额 = 全年综合所得应纳税额 - 已预缴税额
```

### 政策依据

- 《中华人民共和国个人所得税法实施条例》第二十四条、第二十六条
- 《国家税务总局关于发布〈个人所得税扣缴申报管理办法（试行）〉的公告》（2018年第61号）

## 股权激励税务处理

### 股票期权

**纳税义务发生时点**：员工根据股票期权计划选择购买股票（行权）时

**应纳税所得额**：

```
应纳税所得额 = (行权日市场价格 - 行权价格) × 行权数量
```

**计税方式**：

- 居民个人取得股票期权等股权激励，在2027年12月31日前，可选择**不并入当年综合所得**，全额单独适用综合所得税率表计算纳税
- 一个纳税年度内取得两次以上股权激励的，应合并按上述规定计算纳税
- 依据：财税〔2018〕164号第二条

### 限制性股票

**纳税义务发生时点**：员工取得限制性股票时（解禁日）

**应纳税所得额**：

```
完整公式（财税〔2009〕5号）：
应纳税所得额 = (股票登记日市价 + 本批次解禁日市价) ÷ 2 × 本批次解禁数量
             - 被激励对象实际支付的资金总额 × (本批次解禁数量 ÷ 获取的限制性股票总数)

简化版本（常用）：
应纳税所得额 = (解禁日每股市价 - 每股实际取得成本) × 解禁数量
```

**计税方式**：

- 同股票期权，在2027年12月31日前可选择不并入综合所得，单独适用综合所得税率表

### 股票增值权

**纳税义务发生时点**：公司向员工兑现股票增值权时

**应纳税所得额**：

```
应纳税所得额 = (行权日价格 - 授予日价格) × 行权数量
```

**计税方式**：

- 同股票期权，在2027年12月31日前可选择不并入综合所得，单独适用综合所得税率表

### 申报期限

- 取得股权激励所得的次月15日内向税务机关申报纳税
- 纳税人一个纳税年度内取得两次以上股权激励所得，合并计算纳税

### 政策依据

- 《国家税务总局关于个人股票期权所得征收个人所得税问题的通知》（国税发〔2005〕35号）
- 《国家税务总局关于股权激励有关个人所得税问题的通知》（财税〔2016〕101号）
- 《财政部 税务总局关于完善股权激励和技术入股有关所得税政策的通知》（财税〔2016〕101号）

## 年终奖计税政策

### 单独计税政策（延续至2027年）

居民个人取得全年一次性奖金，符合《国家税务总局关于调整个人取得全年一次性奖金等计算征收个人所得税方法问题的通知》（国税发〔2005〕9号）规定的，在2027年12月31日前，可以选择不并入当年综合所得，单独计算纳税。

### 单独计税方法

```
1. 将年终奖金额除以12，根据其数额确定适用税率和速算扣除数
2. 应纳税额 = 年终奖金额 × 税率 - 速算扣除数
```

### 并入综合所得计税

居民个人也可以选择将全年一次性奖金并入当年综合所得计算纳税。

### 选择建议

- 一般情况下，单独计税税负更低
- 综合所得较低或年终奖较小时，并入综合所得可能更优
- 建议通过计算对比选择最优方案

### 政策依据

- 《财政部 税务总局关于个人所得税法修改后有关优惠政策衔接问题的通知》（财税〔2018〕164号）
- 《财政部 税务总局关于延续实施全年一次性奖金个人所得税政策的公告》（财政部 税务总局公告2023年第30号）

## 境外所得申报

### 境外所得范围

- 中国境外取得的工资薪金、劳务报酬、稿酬、特许权使用费
- 中国境外取得的股息、红利、利息、租金、财产转让、偶然所得

### 抵免方法

采用"限额抵免法"：

```
可抵免限额（某国/地区、某类境外所得） = 按中国个人所得税法计算的该国/地区该类境外所得应纳税额
实际抵免额 = min(境外已缴且可抵免的税额，可抵免限额)

综合所得常用口径（用于将境外综合所得分摊到当年综合所得税额中）：
可抵免限额（综合所得） = 境内外综合所得应纳税额 × 该国/地区境外综合所得收入额 ÷ 境内外综合所得收入额合计
```

### 申报要求

- 居民个人从中国境外取得的所得，应在中国申报纳税
- 境外所得一般在办理年度汇算清缴时申报，并按规定申请境外税额抵免
- 若属于需要自行申报预缴的情形（例如无扣缴义务人等），按税法规定在取得所得的次月15日内办理预缴申报（以主管税务机关要求为准）

### 政策依据

- 《中华人民共和国个人所得税法》第七条
- 《中华人民共和国个人所得税法》第十条
- 《财政部 税务总局关于境外所得有关个人所得税政策的公告》（财政部 税务总局公告2020年第3号）

## 税务合规要求

### 申报期限

- **工资薪金所得**：支付单位代扣代缴，个人无需自行申报
- **劳务报酬等综合所得**：支付单位代扣代缴，次年汇算清缴
- **股权激励所得**：取得后次月15日内申报纳税
- **境外所得**：一般在年度汇算清缴时申报；若需自行预缴，按规定在次月15日内办理预缴申报
- **年度汇算清缴**：次年3月1日至6月30日

### 申报义务

1. **扣缴义务人**：支付所得的单位和个人为扣缴义务人
2. **自行申报**：特定情形需自行申报（如多处取得综合所得、境外所得等）

### 信息报送要求

- 扣缴义务人应按规定向税务机关报送专项附加扣除信息
- 纳税人应保留相关凭证备查

### 违法责任

- 未按规定申报纳税的，税务机关责令限期改正，并处以罚款
- 情节严重的，依法追究刑事责任

### 合规建议

- 按时申报纳税，避免逾期申报
- 保留收入凭证、扣除凭证等资料备查
- 复杂情况建议咨询专业税务师
- 关注政策变化，及时调整申报策略
