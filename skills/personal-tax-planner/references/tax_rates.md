## 综合所得适用税率表

综合所得包括：工资薪金、劳务报酬、稿酬、特许权使用费

| 级数 | 全年应纳税所得额               | 税率 | 速算扣除数 |
| ---- | ------------------------------ | ---- | ---------- |
| 1    | 不超过36,000元                 | 3%   | 0          |
| 2    | 超过36,000元至144,000元的部分  | 10%  | 2,520      |
| 3    | 超过144,000元至300,000元的部分 | 20%  | 16,920     |
| 4    | 超过300,000元至420,000元的部分 | 25%  | 31,920     |
| 5    | 超过420,000元至660,000元的部分 | 30%  | 52,920     |
| 6    | 超过660,000元至960,000元的部分 | 35%  | 85,920     |
| 7    | 超过960,000元的部分            | 45%  | 181,920    |

**计算公式：**

```
应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数
应纳税所得额 = 收入额 - 减除费用 - 专项扣除 - 专项附加扣除 - 其他扣除
```

**费用扣除标准：**

- 基本减除费用：60,000元/年（5,000元/月）
- 工资薪金：无需额外扣除
- 劳务报酬：收入额的20%
- 稿酬：收入额的80%，再减征30%（即收入额 × 80% × 70%）
- 特许权使用费：收入额的20%

## 分类所得适用税率表

分类所得适用20%的比例税率

| 收入类型             | 税率 | 费用扣除            |
| -------------------- | ---- | ------------------- |
| 利息、股息、红利所得 | 20%  | 无                  |
| 财产租赁所得         | 20%  | 收入额的20%         |
| 财产转让所得         | 20%  | 财产原值 + 合理费用 |
| 偶然所得             | 20%  | 无                  |

**计算公式：**

```
应纳税额 = 应纳税所得额 × 20%
```

**特殊规定：**

- 财产租赁所得：每次收入不超过4,000元的，减除费用800元；超过4,000元的，减除20%费用
- 财产转让所得：应纳税所得额 = 转让收入 - 财产原值 - 合理费用

## 税率应用说明

### 综合所得税率应用

**1. 累进税率计算**
综合所得采用7级超额累进税率，随着应纳税所得额增加，税率逐步提高。

**示例：**
假设某纳税人全年应纳税所得额为200,000元

```
计算过程：
- 第1级（36,000元 × 3%） = 1,080元
- 第2级（144,000 - 36,000 = 108,000元 × 10%） = 10,800元
- 第3级（200,000 - 144,000 = 56,000元 × 20%） = 11,200元
- 应纳税额 = 1,080 + 10,800 + 11,200 = 23,080元

使用速算扣除数：
应纳税额 = 200,000 × 20% - 16,920 = 23,080元
```

**2. 各项收入调整**

```python
# 劳务报酬
应纳税所得额 = 劳务报酬 × (1 - 20%)

# 稿酬
应纳税所得额 = 稿酬 × (1 - 20%) × (1 - 30%) = 稿酬 × 0.56

# 特许权使用费
应纳税所得额 = 特许权使用费 × (1 - 20%)
```

### 年终奖单独计税税率应用

年终奖单独计税时，先将年终奖除以12，根据其月均值查【按月换算后的综合所得税率表】确定适用税率和速算扣除数。

**按月换算后的综合所得税率表（年终奖单独计税专用）：**

| 级数 | 月均值（年终奖÷12）   | 税率 | 速算扣除数 |
| ---- | ---------------------- | ---- | ---------- |
| 1    | 不超过3,000元          | 3%   | 0          |
| 2    | 超过3,000元至12,000元  | 10%  | 210        |
| 3    | 超过12,000元至25,000元 | 20%  | 1,410      |
| 4    | 超过25,000元至35,000元 | 25%  | 2,660      |
| 5    | 超过35,000元至55,000元 | 30%  | 4,410      |
| 6    | 超过55,000元至80,000元 | 35%  | 7,160      |
| 7    | 超过80,000元           | 45%  | 15,160     |

> 注意：此表的级距为年度税率表级距÷12，速算扣除数也是月度对应值（非年度值）。
> 依据：财税〔2018〕164号"按照按月换算后的综合所得税率表确定适用税率和速算扣除数"

**计算公式：**

```
1. 月均值 = 年终奖金额 ÷ 12
2. 根据月均值查上表确定税率和速算扣除数
3. 应纳税额 = 年终奖金额 × 税率 - 速算扣除数
```

**示例：**
年终奖100,000元

```
100,000 ÷ 12 = 8,333元
根据月度税率表，8,333元适用第2级（10%税率，速算扣除数210）

应纳税额 = 100,000 × 10% - 210 = 9,790元
```

### 股权激励税率应用

股权激励（股票期权、限制性股票、股票增值权）按"工资薪金所得"计税，适用综合所得的累进税率。

**计算公式：**

```
应纳税所得额 = (行权日市价 - 行权价) × 行权数量
应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数
```

税率根据股权激励所得与当月工资薪金合并后的应纳税所得额确定。

## 注意事项

1. **税率级数更新**：本税率表适用于2024年，如政策调整请以最新规定为准
2. **专项附加扣除**：在计算应纳税所得额时，可按规定扣除子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人等支出
3. **汇算清缴**：年度终了后，纳税人应在次年3月1日至6月30日内进行汇算清缴，多退少补
4. **年终奖政策**：年终奖单独计税政策已延长至2027年12月31日
