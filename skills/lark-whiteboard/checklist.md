# 出图检查清单

## 渲染前 — DSL 结构自查

生成 DSL 后、渲染前，用以下问题自查。

---

## 读者能看出分组吗？

- [ ] **图中是否用颜色区分了分组？** 如果用户指定了配色，检查是否使用了用户的颜色；如果未指定，检查是否使用了默认马卡龙色板
- [ ] 同一组的节点视觉完全一致（fillColor、borderColor、borderWidth、borderRadius、fontSize 全部相同）
- [ ] 不同组用了不同的颜色，读者能一眼区分
- [ ] 颜色种类不超过 3-4 种，不会眼花缭乱
- [ ] 连线用中性色（灰色或黑色），不和节点颜色抢注意力

## 读者能看出层级吗？

- [ ] 外层（大分区）比内层（具体内容）视觉更重——外层有浅色背景，内层是白色
- [ ] 嵌套越深越轻，没有出现"内外都用重色"的情况

## 每个元素都看得清吗？

- [ ] 每个节点和背景能清楚区分（有边框、或有填充色、或两者兼有）
- [ ] 相邻元素之间有间距，没有粘连或重叠
- [ ] 文字在背景上清晰可读（深色底用白字，浅色底用深色字）
- [ ] 有连线的节点之间间距足够（gap >= 40），箭头不挤在缝里

## 结构正确吗？

- [ ] frame 都写了 `layout` 属性（不写会导致子节点堆在左上角）
- [ ] 没有 `父 fit-content + 子 fill-container` 的死锁
- [ ] 含文字的节点高度用 `fit-content`（不要写死高度，会截断文字）
- [ ] connector 放在顶层 `nodes` 数组，没有嵌套在 frame 的 `children` 里
- [ ] gap 和 padding 都显式设置了（不设会 Schema 校验失败）

---

## 常见错误速查

| 错误 | 正确做法 | 后果 |
|------|---------|------|
| connector 放进 frame children | 放在顶层 nodes 数组 | Schema 校验失败 |
| 父 `fit-content` + 子 `fill-container` | 最外层指定固定 width | 尺寸退化为 0 |
| 含文字节点写死 height | 用 `height: 'fit-content'` | 文字被截断 |
| frame 忘写 layout 属性 | 必须写 horizontal/vertical/none | 子节点堆在左上角 |
| 同组节点样式不一致 | 所有视觉属性完全相同 | 读者分不清谁和谁是一组 |
| 节点和背景无法区分 | 确保有边框或填充色让节点可辨认 | 节点和背景融为一体 |
| 连线用彩色 | 用灰色 #BBBFC4 或黑色 | 和节点颜色抢注意力 |
| 有连线的节点 gap 太小 | gap >= 40 | 箭头挤成一团 |

---

## 渲染后 — 视觉审查

渲染完成后，**必须查看 PNG 结果**再交付。发现问题时修改 DSL 并重新渲染，最多 2 轮。

### 症状→修复

| 看到的问题 | 改什么 |
|-----------|--------|
| 文字被截断、只显示一半 | height 改为 `'fit-content'` |
| 文字溢出容器右侧 | 增大 width，或缩短文字内容 |
| 节点之间重叠、粘连 | 增大 gap；绝对定位场景调整 x/y 坐标 |
| 连线穿过中间的节点 | 调整 fromAnchor/toAnchor 方向，或增大节点间距 |
| 大面积空白、图很小 | 缩小外层 frame 的固定 width |
| 节点挤成一团 | 增大 padding 和 gap |
| 文字和背景色太接近看不清 | 调整 fillColor 或 textColor，拉开对比度 |
| 布局整体偏左/偏右 | 调整绝对定位的 x 坐标使内容居中 |
