# 公众号图文交付包 Skill（通用终极版）

## 一句话说明
输入行业/受众/主题/目标，得到可直接发布的公众号图文交付包（选题+标题+正文+配图+HTML+自检报告），严格采用固定排版协议。

## 适合谁
- 需要稳定输出内容的公众号运营者
- 多账号矩阵运营团队
- 行业自媒体（任何行业）
- 需要快速产出文章的品牌方

## 产品定位
本Skill不是"写手"，是**公众号图文交付包流水线**：输入行业/受众/主题/目标 → 输出可发布交付包（选题/标题包/正文/配图/HTML/自检报告）。

**重要提醒**：
- 发布前仍需人工最终审核（事实、合规、品牌口吻）
- 禁止绝对化夸大承诺（如"100%准确""自动判断事实真伪""版权完全合规"等）
- 事实/版权只能写"缺失检查/风险提示"

## 你会得到什么（交付物清单）

使用本Skill后，你会收到以下交付包：

### 1. 选题与定位
**A_新闻合集（News Digest）**：
- Top5主线/新闻导览 + 每条点击理由（面向普通人收益）

**B_深度原创（Deep Original）**：
- 主题拆解 + 大纲（段落目标清晰）

### 2. 标题包
- 主标题（1个）
- 备选标题（3个）
- 搜索友好标题（1个）
- 全部中文命名

### 3. 正文稿（固定模块骨架）
严格采用固定排版协议（0-9顺序固定），不得自创结构、不得删改模块顺序、不得减少模块：

**0. 封面图**
- 尺寸：固定1:1（1080×1080）
- 要求：摄影质感、无文字、无水印、禁止抽象渐变"壁纸风"
- **若需要公众号首图横版**：作为"可选附加图"，放在模块0后追加一张900×383，并在05_图片清单与替换说明.md中标记用途

**1. 刊头信息**
- 发布日期
- 期数
- 一句话定位

**2. Topics标签**
- 用inline-block实现，避免复杂flex

**3. Digest导览**
- A：Top5列表+一句话结论
- B：主题拆解大纲

**4. HERO主内容**
- A：今日头条 + 【主编视点】（左侧3px强调线）
- B：正文主干A-D（A-D结构强制，详见5.7）

**5. 扩展条目区**
- A：行业要闻固定4条（每条配图+caption）
- B：误区/坑点/关键观点4-6条

**6. 数据与榜单**
- 数据主视觉图1张
- 3-5条数据+趋势解读

**7. 工具与方法**
- ≥2个
- 必须上手建议+注意事项
- 配图偏界面/产品图

**8. Quote/总结**
- A：每日一言 + 你的解读
- B：一页纸行动清单（F）+ 结尾CTA（G，且只能一个主动作，详见5.7）
- 说明：F为"可复制执行清单"（5-12条动词开头）；G为"唯一CTA"（体验链接/评论关键词/私信关键词/预约咨询/关注系列中择一）。

**9. 参考来源**
- 可见正文禁止裸URL
- 真实URL用HTML注释保留
- A：每条新闻≥1来源；传闻标"报道/传闻"
- B：涉及数据/引用/功能/案例事实必须可追溯；否则标"示例假设/经验建议"
- **参考来源模块可见层必须使用如下格式**：
  ```
  1) [媒体名] 文章标题（domain.com）
  ```
  **真实URL必须写在紧随其后的HTML注释中**：
  ```html
  <!-- https://real.url/here -->
  ```

### 4. 公众号排版成品（HTML）
- 可直接粘贴到公众号后台
- 内联样式，移动端友好
- 必须通过HTML校验（标签闭合/无重复style/无破坏性引号/根容器不提前闭合）
- 仅内联style，禁止style标签/外部CSS/JS
- 禁止position:absolute，尽量避免复杂flex
- 标题区不得用<a>，禁止默认蓝链/下划线
- 可见正文禁止出现完整URL

### 5. 图片清单与替换说明（强制）
每张图包含：
- 用途
- caption
- 生成prompt
- 尺寸比例
- 当前URL

必须包含固定声明：
```
所有图片均可自行替换：保持相同比例尺寸，保留caption；
替换为你自有素材/无版权风险素材即可。
```

### 6. Gate自检报告（强制）
每项检查：
- 通过/不通过
- 定位到模块/段落/图片
- 修复建议

**注意**：事实与版权只做"缺失检查/风险提示"，不能写成"自动判断真伪/绝对合规"。

### 7. 参考来源
- A：每条新闻≥1来源；传闻标"报道/传闻"
- B：涉及数据/引用/功能/案例事实必须可追溯；否则标"示例假设/经验建议"

## 使用步骤（4步）

### 第1步：输入你的需求（支持两种模式）

**A_新闻合集（News Digest）**：
- 基础字段：industry（行业）、audience（受众）、topic（主题）、tone（风格，可选）、constraints（禁区）
- 目标体系：primary_goal、deliverable_type、success_metric、cta
- 模式专用：news_scope（可选）

**B_深度原创（Deep Original）**：
- 基础字段：industry（行业）、audience（受众）、topic（主题）、tone（风格，可选）、constraints（禁区）
- 目标体系：primary_goal、deliverable_type、success_metric、cta
- 模式专用：content_type（必选其一：方法论教程/案例复盘/观点分析/清单指南）

### 第2步：系统自动处理
系统会自动完成：
- 选题筛选（A模式抓取热点；B模式围绕topic生成结构与可复现示例，涉及事实/数据才检索并给来源）
- 标题生成（生成多个候选并筛选）
- 内容撰写（按固定排版协议0-9模块）
- 自动生成图片并写入HTML（默认模式）
- HTML排版（生成可直接发布的HTML，含语法校验与自动修复）
- Gate自检（6大维度，可执行、可复现）

### 第3步：人工审核并发布
- 检查Gate自检报告
- 人工审核：事实准确性、合规性、品牌口吻
- 检查图片URL是否可访问
- 复制HTML到公众号后台，点击发布

**重要提醒**：发布前必须进行人工最终审核，确保事实准确、合规无风险、符合品牌口吻。

## 输入说明

### 基础字段（必填）

**industry**：行业/领域（任意行业）
- 示例：科技、教育、电商、美食、金融、旅行等

**audience**：目标受众（人群特征+典型场景）
- 示例：职场人士（35-45岁，关注效率提升）

**topic**：一句话主题（建议：帮{audience}在{scene}实现{goal}）
- 示例：帮职场人士在日常工作中提升效率

**tone**：风格（可选，缺省为"专业"）
- 可选值（如填写请从中择一）：专业 / 朋友式 / 强干货 / 故事化 / 克制商务
- 若未指定，默认使用"专业"风格

**constraints**：禁区与偏好（可选）
- 示例：不涉及敏感话题，偏向实用性内容

### 目标体系（更通用且可控）

**primary_goal**（必选其一）：
1. 解决问题
2. 达成增长
3. 建立认知
4. 促成决策
5. 训练能力
6. 改变行为
7. 推进协作
8. 塑造品牌/IP

**deliverable_type**（必选1-2项）：
清单 / SOP步骤 / 模板话术 / 决策矩阵 / 复盘框架 / 训练计划 / 方案推荐 / 风险预案

**success_metric**（可选）：
时间缩短 / 成本降低 / 返工减少 / 产出提升 / 转化提升 / 学习效率 / 协作顺畅

**cta**（必填且只能一个主动作）：
体验链接 / 评论关键词领取 / 私信关键词 / 预约咨询 / 关注系列

### 模式专用字段

**A_新闻合集（News Digest）**：
- news_scope：新闻范围（可选）

**B_深度原创（Deep Original）**：
- content_type（必选其一）：
  - 方法论教程
  - 案例复盘
  - 观点分析
  - 清单指南

**B模式强制要求**：
- 必须产出deliverable_type对应的可复制产物（例如模板/清单/矩阵），不能只讲道理

### 5.5 HTML稳定性硬规则

  - 重复style/属性缺空格
  - 根容器提前闭合

## 图片生成（默认全自动；不可用则降级但不能缺）

- 并在HTML里用占位图URL
- 同时明确提示"图片URL可自行替换"

### 数量硬Gate

**A_新闻合集**：≥10张
- 封面图1张
- 头条图1张
- 要闻图4张
- 数据主视觉图1张
- 工具图≥2张
- 一言图1张

**B_深度原创**：≥6张
- 封面图1张
- 正文插图≥4张
- 总结/金句图1张

## Gate自检说明（7大维度，可执行、可复现）

系统会自动检查以下7大维度，确保内容符合发布标准：

### 1. A结构Gate
- 检查内容：0-9模块齐全；要闻=4条；图片数量达标（≥10张）
- 失败提示：模块不完整或图片数量不足（定位到具体模块）
- 修复建议：补充缺失模块或图片

### 2. B结构Gate
- 检查内容：A-G齐全；字数1500-3000；deliverable_type产物必须出现
- 失败提示：结构不完整或字数不达标或缺少deliverable_type产物（定位到具体位置）
- 修复建议：补充缺失部分或调整字数或添加deliverable_type产物

### 3. 来源Gate
- 检查内容：A每条新闻≥1来源；B涉及数据/引用必须可追溯
- 失败提示：新闻缺少来源或数据/引用不可追溯（定位到具体新闻或数据/引用）
- 修复建议：添加来源链接或数据/引用来源

### 4. 图片Gate
- 检查内容：URL可访问、无水印、caption齐全、含可替换声明
- 失败提示：图片URL失效或缺少caption或缺少可替换声明（定位到具体图片URL）
- 修复建议：更换图片URL或补充caption或添加可替换声明

### 5. HTMLGate
- 检查内容：校验通过、无裸URL、无不稳定布局、标签闭合
- 失败提示：HTML校验失败或存在裸URL或不稳定布局或标签未闭合（定位到具体位置）
- 修复建议：修复HTML问题或移除裸URL或调整布局或补充闭合标签

### 6. 风险提示Gate
- 检查内容：事实缺失检查、版权风险提示
- 注意：只做"缺失检查/风险提示"，不能写成"自动判断真伪/绝对合规"
- 失败提示：事实缺失或版权风险（定位到具体位置）
- 修复建议：补充事实来源或更换内容

### 7. 标题区蓝链Gate
- 检查内容：标题容器内是否出现<a>标签或默认蓝链
- 失败提示：标题区包含<a>标签或默认蓝链（定位到具体标题）
- 修复建议：移除标题区中的<a>标签，改为纯文本

**Gate报告要求**：
- 必须可执行、可复现
- 失败原因必须定位到模块/段落/图片URL
- 必须给出明确的修复建议
- 事实与版权只做"缺失检查/风险提示"，不能写成"自动判断真伪/绝对合规"

## 注意事项与边界

### 固定骨架结构
- 必须严格采用固定排版协议（0-9顺序固定）
- 不得自创结构、不得删改模块顺序、不得减少模块
- 违反即判定交付失败

### HTML排版硬规则
- 必须只用内联style，禁止style标签/外部CSS/JS
- 禁止position:absolute，尽量避免复杂flex
- 标签胶囊/导览用display:inline-block + margin
- 必须做HTML闭合校验与修复
- 所有<img>必须有alt，每张图必须有caption

### 图片规范
- 默认模式：自动生成图片并写入HTML（必须）
- A≥10张，B≥6张
- 图片生成后需要：上传到稳定可访问的托管，写入绝对URL
- 兼容模式：输出每张图的prompt + 规格 + 用途，用占位图URL
- 图片来源优先级：官方/权威报道配图 > 权威截图 > AI概念图
- 图片URL必须绝对路径、移动端可访问、加载速度可接受
- 封面图标准：禁止抽象渐变"壁纸风"，必须摄影质感
- 封面图固定1:1（1080×1080），摄影质感、无文字、无水印
- 若需要公众号首图横版：作为"可选附加图"，放在模块0后追加一张900×383，并在05_图片清单与替换说明.md中标记用途

### 内容质量硬规则
- 标题包必须输出：主标题1 + 备选3 + 搜索友好标题1（全部中文）
- A"行业要闻"每条必须包含：一句话结论 + 3点拆解 + 一句点评 + 来源
- 选题必须先合规过滤再热度排序，严格避开敏感类（时政/政务/涉政/国际冲突/社会案件等）
- 每条新闻至少1个可追溯来源；传闻显式标"报道/传闻"
- B必须产出deliverable_type对应的可复制产物，不能只讲道理

### 来源规范
- 每条新闻必须提供至少1条可追溯来源
- 传闻内容必须标注"报道"或"传闻"
- 来源链接按"参考来源"规范呈现，正文可见层禁止裸URL
- 真实URL用HTML注释保留

### 人工审核
- **必须**：最终发布前需人工审核
- 审核重点：
  - 事实准确性
  - 合规性（时政、政务、涉政等）
  - 品牌口吻
  - 版权合规性

### 适用边界
- 支持任何行业（行业无关，任何行业可用）
- 不支持时政、政务、涉政、国际冲突、军事、外交等敏感领域
- 不支持违法、违规、低俗内容

### 质量保证
- Gate自检通过率越高，发布风险越低
- 建议前14天只做新闻合集，确保合规率100%后再扩展
- 如有任何疑问，建议咨询专业编辑

### 禁止绝对化夸大承诺
- 禁止"100%准确""自动判断事实真伪""版权完全合规"等表述
- 事实/版权只能写"缺失检查/风险提示"
- 必须明确：发布前仍需人工最终审核

## 常见问题

**Q: 如何快速上手？**
A: 只需4步：
1. 输入行业/受众/主题/目标
2. 选择 A（新闻合集）或 B（深度原创）模式
3. 系统自动处理：选题/标题包/正文/配图（默认自动生成）/HTML排版/Gate自检
4. 人工最终审核并发布（事实、合规、品牌口吻、版权风险、图片可用性）

**Q: 支持哪些行业？**
A: 支持任何行业（行业无关，任何行业可用），但不支持时政、政务、涉政等敏感领域。

**Q: A模式和B模式有什么区别？**
A: A_新闻合集（News Digest）：适合每日推送行业热点；B_深度原创（Deep Original）：适合写特定主题的深度内容，必须产出deliverable_type对应的可复制产物。

**Q: 可以同时运营多个公众号吗？**
A: 可以。为每个公众号提供不同的行业和受众信息即可。

**Q: 固定排版协议可以自定义吗？**
A: 不可以。必须严格采用固定排版协议（0-9顺序固定），不得自创结构、不得删改模块顺序、不得减少模块。

**Q: Gate自检通过后可以直接发布吗？**
A: 不可以。Gate自检是辅助工具，最终发布前必须进行人工审核，确保事实准确、合规无风险、符合品牌口吻。

**Q: 图片是自动生成的吗？**
A: 是的。默认模式：自动生成图片并写入HTML（必须）。A≥10张，B≥6张。图片生成后上传到稳定托管，写入绝对URL。

**Q: 事实和版权可以自动判断真伪/绝对合规吗？**
A: 不可以。系统只做"缺失检查/风险提示"，不能写成"自动判断真伪/绝对合规"。最终事实和版权责任由使用者承担。

**Q: B模式必须产出deliverable_type对应的可复制产物吗？**
A: 是的。B模式必须产出deliverable_type对应的可复制产物（例如模板/清单/矩阵），不能只讲道理。

**Q: 为什么有些图片没有caption？**
A: 不应该出现这种情况。每张图必须有caption。如果Gate自检报告提示"缺少caption"，请补充。

**Q: HTML语法校验与自动修复是什么？**
A: 系统会自动检查HTML语法，包括：标签未闭合、style双引号破坏、重复style/属性缺空格等，并自动修复这些问题，确保HTML可以直接粘贴到公众号后台。

**Q: 交付物文件名可以自定义吗？**
A: 不建议。交付物文件名使用固定结构（中文命名）：01_选题与定位.md、02_标题包.md、03_正文稿.md、04_公众号排版成品.html、05_图片清单与替换说明.md、06_Gate自检报告.md、07_参考来源.md。

**Q: 固定排版协议的0-9模块可以删减吗？**
A: 不可以。必须严格采用固定排版协议（0-9顺序固定），不得自创结构、不得删改模块顺序、不得减少模块。违反即判定交付失败。

**Q: tone字段必须填写吗？**
A: tone是可选字段，缺省值为"专业"。如果未指定，系统将使用"专业"风格。

**Q: 封面图尺寸是1:1还是900×383？**
A: 封面图固定1:1（1080×1080）。900×383是公众号首图横版，仅在需要时作为"可选附加图"放在模块0后，并在05_图片清单与替换说明.md中标记用途。

**Q: B模式的"主编视点"放在哪个模块？**
A: B模式按照5.7的映射规则，模块4 HERO承载A-D，模块8 Quote/总结承载F+G。B模式不包含【主编视点】元素。

**Q: Gate自检包含哪些维度？**
A: Gate自检包含7大维度：A结构Gate、B结构Gate、来源Gate、图片Gate、HTMLGate、风险提示Gate、标题区蓝链Gate。

**Q: B模式会抓取热点吗？**
A: 不会。B模式不是抓热点，而是围绕topic生成结构与可复现示例，仅涉及事实/数据时才检索并给出来源。
