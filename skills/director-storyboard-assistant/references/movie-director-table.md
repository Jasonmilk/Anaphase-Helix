## 表格用途与定位

**表格名称**：电影导演表（不得修改）

**用途**：
- 根据小说或剧本中的时间、地点（场景）、人物、发生的故事，做强控制整合提示词
- 最终这些提示词＋人物三视图＋场景图一起，用作给Seedance2.0的提示词参考，生成高质量的电影级视频
- 精细化电影级分镜的强控制提示词表

**与其他表格的区别**：
- **电影提示词表**：15秒一组分镜，包含3-6个小分镜，整合多个镜头为一个15秒视频
- **电影导演表**：单个分镜1-15秒，每个分镜独立存在，精细化电影级分镜控制

## 表格结构与字段定义

**默认输出格式**：可编辑的Word文档（包含表格）

**三个全局控制部分**：
1. **全局环境光布光控制**：光源类型、主光源位置与角度、主光源色温、补光与光比、特殊光影或环境光影（确保同场景下光线角度一致性保持）
2. **全局色彩色调**：主体系色、饱和度、色温、高光/中间调/阴影/暗部的色彩控制（确保同场景下色温、色彩一致性保持）
3. **分镜逻辑**：匹配电影风格的精细化分镜，每个分镜1-15秒

**整体约束与质量控制**：
- 整体约束：画面稳定、色调一致、光影逻辑一致
- 质感层：4K超高清、电影级写实、细节丰富
- 负面提示：避免各种画面质量问题

## 全局控制部分

### 一，全局环境光布光控制

**作用**：确保同场景下光线角度一致性保持

**字段定义**：
1. **光源类型**：
   - 软硬：软光（柔和光）/硬光（锐利光）
   - 物理类型：自然光（日光、月光）、人工光（钨丝灯、荧光灯、LED灯）、混合光
   - 环境属性：室内光、室外光、夜景光、晨光、黄昏光、阴天光、晴天光

2. **主光源位置与角度**：
   - 位置：左上方/右上方/正上方/左侧/右侧/正前方/正后方/左下方/右下方
   - 角度：0-90度（垂直角度）、0-180度（水平角度）
   - 示例：左上方45度、正上方90度、右侧30度

3. **主光源色温**：
   - 开尔文数值：2000K-10000K
   - 常用色温：
     - 暖光：2700K-3200K（钨丝灯、日落）
     - 中性光：4000K-5000K（日光、荧光灯）
     - 冷光：5600K-6500K（正午日光、LED灯）
     - 极冷光：7000K-10000K（阴天、阴影）

4. **补光与光比**：
   - 补光位置：相对于主光源的补光位置
   - 光比：主光与补光的比例（如1:8、1:4、1:2）
   - 示例：右下方补光，光比1:8

5. **特殊光影或环境光影**：
   - 无：无特殊光影
   - 体积光：光线穿透空气或烟雾形成的光束效果
   - 炫光：镜头产生的光晕效果
   - 阴影：特殊形状或强度的阴影
   - 反光：物体表面的反光效果
   - 边缘光：勾勒轮廓的光线

**示例**：
```
主光源为天花板圆环的自然顶光，90度垂直照射、主光源色温5600K、光比1:8、补光来自右下方、无特殊光影
```

### 二，全局色彩色调

**作用**：确保同场景下色温、色彩一致性保持

**字段定义**：
1. **主体系色**：
   - 色彩：红色/橙色/黄色/绿色/蓝色/紫色/粉色/棕色/灰色/黑白
   - 色彩风格：单色调、双色调、三色调、多色调、自然色调

2. **饱和度**：
   - 范围：-100 到 +100
   - 负值：降低饱和度（如-20、-50）
   - 正值：提高饱和度（如+20、+50）
   - 0：保持原始饱和度

3. **色温**：
   - 开尔文数值：2000K-10000K
   - 与布光控制的色温保持一致

4. **高光/中间调/阴影/暗部的色彩控制**：
   - 高光（Highlights）：最亮部分的色彩控制，IRE范围90-100
   - 中间调（Midtones）：中等亮度的色彩控制，IRE范围50-90
   - 阴影（Shadows）：较暗部分的色彩控制，IRE范围5-50
   - 暗部（Blacks）：最暗部分的色彩控制，IRE范围0-5

**示例**：
```
单色调、饱和度-20、色温5800K、高光90到95 IRE、中间调50到70 IRE、阴影10到30 IRE、暗部0-5 IRE
```

### 三，分镜逻辑

**作用**：匹配电影风格的精细化分镜控制

**生成规则**：

**规则1：基本生成规则**
1. 必须根据电影剧本的剧情发展和指令中的导演和电影分镜节奏风格匹配
2. 如张艺谋导演的电影《英雄》的风格，大卫芬奇导演的电影《七宗罪》的风格，岩井俊二导演的电影《情书》风格等等
3. 小说或剧本字数很多的情况下，自动生成多个分镜的提示词
4. 单个分镜最短时间是1秒，单个分镜最长时间是15秒
5. 小说剧本转为分镜要发散性思维，可以主动根据参考电影的风格扩写，加入一些空镜（大环境空镜、街道空镜、室内空镜、人物特写空镜、物品空镜）等等
6. 分镜总数可以增加不能减少。比如正常思维这集剧本生成30个分镜的提示词，扩写后加到35个分镜提示词，留给导演后期剪辑的空间

**规则2：用户指定总时长时的分镜逻辑调整**（重要）
- **触发条件**：当指令中包含"总时长XXX秒"或类似表述时
- **分镜数量计算**：
  - 根据用户指定的总时长，结合导演风格计算合理的分镜数量
  - 计算公式：分镜数量 = 总时长 ÷ 平均分镜时长
  - 平均分镜时长根据导演风格和影片类型调整：
    - 悬疑惊悚风格（温子仁）：平均分镜时长3-5秒，节奏紧凑
    - 动作片风格：平均分镜时长2-4秒，节奏快速
    - 剧情片风格：平均分镜时长5-8秒，节奏舒缓
    - 武侠风格（张艺谋）：平均分镜时长4-6秒，节奏适中
    - 心理惊悚风格（大卫芬奇）：平均分镜时长6-10秒，节奏缓慢压抑
    - 青春爱情风格（岩井俊二）：平均分镜时长8-12秒，节奏抒情
- **分镜时长分配**：
  - 根据总时长和分镜数量，合理分配每个分镜的时长
  - 确保所有分镜时长相加等于用户指定的总时长
  - 关键情节分镜时长较长（如情感高潮、重要对话、动作高潮）
  - 过渡场景分镜时长较短（如环境空镜、场景转换）
- **分镜节奏优化**：
  - 根据总时长调整分镜节奏，确保影片节奏流畅
  - 关键情节增加分镜数量，强化情感表达
  - 过渡场景减少分镜数量，加快节奏推进
  - 保持分镜时长的变化节奏，避免单调重复
- **示例**：
  - 指令："把这个剧本转为总时长180秒的温子仁导演悬疑惊悚风格的电影导演表"
  - 计算：180秒 ÷ 4秒（悬疑惊悚风格平均时长）= 45个分镜
  - 调整：关键情节分镜5-8秒，过渡场景分镜2-3秒，确保总时长180秒

**规则3：用户指定分镜数量时的分镜逻辑调整**（重要）
- **触发条件**：当指令中包含"XXX个分镜"或类似表述时
- **分镜合并与分拆**：
  - **分镜合并**（当用户指定的分镜数量少于原风格触发的分镜数量时）：
    - 将相邻的短分镜合并为一个长分镜
    - 合并原则：相同场景、相同人物、连续剧情的分镜优先合并
    - 合并后时长 = 各分镜时长相加，最长不超过15秒
    - 合并后的分镜内容整合，保留关键信息
  - **分镜分拆**（当用户指定的分镜数量多于原风格触发的分镜数量时）：
    - 将长分镜分拆为多个短分镜
    - 分拆原则：根据剧情发展、动作变化、场景变化进行分拆
    - 分拆后每个分镜时长1-15秒
    - 分拆后的分镜内容细化，增加细节描述
- **分镜时长重新分配**：
  - 根据用户指定的分镜数量，重新分配每个分镜的时长
  - 确保所有分镜时长在1-15秒范围内
  - 关键情节分镜时长较长，过渡场景分镜时长较短
- **分镜节奏优化**：
  - 根据分镜数量调整分镜节奏，确保影片节奏流畅
  - 分镜数量增加时，节奏加快，细节更丰富
  - 分镜数量减少时，节奏舒缓，强调关键情节
- **示例**：
  - 指令："把这个剧本转为温子仁导演悬疑惊悚风格的35个分镜的电影导演表"
  - 调整：原风格触发40个分镜，需要合并为35个
  - 合并：将5个短分镜合并为3个长分镜（场景内对话、连续动作、环境展示）
  - 保留：关键情节分镜不合并，确保情感表达完整

**规则4：分镜时长与数量的平衡**
- **时长约束**：单个分镜时长必须在1-15秒范围内
- **数量约束**：分镜数量必须符合用户指定
- **总时长约束**：所有分镜时长相加必须等于用户指定的总时长（如果有指定）
- **优先级**：
  1. 单个分镜时长1-15秒（强制约束）
  2. 用户指定的分镜数量（高优先级）
  3. 用户指定的总时长（高优先级）
  4. 导演风格匹配（中优先级）
  5. 剧情完整性（中优先级）
- **冲突处理**：
  - 如果用户指定的分镜数量与总时长冲突（平均时长超出1-15秒范围），优先满足单个分镜时长约束
  - 如果无法同时满足数量和总时长，优先满足总时长约束，调整分镜数量

**规则5：导演风格与分镜节奏的匹配**
- **温子仁风格（悬疑惊悚）**：
  - 节奏特点：紧张、压抑、快速切换
  - 平均分镜时长：3-5秒
  - 关键手法：特写、仰拍、俯拍、快速剪辑、阴影运用
  - 分镜分布：特写40%、中景30%、全景20%、远景10%
- **张艺谋风格（武侠）**：
  - 节奏特点：流畅、优雅、动作连贯
  - 平均分镜时长：4-6秒
  - 关键手法：慢镜头、大场面、色彩对比、对称构图
  - 分镜分布：全景40%、中景30%、特写20%、远景10%
- **大卫芬奇风格（心理惊悚）**：
  - 节奏特点：缓慢、压抑、细节丰富
  - 平均分镜时长：6-10秒
  - 关键手法：固定镜头、缓慢推进、冷色调、精细构图
  - 分镜分布：特写50%、中景30%、全景15%、远景5%
- **岩井俊二风格（青春爱情）**：
  - 节奏特点：抒情、缓慢、情感细腻
  - 平均分镜时长：8-12秒
  - 关键手法：自然光、柔光效果、缓慢移动、情感特写
  - 分镜分布：特写40%、中景40%、全景15%、远景5%

## 分镜字段详细说明

每个分镜包含以下字段：

1. **镜头编号**：镜头1、镜头2、镜头3...

2. **全局布光控制**：
   - 同"全局环境光布光控制"的定义
   - 每个分镜保持一致，同场景下光线角度一致性保持

3. **全局色彩调色**：
   - 同"全局色彩色调"的定义
   - 每个分镜保持一致，同场景下色温、色彩一致性保持

4. **景别**：
   - 大特写/特写/近景/中景/全景/远景/大远景

5. **焦距**：
   - 广角镜头：14mm-35mm
   - 标准镜头：50mm
   - 长焦镜头：85mm-200mm

6. **光圈**：
   - f/1.4、f/2.0、f/2.8、f/4.0、f/5.6、f/8.0等
   - 小光圈（f/8-f/22）：大景深
   - 大光圈（f/1.4-f/2.8）：浅景深

7. **镜头角度与位置**：
   - 高度：平视/俯视/仰视/高角度/低角度
   - 位置：正面/侧面/背面/斜侧面
   - 具体角度描述：如"高于人物后脑斜下30度左右拍摄"、"在人物左侧，平行人物耳垂，拍摄正侧面"

8. **对焦平面**：
   - 焦点位置：人物面部/眼睛/手部/物体/背景等
   - 景深效果：浅景深/深景深

9. **构图**：
   - 人物位置：居中/左侧/右侧/黄金分割/三分法
   - 画面布局：过肩镜头/正反打镜头/俯视构图/仰视构图
   - 详细构图描述：如"人物斜着45°面朝玻璃右侧的墙壁，头部背对镜头占据画面中间和右侧大部分区域"

10. **运镜**：
    - 基础运镜：固定/推/拉/摇/移/跟/升降
    - Seedance 2.0运镜方式：缓慢推进、快速拉近、左平移、上摇镜头、呼吸感推进、眩晕变焦、忧郁慢推等50+种
    - 详细运镜描述：如"过肩镜头，横向往左平稳运镜，露出笔记本电脑"、"缓慢后退"、"缓慢推近"

11. **剧情**：
    - 人物动作、场景变化、画面动态
    - 包含特效、光效描述（根据影片风格自动添加）
    - 详细描述场景内容
    - **剧情描述规则**（重要，强制执行）：
      1. **描述要具体，而非意境**（强制执行）：
         - 将小说、剧本中的"意境"转换为详细的"画面描述"提示词
         - 错误示范：举头望明月
         - 正确示范：一位中国古代男性面对镜头，抬头望向月亮，忧愁的氛围，夜晚
         - 对剧中人物DNA、场景、道具等的描述要足够详细和具体
         - 必须包含：人物外貌特征、服装细节、动作姿态、面部表情、手部动作等具体信息
         - 必须包含：场景环境细节（室内/室外、光线、背景、道具、装饰等）
         - 避免抽象描述，必须提供可视化的具体画面描述
      2. **结构要清晰，而非堆砌**（强制执行）：
         - 使用结构化的Prompt帮助AI更好地解析各个元素
         - 推荐公式：「主体+外观/细节描述+动作/状态」
         - 结构化示例：一架红色和黑色的直升飞机在空中飞行，背景是雪山和云层
         - 剧情字段描述示例：一位身穿黑色风衣的男性侦探坐在咖啡桌前，手中拿着一杯咖啡，眉头紧锁，眼神专注地看着桌上的文件，咖啡店内有暖黄色的灯光，背景是模糊的城市街道夜景
         - 确保描述的逻辑清晰：先描述主体，再描述细节，最后描述动作和状态
      3. **增加细节以稳定画面**（强制执行）：
         - 对于动态的、复杂的场景（如水流、火焰），提供更多的环境和细节信息
         - 错误示范：海浪
         - 正确示范：薄荷绿的海浪拍打着金色的沙滩，棕榈树在海岸边，微风吹动着棕榈树的叶子，手绘风格，漫画
         - 增加环境细节：描述光线、背景、周围环境、天气条件等
         - 增加动作细节：描述具体的动作幅度、速度、方向等
         - 增加氛围细节：描述情绪、氛围、色调等
         - 细节示例：橘红色的火焰在壁炉中熊熊燃烧，火焰跳动，火星飞溅，木质地板反射着暖黄色的火光，房间内阴影斑驳，营造出温暖的氛围

12. **光效、特效**：
    - 根据影片风格自动识别并添加
    - 如果没有特效、光效，填写"无"

13. **台词**：
    - 人物对白内容
    - 如果没有对白，填写"无"
    - **台词时长计算**（强制执行）：根据台词字数和情绪语速计算时长，严禁出现"分镜只有1-5秒，台词却有20-40字"的情况

**台词时长计算公式**（重要）：
```
台词时长（秒）= 台词字数 ÷ 基础语速 ÷ 情绪系数
```

**基础语速标准**（字/秒）：
- **正常语速**：3.5字/秒（默认语速，适用于平静对话）
- **快速语速**：4.5字/秒（适用于争吵、紧张对话、快节奏场景）
- **慢速语速**：2.5字/秒（适用于深情表白、内心独白、悲伤表达）

**情绪语速系数**（重要）：
- **平静情绪**：1.0x（正常语速，无情绪波动）
- **轻微情绪**（喜悦、惊讶、好奇）：0.9x（语速略微变慢）
- **中等情绪**（激动、担忧、困惑）：0.7-0.8x（语速变慢，留出情绪表达空间）
- **强烈情绪**（愤怒、悲伤、恐惧）：0.5-0.6x（语速显著变慢，情绪表达强烈）
- **极慢表达**（内心独白、深情告白、绝望）：0.4-0.5x（语速极慢，情感极致表达）

**核心强制规则**（最高优先级，强制执行）：
- **不得跳过任何"台词、旁白、内心独白"**：小说、剧本中的所有"台词、旁白、内心独白"必须完整呈现在各个结果表格中
- **严禁遗漏**：无论分镜时长如何限制，都不得遗漏、省略、压缩任何"台词、旁白、内心独白"的内容
- **自然顺延规则**：上一个分镜时长内没说完的"台词、旁白、内心独白"，必须自然顺延到下一个分镜内，直到"台词、旁白、内心独白"完全呈现在各个结果表格中
- **完整呈现规则**：所有"台词、旁白、内心独白"必须完整呈现，不得截断、不得省略、不得简化
- **分镜连续规则**：当一个"台词、旁白、内心独白"需要跨多个分镜时，这些分镜必须连续出现，中间不得插入其他无关内容
- **续接标记规则**：跨镜延续的"台词、旁白、内心独白"必须使用"..."和"（续）"标记，确保清晰标识续接关系

      - 拆分标记：使用"..."表示台词跨镜延续，使用"（续）"表示承接上一个分镜的台词
      - 拆分注意事项：保持语意连贯，配合镜头切换，避免在词语中间拆分，合理分配分镜时长

## 与其他表格的关系

- **电影导演表** vs **电影提示词表**：
  - 电影导演表：单个分镜1-15秒，精细化控制，每个分镜独立
  - 电影提示词表：15秒一组分镜，包含3-6个小分镜，整合输出

- **电影导演表** vs **Seedance2.0生视频提示词表**：
  - 电影导演表：包含全局布光控制、全局色彩调色、更详细的镜头参数
  - Seedance2.0生视频提示词表：16个字段的基础提示词表
