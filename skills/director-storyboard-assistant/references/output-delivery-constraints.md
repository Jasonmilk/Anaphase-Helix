## 输出格式规则

**默认输出格式**：
- 结构化分镜表：可编辑的Excel表格（.xlsx）
- 即梦5.0文生图提示词总表：可编辑的Excel表格（.xlsx）
- 漫屋分镜表：可编辑的Excel表格（.xlsx）
- 电影提示词表：Word文档格式（纯文字，没有表格）
- 电影导演表：可编辑的Word文档（.docx，包含表格）

**格式触发规则**：
1. **默认规则**：当用户未在指令框内指定输出格式时，上述五个表格默认输出为指定的格式（Excel表格或Word文档）
2. **用户指定格式**：仅当用户在指令框内明确输入扣子平台支持的其他格式（如json、csv、markdown等）时，才按照用户指定的格式输出
3. **格式优先级**：用户指定格式 > 默认格式（Excel/Word）
4. **Word文档表格例外**：电影导演表始终输出为Word文档格式（包含表格），不受格式触发规则影响
5. **Word文档纯文字例外**：电影提示词表始终输出为Word文档格式（纯文字，没有表格），不受格式触发规则影响

**扣子平台支持的格式示例**：
- Excel表格（.xlsx）：默认格式，支持直接编辑
- JSON格式：数据交换格式
- CSV格式：逗号分隔值格式
- Markdown格式：文本标记格式

**格式输入示例**：
- 用户输入"输出为json格式"：按JSON格式输出
- 用户输入"输出为csv格式"：按CSV格式输出
- 用户输入"输出为markdown格式"：按Markdown格式输出
- 用户未指定格式：按默认Excel表格格式输出

### 结构化分镜表时长计算规则（重要）

**台词/旁白/内心独白时长计算公式**（强制执行）：
```
时长（秒）= 字数 ÷ 基础语速 ÷ 情绪系数
```

**基础语速标准**（字/秒）：
- **正常语速**：3.5字/秒（默认语速，适用于平静对话）
- **快速语速**：4.5字/秒（适用于争吵、紧张对话、快节奏场景）
- **慢速语速**：2.5字/秒（适用于深情表白、内心独白、悲伤表达）

**情绪语速系数**（重要）：
- **平静情绪**：1.0x（正常语速，无情绪波动）
- **轻微情绪**（喜悦、惊讶、好奇）：0.9x（语速略微变慢）
- **中等情绪**（激动、担忧、困惑）：0.7-0.8x（语速变慢，留出情绪表达空间）
- **强烈情绪**（愤怒、悲伤、恐惧）：0.5-0.6x（语速显著变慢，情绪表达强烈）
- **极慢表达**（内心独白、深情告白、绝望）：0.4-0.5x（语速极慢，情感极致表达）

**台词/旁白/内心独白拆分规则**（重要）：
- 长台词/旁白/内心独白可自然拆分到上下连续的多个分镜中
- 拆分触发条件：计算后的时长超过单个分镜时长上限（15秒）
- 拆分方式：优先在标点符号处拆分，保持语意完整
- 拆分标记：使用"..."表示跨镜延续，使用"（续）"表示承接上一个分镜
- 严禁出现"分镜只有2-5秒，台词却有20-40字"的情况

**时长计算示例**：
```
示例1：平静对话（13字）
时长 = 13 ÷ 3.5 ÷ 1.0 = 3.7秒

示例2：悲伤表达（45字）
时长 = 45 ÷ 2.5 ÷ 0.5 = 36秒 → 拆分为3个分镜

示例3：紧张争吵（38字）
时长 = 38 ÷ 4.5 ÷ 0.6 = 14.1秒

示例4：内心独白（46字）
时长 = 46 ÷ 2.5 ÷ 0.4 = 46秒 → 拆分为4个分镜
```

### 3. 电影提示词表

**表格名称**：电影提示词表（不得修改）

**格式**：Word文档格式（纯文字，没有表格）

**内容结构**（强控制整合提示词，用于Seedance 2.0生成15秒高质量电影级视频）：
- 全局环境光布光控制
- 全局色彩调色
- 分镜逻辑（3-6个子分镜，子分镜的秒数相加总和为15秒，包含特效、光效描述）
- 整体约束
- 质感层
- 负面提示

**分镜逻辑生成规则**（重要）：
- **规则1：子分镜数量要求**（强制）
  - 每个15秒一组的生视频提示词必须包含**多个子分镜**（3-6个子分镜）
  - **禁止生成单个15秒的单独分镜**，除非用户明确指令"生成一个15秒的单独分镜"
  - 子分镜的秒数相加总和必须**等于15秒**
  - 子分镜时长分配示例：
    - 3个子分镜：3秒 + 5秒 + 7秒 = 15秒
    - 4个子分镜：3秒 + 4秒 + 4秒 + 4秒 = 15秒
    - 5个子分镜：2秒 + 3秒 + 3秒 + 3秒 + 4秒 = 15秒
    - 6个子分镜：2秒 + 2秒 + 2秒 + 3秒 + 3秒 + 3秒 = 15秒
- **规则2：子分镜时长分配**（重要）
  - 关键情节子分镜时长较长（如情感高潮、重要对话、动作高潮）：4-7秒
  - 过渡场景子分镜时长较短（如环境空镜、场景转换）：2-3秒
  - 保持子分镜时长的变化节奏，避免单调重复
  - 确保所有子分镜时长相加等于15秒
- **规则3：子分镜内容描述**（重要）
  - 每个子分镜必须明确标注时间区间（如"分镜1（0-3秒）"、"分镜2（3-8秒）"、"分镜3（8-15秒）"）
  - 每个子分镜包含：景别、运镜、画面描述、特效、光效描述
  - 子分镜之间保持逻辑连贯性和视觉流畅性
- **规则4：用户明确指令例外**（重要）
  - 仅当用户**明确指令**"生成一个15秒的单独分镜"或类似表述时，才允许生成单个15秒的分镜
  - 用户未明确指令时，必须按照规则1生成多个子分镜
  - 示例：
    - 用户指令："生成一个15秒的单独分镜" → 允许生成单个15秒分镜
    - 用户指令："生成电影提示词表" → 必须生成3-6个子分镜，总和15秒

**分镜逻辑-特效、光效描述规则**（重要）：
- **添加原则**：根据剧本或小说的风格，自动识别并添加符合影片类型的特效、光效描述
- **添加条件**：仅在剧本或小说中包含特效、光效场景时才添加，如果分镜中没有特效、光效，则不需要描述"特效、光效"

  - **仙侠修真类**（《凡人修仙传》《仙逆》等）：修仙者斗法炫酷特效、飞剑光芒、法阵光晕、灵力爆发、雷电特效、火焰特效、冰霜特效、风刃特效、灵气流转、仙气缭绕、符文发光、法宝光效、神通爆发、渡劫天劫、金光护体、灵力漩涡

### 4. 电影导演表

**表格名称**：电影导演表（不得修改）

**默认输出格式**：可编辑的Word文档（包含表格）

**格式说明**：
- 默认输出为Word文档格式（.docx），包含完整的分镜表格
- 表格可编辑，所有单元格内容可直接修改
- 仅当用户在指令框内明确输入扣子平台支持的其他格式（如json、csv、markdown等）时，才按照用户指定的格式输出
- 如果用户未指定格式，始终输出Word文档格式（包含表格）

**表格用途**：
- 根据小说或剧本中的时间、地点（场景）、人物、发生的故事，做强控制整合提示词
- 最终这些提示词＋人物三视图＋场景图一起，用作给Seedance2.0的提示词参考，生成高质量的电影级视频
- 精细化电影级分镜的强控制提示词表

**内容结构**（精细化电影级分镜的强控制提示词）：
- **一，全局环境光布光控制**：光源类型、主光源位置与角度、主光源色温、补光与光比、特殊光影或环境光影（确保同场景下光线角度一致性保持）
- **二，全局色彩色调**：主体系色、饱和度、色温、高光/中间调/阴影/暗部的色彩控制（确保同场景下色温、色彩一致性保持）
- **三，分镜逻辑**：匹配电影风格的精细化分镜，每个分镜1-15秒，包含18个字段
  - 镜头编号、全局布光控制、全局色彩调色、景别、焦距、光圈、镜头角度与位置、对焦平面、构图、运镜、剧情、光效/特效、台词、旁白、内心独白、音乐、音效、时长
- **整体约束**：画面稳定、色调一致、光影逻辑一致
- **质感层**：4K超高清、电影级写实、细节丰富
- **负面提示**：避免各种画面质量问题

**分镜逻辑生成规则**（重要）：
- 必须根据电影剧本的剧情发展和指令中的导演和电影分镜节奏风格匹配
- 如张艺谋导演的电影《英雄》的风格，大卫芬奇导演的电影《七宗罪》的风格，岩井俊二导演的电影《情书》风格等等
- 小说或剧本字数很多的情况下，自动生成多个分镜的提示词
- 单个分镜最短时间是1秒，单个分镜最长时间是15秒
- 小说剧本转为分镜要发散性思维，可以主动根据参考电影的风格扩写，加入一些空镜（大环境空镜、街道空镜、室内空镜、人物特写空镜、物品空镜）等等
- 分镜总数可以增加不能减少。比如正常思维这集剧本生成30个分镜的提示词，扩写后加到35个分镜提示词，留给导演后期剪辑的空间

## 常见错误与纠正

### 错误1：生成了角色设定表

**错误示例**：
```
输出：结构化分镜表、Seedance2.0生视频提示词表、即梦5.0文生图提示词总表、电影提示词表、漫屋分镜表、角色设定表
```

**纠正方法**：
- 删除"角色设定表"
- 角色设定信息应该整合到"结构化分镜表"的"服化道建议"字段中

### 错误2：改变了表格名称

**错误示例**：
```
输出：分镜表、视频提示词表、图片提示词表、电影提示词、漫屋表
```

**纠正方法**：
- 将"分镜表"改为"结构化分镜表"
- 将"视频提示词表"改为"Seedance2.0生视频提示词表"
- 将"图片提示词表"改为"即梦5.0文生图提示词总表"
- 将"电影提示词"改为"电影提示词表"
- 将"漫屋表"改为"漫屋分镜表"

### 错误3：生成了额外的分析表格

**错误示例**：
```
输出：结构化分镜表、Seedance2.0生视频提示词表、即梦5.0文生图提示词总表、电影提示词表、漫屋分镜表、情绪分析表、导演风格分析表
```

**纠正方法**：
- 删除"情绪分析表"
- 删除"导演风格分析表"
- 分析信息应该整合到各个表格的对应字段中

### 错误4：调整了输出顺序

**错误示例**：
```
输出：漫屋分镜表、电影提示词表、即梦5.0文生图提示词总表、Seedance2.0生视频提示词表、结构化分镜表
```

**纠正方法**：
- 调整为正确的顺序：
  1. 结构化分镜表
  2. Seedance2.0生视频提示词表
  3. 即梦5.0文生图提示词总表
  4. 电影提示词表
  5. 漫屋分镜表

### 错误5：电影提示词表格式错误

**错误示例**：
```
输出：电影提示词表（Markdown表格格式）
```

**纠正方法**：
- 改为Word文档格式（纯文字，没有表格）
- 使用标题和段落结构，不使用表格
