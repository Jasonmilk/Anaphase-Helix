## 概览
本文档提供剧本智能分析的完整方法论，用于自动解析剧本内容，提取关键信息，分析情绪曲线和节奏变化。

## 剧本格式识别

### 常见剧本格式

#### 标准剧本格式
```
场景标题：[场号] [时间] [地点]
[场景描述]
角色：[对白]
（动作指示）
```

**示例**：
```
场景标题：第1场 日 外 公园
阳光明媚的早晨，公园里绿树成荫。
张三：今天天气真好。
李四：是啊，我们去散步吧。
（张三和李四开始散步）
```

#### 简化剧本格式
```
[场号] [时间] [地点]
[场景描述]
角色：[对白]
动作：[动作描述]
```

**示例**：
```
第1场 日 外 公园
阳光明媚的早晨
张三：今天天气真好
李四：是啊
动作：张三和李四开始散步
```

#### 小说式剧本格式
```
段落式描述，包含对白和动作，无明显场次标记。
```

**示例**：
```
清晨的阳光透过窗帘洒进房间。张三睁开眼睛，看到床头的时钟指向8点。他起身穿衣，走进厨房。李四已经准备好了早餐。

张三：今天天气真好。

李四：是啊，我们去散步吧。

两人走出家门，走向公园。
```

#### 短剧剧本格式
```
[场号] [时间] [地点]
[角色] [动作/表情]
[对白]
```

**示例**：
```
第1场 夜 外 天台
约翰 站在边缘，神情凝重
约翰：我们改变不了过去。
```

### 格式识别规则

1. **场景标题识别**：
   - 包含场次编号（第X场、Scene X、SCENE_XXX）
   - 包含时间信息（日、夜、黄昏、黎明）
   - 包含地点信息（内、外、地点名称）

2. **对白识别**：
   - 以角色名开头
   - 后跟冒号或冒号+空格
   - 内容为对白文本

3. **动作指示识别**：
   - 括号内文本：（动作）
   - 动作关键字开头：动作、指示
   - 纯描述性文本（非对白）

4. **场景描述识别**：
   - 场景标题后的纯文本
   - 环境描述、天气描述
   - 人物状态描述

## 场次提取

### 场次信息提取模板

```
场次信息：
- 场号：SCENE_001
- 时间：日
- 地点：内/外 + 具体地点
- 场景描述：[描述内容]
- 出场人物：[人物列表]
- 场次类型：[叙事/过渡/高潮/结尾]
```

### 场次提取规则

1. **场号提取**：
   - 从场景标题中提取场号
   - 统一格式：SCENE_XXX（三位数字）

2. **时间提取**：
   - 日/夜/黄昏/黎明
   - 具体时间（可选）：早上8点、夜晚23点

3. **地点提取**：
   - 内外区分：内/外
   - 具体地点：咖啡馆、办公室、天台等

4. **出场人物提取**：
   - 从本场对白中提取所有角色名
   - 从动作描述中提取出现的角色名

5. **场次类型判断**：
   - **叙事场次**：推动情节发展
   - **过渡场次**：连接不同场景
   - **高潮场次**：冲突激烈，情绪达到顶点
   - **结尾场次**：段落或全剧结束

### 场次提取示例

**输入**：
```
第1场 夜 外 城市天台
约翰站在天台边缘，神情凝重。玛莉从后面走来，脸上带着担忧。
约翰：我们改变不了过去。
玛莉：但你说过...
远处传来警报声。
```

**输出**：
```
场次信息：
- 场号：SCENE_001
- 时间：夜
- 地点：外 + 城市天台
- 场景描述：约翰站在天台边缘，神情凝重。玛莉从后面走来，脸上带着担忧。远处传来警报声。
- 出场人物：约翰、玛莉
- 场次类型：叙事场次
```

## 对白提取

### 对白信息提取模板

```
对白信息：
- 场号：SCENE_XXX
- 角色：[角色名]
- 对白内容：[对白文本]
- 语气：[平静/紧张/悲伤/愤怒/恐惧/喜悦/悬疑]
- 情绪强度：[1-9]
- 上下文：[前后对白关系]
```

### 对白提取规则

1. **角色名提取**：
   - 从对白行提取角色名
   - 统一角色名格式

2. **对白内容提取**：
   - 冒号后的文本
   - 去除首尾空格

3. **语气分析**：
   - **平静**：正常语调，无情绪波动
   - **紧张**：语速加快，语气急促
   - **悲伤**：语速缓慢，语气低沉
   - **愤怒**：语速快，语气激烈
   - **恐惧**：语速不稳，语气颤抖
   - **喜悦**：语速轻快，语气愉快
   - **悬疑**：语速适中，语气神秘

4. **情绪强度评分**（1-9）：
   - 1-2：平静
   - 3-4：轻度情绪
   - 5-6：中度情绪
   - 7-8：高度情绪
   - 9：极致情绪

5. **上下文分析**：
   - 分析对白在情节中的作用
   - 识别对白的前后关系

### 对白提取示例

**输入**：
```
约翰：我们改变不了过去。
玛莉：但你说过...
约翰：那时候我不懂。
```

**输出**：
```
对白信息1：
- 场号：SCENE_001
- 角色：约翰
- 对白内容：我们改变不了过去。
- 语气：平静
- 情绪强度：3
- 上下文：开场对白，设定主题

对白信息2：
- 场号：SCENE_001
- 角色：玛莉
- 对白内容：但你说过...
- 语气：悬疑
- 情绪强度：4
- 上下文：反驳约翰，引出冲突

对白信息3：
- 场号：SCENE_001
- 角色：约翰
- 对白内容：那时候我不懂。
- 语气：悲伤
- 情绪强度：5
- 上下文：回应玛莉，情绪转变
```

## 动作指示提取

### 动作信息提取模板

```
动作信息：
- 场号：SCENE_XXX
- 角色：[角色名，可选]
- 动作类型：[移动/表情/手势/场景变化]
- 动作描述：[描述内容]
- 重要性：[低/中/高]
```

### 动作指示提取规则

1. **动作类型识别**：
   - **移动**：走、跑、跳、转身等
   - **表情**：微笑、皱眉、哭泣、愤怒等
   - **手势**：挥手、点头、摇头等
   - **场景变化**：灯光变化、天气变化、音效等

2. **角色识别**：
   - 从动作描述中提取执行动作的角色
   - 如无明确角色，标记为"场景"

3. **重要性判断**：
   - **低**：普通动作，不影响剧情
   - **中**：重要动作，推动情节
   - **高**：关键动作，影响剧情走向

### 动作指示提取示例

**输入**：
```
约翰转身走向边缘。
玛莉皱着眉头，眼中含泪。
远处传来警报声。
```

**输出**：
```
动作信息1：
- 场号：SCENE_001
- 角色：约翰
- 动作类型：移动
- 动作描述：转身走向边缘
- 重要性：高

动作信息2：
- 场号：SCENE_001
- 角色：玛莉
- 动作类型：表情
- 动作描述：皱着眉头，眼中含泪
- 重要性：高

动作信息3：
- 场号：SCENE_001
- 角色：场景
- 动作类型：场景变化
- 动作描述：远处传来警报声
- 重要性：高
```

## 情绪曲线分析

### 情绪类型定义

**基本情绪类型**：
1. **平静（Calm）**：情绪平稳，强度1-2
2. **紧张（Tension）**：压力感，强度3-5
3. **悲伤（Sadness）**：失落哀伤，强度3-6
4. **愤怒（Anger）**：愤怒爆发，强度5-8
5. **恐惧（Fear）**：害怕惊慌，强度6-9
6. **喜悦（Joy）**：快乐兴奋，强度4-7
7. **悬疑（Suspense）**：不确定好奇，强度4-6

### 情绪曲线分析步骤

1. **分段分析**：
   - 按场次分段分析
   - 每个场次内部再按对白和动作分段

2. **情绪识别**：
   - 从对白内容识别情绪
   - 从动作描述识别情绪
   - 从场景描述识别氛围

3. **强度评分**：
   - 为每个情绪点评分（1-9）
   - 综合对白、动作、场景

4. **曲线绘制**：
   - 绘制时间-情绪强度曲线
   - 标注情绪类型转折点

### 情绪曲线分析示例

**输入**：
```
第1场 夜 外 天台
约翰：我们改变不了过去。（平静，强度3）
玛莉：但你说过...（悬疑，强度4）
约翰：那时候我不懂。（悲伤，强度5）
远处传来警报声。（紧张，强度6）
```

**输出**：
```
情绪曲线：
时间（秒）| 情绪类型 | 强度 | 关键要素
---------|---------|------|---------
0-15     | 平静    | 3    | 约翰开场对白
15-30    | 悬疑    | 4    | 玛莉反驳
30-45    | 悲伤    | 5    | 约翰承认错误
45-60    | 紧张    | 6    | 警报声响起

情绪曲线描述：
[平静0-15] → [悬疑15-30] → [悲伤30-45] → [紧张45-60]

整体趋势：从平静逐步升级到紧张，情绪逐步增强
```

## 节奏变化分析

### 节奏类型定义

**节奏类型**：
1. **慢节奏**：2-5秒/镜头，情绪平缓
2. **中节奏**：1-2秒/镜头，情绪正常
3. **快节奏**：0.5-1秒/镜头，情绪激烈

### 节奏分析步骤

1. **对白节奏分析**：
   - 对白长度
   - 对白间隔
   - 对白语速

2. **动作节奏分析**：
   - 动作复杂度
   - 动作频率
   - 动作幅度

3. **场景节奏分析**：
   - 场景切换频率
   - 场景类型变化
   - 氛围转变速度

4. **综合节奏判断**：
   - 结合对白、动作、场景
   - 确定整体节奏类型

### 节奏分析示例

**输入**：
```
第1场 夜 外 天台
约翰：我们改变不了过去。
玛莉：但你说过...
约翰：那时候我不懂。
远处传来警报声。
```

**输出**：
```
节奏分析：
- 对白节奏：中节奏（对白简短，间隔适中）
- 动作节奏：慢节奏（动作描述简略）
- 场景节奏：慢节奏（单一场景）
- 综合节奏：中偏慢（适合开场铺垫）

建议：
- 开场使用慢节奏，营造氛围
- 后续冲突部分可加快节奏
- 警报声处可切换为快节奏
```

## 注意事项
- 剧本格式多样，需要灵活识别
- 对白情绪分析需结合上下文
- 动作重要性判断需考虑剧情影响
- 情绪曲线和节奏分析需要综合判断
