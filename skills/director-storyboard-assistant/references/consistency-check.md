# 一致性校验

## 目录
- 角色跨镜头一致性
- 场景连续性
- 光影风格统一性
- 校验报告模板

## 概览
本文档提供一致性校验的完整方法论，用于自动检查角色跨镜头一致性、场景连续性、光影风格统一性。

## 角色跨镜头一致性

### 角色一致性要素

1. **外貌一致性**：
   - 发型、发色
   - 面部特征
   - 体型、身高

2. **服装一致性**：
   - 服装款式
   - 服装颜色
   - 配饰

3. **位置一致性**：
   - 人物在场景中的位置
   - 人物与场景的关系

### 角色一致性校验规则

1. **外貌一致性检查**：
   - 检查角色的发型、发色是否一致
   - 检查面部特征是否一致
   - 检查体型、身高是否一致

2. **服装一致性检查**：
   - 检查服装款式是否一致（除非服装有变化）
   - 检查服装颜色是否一致
   - 检查配饰是否一致

3. **位置一致性检查**：
   - 检查人物在场景中的位置是否合理
   - 检查人物与场景的关系是否合理

### 角色一致性校验示例

**输入**：
```
镜头1：约翰，短发，黑色西装，站在天台左侧
镜头2：约翰，长发，黑色西装，站在天台右侧
镜头3：约翰，短发，白色西装，站在天台中央
```

**输出**：
```
角色一致性校验报告（约翰）：

问题1：发型不一致
- 镜头1：短发
- 镜头2：长发
- 建议：统一为短发，或在剧本中说明发型变化原因

问题2：服装颜色不一致
- 镜头1-2：黑色西装
- 镜头3：白色西装
- 建议：确认服装变化是否有剧本依据，或统一服装颜色

问题3：位置不一致
- 镜头1：天台左侧
- 镜头2：天台右侧
- 镜头3：天台中央
- 建议：检查人物移动是否合理，确保连续性

校验结果：3个问题，需要修正
```

## 场景连续性

### 场景连续性要素

1. **场景元素连续性**：
   - 场景中的物体位置
   - 场景中的物体状态

2. **光线连续性**：
   - 光源方向
   - 光线强度
   - 光线色温

3. **时间连续性**：
   - 时间流逝是否合理
   - 季节变化是否合理

### 场景连续性校验规则

1. **场景元素连续性检查**：
   - 检查场景中物体的位置是否一致
   - 检查物体的状态是否一致（除非有变化）

2. **光线连续性检查**：
   - 检查光源方向是否一致
   - 检查光线强度是否一致
   - 检查光线色温是否一致

3. **时间连续性检查**：
   - 检查时间流逝是否合理
   - 检查季节变化是否有说明

### 场景连续性校验示例

**输入**：
```
镜头1：城市天台，夜晚，月光从左侧照射
镜头2：城市天台，夜晚，月光从右侧照射
镜头3：城市天台，白天，阳光明媚
```

**输出**：
```
场景连续性校验报告（城市天台）：

问题1：光线方向不一致
- 镜头1：月光从左侧照射
- 镜头2：月光从右侧照射
- 建议：统一光线方向，或说明光源变化

问题2：时间变化不合理
- 镜头1-2：夜晚
- 镜头3：白天
- 建议：检查时间变化是否有剧本依据，或添加时间过渡

校验结果：2个问题，需要修正
```

## 光影风格统一性

### 光影风格要素

1. **光线类型统一性**：
   - 自然光/人工光/混合光
   - 光源性质（硬光/软光）

2. **光影效果统一性**：
   - 阴影处理方式
   - 光斑、光晕等效果

3. **色彩风格统一性**：
   - 主色调
   - 色彩饱和度
   - 色彩明度

### 光影风格统一性校验规则

1. **光线类型统一性检查**：
   - 检查光线类型是否一致（除非有场景变化）
   - 检查光源性质是否一致

2. **光影效果统一性检查**：
   - 检查阴影处理方式是否一致
   - 检查光斑、光晕等效果是否一致

3. **色彩风格统一性检查**：
   - 检查主色调是否一致
   - 检查色彩饱和度是否一致
   - 检查色彩明度是否一致

### 光影风格统一性校验示例

**输入**：
```
镜头1：冷色调，高饱和度，硬光阴影
镜头2：暖色调，低饱和度，软光阴影
镜头3：冷色调，高饱和度，硬光阴影
```

**输出**：
```
光影风格统一性校验报告：

问题1：色彩风格不一致
- 镜头1：冷色调，高饱和度
- 镜头2：暖色调，低饱和度
- 镜头3：冷色调，高饱和度
- 建议：确认色彩变化是否有剧本依据，或统一色彩风格

问题2：光影效果不一致
- 镜头1：硬光阴影
- 镜头2：软光阴影
- 镜头3：硬光阴影
- 建议：确认光影效果变化是否有场景变化依据，或统一光影效果

校验结果：2个问题，需要修正
```

## 自动校验规则

### 校验触发条件

1. **角色跨镜头一致性**：
   - 同一角色出现在多个镜头
   - 角色的外貌、服装、位置有变化

2. **场景连续性**：
   - 同一场景出现在多个镜头
   - 场景元素、光线、时间有变化

3. **光影风格统一性**：
   - 镜头之间的光影风格有差异
   - 色彩风格有变化

### 校验优先级

1. **高优先级问题**：
   - 角色外貌不一致
   - 场景元素位置不一致
   - 时间变化不合理

2. **中优先级问题**：
   - 服装不一致（无剧本依据）
   - 光线方向不一致
   - 色彩风格不一致

3. **低优先级问题**：
   - 位置微小变化
   - 光线强度微小变化
   - 色彩饱和度微小变化

### 校验修正建议

1. **角色外貌不一致**：
   - 统一角色外貌
   - 或在剧本中说明变化原因

2. **服装不一致**：
   - 统一服装
   - 或在服装变化追踪表中记录变化

3. **场景元素不一致**：
   - 统一场景元素位置
   - 或说明场景变化

4. **光线不一致**：
   - 统一光线方向
   - 或说明光源变化

5. **色彩风格不一致**：
   - 统一色彩风格
   - 或说明风格变化

## 注意事项
- 一致性校验需要基于完整的分镜表
- 校验结果需要结合剧本和创作意图
- 不是所有不一致都是问题，有些是有意的创作选择
- 校验报告应该提供明确的修正建议
