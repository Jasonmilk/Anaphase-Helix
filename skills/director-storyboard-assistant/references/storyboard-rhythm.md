## 节奏设计原则

### 基础原则

1. **节奏与内容匹配**，支持0.1秒精度：
   - 紧张场景：快节奏，短时长（0.1-5秒，可精确到0.1秒）
   - 情感场景：慢节奏，长时长（5-15秒，可精确到0.1秒）
   - 过渡场景：中节奏，中等时长（3-7秒，可精确到0.1秒）

2. **时长精度规则**（重要）：
   - 分镜时长可以精确到0.1秒一个单位
   - 使分镜逻辑和分镜节奏更细腻精准
   - 所有影视剧风格的分镜时长都支持0.1秒精度
   - 示例：基础节奏3秒 → 可调整为2.8秒或3.1秒
   - 示例：基础节奏5秒 → 可调整为4.7秒或5.3秒
   - 示例：基础节奏2秒 → 可调整为1.8秒或2.2秒

3. **节奏变化规则**：
   - 节奏要有快慢变化，避免单调，支持0.1秒精度
   - 高潮部分节奏加快，积累张力，支持0.1秒精度
   - 低谷部分节奏放缓，释放情绪，支持0.1秒精度

4. **时长多样性**：
   - 同一场景内时长要有变化（如2.3秒、3.5秒、4.7秒、7.2秒等）
   - 避免所有镜头时长相同（如全是5秒）
   - 根据情绪和剧情需要灵活调整，支持0.1秒精度

### 节奏类型

1. **快节奏（Fast Pacing）**，支持0.1秒精度：
   - 时长范围：0.1-5秒
   - 适用场景：动作、追逐、冲突、紧张对话
   - 镜头特点：短时长、多切换、快速剪辑
   - 示例时长：0.5秒、1.2秒、2.3秒、3.7秒、4.8秒

2. **中节奏（Medium Pacing）**，支持0.1秒精度：
   - 时长范围：3-8秒
   - 适用场景：对白、叙事、过渡、情感表达
   - 镜头特点：中等时长、平衡切换
   - 示例时长：3.2秒、4.5秒、5.8秒、6.7秒、7.3秒

3. **慢节奏（Slow Pacing）**，支持0.1秒精度：
   - 时长范围：5-15秒
   - 适用场景：情感高潮、氛围营造、内心独白、风景描写
   - 镜头特点：长时长、少切换、沉浸体验
   - 示例时长：5.5秒、7.2秒、9.8秒、12.3秒、14.7秒

## 导演风格节奏特征

### 经典好莱坞

**节奏特征**：
- 节奏平衡：快慢结合，节奏流畅
- 平均时长：4-7秒
- 时长分布：
  - 开场：3-5秒（快速建立场景）
  - 对白：5-8秒（清晰表达对白）
  - 动作：2-4秒（快速展现动作）
  - 高潮：5-10秒（积累张力）
  - 结尾：5-8秒（平稳收尾）

**节奏示例**：
```
开场3秒 → 对白5秒 → 动作3秒 → 对白7秒 → 高潮8秒 → 结尾6秒
```

### 诺兰

**节奏特征**：
- 节奏紧凑：快节奏为主，偶尔慢节奏
- 平均时长：3-6秒
- 时长分布：
  - 快速叙事：2-4秒（推进剧情）
  - 交叉剪辑：1-3秒（多线叙事）
  - 悬疑场景：4-7秒（积累悬念）
  - 史诗镜头：8-15秒（展现宏大规模）

**节奏示例**：
```
交叉剪辑：2秒、3秒、2秒、3秒 → 悬疑场景：5秒、6秒 → 史诗镜头：10秒
```

### 王家卫

**节奏特征**：
- 节奏缓慢：慢节奏为主，沉浸体验
- 平均时长：6-12秒
- 时长分布：
  - 情感表达：8-15秒（沉浸情绪）
  - 环境描写：6-10秒（营造氛围）
  - 慢镜头：10-15秒（时间拉伸）
  - 对白场景：5-8秒（清晰对白）

**节奏示例**：
```
环境描写：8秒 → 情感表达：12秒 → 慢镜头：10秒 → 对白：7秒
```

### 作者电影

**节奏特征**：
- 节奏自然：真实节奏，不做刻意调整
- 平均时长：5-10秒
- 时长分布：
  - 长镜头：10-15秒（真实时间）
  - 对白场景：5-8秒（自然对话）
  - 动作场景：3-6秒（真实动作）
  - 过渡场景：5-10秒（自然过渡）

**节奏示例**：
```
长镜头：12秒 → 对白：7秒 → 动作：5秒 → 长镜头：10秒
```

### 悬疑惊悚

**节奏特征**：
- 节奏多变：快慢交替，营造紧张感
- 平均时长：2-6秒
- 时长分布：
  - 悬疑场景：4-7秒（积累悬念）
  - 惊吓点：1-3秒（突然惊吓）
  - 追逐场景：2-4秒（快速剪辑）
  - 恐怖氛围：5-10秒（营造恐惧）

## 时长计算方法

### 基础时长计算（支持0.1秒精度）

#### 对白场景时长计算

**步骤1：台词长度评估**
- 计算台词字数
- 识别句子数量
- 评估情绪强度

**步骤2：基础时长分配**
- 每句对白分配2-3秒（正常语速，可精确到0.1秒）
- 句子之间的停顿：0.5-1秒（可精确到0.1秒）

**步骤3：情绪调整**
- 平静情绪：不调整
- 轻微情绪：+10-20%（可精确到0.1秒）
- 中等情绪：+20-40%（可精确到0.1秒）
- 激烈情绪：+40-60%（可精确到0.1秒）

**步骤4：导演风格调整**
- 根据导演风格特征调整时长（可精确到0.1秒）
- 快节奏风格：-10-20%（可精确到0.1秒）
- 慢节奏风格：+20-40%（可精确到0.1秒）

**公式**：
```
最终时长 = (句子数 × 2.5秒 + 停顿时间) × 情绪系数 × 风格系数
```

**示例**：
```
台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！"
句子数：3句
基础时长：3 × 2.5 = 7.5秒
停顿时间：1秒（2处停顿 × 0.5秒）
小计：8.5秒
情绪系数：1.3（激烈情绪，+30%）
风格系数：1.0（诺兰风格，不调整）
最终时长：8.5 × 1.3 × 1.0 = 11.05秒 → 11秒
```

#### 动作场景时长计算

**步骤1：动作复杂度评估**
- 简单动作（走路、站立）：1-2秒
- 中等动作（跑步、跳跃）：2-4秒
- 复杂动作（打斗、追逐）：3-5秒

**步骤2：动作序列拆分**
- 将复杂动作拆分为多个简单动作
- 每个简单动作分配1-2秒

**步骤3：导演风格调整**
- 快节奏风格（诺兰、短剧）：-20%（可精确到0.1秒）
- 慢节奏风格（王家卫、作者电影）：+30%（可精确到0.1秒）

**示例**（支持0.1秒精度）：
```
动作：约翰从天台边缘转身，跑向楼梯
动作拆分：转身（1秒）+ 跑向楼梯（3秒）
基础时长：4秒
风格系数：0.8（诺兰风格，快节奏）
最终时长：4 × 0.8 = 3.2秒 → 3.2秒（保留0.1秒精度）
```

#### 情感场景时长计算（支持0.1秒精度）

**步骤1：情绪强度评估**
- 轻微情绪：1-3级
- 中等情绪：4-6级
- 强烈情绪：7-10级

**步骤2：基础时长分配**
- 轻微情绪：3-5秒（可精确到0.1秒）
- 中等情绪：5-8秒（可精确到0.1秒）
- 强烈情绪：8-15秒（可精确到0.1秒）

**步骤3：导演风格调整**
- 王家卫风格：+30-50%（可精确到0.1秒）
- 作者电影风格：+20-40%（可精确到0.1秒）
- 其他风格：不调整

**示例**（支持0.1秒精度）：
```
场景：玛莉眼含泪水，握住约翰的手
情绪强度：7级（强烈）
基础时长：9秒
风格系数：1.4（王家卫风格，慢节奏）
最终时长：9 × 1.4 = 12.6秒 → 12.6秒（保留0.1秒精度，不超过15秒上限）
```

### 时长上限处理（支持0.1秒精度）

**单镜头上限**：15秒（最大值）

**时长范围**：0.1-15秒（最小值0.1秒，最大值15秒）

**超过上限的处理方法**：

1. **拆分为多个镜头**：
   - 保留核心内容在原镜头
   - 拆分次要内容到新镜头
   - 确保每个镜头时长不超过15秒（可精确到0.1秒）

2. **调整时长分配**：
   - 缩短非关键部分
   - 保留关键情感表达
   - 使用镜头切换增强表现力

**示例**：
```
原计划：18秒的长独白
拆分方案：
镜头1：10秒（前半部分独白）
镜头2：8秒（后半部分独白）
```

### 空镜时长计算（支持0.1秒精度）

#### 空镜类型与时长范围

**环境空镜**：
- 时长范围：3-8秒（可精确到0.1秒）
- 适用场景：交代故事发生地的大、小环境（城市天际线、街道、建筑外景、室内环境）
- 时长分配：
  - 大环境（城市全景、城市天际线）：6-8秒（可精确到0.1秒）
  - 中环境（街道、建筑外景）：4-6秒（可精确到0.1秒）
  - 小环境（室内环境、房间）：3-5秒（可精确到0.1秒）

**道具空镜**：
- 时长范围：2-5秒（可精确到0.1秒）
- 适用场景：交代人物关系或情节的小道具（相册、照片、信件、礼物、纪念品）
- 时长分配：
  - 大道具（家具、装饰品）：4-5秒（可精确到0.1秒）
  - 中道具（相册、照片、礼物）：3-4秒（可精确到0.1秒）
  - 小道具（戒指、钥匙、纪念品）：2-3秒（可精确到0.1秒）

**象征空镜**：
- 时长范围：4-10秒（可精确到0.1秒）
- 适用场景：贯穿整部电影多次出现的道具（象征意义的道具、主题相关物品）
- 时长分配：
  - 重大象征（贯穿电影的主题道具）：8-10秒（可精确到0.1秒）
  - 中等象征（阶段性象征道具）：6-8秒（可精确到0.1秒）
  - 轻微象征（细节象征道具）：4-6秒（可精确到0.1秒）

**过渡空镜**：
- 时长范围：2-4秒（可精确到0.1秒）
- 适用场景：场景转换的过渡镜头（场景之间的衔接镜头）
- 时长分配：
  - 场景转场（不同地点之间的过渡）：3-4秒（可精确到0.1秒）
  - 时间过渡（时间流逝的过渡）：2-3秒（可精确到0.1秒）
  - 空间过渡（不同空间的过渡）：2-3秒（可精确到0.1秒）

**氛围空镜**：
- 时长范围：3-6秒
- 适用场景：营造氛围的空镜头（天气、光线、时间、环境细节）
- 时长分配：
  - 强烈氛围（恐怖、紧张、悲伤）：5-6秒
  - 中等氛围（平静、温暖、忧郁）：4-5秒
  - 轻微氛围（轻松、愉悦）：3-4秒

#### 空镜时长计算方法

**步骤1：空镜类型识别**
- 根据空镜内容判断空镜类型
- 根据空镜用途判断空镜类型

**步骤2：基础时长分配**
- 根据空镜类型选择基础时长范围

- 根据导演风格特征调整时长
- 快节奏风格（诺兰、短剧）：-20%

- 场景开场空镜：+20%

- 对白间隙空镜：不调整

```
最终时长 = 基础时长 × 风格系数 × 位置系数
```

## 节奏调整策略

### 节奏变化方法

1. **时长渐变**：
   - 从短到长：2秒 → 4秒 → 6秒 → 8秒（节奏放缓）
   - 从长到短：8秒 → 6秒 → 4秒 → 2秒（节奏加快）

2. **长短交替**：
   - 短长组合：3秒 + 7秒 + 4秒 + 6秒（节奏变化）
   - 长短组合：7秒 + 3秒 + 6秒 + 4秒（节奏变化）

3. **节奏对比**：
   - 快慢对比：快节奏场景后接慢节奏场景
   - 紧松对比：紧张场景后接舒缓场景

### 节奏匹配场景

1. **开场场景**：
   - 目的：快速建立场景和氛围
   - 时长：2-5秒
   - 节奏：快节奏或中节奏

2. **对白场景**：
   - 目的：清晰表达对白和情感
   - 时长：5-8秒
   - 节奏：中节奏

3. **动作场景**：
   - 目的：展现动作和冲突
   - 时长：2-5秒
   - 节奏：快节奏

4. **情感场景**：
   - 目的：沉浸情感和氛围
   - 时长：5-15秒
   - 节奏：慢节奏

5. **高潮场景**：
   - 目的：积累张力和释放情绪
   - 时长：5-10秒
   - 节奏：快节奏或慢节奏（根据导演风格）

6. **结尾场景**：
   - 目的：平稳收尾，留下余韵
   - 时长：5-10秒
   - 节奏：中节奏或慢节奏

### 节奏优化技巧

1. **避免单调**：
   - 同一场景内时长要有变化
   - 不要所有镜头时长相同

2. **节奏起伏**：
   - 节奏要有快慢变化
   - 避免一味快或一味慢

3. **情绪匹配**：
   - 节奏要匹配情绪变化
   - 情绪激烈时节奏加快
   - 情绪平缓时节奏放缓

4. **导演风格**：
   - 严格遵守导演风格的节奏特征
   - 不要偏离导演风格的核心特征

## 完整示例

### 示例1：诺兰风格 - 悬疑场景

**场景描述**：
约翰在天台边缘，玛莉从后方走入，远处有警车灯光，氛围紧张。

**导演风格**：诺兰（快节奏为主，交叉剪辑）

**节奏设计**：
- 镜头1（开场）：3秒（快速建立场景）
- 镜头2（对白）：6秒（中等对白，紧张情绪）
- 镜头3（交叉剪辑）：2秒（另一场景）
- 镜头4（对白）：7秒（激烈对白，情绪激烈）
- 镜头5（交叉剪辑）：3秒（另一场景）
- 镜头6（高潮）：8秒（积累张力）
- 镜头7（结尾）：5秒（快速收尾）

**时长分布**：3秒、6秒、2秒、7秒、3秒、8秒、5秒
**平均时长**：4.9秒
**节奏特征**：快节奏为主，交叉剪辑，时长变化明显

### 示例2：王家卫风格 - 情感场景

### 示例3：红果短剧风格 - 快节奏对白

两人在办公室争吵，节奏紧凑，保持观众注意力。

- 镜头6（对白）：5秒（情感表达）

## 注意事项

- 严格遵守导演风格的节奏特征
- 时长范围：1-15秒
- 单镜头上限：15秒，超过需分割
- 节奏要有变化，避免单调
- 时长要匹配情绪和剧情
- 整体节奏要流畅自然
