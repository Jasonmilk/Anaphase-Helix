# 分镜提示词表格结构

- 提示词表格结构

## 概览
本文档定义了分镜提示词表格的完整结构，用于生成结构化的分镜提示词表格。每个镜头的提示词按照固定的字段顺序排列，便于AI视频生成工具解析和使用。

## 提示词表格结构

### 表格字段顺序

每个镜头的提示词包含以下字段（按顺序）：

```
1. 构图：[角度与构图描述]
2. 光影时段：[光源描述与时段]
3. 色温：[主光源色温 + 辅助光源色温]
4. 景别：[镜头景别]
5. 运镜：[镜头运动方式，整合基础运镜与Seedance 2.0运镜方式]
6. 镜头选择：[镜头焦距]
7. 对焦平面：[焦点位置与景深]
8. 时长：[镜头时长，单位：秒]
9. 画面内容：[人物动作与场景描述]
10. 音效：[环境音、动作音、特殊音效]
11. 台词：[人物对白]
12. 配乐：[背景音乐]
13. 背景：[背景环境描述]
14. 画质：[分辨率与技术参数]
15. 一致性校验：[角色一致性、场景连续性、光影风格统一性校验结果]
16. 修正建议：[如果不一致，提供修正建议]
```

## 字段说明

### 1. 构图
**定义**：描述摄影机的角度和画面构图方式

**包含要素**：
- 摄影机角度：俯视图、平视图、仰视图、侧视图、过肩镜头等
- 构图方式：主体位置、画面布局、空间关系
- 人物位置：明确每个人物在画面中的位置

**描述词**：
- 角度：俯视图、平视图、仰视图、侧视图、荷兰角、过肩镜头
- 构图：主体居中、三分法构图、对角线构图、对称构图、框架构图

**示例**：
```
俯视图，雕塑在画面中央，两特遣队员分立两侧雕塑两侧，举着枪对着雕塑，博士蹲在画面右上方墙角背对镜头使用电脑
```

### 2. 光影时段
**定义**：描述光源类型、位置、强度和时间特征

**包含要素**：
- 主光源：类型、位置、强度
- 辅助光源：类型、位置、作用
- 光线方向：顶光、侧光、逆光、顺光
- 时段特征：白天、夜晚、黄昏、黎明

**描述词**：
- 光源类型：自然光、人造光、顶光、侧光、轮廓光、无影光源
- 时段：白天、夜晚、黄昏、黎明、室内
- 光线效果：均匀白光、红色轮廓光、蓝色冷光、暖黄色调

**示例**：
```
顶部无影光源提供均匀白光，红色应急灯带提供侧面红色轮廓光
```

### 3. 色温
**定义**：描述光源的色温数值和色彩特征

**包含要素**：
- 主光源色温：开尔文数值
- 辅助光源色温：开尔文数值
- 色彩效果：冷白光、暖黄光、红光、蓝光等

**常用色温**：
- 5500K：冷白光（日光）
- 3200K：暖黄光（室内钨丝灯）
- 6500K：正午日光
- 2700K：暖白光（家用灯泡）
- 7500K：冷蓝光（阴天）

**格式**：
```
[主光源色温] + [辅助光源色温]
```

**示例**：
```
5500K冷白光（主光源）+ 3200K暖红光（应急灯）
```

### 4. 景别
**定义**：描述镜头的拍摄距离和画面范围

**景别分类**：
- 大特写（ECU）：眼睛、嘴唇、手部细节
- 特写（CU）：人物面部、上半身
- 中景（MS）：人物腰部以上
- 全景（FS）：人物全身及周围环境
- 远景（LS）：广阔场景，人物较小
- 大远景（ELS）：极端远景，人物极小

**示例**：
```
全景
```

### 5. 运镜
**定义**：描述镜头的运动方式，整合基础运镜方式与Seedance 2.0运镜方式

**包含要素**：
- 基础运镜方式：固定、推、拉、摇、移、跟、升降
- Seedance 2.0运镜方式：
  - 镜头运动方向：缓慢推进、快速拉近、左平移、上摇镜头、固定镜头（呼吸感）、固定镜头（磁吸追踪）、跟随拍摄（磁吸追踪）、跟随拍摄（盗梦空间）、旋转镜头、变焦放大、镜头抖动、慢动作、加速播放、静态延时
  - 镜头视角层级：俯拍全景、仰拍特写、眼睛平视、过肩镜头、鸟瞰镜头、微距视角、鱼眼镜头、窥视构图、倒剁镜头、隧道构图、框式构图、分裂屏幕
  - 镜头动态运镜：环绕拍摄、甩镜头、升降镜头、抛物线运镜、穿越镜头、旋转上升、疾速追踪、碰撞切换、动态变焦、液体运镜、光影切割、失重漂浮
  - 镜头情绪化运镜：忧郁慢推、紧张晃动、浪漫旋转、恐惧倾斜、欢快跳跃、孤独长镜头、悬疑跟拍、梦幻移焦、史诗拉升、焦虑碎片、治愈固定、宿命感旋转
  - 特殊场景运镜：转场镜头、产品展示、美食镜头、街拍限随、舞蹈拍摄、自然风光、建筑巡游、汽车拍摄、服装展示、美妆特写、夜景光绘、雨景镜头

**运镜选择指南**：
- 基础场景：固定、推、拉、摇、移、跟、升降
- 情绪表达：忧郁慢推、紧张晃动、浪漫旋转、恐惧倾斜、欢快跳跃、治愈固定
- 导演风格：诺兰（快速拉近、眩晕变焦、史诗拉升）、王家卫（忧郁慢推、浪漫旋转、梦幻移焦）
- 特殊场景：产品展示、美食镜头、街拍限随、舞蹈拍摄、自然风光

**格式**：
```
[运镜方式描述，优先使用Seedance 2.0高级描述]
```

**示例**：
```
呼吸感推进 + 轻微变焦扭曲
```

### 6. 镜头选择
**定义**：描述摄影机的镜头焦距和视角特征

**镜头类型**：
- 广角镜头：14mm、16mm、20mm、24mm（宽阔视角，变形效果）
- 标准镜头：35mm、50mm（接近人眼视角）
- 长焦镜头：85mm、100mm、135mm（压缩空间，虚化背景）
- 超长焦：200mm、300mm（极端压缩）

**格式**：
```
[焦距] + [镜头类型]
```

**示例**：
```
24mm广角镜头
```

### 7. 对焦平面
**定义**：描述焦点位置和景深效果

**包含要素**：
- 焦点位置：焦点锁定的主体或区域
- 景深：浅景深、深景深、景深适中
- 背景效果：背景虚化、背景清晰

**格式**：
```
焦点锁定在[主体]，[景深效果]
```

**示例**：
```
焦点锁定在雕塑上，浅景深
```

### 8. 时长
**定义**：描述镜头的持续时间，单位为秒

**时长范围**：
- 最短时长：1秒
- 最长时长：15秒
- 推荐时长：3-8秒

**时长选择规则**：
- 无对白动作戏：2-5秒
- 简单对白（1-2句）：3-5秒
- 复杂对白（3-5句）：5-8秒
- 长对白（6句以上）：8-15秒
- 情绪强烈的对白额外增加30-50%时长

**格式**：
```
[数字]秒
```

**示例**：
```
5秒
```

### 9. 画面内容
**定义**：描述人物动作、场景变化和画面动态

**包含要素**：
- 人物动作：具体的行为和表情
- 场景变化：环境中的动态元素
- 交互关系：人物之间的互动

**示例**：
```
博士不停的打字，回头看一眼雕塑，然后转回去
```

### 10. 音效
**定义**：描述环境音、动作音和特殊音效

**音效类型**：
- 环境音：风声、雨声、车流声、虫鸣声
- 动作音：脚步声、敲门声、开门声、打字声
- 特殊音效：爆炸声、枪声、心跳声、呼吸声
- 对白音：人物对白

**格式**：
```
[环境音]，[动作音]，[特殊音效]
```

**示例**：
```
急促的打字声，背景有低沉的电流声
```

### 11. 台词
**定义**：描述人物的对白内容

**格式**：
```
[角色名]：[对白内容]
```

**台词拆分规则（重要）**：
- **拆分原则**：长台词可以自然拆分到上下连续的多个镜头中，符合现实影视剧的台词分镜处理逻辑
- **拆分触发条件**：
  - 台词时长（按情绪语速计算）超过单个镜头时长
  - 台词时长超过当前镜头的预留时长（如当前镜头2-5秒，但台词需要8秒）
- **拆分方式**：
  - **按语意单元拆分**：优先在逗号、句号、问号、感叹号等标点符号处拆分
  - **按情绪转折拆分**：在情绪转折点拆分（如从平静到愤怒）
  - **按镜头切换拆分**：配合镜头切换，在不同景别或角度中继续台词
- **拆分标记**：
  - 使用"..."表示台词跨镜延续
  - 使用"（续）"表示承接上一个镜头的台词
- **拆分示例**：
  ```
  示例：长台词拆分（3个镜头）
  - 原台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！"（按情绪语速需要8秒）
  - 镜头1（3秒）：主角特写，情绪平稳
    台词：主角："我知道你恨我，我也恨我自己。但这一切都是命..."
  - 镜头2（3秒）：镜头切换到侧脸，情绪开始激动
    台词：主角："（续）我们改变不了的！"
  ```
- **拆分注意事项**：
  - 拆分后的台词要保持语意连贯，不破坏情感表达
  - 拆分点要配合镜头切换，增强视觉表现力
  - 避免在词语中间拆分（如"改变不"拆开），要在标点符号处拆分
  - 长台词拆分后，每个镜头的时长要合理分配，确保台词能完整说完

**示例**：
```
博士：这个频率不对...我们找到正确的共振点了
```

### 12. 配乐
**定义**：描述背景音乐的类型和情绪

**配乐类型**：
- 悲伤：悲伤、哀愁、失落
- 紧张：紧张、焦虑、不安
- 恐惧：恐惧、惊吓、害怕
- 浪漫：浪漫、温馨、甜蜜
- 激昂：激昂、热血、兴奋
- 悬疑：悬疑、神秘、未知
- 宁静：宁静、平和、安详
- 无音乐：无音乐

**示例**：
```
紧张氛围音乐，快节奏鼓点
```

### 13. 背景
**定义**：描述背景环境和空间特征

**包含要素**：
- 空间特征：室内、室外、封闭空间、广阔环境
- 环境元素：墙壁、地面、天空、建筑
- 氛围特征：阴森、明亮、压抑、开阔

**示例**：
```
封闭的实验室，金属墙壁，地板上有反光，远处有红色的应急灯带
```

### 14. 画质
**定义**：描述分辨率、技术参数和视觉效果

**技术参数**：
- 分辨率：8K、4K、1080P
- 技术特征：超高清、电影质感、写实风格
- 特殊效果：景深虚化、HDR、光线追踪

**示例**：
```
8K，超高清，电影质感
```

### 15. 一致性校验
**定义**：检查该镜头与前后镜头的一致性，包括角色一致性、场景连续性、光影风格统一性

**校验内容**：
- **角色一致性**：角色外貌、服装、位置是否与前后镜头一致
- **场景连续性**：场景元素、光线、时间是否与前后镜头一致
- **光影风格统一性**：光线类型、色彩风格是否与前后镜头一致

**校验结果**：
- **通过**：所有一致性检查通过，无问题
- **警告**：存在轻微不一致，但不影响整体效果
- **错误**：存在严重不一致，需要修正

**描述格式**：
```
角色一致性：[通过/警告/错误]，[问题描述]
场景连续性：[通过/警告/错误]，[问题描述]
光影风格统一性：[通过/警告/错误]，[问题描述]
```

**示例**：
```
角色一致性：通过，约翰的服装与前一镜头一致
场景连续性：通过，场景元素与前一镜头一致
光影风格统一性：警告，色温与前一镜头略有差异（6500K vs 6300K）
```

**示例（错误情况）**：
```
角色一致性：错误，约翰的服装与前一镜头不一致（前一镜头：黑色战术背心，当前镜头：白色T恤）
场景连续性：通过
光影风格统一性：通过
```

### 16. 修正建议
**定义**：如果一致性校验发现错误或警告，提供具体的修正建议

**修正建议类型**：
- **角色修正**：调整角色服装、位置、外貌
- **场景修正**：调整场景元素、光线、时间
- **光影修正**：调整光线类型、色彩风格、色温
- **自动修正**：智能体可自动应用修正
- **人工确认**：需要用户确认后应用修正

**描述格式**：
```
[字段名]：[修正内容]（[自动修正/人工确认]）
```

**示例**：
```
画面内容：将约翰的服装从"白色T恤"改为"黑色战术背心"，与前一镜头保持一致（自动修正）
色温：将色温从"6300K"改为"6500K"，与前一镜头保持一致（自动修正）
```

**示例（无需修正）**：
```
无需修正
```

## 空镜提示词

### 空镜识别
**识别规则**：
- 画面内容中不包含人物的镜头为空镜
- 画面内容中仅包含环境、道具、物品的镜头为空镜
- 空镜的"台词"字段填写"无台词"或"无"

### 空镜类型标注
**在"构图"字段标注空镜类型**：

**环境空镜**：
```
构图：环境空镜，[构图描述]
```
- 场景开场环境空镜示例：
  ```
  构图：环境空镜，俯视图，城市天际线在画面中央，建筑物错落有致
  ```
- 环境细节空镜示例：
  ```
  构图：环境空镜，平视图，街道两旁的建筑和路灯
  ```

**道具空镜**：
```
构图：道具空镜，[构图描述]
```
- 道具空镜示例：
  ```
  构图：道具空镜，俯视图，相册放在桌面上，照片散落
  ```

**象征空镜**：
```
构图：象征空镜，[构图描述]
```
- 象征空镜示例：
  ```
  构图：象征空镜，特写构图，破碎的怀表躺在地上
  ```

**过渡空镜**：
```
构图：过渡空镜，[构图描述]
```
- 过渡空镜示例：
  ```
  构图：过渡空镜，俯视图，街道转场
  ```

**氛围空镜**：
```
构图：氛围空镜，[构图描述]
```
- 氛围空镜示例：
  ```
  构图：氛围空镜，平视图，雨天窗外的雨滴
  ```

### 空镜运镜选择
**环境空镜**：

- 景别：全景、远景
- 示例：缓慢推进，全景

**道具空镜**：
- 运镜：固定镜头、微震动手持模拟

- 示例：固定镜头，特写

**象征空镜**：
- 运镜：梦幻移焦、孤独长镜头
- 景别：特写、中景
- 示例：梦幻移焦，特写

**过渡空镜**：
- 运镜：动态变焦、快速拉近
- 景别：中景、全景
- 示例：动态变焦，中景

**氛围空镜**：
- 运镜：忧郁慢推、治愈固定
- 景别：中景、全景
- 示例：忧郁慢推，中景

## 完整示例

### 示例1：对话场景
```
1. 构图：过肩镜头，博士在画面左侧，雕塑在画面中央，两特遣队员在画面右侧
2. 光影时段：顶部无影光源提供均匀白光，红色应急灯带提供侧面红色轮廓光，室内
3. 色温：5500K冷白光（主光源）+ 3200K暖红光（应急灯）
4. 景别：中景
5. 运镜：呼吸感推进 + 轻微变焦扭曲
6. 镜头选择：35mm标准镜头
7. 对焦平面：焦点锁定在博士面部，浅景深
```
