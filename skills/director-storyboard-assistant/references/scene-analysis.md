## 场景类型识别

### 场景类型分类

**按室内外分类**：
1. **内景（INT/内）**：室内场景
2. **外景（EXT/外）**：室外场景
3. **内外景（INT/EXT/内外）**：包含室内外转换的场景

**按功能分类**：
1. **生活场景**：家庭、卧室、客厅、厨房
2. **工作场景**：办公室、会议室、工厂
3. **公共场景**：公园、街道、商场、咖啡馆
4. **特殊场景**：天台、地下室、废墟、荒野

**按氛围分类**：
1. **温馨场景**：卧室、咖啡馆
2. **紧张场景**：废弃建筑、密室
3. **宏大场景**：宫殿、广场
4. **私密场景**：卧室、车内

### 场景类型识别规则

1. **从场景标题提取**：
   - 场景标题通常包含地点信息
   - 标注内外（INT/EXT）

2. **从场景描述提取**：
   - 场景描述中的环境细节
   - 通过环境特征判断场景类型

3. **场景类型判断示例**：
   - "公园" → 公共场景/户外
   - "公寓" → 生活场景/室内
   - "办公室" → 工作场景/室内
   - "天台" → 特殊场景/户外

### 场景类型识别示例

**输入**：
```
场景标题：第1场 夜 外 城市天台
```

**输出**：
```
场景类型：
- 内外类型：外景（EXT）
- 功能类型：特殊场景（天台）
- 氛围类型：宏大/私密混合
```

## 空间结构分析

### 空间结构要素

1. **空间大小**：
   - 开阔空间：广场、公园
   - 中等空间：办公室、公寓
   - 狭窄空间：走廊、车内

2. **空间布局**：
   - 开放式布局：无隔断，视线开阔
   - 封闭式布局：有隔断，视线受限
   - 半开放式布局：部分隔断，视线半受限

3. **空间层次**：
   - 前景：最近的物体或人物
   - 中景：主要活动区域
   - 背景：最远的场景

4. **空间关系**：
   - 人物与空间的比例
   - 人物在空间中的位置
   - 空间的封闭程度

### 空间结构分析模板

```
空间结构：
- 场号：SCENE_XXX
- 空间大小：[开阔/中等/狭窄]
- 空间布局：[开放式/封闭式/半开放式]
- 空间层次：[前中后层次描述]
- 空间关系：[人物与空间的关系]
```

### 空间结构分析示例

**输入**：
```
场景描述：城市天台，视野开阔，远处是城市天际线。约翰站在天台边缘，身后是空旷的天台。
```

**输出**：
```
空间结构：
- 场号：SCENE_001
- 空间大小：开阔
- 空间布局：开放式
- 空间层次：
  - 前景：约翰
  - 中景：天台边缘
  - 背景：城市天际线
- 空间关系：人物占较小比例，强调空间的广阔感
```

## 光线设计

### 光线类型分类

1. **自然光**：
   - 阳光（直射、散射）
   - 月光
   - 星光

2. **人工光**：
   - 室内照明（吊灯、台灯）
   - 街灯
   - 霓虹灯
   - 蜡烛

3. **混合光**：
   - 自然光 + 人工光
   - 多种人工光混合

### 光线要素分析

1. **光源方向**：
   - 顺光：从正面照射
   - 侧光：从侧面照射
   - 逆光：从背面照射
   - 顶光：从上方照射
   - 底光：从下方照射

2. **光线强度**：
   - 强光：高亮度，对比强烈
   - 中光：中等亮度，对比适中
   - 弱光：低亮度，对比柔和

3. **光线性质**：
   - 硬光：阴影清晰，对比强烈
   - 软光：阴影柔和，对比柔和

4. **光线色温**：
   - 暖光：3200K以下（黄、橙色）
   - 中性光：3200K-5600K（白色）
   - 冷光：5600K以上（蓝、白色）

### 光线设计模板

```
光线设计：
- 场号：SCENE_XXX
- 光源类型：[自然光/人工光/混合光]
- 光源方向：[顺光/侧光/逆光/顶光/底光]
- 光线强度：[强光/中光/弱光]
- 光线性质：[硬光/软光]
- 色温：[暖光/中性光/冷光]
- 光线效果：[效果描述]
```

### 光线设计示例

**输入**：
```
场景描述：夜晚城市天台，远处有霓虹灯闪烁，街灯投下长长的影子。
```

**输出**：
```
光线设计：
- 场号：SCENE_001
- 光源类型：混合光（月光 + 街灯 + 霓虹灯）
- 光源方向：侧光（街灯）+ 逆光（远处霓虹灯）
- 光线强度：中光
- 光线性质：软光（街灯散射）+ 硬光（霓虹灯直射）
- 色温：冷光（月光）+ 暖光（霓虹灯）
- 光线效果：长阴影，霓虹灯反射光晕，营造夜晚氛围
```

## 色彩基调

### 色彩基调分类

1. **暖色调**：
   - 红色、橙色、黄色
   - 营造温暖、热情、活力的氛围

2. **冷色调**：
   - 蓝色、青色、紫色
   - 营造冷静、冷静、神秘的氛围

3. **中性色调**：
   - 灰色、白色、黑色
   - 营造简洁、专业、高级的氛围

4. **混合色调**：
   - 暖色 + 冷色对比
   - 营造冲突、对比的氛围

### 色彩要素分析

1. **主色调**：
   - 场景的主要颜色
   - 占主导地位的色彩

2. **辅助色**：
   - 陪衬主色调的颜色
   - 增强色彩层次

3. **对比色**：
   - 与主色调形成对比的颜色
   - 增强视觉冲击

4. **色彩饱和度**：
   - 高饱和度：色彩鲜艳，视觉冲击强
   - 中饱和度：色彩自然，视觉舒适
   - 低饱和度：色彩柔和，视觉平和

5. **色彩明度**：
   - 高明度：明亮、轻盈
   - 中明度：平衡、稳重
   - 低明度：深沉、压抑

### 色彩基调模板

```
色彩基调：
- 场号：SCENE_XXX
- 主色调：[颜色]
- 辅助色：[颜色]
- 对比色：[颜色]
- 饱和度：[高/中/低]
- 明度：[高/中/低]
- 色彩效果：[效果描述]
```

### 色彩基调示例

**输入**：
```
场景描述：夜晚城市天台，远处霓虹灯闪烁，红色和蓝色的光芒交织。
```

**输出**：
```
色彩基调：
- 场号：SCENE_001
- 主色调：深蓝色（夜空）
- 辅助色：黑色（阴影）
- 对比色：红色和蓝色（霓虹灯）
- 饱和度：高（霓虹灯）+ 低（夜空）
- 明度：低（夜晚）
- 色彩效果：冷暖对比，色彩丰富，营造夜晚城市的繁华感
```

## 天气时间

### 天气类型分类

1. **晴朗**：
   - 阳光明媚，天空清澈
   - 营造明亮、积极的氛围

2. **多云**：
   - 云层较厚，光线柔和
   - 营造平和、中性的氛围

3. **阴天**：
   - 云层很厚，光线暗淡
   - 营造压抑、阴沉的氛围

4. **雨/雪**：
   - 天气恶劣，视线受限
   - 营造紧张、悲伤的氛围

5. **雾/霾**：
   - 视线模糊，氛围神秘
   - 营造神秘、朦胧的氛围

### 时间分类

1. **黎明**：
   - 日出前后，光线柔和
   - 营造希望、新生的氛围

2. **早晨**：
   - 日出后，光线明亮
   - 营造清新、活力的氛围

3. **中午**：
   - 日光强烈，阴影短
   - 营造清晰、强烈的氛围

4. **黄昏**：
   - 日落前后，光线温暖
   - 营造温暖、浪漫的氛围

5. **夜晚**：
   - 日落后，光线暗淡
   - 营造神秘、紧张的氛围

### 天气时间模板

```
天气时间：
- 场号：SCENE_XXX
- 天气：[晴朗/多云/阴天/雨/雪/雾/霾]
- 时间：[黎明/早晨/中午/黄昏/夜晚]
- 光线条件：[描述]
- 氛围效果：[描述]
```

### 天气时间示例

**输入**：
```
场景标题：第1场 夜 外 城市天台
```

**输出**：
```
天气时间：
- 场号：SCENE_001
- 天气：晴朗（无云）
- 时间：夜晚
- 光线条件：月光 + 街灯 + 霓虹灯
- 氛围效果：神秘、浪漫、紧张
```
