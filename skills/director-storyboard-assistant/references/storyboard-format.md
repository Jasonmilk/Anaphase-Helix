# 分镜表格式规范

## 目录
- 格式定义
- 字段说明
- 填写规则
- 完整示例

## 概览
本规范定义专业分镜表的标准格式，确保分镜信息的完整性和可读性。

## 格式定义

### 文件结构
```
========================================
           导演分镜表
========================================
剧本标题：[剧本名称]
导演风格：[风格名称]
画幅比例：[横屏16:9 / 竖屏9:16]
分段时长：[15秒]
生成时间：[YYYY-MM-DD HH:MM:SS]
========================================

[场景 1]
场号：SCENE_001
地点：[地点描述]
时间：[时间描述]
人物：[人物列表]

----------------------------------------
镜头号：SCENE_001_SHOT_001
景别：[特写/中景/全景/远景/大特写]
角度：[平视/俯视/仰视/荷兰角]
运动：[固定/推/拉/摇/移/跟/升降]
时长：[X秒]
画幅比例：[横屏16:9 / 竖屏9:16]
画面内容：
[详细画面描述]
对白：
[人物]：[对白内容]
服化道建议：
[服装/化妆/道具详细说明]
光影设计：
[主光方向、光比、色温]
摄影机逻辑：
[镜头选择、焦点控制、景深]
----------------------------------------

[重复以上镜头格式...]
========================================
```

## 字段说明

### 场景信息
- **场号**：SCENE_XXX，三位数字编号，从001开始
- **地点**：场景的具体地点（如：城市天台、咖啡馆内、森林边缘）
- **时间**：场景的时间（如：夜、日、黄昏、黎明）
- **人物**：出场人物列表，用顿号分隔

### 镜头信息
- 镜头号：SCENE_XXX_SHOT_XXX，场景号_镜头号，三位数字
- **画幅比例**：
  - 横屏16:9（默认）：传统电影电视格式，适合所有类型（电影、电视剧、真人短剧、AI漫剧、AI解说剧）
  - 竖屏9:16（触发词"竖屏"）：移动端竖屏格式，人物占比较高，以全景、中景、近景、特写、大特写为主
- **景别**：
  - 特写（CU）：面部表情、手部动作，距离1-2米
  - 中景（MS）：人物腰部以上，距离3-5米
  - 全景（FS）：人物全身及周围环境，距离5-10米
  - 远景（LS）：大范围场景，距离10米以上
  - 大特写（ECU）：眼睛、嘴唇等细节，距离0.5米内
- **角度**：
  - 平视：与人物视线平行
  - 俯视：从上向下拍摄，人物显得渺小
  - 仰视：从下向上拍摄，人物显得高大
  - 荷兰角：镜头倾斜15-45度，营造不稳定感
- **运动**：
  - 固定：摄影机静止
  - 推：摄影机向前移动，靠近主体
  - 拉：摄影机向后移动，远离主体
  - 摇：摄影机水平旋转
  - 移：摄影机横向移动
  - 跟：摄影机跟随移动的人物
  - 升降：摄影机垂直移动
- **时长**：所有分镜时长在0.1秒到15秒之间（Seedance2.0限制），支持0.1秒精度，具体时长由智能体根据剧情发展、影视剧类型和台词长度决定，详细规则如下：

#### 台词时长计算规则（核心规则，强制执行）

**计算公式**（重要）：
```
台词时长（秒）= 台词字数 ÷ 基础语速 ÷ 情绪系数
```

**基础语速标准**（字/秒）：
- **正常语速**：3.5字/秒（默认语速，适用于平静对话）
- **快速语速**：4.5字/秒（适用于争吵、紧张对话、快节奏场景）
- **慢速语速**：2.5字/秒（适用于深情表白、内心独白、悲伤表达）

**情绪语速系数**（重要）：
- **平静情绪**：1.0x（正常语速，无情绪波动）
- **轻微情绪**（喜悦、惊讶、好奇）：0.9x（语速略微变慢）
- **中等情绪**（激动、担忧、困惑）：0.7-0.8x（语速变慢，留出情绪表达空间）
- **强烈情绪**（愤怒、悲伤、恐惧）：0.5-0.6x（语速显著变慢，情绪表达强烈）
- **极慢表达**（内心独白、深情告白、绝望）：0.4-0.5x（语速极慢，情感极致表达）

**台词时长计算示例**：
```
示例1：平静对话
- 台词："我们改变不了过去，只能改变未来。"（13字）
- 情绪：平静（1.0x）
- 基础语速：3.5字/秒
- 计算：13 ÷ 3.5 ÷ 1.0 = 3.7秒

示例2：悲伤表达
- 台词："我在那个雨夜失去了一切。我的家人、我的爱人、我的希望。我以为时间会治愈一切，但痛苦永远不会消失。"（45字）
- 情绪：悲伤（0.5x）
- 基础语速：2.5字/秒（慢速语速）
- 计算：45 ÷ 2.5 ÷ 0.5 = 36秒 → 超过15秒上限，拆分为3个分镜
- 分镜1：12秒（前15字）
- 分镜2：12秒（中15字）
- 分镜3：12秒（后15字）

示例3：紧张争吵
- 台词："你根本不懂！我为了这个家付出了多少？每天工作到深夜，还要忍受你的指责！"（38字）
- 情绪：愤怒（0.6x）+ 紧张（快速语速4.5字/秒）
- 计算：38 ÷ 4.5 ÷ 0.6 = 14.1秒

示例4：内心独白
- 台词："我知道我应该放下，但心里的痛就像刀割一样。每一天都在想，如果当初没有那么做，一切会不会不同。"（46字）
- 情绪：内心独白（0.4x）
- 基础语速：2.5字/秒（慢速语速）
- 计算：46 ÷ 2.5 ÷ 0.4 = 46秒 → 拆分为4个分镜
- 分镜1：11.5秒（前11字）
- 分镜2：11.5秒（中12字）
- 分镜3：11.5秒（中12字）
- 分镜4：11.5秒（后11字）
```

#### 基础时长规则（辅助规则，仅在无台词时使用）
- 无对白动作戏：2-5秒
- 纯环境镜头：2-4秒
- 物品展示镜头：1-3秒
- 特效展示镜头：3-8秒

#### 对白时长调整规则（已被台词时长计算规则取代，保留作为参考）
**注意**：此规则已被"台词时长计算规则"取代，仅在无法判断情绪时作为参考。
- 每句对白至少分配2秒（正常语速）
- 情绪表达强烈的对白（愤怒、悲伤、恐惧）额外+1-2秒
- 快节奏对白（争吵、紧张对话）可适当压缩，但每句不少于1.5秒
- **情绪强度**：
  - 平静情绪：按台词长度分配时间
  - 激烈情绪：额外增加30-50%时长，留出情绪表达空间
  - 转折情绪：从平静到激烈或反之，额外+1秒过渡
- **单镜头上限**：单个镜头最长15秒，超过需分割为多个镜头

#### 台词拆分规则（重要，强制执行）

**核心强制规则**（最高优先级，强制执行）：
- **不得跳过任何"台词、旁白、内心独白"**：小说、剧本中的所有"台词、旁白、内心独白"必须完整呈现在各个结果表格中
- **严禁遗漏**：无论分镜时长如何限制，都不得遗漏、省略、压缩任何"台词、旁白、内心独白"的内容
- **自然顺延规则**：上一个分镜时长内没说完的"台词、旁白、内心独白"，必须自然顺延到下一个分镜内，直到"台词、旁白、内心独白"完全呈现在各个结果表格中
- **完整呈现规则**：所有"台词、旁白、内心独白"必须完整呈现，不得截断、不得省略、不得简化
- **分镜连续规则**：当一个"台词、旁白、内心独白"需要跨多个分镜时，这些分镜必须连续出现，中间不得插入其他无关内容
- **续接标记规则**：跨镜延续的"台词、旁白、内心独白"必须使用"..."和"（续）"标记，确保清晰标识续接关系

**拆分原则**（重要）：
- 长台词、旁白、内心独白可以自然拆分到上下连续的多个分镜中
- 符合现实影视剧的长台词/旁白/内心独白分镜处理逻辑
- 台词时长（按情绪语速计算）必须与分镜时长匹配
- 严禁出现"分镜只有2-5秒，台词却有20-40字"的情况

**拆分触发条件**（重要）：
- 台词时长（按情绪语速计算）超过单个分镜时长上限（15秒）
- 台词时长超过当前分镜的预留时长（如当前分镜2-5秒，但台词需要8秒以上）
- 台词字数超过当前分镜可容纳的字数（按情绪语速反推）

**拆分方式**（重要）：
1. **按语意单元拆分**（优先级最高）：
   - 优先在逗号、句号、问号、感叹号等标点符号处拆分
   - 确保每个分镜中的台词都是完整的语意单元
   - 避免在词语中间拆分（如"改变不"拆开）

2. **按情绪转折拆分**：
   - 在情绪转折点拆分（如从平静到愤怒）
   - 配合镜头切换，在不同景别中继续台词
   - 情绪转折处通常配合镜头切换增强表现力

3. **按镜头切换拆分**：
   - 配合镜头切换，在不同景别或角度中继续台词
   - 特写→中景→全景的切换中自然延续台词
   - 侧面→正面→侧面的切换中自然延续台词

**拆分标记**（重要）：
- 在台词/旁白/内心独白字段中使用特殊标记表示台词续接
- 使用"..."表示台词/旁白/内心独白跨镜延续
- 使用"（续）"表示承接上一个分镜的台词/旁白/内心独白
- 在台词/旁白/内心独白字段中明确标注拆分点

**拆分时长分配规则**（重要）：
- 根据台词/旁白/内心独白的情绪强度和语速分配时长
- 情绪强烈的部分分配较长时长（5-15秒）
- 情绪平缓的部分分配较短时长（3-8秒）
- 每个分镜的台词时长必须与分镜总时长匹配
- 分镜总时长 = 台词时长 + 动作时长 + 视觉表现时长（预留0.5-1秒）

**拆分示例**（重要）：

**示例1：长台词拆分（3个分镜）**
```
原台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！从那天晚上开始，我们就没有回头路了！再怎么挣扎都是徒劳的！"
字数：48字
情绪：悲伤愤怒（0.6x）
基础语速：3.5字/秒
总时长：48 ÷ 3.5 ÷ 0.6 = 22.9秒 → 拆分为3个分镜

分镜1（8秒）：主角特写，情绪平稳，眼神悲伤
台词：主角："我知道你恨我，我也恨我自己。但这一切都是命..."

分镜2（8秒）：镜头切换到侧脸，情绪开始激动，泪水滑落
台词：主角："（续）我们改变不了的！从那天晚上开始，我们就没有回头路了！"

分镜3（6.9秒）：镜头切回正面，情绪爆发，双手颤抖
台词：主角："（续）再怎么挣扎都是徒劳的！"
```

**示例2：长旁白拆分（4个分镜）**
```

字数：78字
情绪：平静叙述（0.9x）
基础语速：3.5字/秒
总时长：78 ÷ 3.5 ÷ 0.9 = 24.8秒 → 拆分为4个分镜

分镜1（6秒）：全景，村庄早晨，炊烟袅袅
旁白："在那个人来之前，我们以为生活就是这样的。日出而作，日落而息..."

分镜2（6秒）：中景，村民劳作，宁静祥和
旁白："（续）平静而简单。但他的出现改变了一切。"

分镜3（6.5秒）：特写，主角眼神变化，思考表情
旁白："（续）我们开始思考，开始质疑，开始反抗。"

```

  ```
- **拆分注意事项**：
  - 拆分后的台词要保持语意连贯，不破坏情感表达
  - 拆分点要配合镜头切换，增强视觉表现力

#### 旁白时长调整规则
- **旁白长度**：
  - 短旁白（1-2句）：3-5秒
  - 中等旁白（3-5句）：5-8秒
  - 长旁白（6句以上）：8-15秒
- **节奏控制**：
  - 快节奏旁白（解说、科普）：按语速分配，不额外增加时间
  - 慢节奏旁白（情感表达、氛围营造）：额外增加30-50%时长
- **画面配合**：
  - 画面变化频繁时，可适当缩短旁白时长
  - 画面静止或缓慢变化时，可延长旁白时长

#### 内心独白时长调整规则
- **独白长度**：
  - 短独白（1-2句）：3-5秒
  - 中等独白（3-5句）：5-10秒
  - 长独白（6句以上）：10-15秒
- **情绪强度**：
  - 普通独白：按独白长度分配时间
  - 强烈情绪独白（痛苦、悔恨、绝望）：额外增加50%时长
- **单镜头上限**：单个镜头最长15秒，超过需分割为多个镜头（配合特写切换）

#### 时长计算示例
```
示例1：简短对白（平静）
- 台词："我们改变不了过去，只能改变未来。"（1句）
- 基础时长：3秒
- 情绪调整：0秒（平静）
- 最终时长：3秒

示例2：长对白（情绪激烈）
- 台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！从那天晚上开始，我们就没有回头路了！再怎么挣扎都是徒劳的！"（4句）
- 基础时长：8秒
- 情绪调整：+3秒（激烈情绪）
- 最终时长：11秒

示例3：长独白（强烈情绪）
- 独白："我在那个雨夜失去了一切。我的家人、我的爱人、我的希望。我以为时间会治愈一切，但痛苦永远不会消失。每一天，每一夜，我都在想如果当初..."（6句）
- 基础时长：12秒
- 情绪调整：+6秒（50%，强烈情绪）
- 最终时长：18秒 → 超过15秒上限，分割为2个镜头
- 镜头1：10秒（前4句）
- 镜头2：8秒（后2句）
```

### 画面内容
详细描述画面中的所有元素：
- 人物位置、姿态、表情
- 环境细节、背景、道具
- 动作、运动、变化
- 特殊效果、光影变化

### 对白
标明说话人和对白内容，格式：
```
[人物]：[对白内容]
```
如果无声戏，标注：[无声]

### 服化道建议
- **服装**：人物的服装、配饰、颜色、质地
- **化妆**：人物的妆容、发型、伤妆等
- **道具**：场景中的关键道具、物品

示例：
```
服装：约翰穿着黑色皮夹克，内搭白色T恤，牛仔裤
化妆：玛莉淡妆，眼线略微晕染，营造疲惫感
道具：桌上的咖啡杯（半满）、墙上的挂钟（显示23:45）
```

### 光影设计
- **主光方向**：主光来源方向（如：左侧45度、顶光、背光）
- **光比**：亮部和暗部的亮度比（如：3:1、8:1）
- **色温**：光线的色温（如：3200K、5600K、混合色温）

示例：
```
主光方向：左侧45度，窗户光为主
光比：4:1，暗部保持层次

```
## 画幅模式构图规则

### 横屏16:9模式（默认）

**适用场景**：
- 所有类型默认使用横屏16:9模式
- 电影、电视剧、真人短剧、AI漫剧、AI解说剧
- 传统影视制作流程

**构图特点**：
- 传统影视剧风格
- 支持多人物构图
- 使用过肩镜头、正反打镜头等传统电影语言
- 适合展现环境和空间关系

**人物占比**：
- 特写：人物占画面40-50%
- 中景：人物占画面30-40%
- 全景：人物占画面20-30%
- 远景：人物占画面10-20%

### 竖屏9:16模式（触发词"竖屏"）

**适用场景**：
- 移动端竖屏观看
- 红果短剧平台
- 用户输入"竖屏"触发词时启用

**构图特点**：
- 人物在画面中占比较高
- 以全景、中景、近景、特写、大特写为主
- 强调人物情绪和表情
- 适配竖屏观看体验

**人物占比**：
- 特写：人物占画面60-70%
- 中景：人物占画50-60%
- 近景：人物占画45-55%
- 全景：人物占画35-45%
- 远景：人物占画25-35%

**构图布局**：
- 中心布局：人物居中，适合特写、中景
- 黄金分割布局：人物位于上1/3或下1/3位置，适合中景、全景
- 侧边布局：人物偏左或偏右，适合全景、远景

### 多人物构图规则

**横屏16:9模式**：
- 支持多人物同框
- 使用过肩镜头、正反打镜头
- 支持双人全景、三人全景等

**竖屏9:16模式**：
- 短剧（AI漫剧、AI真人剧、AI旁白剧）以单人分镜为主
- 多人物场景优先切割为多个单人镜头
- 对话场景每人一个镜头，交替切换
- 两人以上同框时，使用过肩镜头和正反打切换镜头
- 减少两人在同一画面内说话，避免AI生视频时口型匹配错误

## 填写规则

### 格式规范
- 使用UTF-8编码，确保中文正确显示
- 使用等号作为分隔线，保持视觉整齐
- 每个镜头用短横线分隔
- 场景和镜头编号保持连续性

### 内容要求
- 所有字段必须填写，不得留空
- 描述要具体、清晰，避免模糊表述
- 对白要准确，不得修改原文
- 技术参数要符合摄影实践

### 一致性要求
- 同一场景内的风格保持一致
- 人物的服装、妆容在不同场景中要连贯
- 光影设计要符合时间地点的逻辑
- 摄影机逻辑要符合导演风格
```
