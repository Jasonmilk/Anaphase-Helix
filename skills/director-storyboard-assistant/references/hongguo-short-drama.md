## 红果短剧平台简介

红果短剧是中国领先的短剧内容平台，提供海量短剧内容，涵盖真人短剧和AI漫剧两大类型。

**平台特点**：
- **默认横屏**：16:9横屏格式（适用于电影、电视剧、真人短剧、AI漫剧、AI解说剧）
- **竖屏触发**：9:16竖屏格式（当用户输入"竖屏"触发词时启用）
- **快节奏叙事**：每集1-3分钟，强情节、强冲突、强情绪
- **多样类型**：都市情感、古装玄幻、悬疑推理、喜剧搞笑等
- **创新形式**：真人短剧与AI漫剧并存，满足不同用户需求

**短剧类型分类**：
1. **真人短剧**：由真人演员出演，贴近传统影视
2. **AI漫剧**：由AI生成的动漫风格短剧，视觉风格独特
3. **AI解说漫**：动漫画面 + 旁白解说形式的漫剧，通过旁白讲述故事
4. **AI旁白漫**：极致节奏，剧本一行字对应一个分镜，强调快速视觉变化和高信息密度

## 短剧视觉特征概览

### 共同特征（真人短剧 & AI漫剧）

**画幅特点**：
- 默认横屏16:9：传统影视剧风格
- 竖屏触发9:16：人物占比较高，以全景、中景、近景、特写、大特写为主

**构图特点**：
- 横屏模式：支持多人物构图，使用过肩镜头、正反打镜头等传统电影语言
- 竖屏模式：人物居中或位于黄金分割点，人物占比较高
- 特写为主：人物面部特写占比高，强调情绪表达
- 快速切换：镜头切换频繁，保持观众注意力

**节奏特点**：
- 超快节奏：每分钟镜头切换15-30次
- 情绪跳跃：情绪变化快速且强烈
- 悬念设置：每集结尾留悬念，吸引继续观看

**色彩特点**：
- 高饱和度：色彩鲜艳，视觉冲击力强
- 对比强烈：明暗对比鲜明，增强戏剧性
- 风格化：根据剧情类型调整色调（暖色/冷色/复古等）

### 差异特征

**真人短剧**：
- 写实风格：追求真实感，贴近生活
- 光影自然：以自然光为主，少量人工光
- 表演真实：演员表情和动作自然

**AI漫剧**：
- 动漫风格：日系/韩系动漫风格
- 色彩鲜艳：高饱和度，色彩丰富
- 表情夸张：人物表情和动作夸张化
- 美型设计：人物形象精致，符合二次元审美

## 真人短剧风格（TOP100优秀作品）

### 都市情感类

#### 风格特征
- **场景**：现代都市、咖啡馆、办公室、家庭
- **色调**：暖色调为主，营造温馨感
- **光影**：柔和自然光，少量补光
- **镜头**：中景和特写为主，平视视角

- **视觉风格**：高对比度，冷色调转暖色调
- **镜头语言**：男主仰拍（强调强大），女主平视（强调平等）
- **色彩方案**：灰色西装 + 红色连衣裙，冷暖对比

- **视觉风格**：现代都市感，简洁明亮

### 真人短剧通用风格要素

#### 竖屏构图规范
```
主体位置：
- 主体居中：用于正式场合、情感表达
- 主体偏上：用于强调人物、突出表情
- 主体偏下：用于展现环境、场景
- 主体左右分割：用于双人对话、对比

画面比例：
- 人物特写：人物占画面60-70%
- 中景：人物占画面40-50%
- 全景：人物占画面30-40%
```

#### 镜头运动规范
```
推镜头：
- 缓慢推：营造紧张感、浪漫感
- 快速推：强调情绪、突出重点
- 急推：制造惊喜、惊吓效果

拉镜头：
- 缓慢拉：展现环境、营造孤独感
- 快速拉：制造距离感、强调变化

摇镜头：
- 水平摇：跟随人物、展现场景
- 垂直摇：强调高度、观察环境

跟拍：
- 前跟：跟随人物前进
- 后跟：跟随人物后退
- 侧跟：跟随人物移动
```

#### AI漫剧分镜特点

**单人分镜优先原则**：
- **单人构图占比>80%**：多人物场景优先切割为多个单人镜头
- **对白场景**：每人一个镜头，交替切换，避免同框
- **反应镜头**：一人说话时，另一人的反应单独成镜
- **9:16竖屏优化**：单人构图更适合竖屏观看体验

**单人分镜优势**：
- 清晰展示人物表情和动作
- 突出个体特征和风格化设计
- 便于AI生成高质量画面
- 控制镜头节奏，增强戏剧张力

**多人物场景处理方法**：
```
原场景（多人物同框）：
```
约翰和玛莉在海边
约翰：我爱你。
玛莉：我也爱你。
```

单人化处理：
```
镜头1：约翰特写，深情凝视（3秒）
镜头2：玛莉特写，羞涩微笑（3秒）
镜头3：约翰中景，伸出手（2秒）
镜头4：玛莉中景，握住手（2秒）
```

**构图规范**：
- 人物居中或黄金分割点
- 背景简洁，突出主体
- 9:16竖屏比例，头部预留空间
- 特写：人物占画面60-70%
- 中景：人物占画面40-50%
- 全景：人物占画面30-40%

**视觉风格**：
- 精致美型：人物形象精致，符合二次元审美
- 风格化：强烈的动漫/漫画风格
- 一致性：保持人物和场景的风格一致

镜头语言：
- 夸张角度：使用动漫中的夸张视角
- 动态构图：活泼的构图方式
- 特效丰富：大量使用视觉特效

色彩设计：
- 高饱和度：色彩鲜艳，视觉冲击力强
- 风格化色调：根据风格选择色调（日系/韩系/国漫）
- 色彩统一：保持整体色调一致性

动画效果：
- 流畅动画：AI生成流畅的动画效果
- 夸张表现：表情和动作夸张化
- 特效点缀：添加特效增强表现力
```

### AI解说漫风格（TOP100优秀作品）

#### AI解说漫特点

**形式特征**：
- **视觉形式**：动漫风格画面
- **音频形式**：旁白解说（无人物对白或极少对白）
- **叙事方式**：通过旁白讲述故事，画面配合叙事
- **节奏特点**：旁白节奏决定画面切换节奏
- **内容类型**：知识科普、历史故事、名著解读、影视解说、游戏攻略等

**与AI漫剧的区别**：
- **AI漫剧**：有完整剧情和人物对白，类似传统动漫
- **AI解说漫**：以旁白解说为主，画面配合叙事，无或少对白

#### AI解说漫风格分类

**单人分镜优先原则**：
- **主播/讲解人**：单人特写或中景，居中展示
- **被讲解内容**：单人镜头或物品特写，避免多元素混乱
- **场景切换**：每个场景聚焦一个主体
- **9:16竖屏优化**：单人构图更适合竖屏观看

**单人分镜应用**：
- 讲解镜头：讲解人特写/中景
- 内容镜头：物品/场景特写
- 示例镜头：单人演示或场景展示
- 强调镜头：重点内容特写

**构图规范**：
- 讲解人：特写占画面60-70%，中景占40-50%
- 物品/场景：特写占画面70-80%，全景占30-40%
- 文字标注：预留文字空间（上方或下方）
- 主体位置：居中或黄金分割点

**多元素场景处理**：
```
原场景（多元素同框）：
```
展示古代城市，包含宫殿、民居、市场
```

单人化处理：
```
镜头1：宫殿全景，宏大建筑（5秒）
镜头2：讲解人特写，介绍宫殿（3秒）
镜头3：民居特写，展示建筑风格（3秒）
镜头4：市场特写，展示商业活动（3秒）
镜头5：讲解人中景，总结城市特点（4秒）
```

### 长台词分镜处理

**长台词定义**：
- 超过10个字的对白
- 适用于AI漫剧、AI真人剧、AI旁白剧等短剧

**处理原则**：
- 在人物出现长台词时，优先开启其它聆听者的分镜或故事发生的环境大全景
- 避免长时间镜头单一不变
- 丰富镜头语言，增强画面表现力

**分镜切换方式**：

1. **说话人镜头（长台词开始）**：
   - 景别：特写或中景
   - 内容：展现说话人表情，开始对白
   - 时长：3-5秒

2. **聆听者镜头（长台词中间）**：
   - 景别：特写或中景
   - 内容：展现聆听者反应（点头、皱眉、凝视等）
   - 时长：3-5秒
   - 用途：丰富镜头语言，表现人物关系

3. **环境大全景（长台词中间）**：
   - 景别：远景或大全景
   - 内容：展现故事环境，营造氛围
   - 时长：3-5秒
   - 用途：展现环境，避免镜头单一

### 过肩镜头和正反打

**适用场景**：
- AI漫剧、AI真人剧、AI旁白剧等短剧
- 两人以上同时出现在画面中的对话场景
- 避免AI生视频时出现口型跟人物匹配错误的概率

**过肩镜头（Over-the-shoulder Shot）**：
- 定义：摄影机位于一个人物身后，透过这个人物的肩膀拍摄另一个人物
- 构图比例：前景人物（肩膀/头部）占15-25%，后景人物（说话人）占40-50%
- 用途：建立人物关系，增加画面层次
- Prompt示例：`过肩镜头，前景人物肩膀位于左侧，后景人物约翰位于中央，表情严肃，对话场景`

**正反打镜头（Shot-Reverse-Shot）**：
- 定义：两个镜头交替切换，分别拍摄两个说话人
- 构图原则：每人一个镜头，交替切换
- 用途：展现对话，避免口型匹配错误，控制对话节奏
- Prompt示例：
  ```
  镜头1：特写，约翰的面部特写，表情严肃，正在说话
  镜头2：特写，玛莉的面部特写，眼神含泪，正在说话
  镜头3：特写，约翰的面部特写，表情变得柔和，正在说话
  ```

- 环境展现：展现室内环境，但主体仍占主要位置
- 细节突出：突出关键道具和细节
- 氛围营造：通过布光和色调营造氛围

室外场景：
- 环境展现：展现室外环境，保持主体可见
- 天空处理：天空占画面上部20-30%
- 地面处理：地面占画面下部20-30%

特殊场景：
- 密闭空间：强调压迫感，使用特写和近景
- 开放空间：强调广阔感，使用全景和远景
- 过渡场景：使用中景，平衡环境和人物
```

### 短剧节奏设计

#### 镜头切换频率
```
快节奏段落（冲突、高潮）：
- 切换频率：每秒1-2次
- 镜头时长：0.5-1秒
- 情绪强度：高强度

中节奏段落（叙事、发展）：
- 切换频率：每2-3秒1次
- 镜头时长：2-3秒
- 情绪强度：中强度

慢节奏段落（情感、回忆）：
- 切换频率：每5-8秒1次
- 镜头时长：5-8秒
- 情绪强度：低强度
```

#### 情绪曲线设计
```
情绪强度等级：
- 等级1（平静）：平和、安宁，使用固定镜头、中景
- 等级3（轻度）：紧张、期待，使用推镜头、特写
- 等级5（中度）：悲伤、愤怒，使用快速切换、极端角度
- 等级7（高度）：恐惧、绝望，使用手持晃动、急速运动
- 等级9（极致）：震惊、崩溃，使用极端特写、快速剪辑

情绪切换：
- 渐进式：1→3→5→7→9，逐步升级
- 突发式：1→9，突然爆发
- 波动式：1→5→1→5，反复波动
- 反转式：9→1，突然反转
```

## 使用建议

### 风格选择
1. **真人短剧**：适用于现实题材、都市情感、古装等
2. **AI漫剧**：适用于奇幻、穿越、甜宠等题材
3. **日系动漫**：适用于日系风格、少年热血、奇幻冒险
4. **韩系漫画**：适用于韩系风格、都市言情、精致唯美
5. **国漫风格**：适用于古风、仙侠、武侠等题材
6. **Q版萌系**：适用于搞笑、甜宠、轻松向内容

### 分镜设计要点
1. **竖屏优先**：始终考虑9:16竖屏格式
2. **节奏紧凑**：短剧需要快节奏，保持观众注意力
3. **情绪强烈**：每个镜头都要有明确的情绪表达
4. **悬念设置**：每集结尾留悬念，吸引继续观看
5. **视觉冲击**：使用高饱和度色彩和强烈的对比
