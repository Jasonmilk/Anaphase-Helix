## 动作戏识别与分类

### 动作戏识别

**识别规则**：
- 剧本中包含人物之间的肢体冲突
- 剧本中包含战斗、打斗、搏斗等描述
- 剧本中包含武术动作、格斗技巧等描述
- 剧本中包含追逐、逃跑、躲藏等动作
- 剧本中包含枪战、爆炸、特技等动作

**触发条件**：
- 用户指定动作戏导演风格
- 剧本中包含动作戏描述
- 用户提及"动作"、"打斗"、"武术"等关键词

### 动作戏类型

**武侠动作**：
- 飞檐走壁、轻功、剑法、刀法
- 空中动作、吊威亚、飘逸动作
- 适用导演：程小东、徐克、袁和平

**功夫动作**：
- 传统武术、硬功、南派功夫
- 真实格斗、打击感、力量展示
- 适用导演：洪金宝、刘家良、袁和平

**动作喜剧**：
- 真实危险、道具利用、幽默元素
- 特技表演、滑稽动作
- 适用导演：成龙、周星驰

**枪战动作**：
- 双枪、慢镜头、白鸽意象
- 教堂场景、暴力美学
- 适用导演：吴宇森

**军事动作**：
- 军事战术、团队配合、现代武器
- 现代装备、战术动作
- 适用导演：林超贤、唐季礼

**现代动作**：
- 追逐戏、车战、特技
- 国际动作、大型场面
- 适用导演：唐季礼、林超贤

## 武术动作优化

### 人物角色定位

**角色类型识别**：
- 武侠高手：轻功深厚，剑法精湛，飘逸灵动
- 功夫大师：力量强大，硬功深厚，真实格斗
- 动作英雄：身体素质好，敏捷灵活，真实危险
- 军人特警：战术动作，团队配合，现代武器
- 喜剧角色：夸张动作，滑稽表演，道具利用

**人物能力评估**：
- 身体素质：力量、速度、敏捷、耐力
- 武术技能：武术类型、熟练程度、招牌动作
- 装备条件：武器类型、防御装备、道具利用
- 性格特征：冷静、暴躁、狡猾、正义

### 武术动作分类

**轻功动作**：
- 飞檐走壁、踏雪无痕、空中转体
- 适用角色：武侠高手、轻功高手
- 适用导演：程小东、徐克

**剑法动作**：
- 剑气、剑招、剑术、剑舞
- 适用角色：剑客、侠客、武林高手
- 适用导演：程小东、袁和平

**拳脚功夫**：
- 拳法、腿法、擒拿、格斗
- 适用角色：功夫大师、格斗专家
- 适用导演：洪金宝、刘家良、袁和平

**硬功展示**：
- 铁砂掌、金钟罩、铜皮铁骨
- 适用角色：硬功高手、传统武术家
- 适用导演：洪金宝、刘家良

**枪战动作**：
- 双枪、射击、换弹、翻滚
- 适用角色：警察、军人、特工
- 适用导演：吴宇森、林超贤

**特技动作**：
- 跳楼、飞车、爆炸、肉身挡子弹
- 适用角色：动作英雄、特技演员
- 适用导演：成龙、唐季礼

**道具动作**：
- 利用环境道具进行战斗
- 楼梯、椅子、桌子、酒瓶等
- 适用角色：动作英雄、喜剧角色
- 适用导演：成龙、周星驰

### 武术动作优化方法

**步骤1：动作识别**
- 从剧本中提取动作描述
- 识别动作类型和复杂程度
- 评估动作可行性

**步骤2：角色定位**
- 确定角色类型和能力
- 评估角色身体素质和武术技能
- 选择符合角色定位的武术动作

**步骤3：动作编排**
- 设计动作序列
- 添加动作细节和技巧
- 确保动作流畅连贯

**步骤4：导演风格匹配**
- 根据导演风格调整动作表现
- 添加导演风格特色元素
- 确保动作美学一致

**步骤5：镜头语言设计**
- 设计动作戏镜头语言
- 选择合适的景别和角度
- 设计动作节奏和剪辑

**示例**：
```
剧本描述：约翰一拳打倒敌人

动作优化：
- 角色定位：功夫大师（洪金宝风格）
- 动作编排：右直拳→左勾拳→右踢腿→膝撞→扫堂腿
- 动作细节：力量感强，打击感真实，身体晃动
- 镜头语言：快速剪辑，特写打击瞬间，慢镜头展示冲击力
```

## 动作戏节奏设计

### 动作戏节奏类型

**快节奏**：
- 用途：紧张、激烈、混乱的动作场面
- 时长：1-3秒/镜头
- 适用导演：洪金宝、成龙、林超贤
- 特征：快速剪辑、多角度切换、高频率动作

**中节奏**：
- 用途：平衡的动作场面
- 时长：3-6秒/镜头
- 适用导演：袁和平、唐季礼
- 特征：节奏适中、动作清晰、流畅切换

**慢节奏**：
- 用途：展现动作美学和细节
- 时长：5-10秒/镜头
- 适用导演：程小东、徐克、吴宇森
- 特征：慢镜头、动作细节、氛围营造

### 动作戏节奏变化

**节奏渐变**：
- 慢→快：从慢动作到快速动作，积累张力
- 快→慢：从快速动作到慢动作，释放张力

**节奏对比**：
- 快慢交替：快节奏和慢节奏交替，增强节奏感
- 紧松对比：紧张动作和舒缓动作交替，调节节奏

**节奏高潮**：
- 节奏加快：在高潮部分加快节奏，增强冲击力
- 节奏放慢：在高潮部分使用慢镜头，突出关键动作

### 动作戏时长计算

**动作场景时长计算**：
- 简单动作（单一招式）：1-2秒
- 中等动作（组合招式）：2-4秒
- 复杂动作（连贯动作）：3-5秒
- 高潮动作（关键打击）：4-7秒

**示例**：
```
动作序列：右直拳→左勾拳→右踢腿→膝撞

时长分配：
- 右直拳：2秒（快速出拳）
- 左勾拳：2秒（快速反击）
- 右踢腿：3秒（踢腿动作）
- 膝撞：4秒（高潮动作，冲击力强）

总时长：11秒
```
