## 情绪类型定义

### 情绪分类系统
根据心理学和影视理论，定义以下7种基本情绪类型：

#### 1. 平静（Calm）
- **特征**：情绪平稳、安宁、无显著波动
- **强度**：0-2（低强度）
- **视觉表现**：自然光线、稳定构图、缓慢运动
- **适用场景**：日常对话、环境描写、过渡段落

#### 2. 紧张（Tension）
- **特征**：压力感、悬念、期待
- **强度**：3-5（中低强度）
- **视觉表现**：快速剪辑、不稳定构图、手持运动
- **适用场景**：追逐前奏、冲突酝酿、等待时刻

#### 3. 悲伤（Sadness）
- **特征**：失落、哀伤、绝望
- **强度**：3-6（中强度）
- **视觉表现**：冷色调、低对比度、慢镜头
- **适用场景**：离别、死亡、挫折、回忆

#### 4. 愤怒（Anger）
- **特征**：愤怒、爆发、对抗
- **强度**：5-8（中高强度）
- **视觉表现**：快速剪辑、强烈对比、手持运动
- **适用场景**：冲突、争吵、对抗、爆发

#### 5. 恐惧（Fear）
- **特征**：害怕、惊慌、无助
- **强度**：6-9（高强度）
- **视觉表现**：阴影、特写、快速运动、不稳定构图
- **适用场景**：威胁、危险、恐怖、未知

#### 6. 喜悦（Joy）
- **特征**：快乐、兴奋、满足
- **强度**：4-7（中高强度）
- **视觉表现**：暖色调、明亮光线、流畅运动
- **适用场景**：成功、团聚、庆祝、发现

#### 7. 悬疑（Suspense）
- **特征**：不确定、猜测、好奇
- **强度**：4-6（中强度）
- **视觉表现**：缓慢推镜头、特写、低角度
- **适用场景**：谜题、悬念、揭示、转折

## 情绪曲线绘制

### 分析方法
1. **分段阅读**：按15秒分段阅读剧本
2. **识别情绪**：根据对白、动作、环境判断情绪类型
3. **评估强度**：根据情绪的激烈程度评分（0-10）
4. **记录节点**：记录每个时间点的情绪类型和强度

### 情绪曲线格式
```
时间（秒）| 情绪类型 | 强度 | 关键要素
---------|---------|------|---------
0-15     | 平静    | 1    | 夜晚城市天台，约翰站在边缘
15-30    | 悬疑    | 4    | 约翰开始说话，远处传来声音
30-45    | 悲伤    | 5    | 玛莉回应，提及过去
45-60    | 紧张    | 6    | 警报声响起，约翰转身
```

### 情绪曲线图描述
使用文字描述情绪曲线的形状和趋势：

**示例**：
```
情绪曲线：
[平静0-15] → [悬疑15-30] → [悲伤30-45] → [紧张45-60]

曲线特征：
- 开端：平静低强度，建立场景氛围
- 发展：悬疑逐步上升，引入冲突
- 高潮：悲伤峰值，情感爆发
- 结尾：紧张急剧上升，留下悬念

整体趋势：从平静到紧张，情绪逐步升级，最终达到高潮
```

### 情绪节奏分析报告
```
情绪节奏分析报告

1. 整体情绪走势
   - 开端（0-15秒）：平静，情绪强度1
   - 发展（15-30秒）：悬疑，情绪强度4，上升+3
   - 发展（30-45秒）：悲伤，情绪强度5，上升+1
   - 高潮（45-60秒）：紧张，情绪强度6，上升+1

2. 情绪转折点
   - 15秒：平静 → 悬疑，转折原因：约翰开始说话
   - 30秒：悬疑 → 悲伤，转折原因：玛莉提及过去
   - 45秒：悲伤 → 紧张，转折原因：警报声响起

3. 情绪峰值
   - 最高情绪：紧张（强度6）
   - 出现时间：45-60秒
   - 峰值原因：警报声触发紧张情绪

4. 情绪连贯性
   - 情绪转换流畅，无明显跳跃
   - 情绪发展符合逻辑：平静 → 悬疑 → 悲伤 → 紧张
   - 整体情绪节奏紧凑，逐步升级

5. 建议调整
   - 30-45秒情绪上升较缓，可增加对白强度
   - 结尾情绪峰值可进一步提升至7-8，增强悬念
```

## Prompt生成模板

### Prompt结构
多参生视频Prompt包含三个部分：
```
[视觉描述]，[摄影机参数]，[音效参数]
```

**详细展开结构**：
```
[景别] + [角度]，[画面内容]，[动作描述]，[运镜方式]，[氛围音乐]，[音效]，[情绪氛围]，[光影效果]，[色彩风格]
```

### 视觉描述模板

#### 场景描述
```
[时间][地点]，[环境细节]，[天气/光线条件]
```

**示例**：
```
夜晚城市天台，远处城市天际线，霓虹灯闪烁
黎明森林边缘，晨雾弥漫，露珠闪烁
午后咖啡馆内，阳光透过窗户，尘埃飞舞
```

#### 人物描述
```
[人物姿态]，[人物表情]，[服装细节]
```

**示例**：
```
人物背对摄影机站在边缘，身体微微前倾
人物侧脸特写，眼角有泪光，嘴唇颤抖
人物全身，双手插兜，眼神坚定
```

#### 动作描述
```
[动作类型]，[运动方向]，[速度]
```

**示例**：
```
快速转身，看向远方，动作突然
缓慢向前走，步伐沉重，速度缓慢
挥手告别，手臂抬起，速度适中
```

### Prompt生成规则

#### 规则1：视觉描述要具体
- 不要写："一个人在看风景"
- 要写："一个中年男子背对摄影机，站在高楼边缘，俯瞰城市夜景"

#### 规则2：风格标签要匹配导演风格
- 诺兰风格：高对比度、冷色调、科幻感
- 王家卫风格：浓烈色彩、慢镜头、视觉抒情
- 经典好莱坞：自然色调、平衡构图、清晰可见

#### 规则3：技术参数要合理
- 分辨率：8K是上限，根据实际需求选择
- 光影：符合场景时间地点的逻辑
- 质量：不要过度堆砌标签，保持简洁

#### 规则4：情绪标签要匹配情绪分析
- 平静：柔和光线、自然色调
- 紧张：快速运动、不稳定构图
- 悲伤：冷色调、低对比度
- 恐惧：阴影、特写、黑暗

#### 规则5：保持一致性
- 同一场景内的Prompt风格要保持一致
- 人物的服装、妆容在不同Prompt中要连贯
- 光影设计要符合时间地点的逻辑
