# 角色设定提取

## 目录
- 角色外貌提取
- 服装设定提取
- 气质特征提取
- 服装变化追踪

## 概览
本文档提供角色设定提取的完整方法论，用于从剧本中自动提取角色的外貌、服装、气质等视觉化信息，并追踪多场次的服装变化。

## 角色外貌提取

### 外貌信息提取模板

```
角色外貌：
- 角色名：[角色名]
- 性别：[男/女]
- 年龄：[年龄范围]
- 身高：[身高范围，可选]
- 体型：[瘦/标准/胖/肌肉型，可选]
- 发型：[发型描述]
- 发色：[发色描述]
- 面部特征：[特征描述]
- 特殊标记：[疤痕、纹身等，可选]
```

### 外貌提取规则

1. **从对白和描述中提取**：
   - 剧本中的直接描述
   - 他人对角色的评价
   - 角色自我描述

2. **外貌特征分类**：
   - **基本特征**：性别、年龄、身高、体型
   - **面部特征**：发型、发色、眼睛、鼻子、嘴巴
   - **身体特征**：身材、皮肤、特殊标记

3. **外貌描述示例**：
   - "她有一头长发" → 发型：长发
   - "他看起来很年轻" → 年龄：20-30岁
   - "她身材苗条" → 体型：瘦

### 外貌提取示例

**输入**：
```
场景描述：玛莉是一个年轻女孩，留着长发，身材苗条。
约翰：你看起来很年轻。
玛莉：我今年25岁。
```

**输出**：
```
角色外貌：
- 角色名：玛莉
- 性别：女
- 年龄：25岁
- 身高：未知
- 体型：瘦
- 发型：长发
- 发色：未知
- 面部特征：未知
- 特殊标记：未知
```

## 服装设定提取

### 服装信息提取模板

```
服装设定：
- 角色名：[角色名]
- 场次：SCENE_XXX
- 上衣：[描述]
- 下装：[描述]
- 鞋子：[描述]
- 配饰：[描述]
- 颜色：[主要颜色]
- 风格：[休闲/正式/运动/古装等]
```

### 服装提取规则

1. **从剧本描述中提取**：
   - 直接的服装描述
   - 通过场景推断服装
   - 通过角色身份推断服装

2. **服装分类**：
   - **上衣**：衬衫、T恤、外套、连衣裙等
   - **下装**：裤子、裙子、短裤等
   - **鞋子**：运动鞋、皮鞋、高跟鞋等
   - **配饰**：眼镜、项链、手表、帽子等

3. **服装风格分类**：
   - **休闲**：T恤、牛仔裤、运动鞋
   - **正式**：西装、正装、皮鞋
   - **运动**：运动服、运动鞋
   - **古装**：汉服、古装、古装鞋

### 服装提取示例

**输入**：
```
场景描述：约翰穿着黑色西装，打着领带。玛莉穿着白色连衣裙。
```

**输出**：
```
服装设定（约翰）：
- 角色名：约翰
- 场次：SCENE_001
- 上衣：黑色西装
- 下装：西裤
- 鞋子：皮鞋
- 配饰：领带
- 颜色：黑色
- 风格：正式

服装设定（玛莉）：
- 角色名：玛莉
- 场次：SCENE_001
- 上衣：白色连衣裙
- 下装：连衣裙
- 鞋子：高跟鞋
- 配饰：无
- 颜色：白色
- 风格：正式/优雅
```

## 气质特征提取

### 气质信息提取模板

```
气质特征：
- 角色名：[角色名]
- 气质类型：[温柔/霸气/忧郁/活泼/冷漠/稳重等]
- 性格特点：[特点描述]
- 行为习惯：[习惯描述]
- 情绪特点：[情绪表现]
```

### 气质提取规则

1. **从对白和描述中提取**：
   - 对白语气
   - 行为描述
   - 他人评价

2. **气质类型分类**：
   - **温柔**：语气温和，行为优雅
   - **霸气**：语气强势，行为果断
   - **忧郁**：语气低沉，行为缓慢
   - **活泼**：语气轻快，行为活跃
   - **冷漠**：语气平淡，行为疏离
   - **稳重**：语气沉稳，行为稳重

### 气质提取示例

**输入**：
```
约翰：我们改变不了过去。（语气低沉）
玛莉：但你说过...（语气犹豫）
约翰转身走向边缘，动作缓慢。
玛莉眼中含泪，表情悲伤。
```

**输出**：
```
气质特征（约翰）：
- 角色名：约翰
- 气质类型：忧郁/沉稳
- 性格特点：内敛、沉稳、有责任感
- 行为习惯：动作缓慢、深思熟虑
- 情绪特点：情绪压抑、不易表露

气质特征（玛莉）：
- 角色名：玛莉
- 气质类型：温柔/感性
- 性格特点：感性、细腻、重感情
- 行为习惯：情绪外露、善于表达
- 情绪特点：情绪丰富、易受影响
```

## 服装变化追踪

### 服装变化追踪表

```
服装变化追踪表：

角色名：[角色名]

场次 | 上衣 | 下装 | 鞋子 | 配饰 | 颜色 | 风格 | 变化说明
-----|------|------|------|------|------|------|----------
SCENE_001 | 黑色西装 | 西裤 | 皮鞋 | 领带 | 黑色 | 正式 | 初始服装
SCENE_002 | 白色衬衫 | 西裤 | 皮鞋 | 领带 | 白色 | 正式 | 脱掉外套
SCENE_003 | 休闲T恤 | 牛仔裤 | 运动鞋 | 无 | 蓝色 | 休闲 | 换上便装
```

### 服装变化追踪规则

1. **记录每场次的服装**：
   - 从剧本中提取服装描述
   - 标注服装变化
   - 记录变化原因（可选）

2. **服装一致性检查**：
   - 检查服装变化的合理性
   - 检查服装是否符合场景
   - 检查服装是否符合角色身份

3. **服装变化类型**：
   - **无变化**：服装与上一场相同
   - **部分变化**：换掉部分衣物（如脱掉外套）
   - **完全变化**：完全换装
   - **风格变化**：服装风格改变（正式→休闲）

### 服装变化追踪示例

**输入剧本**：
```
第1场 夜 外 天台
约翰穿着黑色西装，打着领带。

第2场 夜 内 公寓
约翰脱掉西装外套，穿着白衬衫。

第3场 日 外 公园
约翰换上了休闲装，穿着T恤和牛仔裤。
```

**输出**：
```
服装变化追踪表（约翰）：

场次 | 上衣 | 下装 | 鞋子 | 配饰 | 颜色 | 风格 | 变化说明
-----|------|------|------|------|------|------|----------
SCENE_001 | 黑色西装 | 西裤 | 皮鞋 | 领带 | 黑色 | 正式 | 初始服装
SCENE_002 | 白色衬衫 | 西裤 | 皮鞋 | 领带 | 白色 | 正式 | 脱掉外套
SCENE_003 | 休闲T恤 | 牛仔裤 | 运动鞋 | 无 | 蓝色 | 休闲 | 换上便装

服装变化分析：
- 第1场→第2场：部分变化（脱掉外套），仍保持正式风格
- 第2场→第3场：完全变化（换上便装），风格从正式变为休闲
- 服装变化符合剧情发展（从工作场景到休闲场景）
```
