## 概览
本文档提供多参数生视频提示词生成的完整规范，用于生成包含摄影机参数（景别、角度、运镜）和音效参数（氛围音乐、音效）的完整提示词，适用于AI视频生成工具。

## 提示词结构

### 提示词结构模板

```
[视觉描述]，[摄影机参数]，[音效参数]，[技术参数]
```

**详细展开模板**：
```
[景别] + [角度]，[画面内容]，[动作描述]，[运镜方式]，[氛围音乐]，[音效]，[情绪氛围]，[光影效果]，[色彩风格]
```

**短剧提示词模板**（AI漫剧、AI真人剧、AI旁白剧）：
```
[景别] + [角度]，[画面内容]，[动作描述]，[运镜方式]，[氛围音乐]，[音效]，[情绪氛围]，[光影效果]，[色彩风格]，保持人物一致性不变、保持场景一致性不变
```

### 提示词要素

1. **景别**：镜头的拍摄距离（特写、中景、全景、远景、大特写等）
2. **角度**：摄影机的拍摄角度（平视、俯视、仰视、荷兰角、过肩镜头等）
3. **画面内容**：画面中的主要元素
4. **动作描述**：人物或物体的动作
5. **运镜方式**：摄影机的运动方式（固定、推镜头、拉镜头、摇镜头、跟拍、手持晃动等）
6. **氛围音乐**：背景音乐的类型、情绪、节奏（新增）
7. **音效**：环境音、动作音、特殊音效（新增）
8. **情绪氛围**：画面传达的情绪和氛围
9. **光影效果**：光线的类型和效果
10. **色彩风格**：色彩的基调和风格
11. **画幅比例**：横屏16:9或竖屏9:16（可选，默认横屏）

## 画幅比例识别

### 默认规则
- **默认模式**：横屏16:9模式，Prompt中不包含画幅比例标注，或标注"横屏16:9"
- **竖屏触发**：当用户输入包含"竖屏"触发词时，Prompt中标注"竖屏9:16"或"竖屏构图"

### Prompt模板更新

**横屏16:9模式（默认）**：
```
[景别] + [角度]，[画面内容]，[动作描述]，[运镜方式]，[氛围音乐]，[音效]，[情绪氛围]，[光影效果]，[色彩风格]，横屏16:9
```

**竖屏9:16模式（触发词"竖屏"）**：
```
[景别] + [角度]，[画面内容]，[动作描述]，[运镜方式]，[氛围音乐]，[音效]，[情绪氛围]，[光影效果]，[色彩风格]，竖屏9:16
```

### 示例

**横屏16:9示例（基础）**：
```
中景 + 平视，约翰和玛莉在天台对话，约翰表情严肃，玛莉眼含泪水，固定镜头，悲伤氛围音乐，环境音，悲伤情绪，月光照明，冷蓝色调，横屏16:9
```

**横屏16:9示例（含完整参数）**：
```
特写 + 仰视，约翰的面部特写，表情痛苦，缓慢推镜头，紧张氛围音乐，心跳声，悲伤情绪，柔光照明，冷蓝色调，横屏16:9
```

**竖屏9:16示例（短剧）**：
```
特写 + 过肩镜头，玛莉的侧面特写，哭泣，跟拍，悲伤氛围音乐，抽泣声，悲伤情绪，柔光照明，冷蓝色调，竖屏9:16，保持人物一致性不变、保持场景一致性不变
```

## 景别描述

### 景别分类

1. **大特写（ECU）**：
   - 范围：眼睛、嘴唇、手部细节
   - 用途：强调细节、表现情绪
   - 描述词：眼睛特写、嘴唇特写、手部特写

2. **特写（CU）**：
   - 范围：人物面部、上半身
   - 用途：表现人物表情和情绪
   - 描述词：面部特写、上半身特写

3. **中景（MS）**：
   - 范围：人物腰部以上
   - 用途：表现人物关系和动作
   - 描述词：中景、腰部以上

4. **全景（FS）**：
   - 范围：人物全身及周围环境
   - 用途：展现完整场景和人物关系
   - 描述词：全景、全身

5. **远景（LS）**：
   - 范围：大范围场景
   - 用途：展现环境和氛围
   - 描述词：远景、大远景

### 景别描述示例

**大特写示例**：
```
眼睛特写，约翰的瞳孔放大，眼神恐惧
```

**特写示例**：
```
面部特写，玛莉的眼含泪水，表情悲伤
```

**中景示例**：
```
中景，约翰和玛莉在天台对话
```

**全景示例**：
```
全景，约翰和玛莉在天台，远处城市天际线
```

**大远景示例**：
```
大远景，城市夜景，高楼林立，灯光闪烁
```

## 角度描述

### 角度分类

1. **平视（Eye Level）**：
   - 定义：摄影机与被摄主体视线平齐
   - 用途：客观、真实、平衡
   - 描述词：平视、正面平视、侧面平视

2. **俯视（High Angle）**：
   - 定义：摄影机高于被摄主体
   - 用途：展现环境、弱化主体、压迫感
   - 描述词：俯视、上帝视角、俯拍

3. **仰视（Low Angle）**：
   - 定义：摄影机低于被摄主体
   - 用途：强调主体高大、威严、力量
   - 描述词：仰视、仰拍、低角度

4. **荷兰角（Dutch Angle）**：
   - 定义：摄影机倾斜，地平线不水平
   - 用途：不安、紧张、混乱
   - 描述词：倾斜镜头、荷兰角、不稳定构图

5. **过肩镜头（Over-the-Shoulder）**：
   - 定义：摄影机在人物肩膀后方
   - 用途：对话场景、空间关系
   - 描述词：过肩镜头、肩后视角

6. **第一人称视角（POV）**：
   - 定义：以人物视角拍摄
   - 用途：代入感、主观体验
   - 描述词：第一人称视角、POV、主观视角

7. **鸟瞰（Bird's Eye）**：
   - 定义：摄影机垂直向下拍摄
   - 用途：展现整体布局、位置关系
   - 描述词：鸟瞰、俯瞰、垂直俯拍

### 角度描述示例

**平视示例**：
```
平视，约翰的表情清晰可见，客观视角
```

**俯视示例**：
```
俯视，约翰在天台显得渺小，城市夜景作为背景
```

**仰视示例**：
```
仰视，玛莉显得高大，压迫感强烈
```

**荷兰角示例**：
```
倾斜镜头，地平线倾斜，紧张不安的氛围
```

**过肩镜头示例**：
```
过肩镜头，从约翰肩膀后方拍摄玛莉的表情
```

**第一人称视角示例**：
```
第一人称视角，透过约翰的眼睛看玛莉
```

**鸟瞰示例**：
```
鸟瞰，从高空俯瞰城市街道，车流如织
```

## 构图描述

### 构图分类

1. **中心构图**：
   - 主体居中
   - 用途：突出主体，稳定感
   - 描述词：主体居中、中心构图

2. **三分法构图**：
   - 主体位于黄金分割点
   - 用途：平衡美感
   - 描述词：三分法构图、黄金分割

3. **对角线构图**：
   - 主体沿对角线分布
   - 用途：动态感、运动感
   - 描述词：对角线构图、斜线构图

4. **对称构图**：
   - 左右对称
   - 用途：稳定、庄重
   - 描述词：对称构图、左右对称

5. **框架构图**：
   - 利用前景形成框架
   - 用途：聚焦主体，层次感
   - 描述词：框架构图、前景框架

6. **低角度构图**：
   - 低角度仰拍
   - 用途：强调主体高大、威严
   - 描述词：低角度仰拍、仰视

7. **高角度构图**：
   - 高角度俯拍
   - 用途：展现环境、缩小主体
   - 描述词：高角度俯拍、俯视

### 构图描述示例

```
中心构图，约翰居中站立
三分法构图，约翰位于画面右侧
对角线构图，约翰从左下向右上运动
低角度仰拍，约翰显得高大威严
高角度俯拍，展现天台的广阔
```

## 单人构图指导

### 单人构图原则

**适用场景**：
- 红果短剧（真人短剧、AI漫剧、AI旁白漫剧）
- 对白场景（每人独立镜头）
- 情绪表达场景（强调个体情绪）
- 9:16竖屏格式

**构图优势**：
- 清晰展示人物情绪
- 突出个体特征
- 适应竖屏观看体验
- 便于剪辑节奏控制

### 单人构图类型

1. **单人特写**：
   - 范围：人物面部或上半身
   - 用途：强调表情、情绪、对白
   - 描述词：人物面部特写、上半身特写、单人特写
   - 画面：背景虚化，人物居中或偏黄金分割点

2. **单人中景**：
   - 范围：人物腰部以上
   - 用途：表现对白、动作
   - 描述词：单人中景、腰部以上
   - 画面：人物居中，适度背景

3. **单人全景**：
   - 范围：人物全身
   - 用途：展现人物与场景关系
   - 描述词：单人全景、全身
   - 画面：人物居中或偏侧，展现环境

4. **单人远景**：
   - 范围：人物在广阔环境中
   - 用途：孤独感、距离感
   - 描述词：单人远景、渺小身影
   - 画面：人物在画面中较小，环境占主导

### 单人构图布局（9:16竖屏）

**中心布局**：
- 人物居中
- 适合：特写、中景
- 优势：稳定、突出

**黄金分割布局**：
- 人物位于黄金分割点（上1/3或下1/3位置）
- 适合：中景、全景
- 优势：动感、平衡

**侧边布局**：
- 人物偏左或偏右
- 适合：全景、远景
- 优势：留白、空间感

### 多人物场景的单人化处理

**切割镜头原则**：
- 对话场景：每人一个镜头，交替切换
- 反应镜头：一人说话时，另一人的反应单独成镜
- 过肩镜头：保留少量对方背影，主要展示说话人

**示例处理**：

**原场景（多人物同框）**：
```
约翰和玛莉在咖啡厅对话
约翰：我们分手吧。
玛莉：为什么？
```

**单人化处理**：
```
镜头1：约翰特写，表情冷漠
镜头2：玛莉特写，眼中含泪
镜头3：约翰中景，看向别处
镜头4：玛莉特写，质问的神情
```

### 红果短剧单人构图特殊规则

**真人短剧**：
- 以特写和中景为主，突出演员表情
- 镜头切换频繁，每5-8秒切换一次
- 人物居中或黄金分割点，背景简洁

**AI漫剧**：
- 单人构图比例>80%
- 多人物场景切割为多个单人镜头
- 每个镜头清晰展示一个人物的动作和表情

**AI解说漫**：
- 主播/讲解人：单人特写或中景
- 被讲解内容：单人镜头或物品特写
- 避免多人物同时出现

单人中景，玛莉位于画面左侧，背景简洁

## 过肩镜头

### 过肩镜头定义

**什么是过肩镜头**：
- 摄影机位于一个人物身后，透过这个人物的肩膀拍摄另一个人物
- 常用于对话场景，展现说话人
- 保留前景人物的背影或侧脸作为前景元素

**适用场景**：
- 两人对话场景
- 采访场景
- 会议场景
- 面试场景

### 过肩镜头构图规则

**构图比例**：
- 前景人物（肩膀/头部）：占画面15-25%
- 后景人物（说话人）：占画面40-50%
- 背景：占画面25-45%

**人物位置**：
- 前景人物：位于画面左侧或右侧边缘，肩膀位于画面下1/3位置
- 后景人物：位于画面中央或黄金分割点，面向前景人物

**景别选择**：
- 前景：中景或中近景，展现肩膀和部分头部
- 后景：中景或近景，清晰展现说话人表情

### 过肩镜头Prompt描述

**横屏16:9模式**：
```
过肩镜头，前景人物肩膀位于画面左侧，后景人物约翰位于画面中央，表情严肃，固定镜头，对话场景，侧光照明，室内色调，横屏16:9，保持人物一致性不变、保持场景一致性不变
```

**竖屏9:16模式**：
```
过肩镜头，前景人物肩膀位于画面左侧边缘，后景人物玛莉位于画面中央，眼神含泪，固定镜头，对话场景，柔光照明，暖色调，竖屏9:16，保持人物一致性不变、保持场景一致性不变
```

### 过肩镜头优势

- 建立人物关系：通过前景人物的存在，暗示两人之间的对话关系
- 增加画面层次：前景和后景形成空间层次
- 避免口型匹配错误：主要展现说话人，减少AI生视频时的口型问题

## 正反打镜头

### 正反打镜头定义

**什么是正反打镜头**：
- 两个镜头交替切换：一个镜头拍摄人物A，另一个镜头拍摄人物B
- 常用于对话场景，交替展现两个说话人
- 可以是特写、中景或近景

**适用场景**：
- 两人对话场景
- 争论场景
- 交流场景
- 情感表达场景

### 正反打镜头构图规则

**交替原则**：
- 镜头1：人物A说话（特写/中景）
- 镜头2：人物B说话（特写/中景）
- 镜头3：人物A说话（特写/中景）
- 镜头4：人物B说话（特写/中景）
- 循环交替

**景别一致性**：
- 人物A和人物B使用相同景别（特写/中景）
- 保持视觉一致性
- 便于剪辑节奏控制

**角度一致性**：
- 人物A使用平视或俯视
- 人物B使用平视或仰视
- 建立对话关系

### 正反打镜头Prompt描述

**镜头1（人物A说话）**：
```
特写，约翰的面部特写，表情严肃，眼神坚定，固定镜头，对话场景，侧光照明，冷色调，横屏16:9，保持人物一致性不变、保持场景一致性不变
```

**镜头2（人物B说话）**：
```
特写，玛莉的面部特写，眼中含泪，表情悲伤，固定镜头，对话场景，侧光照明，暖色调，横屏16:9，保持人物一致性不变、保持场景一致性不变
```

**镜头3（人物A说话）**：
```
特写，约翰的面部特写，眼神变得柔和，固定镜头，对话场景，柔光照明，暖色调，横屏16:9，保持人物一致性不变、保持场景一致性不变
```

### 正反打镜头优势

- 避免口型匹配错误：单人镜头，AI生视频时不会出现口型混淆
- 强调人物表情：特写镜头清晰展现人物情绪
- 控制对话节奏：通过镜头切换控制对话节奏
- 增强戏剧张力：快速切换营造紧张感

## 聆听镜头

### 聆听镜头定义

**什么是聆听镜头**：
- 在多人对话场景中，展现人物聆听状态的反应镜头
- 说话人物镜头后，插入聆听人物镜头
- 表现聆听人物的情绪和反应

**适用场景**：

## 运镜描述

### 运镜方式分类

1. **固定镜头**：
   - 摄影机固定不动
   - 用途：稳定观察，表现静态
   - 描述词：固定镜头、静止

2. **推镜头**：
   - 摄影机向前移动
   - 用途：强调主体，增强紧张感
   - 描述词：推镜头、缓慢推、快速推

3. **拉镜头**：
   - 摄影机向后移动
   - 用途：展现环境，营造距离感
   - 描述词：拉镜头、缓慢拉、快速拉

4. **摇镜头**：
   - 摄影机水平旋转
   - 用途：跟随运动，展现场景
   - 描述词：摇镜头、左右摇、快速摇

5. **移镜头**：
   - 摄影机横向移动
   - 用途：跟随人物，平行运动
   - 描述词：移镜头、左右移动、跟拍

6. **升降镜头**：
   - 摄影机垂直移动
   - 用途：展现高度，营造空间感
   - 描述词：升降镜头、上升、下降

7. **跟拍镜头**：
   - 摄影机跟随人物移动
   - 用途：增强代入感
   - 描述词：跟拍、前跟、后跟、侧跟

### 运镜描述示例

```
固定镜头，约翰静止站立
推镜头，缓慢推向约翰的面部
拉镜头，展现周围环境
摇镜头，跟随约翰转身
跟拍镜头，跟随约翰走向边缘
```

## 音效描述

### 音效分类

1. **环境音（Ambient Sound）**：
   - 定义：环境背景音
   - 用途：营造环境氛围
   - 描述词：城市环境音、森林环境音、室内环境音、风声、雨声、车流声、虫鸣声

2. **动作音（Foley Sound）**：
   - 定义：人物动作产生的声音
   - 用途：增强真实感
   - 描述词：脚步声、敲门声、开门声、椅子移动声、衣物摩擦声

3. **对白音（Dialogue Sound）**：
   - 定义：人物对白声音
   - 用途：传递信息、表达情绪
   - 描述词：人物对白、独白、旁白

4. **特殊音效（Special Effect）**：
   - 定义：特殊效果声音
   - 用途：营造特殊氛围或强调
   - 描述词：爆炸声、枪声、心跳声、呼吸声、雷声、钟声

5. **呼吸声（Breathing Sound）**：
   - 定义：人物呼吸声音
   - 用途：表现紧张、恐惧或平静状态
   - 描述词：沉重呼吸声、急促呼吸声、平静呼吸声

6. **心跳声（Heartbeat Sound）**：
   - 定义：心跳声音
   - 用途：表现紧张、恐惧或激昂状态
   - 描述词：心跳声、快速心跳声、缓慢心跳声

7. **无音效**：
   - 定义：无音效
   - 用途：突出对白或氛围音乐
   - 描述词：无音效、静音
