## 概览
本文档定义了漫屋分镜表的完整结构。漫屋分镜表是一个简化版的分镜表格，适用于漫屋应用场景，专注于AI融图和AI视频生成。表格包含10个核心字段，结构清晰，便于快速生成和使用。

## 表格结构

### 表格字段

漫屋分镜表包含以下10个核心字段（按顺序）：

```
1. 分镜编号
2. 建议时长
3. 分镜剧本
4. 画面内容
5. AI融图提示词
6. AI视频提示词
7. 台词
8. 角色
9. 场景
10. 道具
```

## 字段说明

### 1. 分镜编号
**定义**：分镜的唯一标识符

**编号规则**：
- 格式：SHOT_001, SHOT_002, SHOT_003, ...
- 从001开始，依次递增
- 保持三位数字格式

**示例**：
- SHOT_001
- SHOT_002
- SHOT_003

### 2. 建议时长
**定义**：该分镜的建议持续时间，单位为秒

**时长规则**（重要）：
- 范围：0.1-15秒（支持0.1秒精度）
- 根据台词/旁白/内心独白的字数和情绪语速计算时长
- 严禁出现"分镜只有1-5秒，台词却有20-40字"的情况

**台词/旁白/内心独白时长计算公式**（强制执行）：
```
时长（秒）= 字数 ÷ 基础语速 ÷ 情绪系数
```

**基础语速标准**（字/秒）：
- **正常语速**：3.5字/秒（默认语速，适用于平静对话）
- **快速语速**：4.5字/秒（适用于争吵、紧张对话、快节奏场景）
- **慢速语速**：2.5字/秒（适用于深情表白、内心独白、悲伤表达）

**情绪语速系数**（重要）：
- **平静情绪**：1.0x（正常语速，无情绪波动）
- **轻微情绪**（喜悦、惊讶、好奇）：0.9x（语速略微变慢）
- **中等情绪**（激动、担忧、困惑）：0.7-0.8x（语速变慢，留出情绪表达空间）
- **强烈情绪**（愤怒、悲伤、恐惧）：0.5-0.6x（语速显著变慢，情绪表达强烈）
- **极慢表达**（内心独白、深情告白、绝望）：0.4-0.5x（语速极慢，情感极致表达）

**时长分类**（辅助规则，仅在无台词时使用）：
- 动作场景：简单1-2秒、中等2-4秒、复杂3-5秒
- 情感场景：根据台词时长计算公式确定时长
- 空镜：2-6秒

**示例**：
- 3秒（平静对话，10字，3.5字/秒，平静情绪1.0x：10÷3.5÷1.0=2.9秒）
- 5秒（中等情绪，15字，3.5字/秒，中等情绪0.8x：15÷3.5÷0.8=5.4秒）
- 8秒（悲伤表达，20字，2.5字/秒，强烈情绪0.5x：20÷2.5÷0.5=16秒→拆分）

### 3. 分镜剧本
**定义**：该分镜对应的剧本内容描述

**内容要求**：
- 简洁明了，描述核心动作和对白
- 包含角色动作、场景变化、关键事件
- 与原剧本对应

**描述格式**：
```
[角色]：[对白/动作描述]
[动作]：[行为描述]
[场景]：[环境变化]
```

**示例**：
```
约翰：我们改变不了过去，只能改变未来。
玛莉从画面左侧走入，站在约翰身旁。
远处传来警报声。
```

### 4. 画面内容
**定义**：该分镜的视觉画面描述

**内容要求**：
- 描述人物状态、位置、动作
- 描述场景环境、氛围、细节
- 描述光影效果、构图方式
- 为AI生成提供清晰的视觉指导

**描述要素**：
- 人物：外貌、服装、表情、动作、位置
- 场景：环境、氛围、细节
- 光影：光源、光线效果
- 构图：角度、景别、构图方式

**示例**：
```
约翰站在天台边缘，面向远方，侧身轮廓。玛莉从画面左侧缓慢走入，站在约翰右侧，面部微侧。夜幕下的城市天际线在远处，高楼林立，霓虹灯闪烁。月光从右侧照射，形成侧面冷光。俯视角度，全景构图。
```

### 7. 台词
**定义**：该分镜中人物的对白内容

**填写规则**：
- 如果有对白，填写具体台词内容
- 如果没有对白，填写"无台词"或"无"
- 台词格式：[角色名]：[台词内容]
- 多人对话，分行显示

**台词拆分规则（重要，强制执行）**：

**核心强制规则**（最高优先级，强制执行）：
- **不得跳过任何"台词、旁白、内心独白"**：小说、剧本中的所有"台词、旁白、内心独白"必须完整呈现在各个结果表格中
- **严禁遗漏**：无论分镜时长如何限制，都不得遗漏、省略、压缩任何"台词、旁白、内心独白"的内容
- **自然顺延规则**：上一个分镜时长内没说完的"台词、旁白、内心独白"，必须自然顺延到下一个分镜内，直到"台词、旁白、内心独白"完全呈现在各个结果表格中
- **完整呈现规则**：所有"台词、旁白、内心独白"必须完整呈现，不得截断、不得省略、不得简化
- **分镜连续规则**：当一个"台词、旁白、内心独白"需要跨多个分镜时，这些分镜必须连续出现，中间不得插入其他无关内容
- **续接标记规则**：跨镜延续的"台词、旁白、内心独白"必须使用"..."和"（续）"标记，确保清晰标识续接关系

- **拆分原则**：长台词可以自然拆分到上下连续的多个分镜中，符合现实影视剧的台词分镜处理逻辑
- **拆分触发条件**：
  - 台词时长（按情绪语速计算）超过单个分镜时长上限（15秒）
  - 台词时长超过当前分镜的预留时长（如当前分镜3-5秒，但台词需要8秒）
  - 严禁出现"分镜只有1-5秒，台词却有20-40字"的情况
- **拆分方式**：
  - **按语意单元拆分**：优先在逗号、句号、问号、感叹号等标点符号处拆分
  - **按情绪转折拆分**：在情绪转折点拆分（如从平静到愤怒）
  - **按镜头切换拆分**：配合镜头切换，在不同景别或角度中继续台词
- **拆分标记**：
  - 使用"..."表示台词跨镜延续
  - 使用"（续）"表示承接上一个分镜的台词
- **拆分标记**：
  - 使用"..."表示台词跨镜延续
  - 使用"（续）"表示承接上一个分镜的台词
- **拆分示例**：
  ```
  示例：长台词拆分（3个分镜）
  - 原台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！"（按情绪语速需要9秒）
  - 分镜1（3秒）：主角特写，情绪平稳
    台词：约翰："我知道你恨我，我也恨我自己。但这一切都是命..."
  - 分镜2（3秒）：镜头切换到侧脸，情绪开始激动
    台词：约翰："（续）我们改变不了的！"
  - 分镜3（3秒）：镜头切回正面，情绪爆发
    台词：约翰："（续）再怎么挣扎都是徒劳的！"
  ```
- **拆分注意事项**：
  - 拆分后的台词要保持语意连贯，不破坏情感表达
  - 拆分点要配合镜头切换，增强视觉表现力
  - 避免在词语中间拆分（如"改变不"拆开），要在标点符号处拆分
  - 长台词拆分后，每个分镜的时长要合理分配，确保台词能完整说完

**示例**：
```

```

```

```

**多人对话示例**：

## 生成规则

### 分镜编号生成
- 从SHOT_001开始，依次递增
- 保持连续性，不跳号
- 每个分镜有唯一的编号

### 时长计算
- 根据内容复杂度调整时长
- 对白场景：(句子数 × 2.5秒 + 停顿时间)
- 动作场景：简单1-2秒、中等2-4秒、复杂3-5秒
- 情感场景：轻微3-5秒、中等5-8秒、强烈8-12秒
- 空镜：2-6秒
- 单镜头最长15秒，超过需分割

### 分镜剧本提取
- 从原剧本中提取对应内容
- 保持原剧本的语言风格
- 简化冗余描述，突出核心内容

### 画面内容生成
- 基于分镜剧本生成画面内容
- 添加视觉细节（人物、场景、光影、构图）
- 为AI生成提供清晰的视觉指导

### AI融图提示词生成
- 基于画面内容生成AI融图提示词
- 包含强制关键词（8K超高清，电影质感，细节拉满）
- 确保提示词简洁明了，易于AI理解

### AI视频提示词生成
- 基于画面内容和运镜方式生成AI视频提示词
- 包含运镜方式、景别、角度、时长、音效、配乐
- 确保提示词包含足够的动态信息

### 台词提取
- 从原剧本中提取对白内容
- 保持原剧本的语言风格
- 如果没有对白，填写"无台词"

### 角色提取
- 从原剧本中提取出现的角色
- 列出所有角色，用逗号分隔
- 如果没有角色，填写"无角色"

### 场景提取
- 从原剧本中提取场景信息
- 描述场景地点、时间、氛围
- 保持简洁明了

### 道具提取
- 从原剧本中提取重要道具
- 列出所有重要道具，用逗号分隔
- 如果没有道具，填写"无道具"
