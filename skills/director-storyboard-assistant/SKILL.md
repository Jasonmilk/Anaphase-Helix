# 导演分镜助手

## 任务目标
本 Skill 用于将文学剧本自动转换为专业结构化分镜表，为影视前期制作提供完整的导演分镜方案。

能力包含：
- 剧本智能解析（场景、人物、对白、动作识别）
- 角色设定提取（外貌、性格、服装、道具）
- 场景设定分析（地点、时间、光线、氛围）
- 情绪节拍分析（生成情绪节奏曲线）
- 导演风格匹配（支持TSPDT影史最伟大导演TOP250 + 红果短剧平台风格 + 豆瓣恐怖片Top100风格 + 动作戏导演风格 + 2010-2025年全球优秀广告片风格 + 国漫风格（赵霁、饺子） + 日韩动漫风格）
- 动作戏优化（支持10位著名动作戏导演，优化武术动作和动作戏设计）
- 广告片风格优化（支持2010-2025年全球优秀广告片，包含极简主义、情感叙事、创意冲击、生活真实、社会议题等风格）
- 结构化分镜生成（15秒镜头单元，支持9:16竖屏格式）
- 多参生视频Prompt生成（包含摄影机景别、角度、运镜方式和氛围音乐、音效）
- 即梦5.0文生图提示词生成（包含角色特写、角色全身、角色+场景一体化提示词）
- 一致性校验（合并到分镜表格中，包含角色跨镜头、场景连续性、光影风格统一性校验）
- 多格式导出（Markdown/JSON/CSV/Excel，支持按场次/角色/场景分类）

**最终输出交付**（强制执行）：
- 导演分镜助手V3最终交付**只有五个**表格/文档：
  1. 结构化分镜表
  2. 即梦5.0文生图提示词总表
  3. 电影提示词表
  4. 电影导演表
  5. 漫屋分镜表
- **不得改变名称**或生成其它名称的表格

**使用范围**：私有技能，仅限指定团队成员使用

触发条件：
- 用户提交剧本文本或剧本文件
- 用户询问"如何分镜"、"设计镜头"、"导演视角"等分镜相关问题
- 用户需要生成情绪曲线或视觉化分析
- 用户需要角色设定或场景分析
- 用户需要即梦5.0文生图提示词
- 用户需要一致性校验（已合并到分镜表格中）
- 用户指定动作戏导演风格，需要优化动作戏
- 用户指定广告片风格或品牌，需要应用广告片分镜风格

0.5. **画幅模式判断（必需）**
   - **默认模式**：横屏16:9模式（适用于所有类型的影视剧，包括电影、电视剧、真人短剧、AI漫剧、AI解说剧）
   - **竖屏触发**：只有当用户输入指令窗口包含"竖屏"触发词时，才启用9:16竖屏模式
   - **模式特点**：
     - 横屏16:9模式（默认）：保持原有影视剧风格，传统的电影电视分镜方式
     - 竖屏9:16模式（触发词"竖屏"）：人物在画面中占比较高，以全景、中景、近景、特写、大特写为主
   - **重要**：所有风格的影视剧默认都是横屏16:9，只有在用户指令窗口输入"竖屏"时，才触发并在生成表格和文档时是竖屏9:16
   - 详细构图规则见 [references/storyboard-format.md](references/storyboard-format.md) 的"画幅模式构图规则"章节

1. **剧本输入与智能解析**
   - 获取剧本内容（直接粘贴文本或读取上传文件）
   - 深度解析剧本结构：
     - 识别场景（场号、地点、时间）
     - 识别人物（角色名称、出场顺序）
     - 提取对白（人物台词）
     - 提取动作（行为描述、场景变化）
   - 详细解析方法见 [references/script-analysis.md](references/script-analysis.md)

2. **角色设定提取**
   - 从剧本中提取角色设定：
     - 外貌特征（发型、体型、面部特征）
     - 性格特点（性格描述、行为模式）
     - 服装建议（服装款式、颜色、配饰）
     - 道具设定（常用道具、特殊道具）
   - 生成角色设定卡片
   - 详细提取方法见 [references/character-extraction.md](references/character-extraction.md)

3. **场景设定分析**
   - 从剧本中分析场景设定：
     - 地点特征（室内外、具体地点）
     - 时间设定（昼夜、季节、具体时间）
     - 光线条件（自然光、人工光、光线方向）
     - 氛围营造（情绪氛围、环境描述）
   - 生成场景设定卡片
   - 详细分析方法见 [references/scene-analysis.md](references/scene-analysis.md)

4. **情绪节拍分析**
   - 按时间段落分析情绪节奏（每15秒为一个节拍）
   - 判断情绪类型：平静、紧张、悲伤、愤怒、恐惧、喜悦、悬疑
   - 生成情绪曲线图描述（时间-情绪强度坐标）
   - 输出情绪节奏分析报告

6. **结构化分镜生成**
   - 将剧本按15秒分段
   - 为每个段落生成分镜镜头
   - 分镜格式见 [references/storyboard-format.md](references/storyboard-format.md)
   - 每个镜头包含：
     - 镜头号（SCENE_SHOT_001）
     - 景别（特写/中景/全景/远景/大特写）
     - 角度（平视/俯视/仰视/荷兰角）
     - 运镜（固定/推/拉/摇/移/跟/升降）：根据导演风格、剧情需求、情绪类型选择合适的运镜方式，详见Seedance 2.0运镜大全
     - 时长（根据导演风格、剧情发展、情绪强度动态调整，0.1-15秒，支持0.1秒精度）
     - 画面内容（场景描述、人物状态）
     - 对白（对应台词）
     - 服化道建议（服装、化妆、道具）
     - 光影设计（主光方向、光比、色温）
     - 摄影机逻辑（镜头选择、焦点控制）
   - **时长优化规则**（重要）：
     - **基础规则**：所有分镜时长在0.1秒到15秒之间（Seedance2.0限制），支持0.1秒精度，具体时长由智能体根据导演风格、剧情发展和影视剧类型决定
     - **精度规则**（重要）：分镜时长可以精确到0.1秒一个单位，使分镜逻辑和分镜节奏更细腻精准
       - 示例：基础节奏3秒 → 可根据剧本实际情况调整为2.8秒或3.1秒
       - 示例：基础节奏5秒 → 可根据剧本实际情况调整为4.7秒或5.3秒
       - 示例：基础节奏2秒 → 可根据剧本实际情况调整为1.8秒或2.2秒
       - 所有影视剧风格的分镜时长都支持0.1秒精度
     - **节奏设计规则**（重要）：根据导演风格设计分镜节奏，时长多样性，避免单调，支持0.1秒精度
       - 经典好莱坞：节奏平衡，平均4-7秒，开场3-5秒（可调整为3.2-4.8秒）、对白5-8秒（可调整为4.8-8.2秒）、动作2-4秒（可调整为1.8-4.2秒）、高潮5-10秒（可调整为4.8-10.2秒）、结尾5-8秒（可调整为4.8-8.2秒）
       - 诺兰：节奏紧凑，平均3-6秒，快速叙事2-4秒（可调整为1.8-4.2秒）、交叉剪辑1-3秒（可调整为0.8-3.2秒）、悬疑4-7秒（可调整为3.8-7.2秒）、史诗8-15秒（可调整为7.8-15秒）
       - 王家卫：节奏缓慢，平均6-12秒，情感8-15秒（可调整为7.8-15秒）、环境6-10秒（可调整为5.8-10.2秒）、慢镜头10-15秒（可调整为9.8-15秒）、对白5-8秒（可调整为4.8-8.2秒）
       - 作者电影：节奏自然，平均5-10秒，长镜头10-15秒（可调整为9.8-15秒）、对白5-8秒（可调整为4.8-8.2秒）、动作3-6秒（可调整为2.8-6.2秒）、过渡5-10秒（可调整为4.8-10.2秒）
       - 悬疑惊悚：节奏多变，平均2-6秒，悬疑4-7秒（可调整为3.8-7.2秒）、惊吓1-3秒（可调整为0.8-3.2秒）、追逐2-4秒（可调整为1.8-4.2秒）、恐怖5-10秒（可调整为4.8-10.2秒）
       - 豆瓣恐怖片：节奏压抑，平均4-9秒，恐怖6-10秒（可调整为5.8-10.2秒）、悬疑5-8秒（可调整为4.8-8.2秒）、惊吓1-3秒（可调整为0.8-3.2秒）、压迫7-12秒（可调整为6.8-12.2秒）
       - 红果短剧：节奏紧凑，平均2-5秒，对白3-5秒（可调整为2.8-5.2秒）、动作2-4秒（可调整为1.8-4.2秒）、情绪4-6秒（可调整为3.8-6.2秒）、过渡2-3秒（可调整为1.8-3.2秒）
       - AI旁白漫：极快节奏，一行一分镜，平均1-2秒（可调整为0.8-2.2秒），剧本每一行文字对应一个独立分镜，**核心约束：不能遗落、不能合并、不能跳过任何一行旁白/台词，必须一一对应，剧本第N行=分镜第N个镜头**
       - 详细节奏设计方法见 [references/storyboard-rhythm.md](references/storyboard-rhythm.md)
     - **时长计算规则**（重要）：根据台词/旁白/内心独白的字数、情绪强度和语速计算时长，支持0.1秒精度
       - **计算公式**（强制执行）：时长（秒）= 字数 ÷ 基础语速 ÷ 情绪系数
       - **基础语速标准**（字/秒）：
         - 正常语速：3.5字/秒（默认语速，适用于平静对话）
         - 快速语速：4.5字/秒（适用于争吵、紧张对话、快节奏场景）
         - 慢速语速：2.5字/秒（适用于深情表白、内心独白、悲伤表达）
       - **情绪语速系数**（重要）：
         - 平静情绪：1.0x（正常语速，无情绪波动）
         - 轻微情绪（喜悦、惊讶、好奇）：0.9x（语速略微变慢）
         - 中等情绪（激动、担忧、困惑）：0.7-0.8x（语速变慢，留出情绪表达空间）
         - 强烈情绪（愤怒、悲伤、恐惧）：0.5-0.6x（语速显著变慢，情绪表达强烈）
         - 极慢表达（内心独白、深情告白、绝望）：0.4-0.5x（语速极慢，情感极致表达）
       - **台词/旁白/内心独白拆分规则**（重要，强制执行）：

**核心强制规则**（最高优先级，强制执行）：
- **不得跳过任何"台词、旁白、内心独白"**：小说、剧本中的所有"台词、旁白、内心独白"必须完整呈现在各个结果表格中
- **严禁遗漏**：无论分镜时长如何限制，都不得遗漏、省略、压缩任何"台词、旁白、内心独白"的内容
- **自然顺延规则**：上一个分镜时长内没说完的"台词、旁白、内心独白"，必须自然顺延到下一个分镜内，直到"台词、旁白、内心独白"完全呈现在各个结果表格中
- **完整呈现规则**：所有"台词、旁白、内心独白"必须完整呈现，不得截断、不得省略、不得简化
- **分镜连续规则**：当一个"台词、旁白、内心独白"需要跨多个分镜时，这些分镜必须连续出现，中间不得插入其他无关内容
- **续接标记规则**：跨镜延续的"台词、旁白、内心独白"必须使用"..."和"（续）"标记，确保清晰标识续接关系

         - 长台词/旁白/内心独白可自然拆分到上下连续的多个分镜中
         - 拆分触发条件：计算后的时长超过单个分镜时长上限（15秒）
         - 拆分方式：优先在标点符号处拆分，保持语意完整，使用"..."和"（续）"标记拆分
         - 严禁出现"分镜只有2-5秒，台词却有20-40字"的情况
       - **动作场景时长**：简单1-2秒（可调整为0.8-2.2秒）、中等2-4秒（可调整为1.8-4.2秒）、复杂3-5秒（可调整为2.8-5.2秒），根据风格调整
       - **情感场景时长**：根据台词时长计算公式确定时长
       - 详细计算方法见 [references/storyboard-rhythm.md](references/storyboard-rhythm.md)
     - **节奏变化规则**（重要）：确保时长多样性，节奏起伏
       - 时长渐变：从短到长或从长到短
       - 长短交替：快慢组合，避免单调
       - 节奏对比：快节奏后接慢节奏，紧张后接舒缓
       - 严禁所有镜头时长相同
     - 台词/旁白/内心独白时长按情绪语速计算，严禁出现"分镜只有2-5秒，台词却有20-40字"的情况
     - 长台词/旁白/内心独白拆分到连续分镜中，使用"..."和"（续）"标记
     - 单镜头最长15秒，超过需分割为多个镜头
     - 详细时长计算方法见 [references/storyboard-rhythm.md](references/storyboard-rhythm.md)
   - **动作戏优化规则**（重要，当剧本包含动作戏或用户指定动作戏导演时启用）：
     - **动作戏识别**（重要）：
       - 识别剧本中包含人物之间的肢体冲突
       - 识别剧本中包含战斗、打斗、搏斗等描述
       - 识别剧本中包含武术动作、格斗技巧等描述
       - 识别剧本中包含追逐、逃跑、躲藏等动作
       - 识别剧本中包含枪战、爆炸、特技等动作
       - 详细识别方法见 [references/action-sequences.md](references/action-sequences.md) 的"动作戏识别与分类"章节
     - **动作戏类型分类**（重要）：
       - 武侠动作：飞檐走壁、轻功、剑法、刀法，空中动作、吊威亚、飘逸动作（程小东、徐克、袁和平）
       - 功夫动作：传统武术、硬功、南派功夫，真实格斗、打击感、力量展示（洪金宝、刘家良、袁和平）
       - 动作喜剧：真实危险、道具利用、幽默元素，特技表演、滑稽动作（成龙、周星驰）
       - 枪战动作：双枪、慢镜头、白鸽意象，教堂场景、暴力美学（吴宇森）
       - 军事动作：军事战术、团队配合、现代武器，现代装备、战术动作（林超贤、唐季礼）
       - 现代动作：追逐戏、车战、特技，国际动作、大型场面（唐季礼、林超贤）
     - **人物角色定位**（重要）：
       - 角色类型识别：武侠高手、功夫大师、动作英雄、军人特警、喜剧角色
       - 人物能力评估：身体素质（力量、速度、敏捷、耐力）、武术技能（武术类型、熟练程度、招牌动作）、装备条件（武器类型、防御装备、道具利用）、性格特征（冷静、暴躁、狡猾、正义）
       - 根据角色定位选择符合角色定位的武术动作
       - 详细方法见 [references/action-sequences.md](references/action-sequences.md) 的"人物角色定位"章节
     - **武术动作优化**（重要）：
       - 轻功动作：飞檐走壁、踏雪无痕、空中转体，适用武侠高手，程小东、徐克风格
       - 剑法动作：剑气、剑招、剑术、剑舞，适用剑客、侠客、武林高手，程小东、袁和平风格
       - 拳脚功夫：拳法、腿法、擒拿、格斗，适用功夫大师、格斗专家，洪金宝、刘家良、袁和平风格
       - 硬功展示：铁砂掌、金钟罩、铜皮铁骨，适用硬功高手、传统武术家，洪金宝、刘家良风格
       - 枪战动作：双枪、射击、换弹、翻滚，适用警察、军人、特工，吴宇森、林超贤风格
       - 特技动作：跳楼、飞车、爆炸、肉身挡子弹，适用动作英雄、特技演员，成龙、唐季礼风格
       - 道具动作：利用环境道具进行战斗（楼梯、椅子、桌子、酒瓶等），适用动作英雄、喜剧角色，成龙、周星驰风格
       - 详细优化方法见 [references/action-sequences.md](references/action-sequences.md) 的"武术动作优化"章节
     - **动作戏镜头语言**（重要）：

   - **台词拆分规则**（重要，适用于所有表格）：
     - **拆分原则**：长台词可以自然拆分到上下连续的多个分镜/镜头/子分镜中，符合现实影视剧的台词分镜处理逻辑
     - **拆分触发条件**：
       - 台词时长（按情绪语速计算）超过单个分镜时长上限（如15秒）
       - 台词时长超过当前分镜的预留时长（如当前分镜2-5秒，但台词需要8秒）
     - **拆分方式**：
       - **按语意单元拆分**：优先在逗号、句号、问号、感叹号等标点符号处拆分
       - **按情绪转折拆分**：在情绪转折点拆分（如从平静到愤怒）
       - **按镜头切换拆分**：配合镜头切换，在不同景别或角度中继续台词
     - **拆分标记**：
       - 在台词字段中使用"..."表示台词跨镜延续
       - 使用"（续）"表示承接上一个分镜的台词
     - **拆分示例**：
       ```
       示例：长台词拆分（3个分镜）
       - 原台词："我知道你恨我，我也恨我自己。但这一切都是命，我们改变不了的！"（按情绪语速需要8秒）
       - 分镜1（3秒）：主角特写，情绪平稳
         台词：主角："我知道你恨我，我也恨我自己。但这一切都是命..."
       - 分镜2（3秒）：镜头切换到侧脸，情绪开始激动
         台词：主角："（续）我们改变不了的！"
       - 分镜3（2秒）：镜头切回正面，情绪爆发
         台词：主角："（续）再怎么挣扎都是徒劳的！"
       ```
     - **拆分注意事项**：
       - 拆分后的台词要保持语意连贯，不破坏情感表达
       - 拆分点要配合镜头切换，增强视觉表现力
       - 避免在词语中间拆分（如"改变不"拆开），要在标点符号处拆分
       - 长台词拆分后，每个分镜的时长要合理分配，确保台词能完整说完
     - **适用范围**：适用于结构化分镜表、电影提示词表、电影导演表、漫屋分镜表
     - **详细规则**：详见各表格的参考文档（storyboard-format.md、movie-prompt-table.md、movie-director-table.md、manwu-storyboard-table.md等）
   - **长台词分镜处理规则**（重要，仅适用于AI漫剧、AI真人剧、AI旁白剧）：
     - **长台词定义**：超过10个字的对白
     - **处理原则**：在人物出现长台词时，优先开启其它聆听者的分镜或故事发生的环境大全景

       - 环境大全景（长台词中间）：远景或大全景，展现故事环境
       - 说话人镜头（长台词结束）：回到说话人，完成对白

     - 详细规则见 [references/hongguo-short-drama.md](references/hongguo-short-drama.md) 的"长台词分镜处理"章节

- **包含三个全局控制部分**：

- **分镜逻辑生成规则**（重要）：
  - **规则1：基本生成规则**
    - 必须根据电影剧本的剧情发展和指令中的导演和电影分镜节奏风格匹配
    - 如张艺谋导演的电影《英雄》的风格，大卫芬奇导演的电影《七宗罪》的风格，岩井俊二导演的电影《情书》风格等等
    - 小说或剧本字数很多的情况下，自动生成多个分镜的提示词
    - 单个分镜最短时间是1秒，单个分镜最长时间是15秒
    - 小说剧本转为分镜要发散性思维，可以主动根据参考电影的风格扩写，加入一些空镜（大环境空镜、街道空镜、室内空镜、人物特写空镜、物品空镜）等等
    - 分镜总数可以增加不能减少。比如正常思维这集剧本生成30个分镜的提示词，扩写后加到35个分镜提示词，留给导演后期剪辑的空间
  - **规则2：用户指定总时长时的分镜逻辑调整**（重要）
    - **触发条件**：当指令中包含"总时长XXX秒"或类似表述时
    - **分镜数量计算**：
      - 根据用户指定的总时长，结合导演风格计算合理的分镜数量
      - 计算公式：分镜数量 = 总时长 ÷ 平均分镜时长
      - 平均分镜时长根据导演风格和影片类型调整：
        - 悬疑惊悚风格（温子仁）：平均分镜时长3-5秒，节奏紧凑
        - 动作片风格：平均分镜时长2-4秒，节奏快速
        - 剧情片风格：平均分镜时长5-8秒，节奏舒缓
        - 武侠风格（张艺谋）：平均分镜时长4-6秒，节奏适中
        - 心理惊悚风格（大卫芬奇）：平均分镜时长6-10秒，节奏缓慢压抑
        - 青春爱情风格（岩井俊二）：平均分镜时长8-12秒，节奏抒情
    - **分镜时长分配**：
      - 根据总时长和分镜数量，合理分配每个分镜的时长
      - 确保所有分镜时长相加等于用户指定的总时长
      - 关键情节分镜时长较长（如情感高潮、重要对话、动作高潮）
      - 过渡场景分镜时长较短（如环境空镜、场景转换）
    - **分镜节奏优化**：
      - 根据总时长调整分镜节奏，确保影片节奏流畅
      - 关键情节增加分镜数量，强化情感表达
      - 过渡场景减少分镜数量，加快节奏推进
      - 保持分镜时长的变化节奏，避免单调重复
    - **示例**：
      - 指令："把这个剧本转为总时长180秒的温子仁导演悬疑惊悚风格的电影导演表"
      - 计算：180秒 ÷ 4秒（悬疑惊悚风格平均时长）= 45个分镜
      - 调整：关键情节分镜5-8秒，过渡场景分镜2-3秒，确保总时长180秒
  - **规则3：用户指定分镜数量时的分镜逻辑调整**（重要）
    - **触发条件**：当指令中包含"XXX个分镜"或类似表述时
    - **分镜合并与分拆**：
      - **分镜合并**（当用户指定的分镜数量少于原风格触发的分镜数量时）：
        - 将相邻的短分镜合并为一个长分镜
        - 合并原则：相同场景、相同人物、连续剧情的分镜优先合并
        - 合并后时长 = 各分镜时长相加，最长不超过15秒
        - 合并后的分镜内容整合，保留关键信息
      - **分镜分拆**（当用户指定的分镜数量多于原风格触发的分镜数量时）：
        - 将长分镜分拆为多个短分镜
        - 分拆原则：根据剧情发展、动作变化、场景变化进行分拆
        - 分拆后每个分镜时长1-15秒
        - 分拆后的分镜内容细化，增加细节描述
    - **分镜时长重新分配**：
      - 根据用户指定的分镜数量，重新分配每个分镜的时长
      - 确保所有分镜时长在1-15秒范围内
      - 关键情节分镜时长较长，过渡场景分镜时长较短
    - **分镜节奏优化**：
      - 根据分镜数量调整分镜节奏，确保影片节奏流畅
      - 分镜数量增加时，节奏加快，细节更丰富
      - 分镜数量减少时，节奏舒缓，强调关键情节
    - **示例**：
      - 指令："把这个剧本转为温子仁导演悬疑惊悚风格的35个分镜的电影导演表"
      - 调整：原风格触发40个分镜，需要合并为35个
      - 合并：将5个短分镜合并为3个长分镜（场景内对话、连续动作、环境展示）
      - 保留：关键情节分镜不合并，确保情感表达完整
  - **规则4：分镜时长与数量的平衡**
    - **时长约束**：单个分镜时长必须在1-15秒范围内
    - **数量约束**：分镜数量必须符合用户指定
    - **总时长约束**：所有分镜时长相加必须等于用户指定的总时长（如果有指定）
    - **优先级**：
      1. 单个分镜时长1-15秒（强制约束）
      2. 用户指定的分镜数量（高优先级）
      3. 用户指定的总时长（高优先级）
      4. 导演风格匹配（中优先级）
      5. 剧情完整性（中优先级）
    - **冲突处理**：
      - 如果用户指定的分镜数量与总时长冲突（平均时长超出1-15秒范围），优先满足单个分镜时长约束
      - 如果无法同时满足数量和总时长，优先满足总时长约束，调整分镜数量
  - **规则5：导演风格与分镜节奏的匹配**
    - **温子仁风格（悬疑惊悚）**：
      - 节奏特点：紧张、压抑、快速切换
      - 平均分镜时长：3-5秒
      - 关键手法：特写、仰拍、俯拍、快速剪辑、阴影运用
      - 分镜分布：特写40%、中景30%、全景20%、远景10%
    - **张艺谋风格（武侠）**：
      - 节奏特点：流畅、优雅、动作连贯
      - 平均分镜时长：4-6秒
      - 关键手法：慢镜头、大场面、色彩对比、对称构图
      - 分镜分布：全景40%、中景30%、特写20%、远景10%
    - **大卫芬奇风格（心理惊悚）**：
      - 节奏特点：缓慢、压抑、细节丰富
      - 平均分镜时长：6-10秒
      - 关键手法：固定镜头、缓慢推进、冷色调、精细构图
      - 分镜分布：特写50%、中景30%、全景15%、远景5%
    - **岩井俊二风格（青春爱情）**：
      - 节奏特点：抒情、缓慢、情感细腻
      - 平均分镜时长：8-12秒
      - 关键手法：自然光、柔光效果、缓慢移动、情感特写
      - 分镜分布：特写40%、中景40%、全景15%、远景5%
- **每个分镜包含18个字段**：
  1. 镜头编号：镜头1、镜头2、镜头3...
  2. 全局布光控制：同"全局环境光布光控制"的定义
  3. 全局色彩调色：同"全局色彩色调"的定义
  4. 景别：大特写/特写/近景/中景/全景/远景/大远景
  5. 焦距：14mm-200mm（广角/标准/长焦）
  6. 光圈：f/1.4-f/22（大光圈/小光圈）
  7. 镜头角度与位置：具体角度和位置描述
  8. 对焦平面：焦点位置和景深效果
  9. 构图：人物位置和画面布局
  10. 运镜：基础运镜和Seedance 2.0运镜方式
  11. 剧情：人物动作、场景变化、画面动态
     - **剧情描述规则**（重要，强制执行）：
       1. **描述要具体，而非意境**：将小说、剧本中的"意境"转换为详细的"画面描述"提示词
          - 错误示范：举头望明月
          - 正确示范：一位中国古代男性面对镜头，抬头望向月亮，忧愁的氛围，夜晚
          - 对剧中人物DNA、场景、道具等的描述要足够详细和具体
       2. **结构要清晰，而非堆砌**：使用结构化的Prompt帮助AI更好地解析各个元素
          - 推荐公式：「主体+外观/细节描述+动作/状态」
          - 结构化示例：一架红色和黑色的直升飞机在空中飞行，背景是雪山和云层
       3. **增加细节以稳定画面**：对于动态的、复杂的场景，提供更多的环境和细节信息
          - 错误示范：海浪
          - 正确示范：薄荷绿的海浪拍打着金色的沙滩，棕榈树在海岸边，微风吹动着棕榈树的叶子，手绘风格，漫画
  12. 光效、特效：根据影片风格自动识别并添加
  13. 台词：人物对白内容
  14. 旁白：旁白内容
  15. 内心独白：人物内心独白
  16. 音乐：背景音乐类型和情绪
  17. 音效：环境音、动作音、特殊音效
  18. 时长：1-15秒，格式【Xs】
- **整体约束**：
  - 画面全程稳定无抖动，色调无偏移，光影逻辑一致，4K超高清，无画面闪烁与变形
  - 全程不能有背景音乐（无BGM），只能有环境音效
- **质感层**：4K超高清、电影级写实、细节丰富、电影级布光、色调统一
- **负面提示**：画面扭曲、人物变形、肢体畸形、面部崩坏、五官错位、画面剧烈抖动、果冻效应、画质模糊、低分辨率、构图混乱、穿帮镜头、逻辑错误
- **与其他表格的关系**：
  - 电影导演表与电影提示词表的区别：
    - 电影导演表：单个分镜1-15秒，精细化控制，每个分镜独立
    - 电影提示词表：15秒一组分镜，包含3-6个小分镜，整合输出
  - 电影导演表与结构化分镜表的关系：
    - 电影导演表：包含全局布光控制、全局色彩调色、更详细的镜头参数、18个字段
    - 结构化分镜表：包含20个字段，用于即梦5.0文生图提示词总表和漫屋分镜表的生成
- **触发条件**：
  - 用户明确要求生成"电影导演表"
  - 用户指定导演风格（如"按照大卫芬奇风格生成电影导演表"）
  - 用户指定总时长（如"总时长180秒"）
  - 用户指定分镜数量（如"35个分镜"）
  - 用户需要精细化电影级分镜控制
- **输入示例**：
  - "按照剧本字数和场景数把剧本转化为大卫芬奇导演的电影《七宗罪》风格的35个分镜提示词"

  - "把这个剧本转为温子仁导演悬疑惊悚风格的35个分镜的电影导演表，给我word文档(纯文本格式)"

- 场景设定分析需准确把握地点、时间、光线、氛围，为分镜提供基础
- 情绪分析需结合文本内容和上下文，理解潜台词和人物动机

- Prompt生成需包含足够的视觉细节，确保AI生成的画面符合导演意图
- 一致性校验结果直接体现在分镜表格中（一致性校验字段和修正建议字段），不再生成单独的一致性校验报告
- 输出文件需使用UTF-8编码，确保中文字符正确显示
- 多格式导出需严格按照格式规范，确保数据的完整性和可读性

## 在线编辑与快速迭代

### 对话式快速修改
本Skill支持通过对话快速修改表格，无需下载-编辑-重新导入流程。

**支持的操作类型**：
- **单行修改**："修改第3行的景别为中景"、"将第5行的时长改为8秒"
- **批量修改**："将所有空镜的时长改为3秒"、"把所有对白场景的景别改为中景"
- **风格调整**："将现有分镜改为王家卫风格"、"应用诺兰风格重新生成"
- **字段调整**："在第2行之后插入一个新的空镜"、"删除第7行"
- **一致性修复**："检查并修复约翰的服装不一致问题"、"确保所有场景的光影一致"

**快速修改流程**：
1. 智能体生成初始表格（分镜表、即梦5.0文生图提示词总表）
2. 用户提出修改意见（通过对话）
3. 智能体立即应用修改并重新生成表格
4. 用户继续提出修改意见，重复步骤2-3
5. 直到用户满意，最终输出表格

**示例对话**：
```
用户：帮我将这个剧本转换为诺兰风格的分镜
智能体：[生成分镜表格]
用户：修改第3行的景别为中景，时长改为8秒
智能体：[立即修改并重新生成表格]
用户：将所有空镜的时长改为3秒
智能体：[批量修改并重新生成表格]
用户：很好，输出最终版本
智能体：[输出最终表格]
```

4. 多人实时编辑、评论、讨论
5. 使用协作工具的版本管理功能回溯历史版本
6. 编辑完成后，将最终表格复制回智能体对话
7. 智能体进行一致性校验并输出最终结果

**版本管理**：
- 协作表格工具提供自动历史版本保存功能
- 支持查看和恢复任意历史版本
- 支持版本对比和变更追踪
- 支持版本标签和备注

### Markdown表格在线查看
Skill输出的Markdown表格可以在扣子平台的消息流中直接查看，支持以下操作：
- 查看表格内容
- 复制表格到剪贴板
- 对话式快速修改
- 实时预览修改结果

**Markdown表格优点**：
- 格式清晰，易于阅读
- 支持富文本显示
- 可直接在平台内查看
- 支持快速修改

**局限性**：
- 不支持多人实时编辑
- 不支持评论功能
- 不支持历史版本回溯

**建议使用场景**：
- 个人快速迭代修改
- 小规模调整（<10次修改）
- 快速预览和验证

### 推荐工作流程

**流程1：个人快速修改（推荐）**
```
1. 智能体生成Markdown表格
2. 用户在对话中提出修改意见
3. 智能体立即修改并重新生成表格
4. 重复步骤2-3直到满意
5. 输出最终表格
```

**流程2：团队协作编辑（推荐）**
```
1. 智能体生成JSON格式数据
2. 团队成员A将数据导入协作表格工具
3. 邀请团队成员B、C、D加入协作
4. 多人实时编辑、评论、讨论
5. 使用版本管理功能回溯历史版本
6. 编辑完成后，将最终表格复制回智能体对话
7. 智能体进行一致性校验并输出最终结果
```

**流程3：混合模式**
```
1. 智能体生成Markdown表格
2. 用户在对话中快速修改5-10次
3. 导出JSON格式数据
4. 导入协作表格工具进行多人协作
5. 协作完成后，将最终表格复制回智能体对话
6. 智能体进行最终一致性校验
7. 输出最终表格
```

## 权限管理架构

### 权限控制流程
```
外部权限管理系统
    ↓ 验证用户身份
智能体（检查访问权限）
    ↓ 通过验证
director-storyboard-assistant Skill执行
```

### 成员管理（由外部系统支持）
- **添加成员**：管理员在外部权限系统中添加团队成员
- **删除成员**：管理员移除团队成员的访问权限
- **权限设置**：可为不同成员设置不同的使用权限级别
- **离职处理**：快速移除离职员工的所有访问权限

### 使用限制
- 仅在用户通过权限验证后，智能体才会执行Skill
- 智能体会记录使用日志，便于管理员监控使用情况
- 输出内容包含用户标识，确保可追溯性
