# 财税报告格式规范

## 目录
- [HTML格式规范](#html格式规范)
- [Word格式规范](#word格式规范)

## 概览
本文档定义财税分析报告HTML和Word两种输出格式的详细规范，确保报告的专业美观与一致性。

## HTML格式规范

### 页面布局
- 响应式设计，适配PC、平板、手机
- 最大宽度1200px，居中显示
- 页边距：上下2em，左右1em

### 字体规范
- 标题字体：Microsoft YaHei, SimHei, sans-serif
- 正文字体：Microsoft YaHei, Arial, sans-serif
- 代码字体：Consolas, Monaco, monospace

### 字号与层级
- H1（文档标题）：32px，加粗，行高1.3
- H2（章节标题）：28px，加粗，行高1.4，上边距40px
- H3（小节标题）：24px，加粗，行高1.4，上边距30px，虚线底边框
- 正文：16px，行高1.8
- 表格文字：14px

### 颜色方案
- 主色调：#1a5f7a（深蓝）
- 辅助色：#4a90e2（浅蓝）
- 强调色：#e74c3c（红色，用于重要提示）
- 文字颜色：#333333
- 链接颜色：#1a5f7a，hover时#4a90e2

### 段落格式
- 段落间距：1.5em
- 首行缩进：2em
- 对齐方式：两端对齐

### 表格格式
- 表格宽度：100%
- 边框：1px solid #e0e0e0
- 表头背景色：#f5f5f5
- 表头文字：加粗，14px
- 单元格内边距：12px
- 行高：1.6
- 奇偶行背景交替：奇数行白色，偶数行#fafafa

### 参考文献格式
- 列表样式：有序列表
- 缩进：2em
- 链接样式：下划线，蓝色
- 间距：1em

### 代码块格式
- 背景色：#f5f5f5
- 边框：1px solid #e0e0e0
- 内边距：1em
- 圆角：4px
- 字体大小：14px

### 响应式断点
- 移动端（< 768px）：
  - H1: 24px
  - H2: 20px
  - H3: 18px
  - 正文：14px
  - 表格：可横向滚动

## Word格式规范

### 页面设置
- 纸张大小：A4
- 页边距：上下2.54cm，左右3.17cm
- 页眉页脚：1.5cm

### 字体规范
- 标题：黑体，加粗
- 正文：宋体，常规
- 英文数字：Times New Roman

### 字号与层级
- H1（文档标题）：三号（16pt），加粗，居中
- H2（章节标题）：小三号（15pt），加粗，左对齐，段前段后各1行
- H3（小节标题）：四号（14pt），加粗，左对齐，段前0.5行，虚线底边框
- 正文：小四号（12pt），常规
- 表格文字：五号（10.5pt）

### 段落格式
- 行距：1.5倍
- 首行缩进：2字符
- 对齐方式：两端对齐
- 段前间距：0.5行
- 段后间距：0.5行

### 表格格式
- 表格样式：浅色底纹
- 边框：1磅，黑色
- 表头：加粗，底色浅灰
- 单元格内边距：上下0.3cm，左右0.5cm
- 文字居中或左对齐（根据内容）

### 参考文献格式
- 悬挂缩进：2字符
- 编号：方括号阿拉伯数字
- 间距：行距1.5倍
- 段后间距：0.5行

### 标题编号规范
- H1：文档标题（无编号）
- H2：一、二、三、...
- H3：1.1、1.2、2.1、...
- H4（如有）：1.1.1、1.1.2、...

### 页眉页脚
- 页眉：左侧报告标题，右侧页码
- 页脚：居中显示页码
- 字体：五号，常规

## 通用格式要求

### 标题层级示例
```
文档标题 (H1)
├─ 摘要 (H2)
├─ 一、背景 (H2)
│  ├─ 1.1 政策条款解读 (H3) - 24px，虚线底边框
│  └─ 1.2 多维分析 (H3)
├─ 二、分析过程 (H2)
│  ├─ 2.1 分析框架 (H3)
│  └─ 2.2 深度解读 (H3)
├─ 三、数据支撑 (H2)
│  ├─ 3.1 2024年增值税收入 (H3)
│  └─ 3.2 行业对比分析 (H3)
├─ 四、案例示例 (H2)
├─ 五、相关影响 (H2)
│  ├─ 5.1 对企业的影响 (H3)
│  └─ 5.2 对行业的影响 (H3)
└─ 六、应对策略 (H2)
```

### 特殊格式要求
- **摘要**：独立H2章节，不参与大章节编号
- **H3虚线边框**：用于背景章节的小节标题，虚线样式
- **表格**：必须有表头、边框、数据来源
- **数据**：所有数据必须标注来源

### 排版美观原则
- 层次清晰，标题醒目
- 段落适当，避免大段文字
- 表格美观，数据准确
- 留白适当，不拥挤
- 颜色协调，专业稳重

### 注意事项
- HTML和Word内容保持一致
- 格式统一，避免混用
- 打印预览效果良好
- 导出后格式稳定
