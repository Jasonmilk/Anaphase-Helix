## 概览
本文档定义财税分析报告参考文献的引用规范，确保引用的权威性、准确性与可追溯性。

## 权威来源清单

### 一级权威来源（必须优先使用）

#### 政府机构官网
1. **国家税务总局**
   - 官网：http://www.chinatax.gov.cn
   - 权威文件：政策法规、公告、解读
   - 适用：所有税收政策、法规、文件

2. **财政部**
   - 官网：http://www.mof.gov.cn
   - 权威文件：财税政策、预算、会计制度
   - 适用：财政政策、会计准则、税收制度

3. **国务院**
   - 官网：http://www.gov.cn
   - 权威文件：行政法规、重要政策
   - 适用：重大政策、行政法规

4. **最高人民法院**
   - 官网：http://www.court.gov.cn
   - 权威文件：司法解释、指导案例
   - 适用：税务争议案例、法律适用

5. **地方税务局官网**
   - 示例：北京市税务局、上海市税务局等
   - 权威文件：地方性政策、实施细则
   - 适用：地方性政策、操作细则

#### 正规财经媒体
1. **中国税务报**
   - 官网：http://www.ctaxnews.com.cn
   - 适用：政策解读、案例分析

2. **财政部会计准则委员会**
   - 官网：http://www.casc.org.cn
   - 适用：会计准则、财务制度

### 二级权威来源（可补充使用）
1. **中国注册会计师协会**
   - 官网：https://www.cicpa.org.cn

2. **中国税务学会**
   - 官网：http://www.ctcs.org.cn

3. **四大会计师事务所官网**
   - 普华永道：https://www.pwc.com
   - 德勤：https://www.deloitte.com
   - 安永：https://www.ey.com
   - 毕马威：https://home.kpmg

### 禁止使用的来源
- ❌ 个人博客、自媒体
- ❌ 非正规网站
- ❌ 未标注来源的二手资料
- ❌ 过时或失效的链接

## 引用格式规范

### 政策文件引用格式
```
[1] 财政部、国家税务总局《关于增值税政策的通知》（财税〔2024〕X号）
[2] 国家税务总局公告2024年第X号《关于...》
[3] 国务院令第XXX号《增值税暂行条例》
```

### 司法案例引用格式
```
[1] 最高人民法院（2023）最高法行申XXX号行政裁定书
[2] 北京市第一中级人民法院（2023）京01行初XXX号行政判决书
[3] 税务处理决定书（XX税处〔2023〕XXX号）
```

### 学术研究引用格式
```
[1] 王某某. 增值税改革对企业税负的影响研究[J]. 税务研究, 2024(1): 45-52.
[2] 李某某. 企业税务风险管理研究[M]. 北京: 财政经济出版社, 2023.
```

### 官方解读引用格式
```
[1] 国家税务总局政策法规司《关于...的解读》
[2] 财政部税政司《...政策答问》
```

## HTML链接要求

### 链接格式
- 必须为可点击的超链接
- 链接地址必须指向权威网站
- 链接文字为文献标题或简称
- 链接打开方式：target="_blank"

### 示例代码
```html
<ol class="references">
  <li><a href="http://www.chinatax.gov.cn/xxx" target="_blank">
    财政部、国家税务总局《关于增值税政策的通知》（财税〔2024〕X号）
  </a></li>
  <li><a href="http://www.court.gov.cn/xxx" target="_blank">
    最高人民法院（2023）最高法行申XXX号行政裁定书
  </a></li>
</ol>
```

### CSS样式建议
```css
.references a {
  color: #1a5f7a;
  text-decoration: underline;
  transition: color 0.3s;
}
.references a:hover {
  color: #4a90e2;
}
```

## Word引用要求

### 基本格式
- 编号：方括号阿拉伯数字，如[1]、[2]
- 悬挂缩进：2字符
- 行距：1.5倍
- 包含完整URL地址（括号内或独立一行）

### 示例格式
```
[1] 财政部、国家税务总局《关于增值税政策的通知》（财税〔2024〕X号）
    http://www.chinatax.gov.cn/xxx/xxx.html
[2] 最高人民法院（2023）最高法行申XXX号行政裁定书
    http://www.court.gov.cn/xxx/xxx.html
```

### 超链接设置（可选）
- 可以为文献标题添加超链接
- 超链接地址与URL地址一致
- 便于阅读时直接跳转

## 引用注意事项

### 准确性要求
- 文献标题准确无误
- 文号准确完整
- URL地址有效可访问
- 发布时间或日期准确

### 时效性要求
- 优先使用最新版本的政策文件
- 案例引用注明审结时间
- 数据引用注明统计年份

### 完整性要求
- 政策文件：发文机关、文号、标题齐全
- 司法案例：法院名称、案号、案由齐全
- 学术文献：作者、标题、出处齐全

### 一致性要求
- 同一类型文献引用格式一致
- 编号顺序与正文引用顺序一致
- HTML和Word引用信息一致

## 常见错误示例

### 错误示例1：来源不权威
```
❌ [1] 某某公众号《增值税新政解读》
✅ [1] 国家税务总局《关于增值税政策的解读》
```

### 错误示例2：链接无效
```
❌ [1] 财政部《...》http://xxx.xxx (链接已失效)
✅ [1] 财政部《...》http://www.mof.gov.cn/xxx (链接有效)
```

### 错误示例3：信息不完整
```
❌ [1] 增值税暂行条例
✅ [1] 国务院令第XXX号《增值税暂行条例》
```

## 检查清单

在提交报告前，请检查：
- [ ] 所有参考文献均来自权威来源
- [ ] HTML链接可点击且指向正确网址
- [ ] Word参考文献包含完整URL
- [ ] 文献信息完整准确（标题、文号、发布机关等）
- [ ] 引用格式统一规范
- [ ] 编号顺序正确
- [ ] 所有URL地址有效可访问
- [ ] 政策文件为最新版本
- [ ] 案例注明审结时间
- [ ] 数据注明统计年份
