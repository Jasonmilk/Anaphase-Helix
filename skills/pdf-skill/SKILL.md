# PDF Skill

## 职责与协作

与其它 skill 并存时：非 PDF 主编辑由对应 skill 承担，本 skill 只做 PDF 相关步骤。

## 路由选择

| 路由 | 触发条件 | 路由文件 |
|------|---------|---------|
| **创建**（默认） | 用户要求"写/生成/创建"PDF，且无 Office/LaTeX 附件 | `routes/create.md` |
| **转换** | 用户提供 .docx/.pptx/.xlsx/.tex 等附件，要求格式互转 | `routes/convert.md` |
| **处理** | 对已有 PDF 进行操作（读取、提取、合并、拆分、填表等） | `routes/process.md` |

### 强制要求：实现前必须先读路由文件

<system-reminder>
实现任何功能前，必须先读取对应的路由文件。
路由文件包含关键的实现细节，此处不会重复。
跳过此步会导致输出错误（脚本调用错误、CSS 缺失、布局损坏）。
</system-reminder>

**实现前必须：**
1. 判断路由（创建 / 转换 / 处理）
2. **读取路由文件**（`routes/create.md`、`routes/convert.md` 或 `routes/process.md`）
3. **创建路由还需读取** `design/design.md`（设计规范）
4. 然后再开始实现

### 路由判断规则

| 用户输入 | 路由 |
|---------|------|
| "写一份报告"、"生成 PDF"、"创建文档"、"帮我做一份简历" | **创建** |
| 提供了 .docx/.pptx/.xlsx 附件 + "转成 PDF" | **转换** |
| 提供了 .tex 文件或说"编译 LaTeX" | **转换** |
| "把 PDF 转成 Word" | **转换** |
| "提取这个 PDF 的文本"、"合并这些 PDF"、"填写这个表单" | **处理** |
| "读取/阅读这个 PDF"、"帮我看看这个 PDF"、"总结这个 PDF 的内容" | **处理** |
| 提供 PDF + "重新排版/美化" | **创建**（先用处理路由提取内容，再用创建路由重新生成） |

**优先级**：有 Office/LaTeX 附件 → 转换 > 有 PDF + 操作指令 → 处理 > 其余 → 创建

## 快速开始

**使用统一 CLI 进行所有操作：**

```bash
# 检查环境（JSON 输出，退出码 0=正常，2=缺少依赖）
scripts/pdf.sh check

# 自动修复缺失依赖（幂等，可安全重复运行）
scripts/pdf.sh fix

# HTML 转 PDF
scripts/pdf.sh html input.html

# LaTeX 编译为 PDF
scripts/pdf.sh latex input.tex

# PDF 处理（通过 Python CLI）
python3 scripts/pdf.py <命令> <子命令> [选项]
```

**退出码：**
- `0` = 成功
- `1` = 用法错误
- `2` = 依赖缺失（运行 `pdf.sh fix`）
- `3` = 运行时错误

**各路由依赖：**
- **创建路由**：Node.js、Playwright、Chromium
- **转换路由**：LibreOffice（Office 方向）、Tectonic（LaTeX 方向）
- **处理路由**：Python 3、pikepdf、pdfplumber

**如果 `html_to_pdf.js` 运行后无输出**（最常见问题）：

```bash
cd scripts && npm install && npx playwright install chromium
```

## 核心约束（必须遵守）

### 0. 禁止加载外部资源

<system-reminder>
HTML 中禁止引用任何外部 CDN 资源。包括但不限于：
- Google Fonts（`fonts.googleapis.com`）
- Adobe Fonts
- 任何 `@import url('https://...')` 字体引用
- 任何外部 CSS/JS 框架 CDN

原因：沙箱/离线环境中，外部请求会被代理拦截（407 错误），导致页面渲染空白或挂起。
唯一例外：KaTeX 和 Mermaid CDN（已在脚本中处理）。
字体必须使用系统字体（Georgia、SimSun、Arial 等）。
</system-reminder>

### 1. 输出语言

**输出语言必须与用户查询语言一致。**
- 用户用中文提问 → PDF 内容用中文
- 用户用英文提问 → PDF 内容用英文
- 用户明确指定语言 → 按用户指定

### 2. 字数与页数约束

| 用户要求 | 执行标准 |
|---------|---------|
| 明确字数（如"3000字"） | ±20% 范围内，即 2400-3600 字 |
| 明确页数（如"5页"） | 精确等于，末页可不满 |
| 字数范围（如"2000-3000字"） | 必须落在范围内 |
| 无明确要求 | 根据文档类型合理推断，宁详勿略 |
| 下限要求（如"不少于5000字"） | 不超过 2 倍，即 5000-10000 字 |

**禁止行为**：
- 随意缩减内容（"简洁"不是借口）
- 用大量项目符号充页数（保持高信息密度）
- 超过用户要求 2 倍的篇幅

**特殊情况 — 简历**：默认 **1 页**，除非用户另有说明。使用紧凑边距 `margin: 1.5cm`。

### 3. 引用与搜索规范

#### 搜索后再写（禁止编造）

<system-reminder>
禁止在未搜索的情况下撰写涉及统计数据、研究结论或政策法规的内容。
编造事实是严格禁止的行为。存疑时，必须搜索。
</system-reminder>

| 场景 | 是否搜索 | 说明 |
|------|---------|------|
| 统计数据、数字 | **必须** | 如"2024年就业率" |
| 政策法规 | **必须** | 如"创业补贴政策" |
| 学术研究、论文 | **必须** | 如"某方法的有效性" |
| 时效性内容 | **必须** | 知识截止日期后的信息 |
| **不确定的事实** | **必须** | 只要不确定，就搜索 |
| 常识 | 不需要 | 如"水在100°C沸腾" |

**搜索流程**：
1. 识别需要验证的事实/数据
2. 搜索权威来源
3. 搜索结果不充分时，**迭代搜索**直到获得可靠信息
4. 在参考文献中标注真实来源
5. **反复搜索仍失败时，告知用户**，而非编造数据

#### 引用格式

| 文档语言 | 格式 |
|---------|------|
| 中文 | GB/T 7714（使用 [J][M][D] 标识符） |
| 英文 | APA |
| 中英混合 | 中文文献 → GB/T 7714，英文文献 → APA |

**引用必须真实**：所有引用必须有正确的作者/机构名、准确的标题、可验证的年份和出处。**禁止编造参考文献。**

#### 交叉引用（必须可点击）

```html
如<a href="#fig-1-1">图 1-1</a>所示……
由<a href="#eq-2-1">公式 (2-1)</a>可得……
详见<a href="#sec3">第三章</a>……
```

### 4. 大纲遵守（强制）

**用户提供大纲时**：
- **严格遵循**用户提供的大纲结构
- 章节标题必须与大纲一致（可微调措辞，不得改变层级/顺序）
- 不得随意增删章节
- 如果大纲有问题，**先询问用户**再修改

**无用户大纲时**，按文档类型使用标准结构：
- **学术论文**：IMRaD 或 引言-文献综述-方法-结果-讨论-结论
- **商业报告**：结论先行（执行摘要 → 详细分析 → 建议）
- **技术文档**：概述 → 原理 → 使用 → 示例 → FAQ
- **课程作业**：按作业要求的结构

## 封面风格选择

| 场景 | 风格 |
|------|------|
| 学术论文、毕业论文、正式课程作业 | **极简**（白底、居中、无装饰） |
| 报告、提案、商业文档 | **设计**（从 `design/design.md` 中选择） |
| 不确定 | 默认选**设计** — 纯文字封面 = 平庸 |

**核心原则**：封面背景色是区分"及格"与"出众"的关键。详见 `design/design.md` 中的封面模式。

## 配色推荐

根据文档内容和行业选择主色调：

| 场景 | 推荐色系 |
|------|---------|
| 法律 / 合规 / 金融 | 深海军蓝 `#1C3A5E`、炭灰 `#2E3440`、板岩灰 `#3D4C5E` |
| 医疗 / 健康 | 绿松石 `#2A6B5A`、冷绿 `#3A7D6A` |
| 科技 / 工程 | 钢蓝 `#2D5F8A`、靛蓝 `#3D4F8A` |
| 环保 / 可持续 | 森林绿 `#2E5E3A`、橄榄绿 `#4A5E2A` |
| 创意 / 艺术 / 文化 | 酒红 `#6B2A35`、梅紫 `#5A2A6B`、赤陶 `#8A3A2A` |
| 学术 / 研究 | 深青 `#2A5A6B`、书卷蓝 `#2A4A6B` |
| 企业 / 中性 | 板岩 `#3D4A5A`、石墨 `#444C56` |
| 奢品 / 高端 | 暖黑 `#1A1208`、深铜 `#4A3820` |

**原则**：选择对该文档内容有意义的颜色，而非类型的默认色。低饱和、偏暗的色调效果最好。不确定时，选更深更中性的色。
