# 设计系统

视觉层。在创建任何 PDF 之前，先阅读此文件。
此文件回答"应该长什么样，为什么这样设计"。

---

## 核心原则

每个设计决策都必须**植根于文档的内容和目的**。

深青配奶白不等于"专业"。衬线配米色不等于"优雅"。因为**契合内容**而选的颜色，永远比因为**看起来安全**而选的颜色效果好。

## 配色逻辑

### 氛围 → 基础配色

| 内容特征 | 氛围 | 封面背景 | 主色调 | 文字色 |
|---------|------|---------|--------|--------|
| 研究、科学、分析 | 权威 | `#0F1F2E` 深墨蓝 | `#00B4A6` 青绿 | `#F0EDE6` 暖白 |
| 商业、战略、金融 | 自信 | `#1C1C2B` 近黑 | `#E8A020` 琥珀 | `#F5F2EC` 奶白 |
| 创意、作品集、设计 | 表现 | `#1A0A2E` 深紫 | `#FF6B6B` 珊瑚红 | `#FAF5FF` 薰衣草白 |
| 教育、学术论文 | 学术 | `#FAFAF7` 暖白 | `#2C4A7C` 海军蓝 | `#1A1A2E` 深色 |
| 医疗、健康 | 平静 | `#F5F9F8` 淡薄荷 | `#2D8B72` 森林绿 | `#1E3830` 深绿 |
| 简历 / 个人 | 干净 | `#FFFFFF` 白色 | 从内容选取 | `#111111` 近黑 |
| 通用 / 未知 | 中性 | `#F8F6F1` 暖米白 | `#3D3D3D` 深灰 | `#1A1A1A` 黑色 |

### 主色调选择规则

- **只用一个主色调。** 使用两个主色调会分散视觉能量。
- 主色调出现位置：封面几何元素、章节标题下划线、引用框左边框、表头背景、页眉线。其他地方不出现。
- 主色调必须与封面背景色的对比度不低于 4.5:1（WCAG AA 标准）。
- **不要默认选蓝色。** 蓝色是 AI 生成文档中最泛滥的主色调。

### 配色反面模式（禁止使用）

| 禁止 | 原因 |
|------|------|
| 白底紫渐变 | 典型 AI 美学——一眼看出是生成的 |
| 海军蓝 + 金色 | 过度使用的企业陈词滥调 |
| 全黑背景 | 打印效果差，视觉攻击性强 |
| 系统中超过 3 种颜色 | 视觉噪音 |
| 正文文字用主色调 | 破坏可读性 |

## 字体系统

### 字体配对逻辑

**最多两种字体。始终如此。**

| 角色 | 标准 | 推荐选择 |
|------|------|---------|
| 展示字体（封面标题、H1） | 有辨识度、强对比、高字重 | Times New Roman, Georgia（衬线） |
| 正文字体（段落、注释） | 10-11pt 下高可读性 | Helvetica, Arial（无衬线） |

**禁止使用 `@import url(...)` 加载外部字体。** 沙箱环境中外部请求会被代理拦截。必须使用系统字体。

### 按氛围选择封面字体对

| 氛围 | 展示字体（系统字体） | 正文字体（系统字体） |
|------|---------|---------|
| 权威 | Georgia, 'Times New Roman', serif | Arial, Helvetica, sans-serif |
| 自信 | 'Trebuchet MS', Verdana, sans-serif | Arial, sans-serif |
| 表现 | Georgia, serif | Verdana, sans-serif |
| 学术 | 'Times New Roman', Georgia, serif | Arial, Helvetica, sans-serif |
| 干净 | Georgia, serif | 'Segoe UI', Tahoma, sans-serif |
| 克制 | 'Palatino Linotype', 'Book Antiqua', serif | Verdana, sans-serif |
| 粗犷 | 'Arial Narrow', Arial, sans-serif | Arial, sans-serif |
| 古典 | 'Palatino Linotype', Georgia, serif | Georgia, serif |
| 编辑 | Impact, 'Arial Black', sans-serif | Arial, Helvetica, sans-serif |

**注意**：以上全部为系统字体，无需加载外部 CDN。中文字体自动从 `SimSun`、`Microsoft YaHei`、`Noto Sans CJK SC` 中回退。

### 字号体系

所有尺寸单位为 pt。

| Token | 大小 | 行高 | 用途 |
|-------|------|------|------|
| display | 36-54pt | 1.0 | 封面标题 |
| h1 | 22pt | 1.3 | 章节标题 |
| h2 | 15pt | 1.4 | 小节标题 |
| h3 | 11.5pt | 1.5 | 子小节 |
| body | 10.5pt | 1.6 | 正文 |
| caption | 8.5pt | 1.4 | 图表标题 |
| meta | 8pt | 1.3 | 页眉/页脚 |

### 间距体系

| Token | 值 | 说明 |
|-------|-----|------|
| margin_outer | 2.8cm | 左右页边距 |
| margin_top | 2.8cm | 上边距 |
| margin_bottom | 2.5cm | 下边距 |
| section_gap | 26pt | H1 前间距 |
| para_gap | 8pt | 段落后间距 |
| line_gap | 17pt | 正文行距 |

## 封面设计

封面是最重要的页面。它决定读者是否信任这份文档。

### 六种封面模式

根据文档类型选择封面模式：

**1. `fullbleed`（全幅）** — 适用于：报告、通用文档
- 深色背景填满 100% 页面
- 标题：大号，左对齐，页面上方 60%
- 主色调：细横线 + 右上角色带
- 点阵网格背景纹理（微弱，8-10% 透明度）
- 底部栏：作者 + 日期

**2. `split`（分割）** — 适用于：提案、方案
- 左侧 42% 面板：封面色实底，标题 + 作者
- 右侧 58%：灰白色，点阵装饰
- 主色调竖线分隔
- 无渐变——纯平面几何

**3. `typographic`（字体型）** — 适用于：简历、学术论文
- 白色/灰白背景
- 标题作为超大展示字体（60-80pt），左对齐
- 首词用主色调，其余深色
- 标题块下方细线

**4. `minimal`（极简）** — 适用于：极简风格文档
- 近白背景，仅有 8px 左侧主色调竖条
- 标题用超大、轻字重展示字体（300 weight）
- 发丝细线，作者+日期为单行灰色文字
- 竖条是唯一的视觉元素

**5. `frame`（边框）** — 适用于：年度报告、法律文书、正式文档
- 白色/奶白背景，内嵌矩形边框（1.2px，距边缘 28px）
- 边框内上下主色条带；小主色角方块
- 标题在边框内居中，古典字重

**6. `editorial`（编辑）** — 适用于：杂志风格、创意文档
- 幽灵字母背景（超大半透明字母）
- 全大写标题
- 粗犷、大胆的排版风格

### 封面 CSS 要求

- 画布固定 `width: 210mm; height: 297mm`（A4）
- `body { margin: 0; }`
- 纹理使用 **inline SVG**，禁止使用 `background-image: url()` 外部链接
- **禁止** `@import url(...)` 加载外部字体，使用系统字体
- 所有颜色使用 CSS 变量

## 内页排版规则

### 章节标题（H1）

- 主色调 2px 下划线，宽度为页面宽度的 30-40%
- 标题上方 26pt 间距
- 字号 22pt，粗体

### 引用/高亮框

- 左边框 3px，颜色为主色调
- 内边距左侧 1em
- 背景可选用主色调浅色版（5-8% 透明度）

### 表格

- 表头：主色调背景 + 白色文字
- 交替行：主色调浅色版
- 边框：仅顶部 2px、表头底部 1px、末行底部 2px（三线表）

### 代码块

- 背景 `#f5f5f5`
- 左边框 3px 主色调
- 等宽字体：`'Courier New', monospace`
- 字号 9pt

## 质量标准

| 检查项 | 标准 |
|--------|------|
| 封面 | 必须有，必须全页，必须与正文分离 |
| 颜色数量 | 系统中不超过 3 种颜色（主色调 + 深色 + 浅色变体） |
| 字体数量 | 不超过 2 种字体 |
| 页边距 | 不得使用默认值，必须显式设置 |
| 对比度 | 正文文字与背景对比度 >= 7:1 |
| 打印友好 | 避免大面积深色背景（封面除外） |
