# 专利

## 适用场景
- 检索专利申请与授权信息、发明人与受让人
- 获取申请号、申请日与来源链接

## 常用方法
- API 优先：使用官方或开放接口进行关键词与受让人检索
- GUI 备选：在接口受限或需页面细节时使用

## GUI 操作建议
- 在官方网站以技术词或受让人检索并进入条目页
- 记录申请号、申请日、发明人与链接
- 对重要条目使用多源交叉验证

## API 与程序化接入
- USPTO PatentsView
- EPO OPS（需开发者注册）
- 部分平台需令牌或付费，按站点说明执行

## 权威入口与URL
- USPTO PatentsView: https://patentsview.org / API: https://api.patentsview.org
- EPO OPS: https://www.epo.org / Dev: https://developer.epo.org
- Lens: https://www.lens.org / API: https://api.lens.org（需令牌）

## 示例任务
- 搜索 CRISPR-Cas9 相关专利，输出申请号与来源链接
