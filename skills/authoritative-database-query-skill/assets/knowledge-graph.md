# 知识图谱与通识

## 适用场景
- 结构化实体属性与通用知识检索
- 需要可验证的引用与来源

## 常用方法
- API/SPARQL 优先：使用查询端点获取结构化结果
- GUI 备选：用于浏览实体页与参考文献反查

## GUI 操作建议
- 搜索实体并进入实体页，记录实体 ID 与关键属性
- 使用参考文献反查到原始权威来源

## API 与程序化接入
- SPARQL 查询端点
- 项目提供的 REST 接口

## 权威入口与URL
- Wikidata: https://www.wikidata.org / SPARQL: https://query.wikidata.org/sparql
- Wikipedia: https://www.wikipedia.org / API: https://en.wikipedia.org/w/api.php

## 示例任务
- 查询某公司 CEO、成立日期与总部，并给出实体 ID 与来源
