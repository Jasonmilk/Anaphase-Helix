# 地理与空间

## 适用场景
- 获取坐标、地图要素与公共空间数据集
- 记录要素 ID 与来源链接

## 常用方法
- API 优先：使用 OSM/GeoNames/Nominatim/Overpass 接口
- GUI 备选：数据集下载或复杂要素的页面浏览

## GUI 操作建议
- 在地图网站搜索地名或要素并进入详情页
- 记录坐标与要素 ID，按需要导出
- 数据集下载按比例尺与主题选择

## API 与程序化接入
- Overpass API
- Nominatim 搜索接口
- GeoNames 搜索接口

## 权威入口与URL
- OpenStreetMap: https://www.openstreetmap.org
- Overpass: https://overpass-turbo.eu / API: https://overpass-api.de/api/interpreter
- Nominatim: https://nominatim.openstreetmap.org
- GeoNames: https://www.geonames.org / API: http://api.geonames.org
- Natural Earth: https://www.naturalearthdata.com
