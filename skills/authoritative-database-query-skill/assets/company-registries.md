# 公司注册信息

## 适用场景
- 检索公司注册号、辖区、状态与注册地址
- 获取权威来源链接用于核验

## 常用方法
- API 优先：使用开放接口检索公司条目
- GUI 备选：核对页面字段或下载 PDF 附件

## GUI 操作建议
- 在官方网站输入公司名并选择匹配条目
- 提取注册号、管辖区、状态、地址并记录来源链接

## API 与程序化接入
- OpenCorporates 搜索接口
- 各国/地区官方登记处接口按站点说明使用

## 权威入口与URL
- OpenCorporates: https://opencorporates.com / API: https://api.opencorporates.com
- 英国 Companies House: https://www.gov.uk/government/organisations/companies-house
- 美国各州登记处：按州官方站点检索（示例：加州 https://bizfileonline.sos.ca.gov/）

## 示例任务
- 查询某公司的注册详情并提供来源链接与关键字段
