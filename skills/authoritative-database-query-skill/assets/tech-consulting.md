# 科技咨询与行业报告

## 适用场景
- 产业研究、市场规模与趋势洞察
- 获取报告标题、发布日期与机构信息

## 常用方法
- GUI 为主：官方网站公开摘要与报告页面
- API/数据接口：多数机构不提供统一开放接口，按站点说明使用

## GUI 操作建议
- 在站内搜索框输入主题词并使用筛选器限定年份、行业与区域
- 打开报告或洞察页面，记录标题、发布日期、作者/机构、版本号与页码
- 如存在付费墙，记录执行摘要并用权威数据源交叉验证关键数字

## 示例任务
- 查看某主题的最新洞察报告，返回摘要要点与来源链接
