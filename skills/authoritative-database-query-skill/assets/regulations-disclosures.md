# 法规与披露

## 适用场景
- 法规文本、判例与上市公司官方披露查询
- 获取官方编号（如 CELEX）与权威来源链接

## 常用方法
- API 优先：可检索元数据与结构化条目
- GUI 备选：长文阅读、附件下载或页面仅提供的内容

## GUI 操作建议
- 在官方网站以法规名或编号检索并使用筛选器限制语言与年份
- 进入条文页复制官方引用与链接
- 上市公司披露按公司名与文档类型检索最新条目

## API 与程序化接入
- EDGAR Open Data（XBRL Company Facts）
- EUR-Lex Webservice

## 权威入口与URL
- SEC EDGAR: https://www.sec.gov/edgar / Open Data: https://data.sec.gov
- EUR-Lex: https://eur-lex.europa.eu / Webservice: https://eur-lex.europa.eu/oeil-static/api

## 示例任务
- 查找 Apple Inc. 最新年度披露，输出关键财务摘要与官方链接
- 定位 GDPR 官方文本，提供 CELEX 编号与来源链接
