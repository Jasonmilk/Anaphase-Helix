# 民事诉讼文书起草

## 任务目标
- 用于生成民事起诉状、答辩状、上诉状及证据目录清单
- 能力：收集案情、法律分析、草拟文书、生成证据目录、输出独立文档
- 触发条件：用户需要草拟上述文书或相关模板、撰写指导
- **输出格式**：所有文书和证据目录必须以 Word（.docx）格式输出

## 【强制执行】法规检索要求

**【警告】起草任何文书前，必须先执行法规检索脚本，严禁跳过此步骤！**

在起草起诉状、答辩状、上诉状之前，**必须**严格按照以下流程执行法规检索：
1. 创建 `law_search_request.json` 文件
2. **必须调用** `scripts/law_search.py` 脚本进行法规检索
3. 验证返回法规的时效性（仅引用时效性为"01"的法规）
4. 获取法规原文
5. 在文书中引用验证有效的法规

**这是强制性步骤，不得跳过，不得省略，必须严格按照流程执行！**

## 文书类型

1. **民事起诉状**：向人民法院提起民事诉讼
2. **民事答辩状**：针对原告起诉状进行答辩
3. **民事上诉状**：不服一审判决提起上诉

## 准备工作

### 第一阶段：信息收集

根据文书类型，收集相应信息（详见 `references/info-collection.md`）：

**所有文书共通信息**：
- 当事人信息（原告/被告/上诉人/被上诉人/原审原告/原审被告/答辩人/被答辩人）
- 案情基本事实
- 证据材料清单
- 诉讼请求或上诉请求或答辩请求

**起诉状特有信息**：
- 找全法律关系主体，把被告拉满
- 排查担保人、保证人、连带责任人、共同侵权人等
- 管辖法院信息

**答辩状特有信息**：
- 起诉状全文内容
- 答辩意见和抗辩理由
- 答辩证据（如有）

**上诉状特有信息**：
- 一审判决书全文
- 一审法院名称、案号、判决日期、判决结果
- 上诉人一审诉讼地位
- 被上诉人一审诉讼地位
- 未上诉主体的一审诉讼地位（如存在）
- 一审判决的错误（认定事实错误/不清、适用法律错误/程序违法）
- 是否提供新证据（仅当上诉方提供新证据时才需生成证据目录）

### 第二阶段：法律分析

**【强制执行】法规检索与时效性验证**

**【警告】在撰写任何文书的事实与理由部分之前，必须先执行法规检索脚本，严禁跳过此步骤！**

**这是强制性步骤，不得跳过，不得省略，必须严格按照以下流程执行：**

1. **检索法规**：
   - 根据案件案情和法律关系，准备检索关键词
   - **关键原则**：检索关键词必须同时满足以下要求：
     - **必须结合案情**：能够准确反映本案涉及的法律问题
     - **必须来源于法条原文**：必须是法规原文中出现的词组
     - **禁止延伸和抽象归纳**：不得使用非原文的概括性词语或自创的概念
   - 创建 `law_search_request.json` 文件（格式如下）：
```json
[{
     "group_id": "1",
     "parameters": {
            "title":"民法典", "fulltext":"租赁合同"
     }
},{
     "group_id": "2",
     "parameters": {
            "title":"民法典", "fulltext":"婚姻"
     }
},...]
```
   - **【强制执行】必须调用** `scripts/law_search.py` 脚本进行法规检索，**严禁跳过此步骤**
   - 调用脚本参数：
     - input：输入的 law_search_request.json 文件的路径
     - output：生成的 law_search_result.json 文件的路径
   - **脚本调用示例**：
```bash
python scripts/law_search.py --input law_search_request.json --output law_search_result.json
```

2. **验证时效性**：
   - 检查返回结果的 `TimelinessDic` 字段
   - 确认时效性是否为 `"01"`（现行有效）
   - **仅引用时效性为"01"的法规**，不得引用废止或失效法规
   - 时效性说明：
     - `01`: 现行有效
     - `02`: 废止或失效
     - `03`: 已被修改

3. **获取法规原文**：
   - 法律数据库API不返回法规原文，仅用于验证时效性
   - 确认法规有效后，使用搜索工具搜索法律名为Title且颁布机关为IssueDepartment的法律
   - 搜索关键词：法规标题（Title）+ 发布部门（IssueDepartment）
   - 示例：搜索"民法典 全国人民代表大会"

4. **引用规范**：
   - 在事实与理由中引用法规时，必须注明法规标题和条文内容
   - 引用格式：`根据《中华人民共和国民法典》第XXX条规定，...`
   - 确保引用的法规内容准确、完整

#### 起诉状法律分析

**【强制要求】在事实与理由中引用法规前，必须先执行上述法规检索与时效性验证步骤**

1. **查清基本事实**：根据现有证据材料还原基本事实，区分原告陈述的事实和可证明的事实

2. **确定诉讼时效**（详见 `references/limitation-period.md`）：一般诉讼时效为3年，检查是否在时效期间内，考虑是否有中断、中止情形

3. **确定诉讼主体**：核对身份信息或营业执照信息，确保主体适格，**充分思考案件中的法律关系，找全法律关系主体，尽可能把被告拉满**

4. **确定法律关系和案由**（详见 `references/case-causes.md` 及 `assets/民事案件案由选择工作指引.docx`）：
   - 在确定案由之前，应当进行充分的法律分析，根据核心法律关系确定案由
   - **采用"先纵后横"的定位方法**：
     - **纵向定位**：按优先顺序检查案由类型（非讼程序 > 特殊诉讼程序 > 特殊法律关系 > 合同 > 无因管理 > 物权 > 不当得利 > 特殊侵权 > 人格权 > 一般侵权）
     - **横向定位**：优先选择最具体的案由层级（四级 > 三级 > 二级 > 一级）
   - **穿透双方形式上的文件，实质性考虑双方真实纠纷关系**
   - **特殊优于一般**：多个法律关系竞合时，根据特殊优于一般规则确定案由

5. **确定诉讼请求**：
   - 诉讼请求必须具体明确，最好具体到可以直接执行的程度
   - 涉及金额的必须具体到数额
   - **涉及解除合同/协议时，必须明确写明希望解除的时间点**
   - **如涉及诉讼费用之外的其他费用（如律师费、鉴定费、评估费等），务必在诉讼请求中不要遗漏**

6. **确定管辖法院**（详见 `references/jurisdiction-guide.md`）：
   - 确定级别管辖（基层、中级、高级、最高法院）
   - 确定地域管辖（专属管辖 > 协议管辖 > 特殊地域管辖 > 一般地域管辖）
   - 处理管辖冲突（多个有管辖权法院，由最先立案法院管辖）

#### 答辩状法律分析

**【强制要求】在答辩意见中引用法规前，必须先执行上述法规检索与时效性验证步骤**

**核心要求：以我方利益为导向进行分析**

1. **分析起诉状内容**：逐项分析原告的诉讼请求，识别原告主张的事实和法律依据，找出起诉状中的漏洞或不实之处，**区分对答辩人有利、不利的事实**

2. **确定答辩要点**（详见 `references/defense-content-reference.md`）：确定答辩的重点和策略，选择最有力的抗辩理由，**利益最大化**

3. **确定答辩请求**：具体明确，包括驳回诉讼请求和诉讼费用承担，**如涉及诉讼费用之外的其他费用，务必在答辩请求中不要遗漏**

4. **确定诉讼时效**（详见 `references/limitation-period.md`）：检查原告是否在诉讼时效期间内起诉

**答辩立场要求**：
- 在撰写答辩意见前，必须先进行立场分析
- **对不利事实的处理原则**：
  - 对于原告主张的对答辩人不利的事实，应选择否认、质疑事实的真实性或完整性
  - 对于无法否认但对我方不利的事实，应尝试通过法律适用、因果关系、责任分担等方面进行抗辩
  - **避免主动承认或暗示承认对答辩人不利的事实**

#### 上诉状法律分析

**【强制要求】在事实与理由中引用法规前，必须先执行上述法规检索与时效性验证步骤**

1. **审查一审判决**：仔细阅读一审判决书全文，理解一审判决的裁判理由和逻辑，找出一审判决的错误之处

2. **确定上诉主体**：有上诉权的当事人（一审原告、一审被告、有独立请求权的第三人），无独立请求权的第三人只有在判决承担民事责任时才有上诉权

3. **分析一审判决的错误**：
   - 认定事实错误：一审判决认定的事实与实际不符
   - 认定事实不清：一审判决对关键事实未查清
   - 适用法律错误：一审判决适用的法律条款不当或理解错误
   - 程序违法：一审程序违反法律规定

4. **确定上诉请求**：
   - 第一项：撤销一审判决（必须准确写明一审法院名称和案号）
   - 第二项：依法改判（必须具体明确）
   - 第三项：诉讼费用承担
   - **上诉请求不能超出一审诉讼请求的范围**
   - **如涉及诉讼费用之外的其他费用，务必在上诉请求中不要遗漏**

5. **确定二审法院**：基层人民法院→中级人民法院，中级人民法院→高级人民法院，高级人民法院→最高人民法院

6. **整理上诉理由**：选择最有胜诉把握的错误，选择对案件结果影响最大的错误

## 文书撰写步骤

### A. 起诉状撰写步骤

**【警告】在撰写起诉状之前，必须先完成法规检索与时效性验证步骤，严禁跳过！**

**强制要求**：
1. **必须先执行法规检索脚本**（`scripts/law_search.py`）
2. **必须验证法规时效性**（仅引用时效性为"01"的法规）
3. 在撰写事实与理由部分前，必须先完成上述步骤

**重要提醒**：
1. 严格按照既定格式起草，不要增加格式要求以外的内容
2. **起诉状必须包含案由字段**
3. **主体信息（原告、被告）必须严格按照格式输出，不得遗漏任何要素**
4. **诉讼请求必须完整**（包括其他维权费用）
5. 起诉状和证据目录是两个独立文件，需要分别生成并输出
6. **必须以 Word（.docx）格式输出**

#### 格式要求

1. **标题**：居中写"民事起诉状"

2. **原告信息**：
   - 自然人：姓名、性别、民族、出生日期、住址、身份证号码、联系电话
   - 法人或组织：名称、住所地、法定代表人、统一社会信用代码
   - 多个原告依次列为"原告1"、"原告2"...

3. **被告信息**：同原告信息格式，多个被告依次列为"被告1"、"被告2"...

4. **诉讼请求**：
   - 编号列出（1、2、3...）
   - 包括具体的实体请求、其他维权费用、诉讼费用承担
   - 涉及解除合同/协议时，必须明确写明希望解除的时间点

5. **案由**：根据"先纵后横"定位方法确定准确案由

6. **事实与理由**：
   - **禁止**输出"证据X"等引用标识
   - 根据证据载明的事实内容按逻辑书写
   - **禁止**原封不动摘抄案情本身
   - 在高度归纳概括的法律事实基础之上，结合法律依据进行分析

7. **管辖法院**：写明具体法院名称，不要长篇大论论证管辖权

8. **签章与日期**：
   - 右下角写："具状人："（多个原告分别写"具状人1："、"具状人2："等）
   - 右下角写明日期（中文数字格式：二〇二五年七月十三日）

---

### B. 答辩状撰写步骤

**【警告】在撰写答辩状之前，必须先完成法规检索与时效性验证步骤，严禁跳过！**

**强制要求**：
1. **必须先执行法规检索脚本**（`scripts/law_search.py`）
2. **必须验证法规时效性**（仅引用时效性为"01"的法规）
3. 在撰写答辩意见前，必须先完成上述步骤

**核心原则**：
- **答辩必须始终站在我方立场**
- **不要对不利事实进行自认**

**重要提醒**：
1. 严格按照既定格式起草，不要增加格式要求以外的内容
2. 答辩状和证据目录是两个独立文件
3. 答辩状**禁止**输出案由
4. 事实与理由部分**禁止**输出"证据X"等引用标识
5. **必须以 Word（.docx）格式输出**

#### 格式要求

1. **标题**：居中写"民事答辩状"

2. **答辩人信息**：多个答辩人依次列为"答辩人1"、"答辩人2"...

3. **被答辩人信息**：即起诉状中的原告，多个被答辩人依次列为"被答辩人1"、"被答辩人2"...

4. **答辩意见与事实理由**：
   - **合并书写**：将答辩意见和事实与理由合并为一个部分
   - 逐项回应原告的诉讼请求和事实陈述
   - 明确表明答辩人的态度（承认、否认、部分承认）
   - 陈述答辩人认可的事实（限于对我方有利的部分）
   - 提出答辩人的抗辩理由
   - 引用法律依据作为抗辩的支撑
   - 使用"一、""二、"等编号逐项阐述

5. **总结与答辩请求**：在事实与理由之后，写总结陈述和答辩请求

6. **签章与日期**：
   - 右下角写："答辩人："（多个答辩人分别写"答辩人1："、"答辩人2："等）
   - 右下角写明日期（中文数字格式）

**强制要求**：
1. **必须先执行法规检索脚本**（`scripts/law_search.py`）
2. **必须验证法规时效性**（仅引用时效性为"01"的法规）
3. 在撰写事实与理由部分前，必须先完成上述步骤

**重要提醒**：
1. 严格按照既定格式起草，不要增加格式要求以外的内容
2. 上诉状和证据目录是两个独立文件
3. **必须以 Word（.docx）格式输出**

#### 格式要求

1. **标题**：居中写"民事上诉状"

2. **上诉人信息**：
   - **必须注明一审诉讼地位**：（系一审原告/一审被告/一审第三人）
   - 多个上诉人依次列为"上诉人1"、"上诉人2"...

3. **被上诉人信息**：
   - 同上诉人信息格式
   - **必须注明一审诉讼地位**：（系一审原告/一审被告/一审第三人）
   - 多个被上诉人依次列为"被上诉人1"、"被上诉人2"...

   - 第一项：撤销一审判决（必须准确写明一审法院名称和案号）

   - 第三项：诉讼费用承担

7. **管辖法院**：写明具体二审法院名称

8. **签章与日期**：
   - 右下角写："上诉人："（多个上诉人分别写"上诉人1："、"上诉人2："等）
   - 右下角写明日期（中文数字格式）

## 证据目录清单生成步骤

**证据目录生成条件**：
- **起诉状**：始终需要生成证据目录
- **答辩状**：仅当在 prompt 和用户参考资料中提到答辩人提交了证据，或者原告提交的证据内容能被我方所使用时才需要输出证据目录
- **上诉状**：仅在上诉方提供了新证据的时候生成证据目录；如上诉方未提供新证据，则无需生成证据目录（新证据是指一审程序经双方举证质证的证据之外的能够证明新事实的证据）

按照以下步骤生成证据目录清单（详见 `references/evidence-template.md`）：

**重要规范**：
1. 证据目录是独立的文件，与主文书分开生成
2. 答辩状场景下：答辩人提交的证据必须有利于我方，禁止输出不利于我方的证据
3. 禁止编造证据目录的内容，所有证据内容必须来自用户提供的材料

### 格式要求

1. **标题**：居中写"证据目录"

2. **当事人信息**：
   - 起诉状/上诉状格式：原告、被告
   - 答辩状格式：答辩人、被答辩人
   - 上诉状格式：上诉人、被上诉人

3. **提交人信息**：`提交人（原告/上诉人/答辩人）：【提交人名称】          提交时间：`（提交时间留空）

4. **代理人信息**：`代理人（签字）：`（如有代理人，填写并签字；如无，留空或删除）

5. **签收人信息**：`签收人：                                           签收时间：`（均留空）

6. **证据表格**：

| 序号 | 证据名称 | 证据来源 | 份数 | 页数 | 证明目的 |
|------|----------|----------|------|------|----------|
| 1 | 【证据名称】 | 【证据来源】 | 【份数】 | 【页数】 | 【证明目的】 |
| ... | ... | ... | ... | ... | ... |

### 填写说明

1. **序号**：从1开始连续编号
2. **证据名称**：准确描述证据的名称
3. **证据来源**：**严格按照assets下面的《证据目录模版》生成，禁止自由发挥**
4. **份数**：**除己方之外各方当事人数量+1**
5. **页数**：该证据的页数
6. **证明目的**：**禁止编造证明目的，必需完全依托现有材料，禁止自由发挥和延伸**
   - 不要采纳无关证据
   - 不要采纳不利己方证据
   - **绝对禁止为了采纳某证据编造证明目的**

**重要补充规范**：
- **原被告主体资格文件不是证据**：自然人的身份证信息、户口本等；企业信用信息公示系统公示的工商登记信息
- **类案、法律法规文本不是证据**：类似案例、法律法规条文、司法解释等规范性文件
- 证据目录必须严格按照assets下面的《证据目录模版》生成

## 注意事项

### 主体信息规范
- **禁止编造主体信息**：如无法从案情和相关材料中获取主体信息，返回空即可

### 事实与理由部分规范（适用于所有文书）
- **禁止**在事实与理由部分输出"证据X"等引用标识
- **事实陈述原则**：对证据所证明的事实内容进行归纳概括，而不是大段摘抄；在高度归纳概括的法律事实基础之上，结合法律依据进行分析
- **禁止**原封不动摘抄案情本身
- 法律依据要写在事实与理由里面，不要单独列出

### 案由选择规范（适用于起诉状）
- 在确定案由之前，应当进行充分的法律分析，根据核心法律关系确定案由
- 采用"先纵后横"的定位方法
- 应穿透双方形式上的文件，实质性考虑双方真实纠纷关系
- 详细案由选择方法见 `assets/民事案件案由选择工作指引.docx`

### 证据目录规范
- **证据份数计算**：证据目录的份数为**除己方之外各方当事人数量+1**
- **禁止列入非证据材料**：原被告主体资格文件、类案、法律法规文本
- 严格按照assets下面的《证据目录模版》生成证据目录
- **禁止编造证明目的/证明内容**

### 上诉状特殊规范
- 除需列明上诉人和被上诉人之外，如存在未上诉的主体，需判断未上诉主体在原审中的地位
- 证据目录仅在上诉方提供了新证据的时候生成

### 费用承担规范（适用于所有文书）
- **起诉状**：诉讼请求必须完整，除诉讼费用外，如 prompt 涉及其他维权费用，务必不要遗漏
- **答辩状**：如涉及诉讼费用之外的其他费用，务必在答辩请求中不要遗漏
- **上诉状**：如涉及诉讼费用之外的其他费用，务必在上诉请求中不要遗漏

### 一致性检查规范（适用于所有文书）
- 在生成最终的诉讼文书和证据目录之前，需要对文书和证据目录的一致性进行检查
- 如有冲突以诉讼文书为准并对证据目录进行修正

## 法规检索与引用规范

**【警告】这是强制性步骤，不得跳过！在引用任何法规前，必须先执行以下检索流程！**

**适用场景**：当法律分析需要引用法律法规作为依据时

### 检索流程（必须严格执行）

1. **准备检索请求**：
   - 根据案件涉及的法律主题，确定检索关键词
   - 创建 `law_search_request.json` 文件（格式详见 `references/law-data-format.md`）
   - 支持多组关键词检索，每组使用独立的 `group_id`

2. **【强制执行】调用法规检索脚本**：
   - 执行命令：`python scripts/law_search.py --input law_search_request.json --output law_search_result.json`
   - **严禁跳过此步骤，必须执行**
   - 脚本会调用法律数据库API检索相关法规
   - 检索结果会输出到终端并保存到 `law_search_result.json`

3. **【强制执行】验证法规时效性**（关键步骤，**严禁跳过**）：
   - 检查返回法规的 `TimelinessDic` 字段
   - 确认时效性是否为 `"01"`（现行有效）
   - **仅引用时效性为"01"的法规**，严禁引用废止或失效法规
   - 时效性说明：
     - `01`: 现行有效
     - `02`: 废止或失效
     - `03`: 已被修改

4. **获取法规原文**：
   - 法律数据库API不返回法规原文
   - 确认法规有效后，使用搜索工具搜索法律名为Title且颁布机关为IssueDepartment的法律
   - 搜索关键词：`法规标题（Title）` + `发布部门（IssueDepartment）`

5. **引用规范**：
   - 在事实与理由中引用法规时，必须注明法规标题和条文内容
   - 引用格式：`根据《中华人民共和国民法典》第XXX条规定，"XXX"`
   - 确保引用的法规内容准确、完整

### 使用示例

**检索民法典租赁合同相关法规**：

1. 创建 `law_search_request.json`：
```json
[{
     "group_id": "1",
     "parameters": {
            "title":"民法典", "fulltext":"租赁合同"
     }
},...]
```

2. 调用脚本：
```bash
python scripts/law_search.py --input law_search_request.json --output law_search_result.json
```

3. 检查返回结果，确认 `TimelinessDic` 为 `"01"`

4. 获取原文：
```
搜索"中华人民共和国民法典 全国人民代表大会"
```

5. 在文书中引用：
```
根据《中华人民共和国民法典》第七百零三条第一款规定，"租赁合同是出租人将租赁物交付承租人使用、收益，承租人支付租金的合同。"
```

### 注意事项

- **【强制执行】时效性优先**：必须先验证法规时效性，再决定是否引用，**严禁引用未验证时效性的法规**
- **原文准确性**：引用法规条文必须准确无误，不得断章取义
- **关联性**：引用的法规必须与案件事实和法律问题直接相关
- **【强制执行】严禁跳过**：法规检索是强制性步骤，不得以任何理由跳过或省略

## 文书校验

在生成最终的诉讼文书和证据目录后，必须执行全面的校验检查。

### 通用校验项（适用于所有文书）

- [ ] **【强制执行】法规检索执行校验**：是否已执行法规检索脚本（`scripts/law_search.py`）；是否已创建 `law_search_request.json` 文件；是否已调用脚本并获取检索结果
- [ ] **输出格式校验**：所有诉讼文书和证据目录是否为 Word（.docx）格式
- [ ] **主体信息完整性校验**：自然人是否包含姓名、性别、民族、出生日期、住址、身份证号码、联系电话；法人或组织是否包含名称、住所地、法定代表人、统一社会信用代码
- [ ] **事实与理由格式校验**：是否包含"证据X"等引用标识
- [ ] **事实与理由内容校验**：是否原封不动摘抄案情本身；是否对证据证明的事实进行了归纳概括；是否结合法律依据进行了分析
- [ ] **法律依据位置校验**：法律依据是否写在事实与理由里面
- [ ] **法规引用时效性校验**：引用的法规是否已验证时效性为"01"
- [ ] **费用承担完整性校验**：是否遗漏了诉讼费用之外的其他费用
- [ ] **日期格式校验**：日期是否使用中文数字
- [ ] **一致性校验**：文书和证据目录是否存在冲突

### 起诉状专用校验项

- [ ] **标题校验**：是否为"民事起诉状"
- [ ] **案由字段校验**：是否包含案由字段
- [ ] **诉讼请求完整性校验**：诉讼请求是否具体明确，涉及金额的是否具体到数额，解除合同/协议是否明确写了解除时间点
- [ ] **管辖法院校验**：是否写明具体法院名称，是否包含论证管辖权等不必要内容
- [ ] **证据目录生成校验**：是否生成了证据目录
- [ ] **证据目录内容校验**：证据份数是否为"除己方之外各方当事人数量+1"；是否列入了原被告主体资格文件、类案、法律法规文本；是否编造了证明目的

### 答辩状专用校验项

- [ ] **标题校验**：是否为"民事答辩状"
- [ ] **案由字段校验**：是否包含案由字段（必须删除）
- [ ] **答辩立场校验**：答辩意见是否站在我方立场；是否对不利事实进行了自认
- [ ] **答辩意见与事实理由格式校验**：是否将答辩意见和事实与理由合并为一个部分
- [ ] **证据目录生成条件校验**：是否符合生成条件

### 上诉状专用校验项

- [ ] **标题校验**：是否为"民事上诉状"
- [ ] **上诉请求校验**：第一项是否撤销一审判决；第二项是否依法改判；第三项是否诉讼费用承担；上诉请求是否超出一审诉讼请求范围
- [ ] **事实与理由校验**：是否围绕一审判决的错误展开
- [ ] **证据目录生成条件校验**：是否符合生成条件
