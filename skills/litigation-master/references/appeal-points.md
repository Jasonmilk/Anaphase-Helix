# 上诉状要点与注意事项

- 上诉状的定位与目的

- 上诉策略与技巧

## 上诉状的定位与目的

### 上诉状的作用
上诉状的主要作用是**启动二审程序**，而非立即改变一审判决结果。

**核心理解**：
- 上诉状不是为了让二审法官看到上诉状就支持上诉请求
- 上诉状不是为了详细阐述全部事实和理由
- 上诉状是为了让二审法院受理上诉，进入二审程序
- 二审法院主要通过开庭审理、阅卷等方式形成判断

### 上诉状的特点
1. **程序启动功能**：核心作用是启动二审程序
2. **简洁性**：不宜长篇大论，应简明扼要
3. **针对性**：围绕一审判决的错误展开
4. **程序性**：必须符合法定格式和期限要求

---

## 上诉的条件与限制

### 上诉的法定条件

#### 1. 上诉主体适格
- 有上诉权的当事人：原告、被告、有独立请求权的第三人
- 无独立请求权的第三人只有在判决承担民事责任时才有上诉权
- 法定代表人可以代为上诉

#### 2. 上诉对象
- 地方各级人民法院第一审判决、裁定
- 最高人民法院的一审判决、裁定不得上诉

#### 3. 上诉期限
- **判决**：收到判决书之日起15日内
- **裁定**：收到裁定书之日起10日内
- 涉外案件：判决30日，裁定15日

**重要提示**：
- 期限自送达之日起计算，不是签收之日起计算
- 必须在期限内提交上诉状，否则视为放弃上诉权
- 上诉状提交给一审法院，由一审法院移送二审法院

#### 4. 上诉范围限制
- **不得超出原审诉讼请求范围**
- 可以在一审诉讼请求范围内变更具体内容
- 二审法院对超出原审诉讼请求的上诉请求不予审理

**示例**：
- 一审诉讼请求：返还借款本金10万元
- 上诉请求可以是：返还借款本金10万元+支付利息（增加了利息请求，属于超出范围，不予审理）
- 上诉请求可以是：返还借款本金8万元（减少了金额，属于变更具体内容，可以审理）

## 上诉状的撰写要点

### 1. 上诉请求的撰写

#### 基本格式
```
上诉请求：

1. 撤销XX省XX市XX区人民法院（20XX）XX民初字第XX号民事判决；
2. 依法改判【具体改判内容】；
3. 本案一、二审诉讼费用由被上诉人承担。
```

#### 关键要点

**第一项：撤销一审判决**
- 必须准确写明一审法院的完整名称
- 必须准确写明案号（年份+法院代字+民初字+编号）
- 案号格式示例：（2025）京0105民初12345号

**第二项：依法改判**
- 必须具体明确，最好具体到可以直接执行的程度
- 涉及金额的必须具体到数额
- 涉及解除合同/协议的，必须明确解除时间点
- 常见表述：
  - 依法改判驳回被上诉人的全部诉讼请求
  - 依法改判支持上诉人的全部诉讼请求
  - 依法改判被上诉人向上诉人返还本金X元，支付利息X元
  - 依法改判确认XX合同于XX年XX月XX日解除

**第三项：诉讼费用承担**
- 标准表述：本案一、二审诉讼费用由被上诉人承担
- 包括一审、二审的诉讼费、保全费等

#### 常见错误
❌ 错误：请求撤销一审判决，改判支持上诉人的诉讼请求
✅ 正确：请求撤销XX法院XX号民事判决；依法改判驳回被上诉人的全部诉讼请求

❌ 错误：请求改判被上诉人向上诉人支付合理利息
✅ 正确：请求改判被上诉人向上诉人支付利息1670.56元（具体数额）

---

### 2. 当事人信息的撰写

#### 上诉人信息
**必须注明一审诉讼地位**：
```
上诉人：张三，男，汉族，1990年1月1日出生，
住北京市朝阳区XX路XX号，公民身份号码：110101199001011234。
联系电话：13800138000

（系一审被告）
```

**身份地位格式**：
- （系一审原告）
- （系一审被告）
- （系一审第三人）

**重要性**：
- 必须注明，否则二审法院无法确定上诉人的诉讼地位
- 一审原告上诉，称为上诉人；一审被告则称为被上诉人
- 一审第三人上诉，也称为上诉人

#### 被上诉人信息
同样必须注明一审诉讼地位：
```
被上诉人：李四，男，汉族，1992年5月10日出生，
住北京市海淀区XX路XX号，公民身份号码：110108199205105678。
联系电话：13900139000

（系一审原告）
```

### 3. 事实与理由的撰写

#### 基本结构
```
事实与理由：

【第一段：简述一审判决结果并提起上诉】
XX法院于XX年XX月XX日作出的（20XX）XX民初字第XX号民事判决，【判决结果】，该判决【错误类型】，现依法提起上诉。

【第二段：指出一审判决的错误】
一审判决存在以下错误：

【第三段：逐项论证】
一、一审判决【错误类型】，具体理由如下：
【论证内容】

二、一审判决【错误类型】，具体理由如下：
【论证内容】

【第四段：引用法律和证据】
根据【法律名称】【具体条款】之规定，【法律条文内容】。上诉人提供的【证据名称】可以证明【证明目的】。

【第五段：总结】
综上所述，一审判决【错误类型】，应予撤销。为维护上诉人的合法权益，特依法提起上诉，望二审法院查清事实，依法改判。
```

#### 错误类型

**一、认定事实错误**
- 一审判决认定的事实与实际不符
- 一审判决遗漏重要事实
- 一审判决对证据的认定错误

**二、认定事实不清**
- 一审判决对关键事实未查清
- 一审判决对事实认定模糊

**三、适用法律错误**
- 一审判决适用的法律条款不当
- 一审判决对法律条款理解错误
- 一审判决应当适用的法律未适用

**四、程序违法**
- 一审程序违反法律规定
- 一审剥夺了当事人的诉讼权利

#### 论证技巧

**1. 对比论证法**
- 对比一审判决认定的事实与实际事实
- 指出一审判决认定事实的矛盾之处
- 引用证据证明一审判决的错误

**示例**：
```
一审判决认定"双方存在民间借贷关系"，属认定事实错误。
实际上，双方系赠与关系。根据上诉人提供的微信聊天记录（证据1），
被上诉人多次表示"不用还"、"当作我送你的"等，足以证明双方系赠与关系。
一审判决仅凭被上诉人的陈述，未全面审查案件事实，错误认定双方存在民间借贷关系。
```

**2. 法律论证法**
- 引用相关法律条文
- 论证一审判决对法律的理解或适用错误
- 说明应当适用哪些法律条款

**示例**：
```
一审判决适用法律错误。
一审判决依据《中华人民共和国民法典》第六百六十七条之规定认定双方构成民间借贷关系，
但该条款适用于借款合同关系，不适用于本案赠与关系。
根据《中华人民共和国民法典》第六百五十七条之规定，
"赠与合同是赠与人将自己的财产无偿给予受赠人，受赠人表示接受赠与的合同"。
本案中，上诉人将款项无偿给予被上诉人，被上诉人表示接受，双方已形成赠与关系，
不适用借贷关系的相关法律规定。
```

**3. 证据论证法**
- 引用证据证明一审判决的事实认定错误
- 说明一审判决对证据的认定不当
- 指出一审判决遗漏了重要证据

**示例**：
```
一审判决认定事实不清。
根据上诉人提供的银行转账记录（证据2），转账附言明确写明"赠与"，足以证明款项性质。
一审判决未审查该证据，错误认定双方存在借贷关系。
```

#### 注意事项

**1. 不要罗列全部事实**
- 上诉状不是重申全部事实的地方
- 只需围绕一审判决的错误展开
- 不要事无巨细地陈述所有事实

**2. 不要重复一审已经提出的观点**
- 除非一审判决对相关观点处理错误
- 否则不需要重复一审已经提出的观点
- 重点指出一审判决的错误

**3. 不要单独列出"法律依据"**
- 法律依据应写在"事实与理由"部分
- 作为论证一审判决错误的依据
- 不要单独列出"法律依据"部分

**4. 不要罗列证据目录**
- 证据目录应单独成文
- 可以在事实与理由中引用证据（如"证据1"）
- 不要在上诉状中列出证据目录表格

**5. 简洁明了**
- 上诉状的目的在于启动二审程序
- 应尽量简单、明确
- 不要长篇大论

---

### 4. 管辖法院的撰写

#### 确定方法
根据一审法院的级别确定二审法院：

| 一审法院 | 二审法院 |
|---------|---------|
| 基层人民法院（XX区人民法院） | 中级人民法院（XX市中级人民法院） |
| 中级人民法院（XX市中级人民法院） | 高级人民法院（XX省高级人民法院） |
| 高级人民法院（XX省高级人民法院） | 最高人民法院 |

#### 填写格式
```
此致
XX省XX市XX中级人民法院
```

#### 注意事项
- 不要长篇大论论证管辖权
- 不要在管辖法院部分展开论述
- 只需写明二审法院名称即可

---

### 5. 签章与日期

#### 格式
```
上诉人：张三
二〇二五年七月十三日
```

#### 注意事项
- 使用中文数字：二〇二五年七月十三日
- 不要使用阿拉伯数字：2025年7月13日

## 常见错误与注意事项

### 常见错误

#### 1. 上诉请求不具体
❌ 错误：请求改判支持上诉人的诉讼请求
✅ 正确：请求依法改判驳回被上诉人的全部诉讼请求

#### 2. 撤销一审判决表述错误
❌ 错误：请求撤销一审判决
✅ 正确：请求撤销北京市朝阳区人民法院（2025）京0105民初12345号民事判决

#### 3. 未注明一审诉讼地位
❌ 错误：
```
上诉人：张三，男，汉族...
```
✅ 正确：
```
上诉人：张三，男，汉族...
（系一审被告）
```

#### 4. 上诉请求超出原审诉讼请求范围
❌ 错误：一审诉讼请求返还本金10万，上诉请求改判返还本金10万+支付利息（超范围）
✅ 正确：在一审诉讼请求范围内变更具体内容

#### 5. 事实与理由过于冗长
❌ 错误：事无巨细地陈述全部事实和理由
✅ 正确：围绕一审判决的错误展开，简洁明了

#### 6. 单独列出法律依据
❌ 错误：在事实与理由后单独列出"法律依据"部分
✅ 正确：法律依据写在事实与理由里面

#### 7. 罗列证据目录
❌ 错误：在上诉状中列出证据目录表格
✅ 正确：证据目录单独成文，在上诉状中引用证据

### 重要注意事项

#### 1. 隐藏火力点
- 诉讼要循序渐进，开头王炸不可取
- 不要在上诉状中把全部意见都暴露出来
- 避免被上诉人针对己方观点和证据进行相应准备
- 保留部分观点在二审庭审中提出

#### 2. 多写多错
- 上诉状中可能出现的事实性描述可能对己方不利
- 不要描述与案件无关的事实
- 避免出现描述的事实与上诉请求矛盾

#### 3. 证据与事实的对应
- 上诉状中引用的证据必须与证据目录对应
- 证据序号要保持一致
- 证明目的要明确

#### 4. 法律依据的准确性
- 引用法律条文必须准确
- 写明法律名称、条款编号
- 不要编造法律条文

#### 5. 程序性要求
- 必须在法定期限内提交上诉状
- 上诉状必须提交给一审法院
- 需要缴纳上诉费的，应及时缴纳

## 上诉策略与技巧

### 1. 选择上诉重点
- 不要对所有问题都提出上诉
- 选择最有胜诉把握的问题
- 选择对案件结果影响最大的问题

### 2. 关注一审判决的错误
- 认定事实错误
- 认定事实不清
- 适用法律错误
- 程序违法

### 3. 充分利用一审判决
- 一审判决中对自己有利的认定要充分利用
- 一审判决中矛盾的认定要指出
- 一审判决中遗漏的事实要补充

### 4. 准备充分的证据
- 二审程序中原则上不允许提交新证据
- 如确有新证据，需说明为何在一审未能提交
- 重新整理现有证据，突出重点

### 5. 预判对方观点
- 预判被上诉人的答辩观点
- 在上诉状中提前回应
- 避免在二审庭审中被对方打乱节奏

## 上诉状与起诉状的区别

| 项目 | 起诉状 | 上诉状 |
|-----|-------|-------|
| 当事人称谓 | 原告、被告 | 上诉人、被上诉人 |
| 诉讼地位 | 不需要注明 | 必须注明一审诉讼地位 |
| 诉讼请求 | 请求法院判决支持诉讼请求 | 第一项必须是"撤销一审判决" |
| 事实与理由 | 陈述全部事实和理由 | 围绕一审判决的错误展开 |
| 管辖法院 | 基层人民法院 | 中级人民法院以上 |
| 目的 | 启动一审程序 | 启动二审程序 |

---

## 总结

### 上诉状的核心要点
1. **启动程序**：上诉状的核心作用是启动二审程序
2. **针对错误**：围绕一审判决的错误展开
3. **简洁明了**：不宜长篇大论，应简明扼要
4. **具体明确**：上诉请求必须具体明确
5. **格式规范**：严格按照法定格式撰写

### 上诉状的目的
- 让二审法院受理上诉
- 指出一审判决的错误
- 为二审审理提供方向
- 不是立即改变一审判决结果

### 上诉状的原则
- **针对性原则**：针对一审判决的错误
- **具体性原则**：上诉请求具体明确
- **简洁性原则**：事实与理由简洁明了
- **程序性原则**：符合法定格式和期限
