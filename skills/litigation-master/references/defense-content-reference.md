## 答辩状基本结构

### 标准格式

```
民事答辩状

答辩人（被告）：【姓名】，【性别】，【民族】，【出生年月日】出生，
住【住址】，公民身份号码：【身份证号码】，联系电话：【电话号码】。

被答辩人（原告）：【姓名】，【性别】，【民族】，【出生年月日】出生，
住【住址】，公民身份号码：【身份证号码】，联系电话：【电话号码】。

案由：答辩人【姓名】就与被答辩人【姓名】之间的"【案由】"一案【案号：XXXX】，现针对其《民事起诉状》内容，依法提出答辩如下：

答辩请求：
1.【答辩请求1】
2.【答辩请求2】
3.【答辩请求3】

事实与理由：
【答辩事实与理由】

此致
【法院名称】

答辩人（签名）：【姓名】
【日期】
```

### 基本信息

**答辩人（被告）信息**：
- 姓名：写清楚姓名、性别、民族、出生年月日、住址、联系方式等
- 如果是单位，则写明单位名称、地址、法定代表人及职务

**被答辩人（原告）信息**：
- 同答辩人信息格式

**案由说明**：
- 简要说明您是对哪个案件的起诉状进行答辩
- 例如："答辩人因与[原告姓名]的[案件类型，如：买卖合同纠纷]一案，现提出答辩如下"

## 答辩请求的撰写要点

### 基本原则

答辩请求是您向法院提出的明确请求，直接回应原告的"诉讼请求"。

### 常用表述

**1. 全部驳回原告的诉讼请求**
```
1. 依法驳回被答辩人的全部诉讼请求；
```
适用情况：如果您认为原告完全无理

**2. 部分驳回原告的诉讼请求**
```
1. 依法驳回被答辩人关于[具体请求]的诉讼请求，并依法确认截至本案庭审辩论终结前，[答辩人尚欠的具体金额]；
2. 依法驳回被答辩人关于[具体请求]的诉讼请求；
```
适用情况：如果您只部分不同意

### 撰写技巧

- **明确、具体、直接**：答辩请求应明确、具体、直接，让法官一眼就知道您的立场
- **逐项回应**：针对原告的每一项诉讼请求，都要有明确的答辩请求
- **逻辑清晰**：答辩请求之间要有逻辑关系，不要自相矛盾

### 示例

**示例1：民间借贷纠纷（部分承认）**
```
答辩请求：
1. 依法驳回被答辩人关于支付借款本金50万元的诉讼请求，并依法确认截至本案庭审辩论终结前，答辩人尚欠本金为32万元；
2. 依法驳回被答辩人关于支付高额利息及违约金的诉讼请求；
```

**示例2：买卖合同纠纷（全部驳回）**
```
答辩请求：
1. 依法驳回被答辩人的全部诉讼请求；
```

## 事实与理由的撰写要点

### 基本原则

事实与理由是答辩状最关键的部分，需要有条理、有证据地反驳原告。

### 推荐结构：总分结构

采用"总-分"结构进行论述，使逻辑清晰、层次分明。

#### 第一层：总体回应（总）

**开篇先亮明您对本案的基本态度。**

**常用表述**：
```
答辩人承认/不承认[某项事实]，但对被答辩人在起诉状中所述[概括原告的主张]，均不予认可。
```

**示例**：
```
答辩人承认于2020年1月15日向被答辩人借款人民币50万元的事实，但对被答辩人在起诉状中所述"经多次催讨，被告均以各种理由推诿，拒不偿还"以及要求支付全部50万元本金及高额利息的诉讼请求，均不予认可。被答辩人隐瞒了部分还款及关键沟通事实，其诉讼请求与实际情况严重不符。
```

#### 第二层：逐点反驳（分）

这是最核心的部分。针对起诉状中的"事实与理由"，一一进行回应。

**推荐句式**：
- "针对原告提出的……，答辩人认为……"
- "关于……，答辩人认为……"

### 具体撰写步骤

#### 步骤1：澄清事实

**模板话术**：
```
一、关于起诉状中"[概括性引用原告的第一个核心观点]"的回应。

被答辩人在起诉状中称[详细引用或概括原告的主张]。答辩人对此不予认可，事实情况是[陈述您所认为的客观事实]。
```

**示例**：
```
二、针对事实部分的澄清与反驳

1. 借款本金已部分偿还，剩余欠款金额并非50万元。

答辩人自2021年3月至2022年8月期间，通过银行转账及微信支付方式，分五笔向被答辩人累计偿还了人民币18万元（详见证据一：还款记录清单及凭证）。因此，截至目前，答辩人实际尚欠被答辩人的借款本金应为人民币32万元，而非其诉称的50万元。被答辩人在诉状中对已还款事实只字未提，有违诚实信用原则。
```

#### 步骤2：补充关键事实

**说明与原告沟通的新情况**

**示例**：
```
2. 双方曾就还款事宜达成新的合意，并非"拒不偿还"。

2022年10月，答辩人因经营困难与被答辩人进行沟通，双方曾口头协商一致，同意剩余款项可延期至2023年12月31日前还清，且在此期间暂不计息（详见证据二：2022年10月15日的微信聊天记录截图）。答辩人一直抱有还款诚意，并积极筹措资金，并非起诉状所称的"拒不偿还"。
```

#### 步骤3：法律抗辩

**提出法律上的抗辩理由**

**示例**：
```
三、针对法律适用的主要抗辩理由

关于借款本金：应以实际未还金额32万元为准。

根据《中华人民共和国民法典》第五百六十一条及民间借贷相关司法解释，债务人部分履行债务的，债权债务关系在已履行范围内消灭。答辩人已偿还的18万元应予扣除，本案争议本金应依法核定为32万元。

关于利息及违约责任：原告主张过高，且存在诉讼时效问题。

利息计算有误：即使按照原约定计算利息，被答辩人也未扣除已还本金部分，其利息计算方式错误，金额虚高。

诉讼时效抗辩：本案借款到期日为2021年1月15日。截至被答辩人起诉之日（2024年2月），已超过三年。在此期间，除2022年10月15日那次沟通外，被答辩人未能提供任何证据证明其在2021年1月16日至2024年2月期间向答辩人进行过有效催收，导致诉讼时效中断。因此，该笔借款（即使按原合同）已超过三年的普通诉讼时效期间。根据《中华人民共和国民法典》第一百八十八条，人民法院应驳回其诉讼请求。

关于2022年的口头协议：该协议构成对原合同内容的变更，应作为确定双方权利义务的新依据。答辩人正是基于对该新协议的信任而安排资金计划。
```

### 完整模板

```
事实与理由：
【这是答辩状最关键的部分，需要有条理、有证据地反驳原告。推荐采用"总-分"结构进行论述：】

一、对原告诉讼请求及事实的总体回应

答辩人承认[某项事实]，但对被答辩人在起诉状中所述[概括原告的主张]，均不予认可。被答辩人隐瞒了[部分事实]，其诉讼请求与实际情况严重不符。

二、针对事实部分的澄清与反驳

1. [第一个反驳点]

[具体反驳内容，包括您的事实和证据]

2. [第二个反驳点]

[具体反驳内容，包括您的事实和证据]

三、针对法律适用的主要抗辩理由

关于[第一个法律问题]：

[法律依据和分析]

关于[第二个法律问题]：

[法律依据和分析]

基于上述事实与理由，为维护答辩人的合法权益，恳请贵院在查明事实的基础上，依法作出公正裁决：
```

### 撰写技巧

**1. 陈述对方观点 - 亮明我方立场 - 阐述我方事实 - 引用证据**

这是标准的反驳结构，逻辑清晰，易于理解。

**示例**：
```
被答辩人在起诉状中称"经多次催讨，被告均以各种理由推诿，拒不偿还"。答辩人对此不予认可，事实情况是答辩人一直在积极筹措资金，并与被答辩人保持沟通。以上事实，有证据一、证据二等证据予以证实（详见附件证据清单）。
```

**2. 提出法律抗辩**

即使假设对方部分成立的情况下，被答辩人的主张也因提出法律上的抗辩理由，例如：已超过诉讼时效、对方也存在过错等而不能成立。

**示例**：
```
此外，即便按照原合同约定计算利息，被答辩人的主张也因已超过三年诉讼时效而不能成立。
```

**3. 链接证据**

必须明确引用证据，说明证据证明了什么事实。

**示例**：
```
以上事实，有证据一、证据二等证据予以证实（详见附件证据清单）。
```

## 常见答辩思路和技巧

### 1. 事实抗辩

**否认事实**：
- 否认原告主张的事实
- 提出相反的事实
- 指出原告事实陈述的矛盾或不实之处

**示例**：
```
关于原告主张的"2024年11月30日被告向原告借款100,000元"这一事实，答辩人认为该事实不存在。事实情况是：答辩人曾于2024年10月1日借给原告150,000元，原告于2024年11月30日通过银行转账方式向答辩人归还100,000元，该笔款项系原告归还之前的借款。
```

**澄清事实**：
- 澄清被原告隐瞒的事实
- 补充原告未提及的重要事实
- 说明事实的前因后果

**示例**：
```
答辩人自2021年3月至2022年8月期间，通过银行转账及微信支付方式，分五笔向被答辩人累计偿还了人民币18万元。因此，截至目前，答辩人实际尚欠被答辩人的借款本金应为人民币32万元，而非其诉称的50万元。被答辩人在诉状中对已还款事实只字未提，有违诚实信用原则。
```

### 2. 法律抗辩

**诉讼请求缺乏法律依据**：
- 原告的诉讼请求没有相应的法律依据
- 原告适用的法律条文不正确

**示例**：
```
关于借款本金：应以实际未还金额32万元为准。根据《中华人民共和国民法典》第五百六十一条及民间借贷相关司法解释，债务人部分履行债务的，债权债务关系在已履行范围内消灭。答辩人已偿还的18万元应予扣除，本案争议本金应依法核定为32万元。
```

**诉讼时效抗辩**：
- 原告的起诉已经超过诉讼时效
- 不存在诉讼时效中断、中止的情形

**示例**：
```
诉讼时效抗辩：本案借款到期日为2021年1月15日。截至被答辩人起诉之日（2024年2月），已超过三年。在此期间，除2022年10月15日那次沟通外，被答辩人未能提供任何证据证明其在2021年1月16日至2024年2月期间向答辩人进行过有效催收，导致诉讼时效中断。因此，该笔借款（即使按原合同）已超过三年的普通诉讼时效期间。根据《中华人民共和国民法典》第一百八十八条，人民法院应驳回其诉讼请求。
```

**合同变更抗辩**：
- 双方已达成新的合意，变更了原合同内容
- 应以新协议作为确定权利义务的依据

**示例**：
```
关于2022年的口头协议：该协议构成对原合同内容的变更，应作为确定双方权利义务的新依据。答辩人正是基于对该新协议的信任而安排资金计划。
```

### 3. 部分承认策略

**承认部分事实，否认部分事实**：
- 承认原告主张的部分事实
- 否认原告主张的部分事实
- 明确说明承认的部分和否认的部分

**示例**：
```
答辩人承认于2020年1月15日向被答辩人借款人民币50万元的事实，但对被答辩人在起诉状中所述"经多次催讨，被告均以各种理由推诿，拒不偿还"以及要求支付全部50万元本金及高额利息的诉讼请求，均不予认可。被答辩人隐瞒了部分还款及关键沟通事实，其诉讼请求与实际情况严重不符。
```

## 法律依据的引用规范

### 基本原则

- 引用的法律条文要准确
- 法律条文要与案件事实相对应
- 将法律依据融入事实与理由中
- 不要单独列出"法律依据"部分

### 引用格式

**标准格式**：
```
根据《中华人民共和国民法典》第XXX条之规定，[引用条文内容]，因此[得出结论]。
```

**示例**：
```
根据《中华人民共和国民法典》第五百六十一条及民间借贷相关司法解释，债务人部分履行债务的，债权债务关系在已履行范围内消灭。答辩人已偿还的18万元应予扣除，本案争议本金应依法核定为32万元。
```

### 常用法律条文

**民间借贷纠纷**：
- 《中华人民共和国民法典》第六百六十七条（借款合同定义）
- 《中华人民共和国民法典》第六百八十条（利息约定）
- 《中华人民共和国民法典》第五百六十一条（部分履行）
- 《中华人民共和国民法典》第一百八十八条（诉讼时效）

**买卖合同纠纷**：
- 《中华人民共和国民法典》第五百八十二条（履行不符合约定）
- 《中华人民共和国民法典》第五百九十条（不可抗力）
- 《中华人民共和国民法典》第五百七十七条（违约责任）

**侵权责任纠纷**：
- 《中华人民共和国民法典》第一千一百六十五条（过错责任）
- 《中华人民共和国民法典》第一千一百七十九条（赔偿范围）
- 《中华人民共和国民法典》第一千一百八十三条（精神损害赔偿）

## 证据的使用和引用

### 证据引用格式

**标准格式**：
```
详见证据X：【证据名称】
```

**示例**：
```
答辩人自2021年3月至2022年8月期间，通过银行转账及微信支付方式，分五笔向被答辩人累计偿还了人民币18万元（详见证据一：还款记录清单及凭证）。
```

### 证据引用原则

1. **明确性**：必须明确指出证据的名称和证明目的
2. **相关性**：证据必须与答辩观点相关
3. **真实性**：证据必须是真实的、合法的
4. **完整性**：不要只引用部分证据，导致误导

### 证据清单

在事实与理由的末尾，通常会引用证据清单：

```
以上事实，有证据一、证据二等证据予以证实（详见附件证据清单）。
```

## 完整示例

### 民间借贷纠纷

```
民事答辩状

答辩人（被告）：王五，男，汉族，1985年5月10日出生，
住北京市海淀区XX路XX号院X号楼X单元XXX室，
公民身份号码：11010519850510XXXX，联系电话：138-XXXX-XXXX。

被答辩人（原告）：赵六，男，汉族，1978年12月25日出生，
住北京市朝阳区XX大街XX小区X号楼XXX室，
公民身份号码：11010519781225XXXX，联系电话：139-XXXX-XXXX。

案由：答辩人王五就与被答辩人赵六之间的"民间借贷纠纷"一案【案号：（2024）京01XX民初XXXX号】，现针对其《民事起诉状》内容，依法提出答辩如下：

答辩请求：
1. 依法驳回被答辩人关于支付借款本金50万元的诉讼请求，并依法确认截至本案庭审辩论终结前，答辩人尚欠本金为32万元；
2. 依法驳回被答辩人关于支付高额利息及违约金的诉讼请求；
3. 本案的全部诉讼费用由被答辩人承担。

事实与理由：

答辩人承认于2020年1月15日向被答辩人借款人民币50万元的事实，但对被答辩人在起诉状中所述"经多次催讨，被告均以各种理由推诿，拒不偿还"以及要求支付全部50万元本金及高额利息的诉讼请求，均不予认可。被答辩人隐瞒了部分还款及关键沟通事实，其诉讼请求与实际情况严重不符。

一、针对事实部分的澄清与反驳

1. 借款本金已部分偿还，剩余欠款金额并非50万元。
```
