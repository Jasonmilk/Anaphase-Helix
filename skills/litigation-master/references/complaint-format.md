# 民事起诉状格式模板

## 目录
- 格式结构
- 逐部分说明
- 格式示例
- 注意事项

## 格式结构

民事起诉状应按以下顺序排列：

1. 标题（居中）
2. 原告信息
3. 被告信息
4. 诉讼请求
5. 事实与理由
6. 管辖法院
7. 签章与日期

## 逐部分说明

### 1. 标题

**格式要求**：
- 居中写"民事起诉状"
- 字体：一般用宋体或楷体
- 位置：页面顶部居中

**示例**：
```
民事起诉状
```

---

### 2. 原告信息

**自然人格式**：
```
原告： 【姓名】， 【性别】， 【民族】， 【出生日期】出生，
住【住址】， 公民身份号码：【身份证号码】。
联系电话：【电话号码】
```

**填写说明**：
- 姓名：写身份证上的全名
- 性别：男/女
- 民族：汉族/其他民族
- 出生日期：XXXX年XX月XX日
- 住址：写身份证上的住址，或实际送达地址
- 身份证号码：18位身份证号码
- 联系电话：可联系的联系电话

**法人或其他组织格式**：
```
原告： 【名称】，住所地：【住所地址】。
法定代表人：【姓名】，职务：【职务】。
统一社会信用代码：【统一社会信用代码】。
联系电话：【电话号码】
```

**填写说明**：
- 名称：营业执照上的全称
- 住所地：营业执照上的住所地
- 法定代表人：法定代表人的姓名
- 职务：法定代表人的职务（如董事长、经理等）
- 统一社会信用代码：18位统一社会信用代码
- 联系电话：可联系的联系电话

---

### 3. 被告信息

**格式**：同原告信息格式

**自然人格式**：
```
被告： 【姓名】， 【性别】， 【民族】， 【出生日期】出生，
住【住址】， 公民身份号码：【身份证号码】。
联系电话：【电话号码】
```

**法人或其他组织格式**：
```
被告： 【名称】，住所地：【住所地址】。
法定代表人：【姓名】，职务：【职务】。
统一社会信用代码：【统一社会信用代码】。
联系电话：【电话号码】
```

**注意事项**：
- 原告和被告的格式要保持一致
- 若有多个原告或被告，分别列出

---

### 4. 诉讼请求

**格式**：
```
诉讼请求：

1. 请求依法判令被告向原告【具体诉求1】；
2. 请求依法判令被告向原告【具体诉求2】；
3. 请求依法判令被告【具体诉求3】；
```

**填写说明**：
- 每项请求前加序号（1. 2. 3. ...）
- 每项请求末尾用分号（；）结束，最后一项用句号（。）
- 诉讼请求必须具体明确，最好具体到可以直接执行的程度

**常见诉讼请求类型**：

**1. 返还财产类**：
```
1. 请求依法判令被告向原告返还借款本金100,000元；
```

**2. 支付利息类**：
```
2. 请求依法判令被告向原告支付借款利息1670.56元（以本金100,000元
为基数，按照中国人民银行授权全国银行间同业拆借中心发布的一年期贷
款市场报价利率(LPR)标准，自2025年1月1日计算至被告清偿完毕之日止，
暂计至2025年7月13日为1670.56元）；
```

**3. 承担费用类**：
```
3. 请求依法判令被告承担本案诉讼费、保全费等各项费用。
```

**4. 交付财产类**：
```
4. 请求依法判令被告向原告交付位于【地址】的房屋（房产证号：
XXXXXX）；
```

**5. 停止侵害类**：
```
5. 请求依法判令被告停止侵害原告名誉权的行为；
```

**6. 赔偿损失类**：
```
6. 请求依法判令被告赔偿原告经济损失50,000元；
```

**注意事项**：
- 诉讼请求是起诉状的核心，案件的审理和裁判围绕其展开
- 最好根据实际情况制定诉讼策略，分析和比较各类请求权基础
- 检查诉讼请求是否有遗漏
- 例如：根据《民间借贷规定》第二十八条，即使借条未约定借期内利率和逾期利率，出借人也可以主张借款人自逾期还款之日起参照LPR标准承担逾期还款的违约责任

---

### 5. 事实与理由

**格式**：
```
【陈述案件基本事实】

【分析法律关系】

【引用法律依据】

【结论】
```

**填写说明**：
- 简洁清晰地陈述案件基本事实
- 围绕诉讼请求展开
- 说明"哪些主体在什么时间、地点实施了哪些行为，各方之间形成了什么样的法律关系，在整个事件中我方基于何种事实和法律依据有权主张哪些权利"
- 不要事无巨细地罗列所有事实
- 不要在起诉状中过多论证，这是庭审的工作

**示例结构**：

**事实部分**：
```
2024年11月30日，被告以资金周转需要为由向原告提出借款100,000元
的请求，还款期限为1个月。原告出于好意同意借款，并于当日通过银行转
账的方式向原告出借本金100,000元。根据约定，被告应当于2025年1月1日
之前全额返还借款本金，但截止至起诉之日，被告始终未向原告支付任何借
款本金。
```

**理由部分**：
```
原被告双方的民间借贷关系合法有效，应当受到法律的保护。现被告至今
不履行还本付息义务的行为，已严重侵犯了原告的合法权益。根据《中华
人民共和国民法典》等相关法律法规，原告有权追究被告的民事责任，追偿
请求包括但不限于返还全部本金及利息、承担本案诉讼费等等。因此，为
维护自身合法权益，原告特根据相关法律规定，依法向贵院起诉，望判如
所请。
```

**注意事项**：
- 起诉状的作用主要在于立案，这部分围绕诉讼请求简洁清晰地陈述即可
- 不要在起诉状中写过多的法律条文和论证
- 原告与被告的称呼要保持一致，不要混乱

---

### 6. 管辖法院

**格式**：
```
【省市区】人民法院
```

**填写说明**：
- 写明具体法院名称
- 格式：省市区+人民法院
- 例如：XX省XX市XX区人民法院

**管辖法院确定原则**：

**一般原则**：
- 通常是被告住所地的基层人民法院
- 若被告住所地与经常居住地不一致，以经常居住地为准

**特殊情形**：
- 借款合同纠纷：可以由原告住所地、被告住所地、合同履行地法院管辖
- 侵权纠纷：由侵权行为地或被告住所地法院管辖
- 不动产纠纷：由不动产所在地法院管辖
- 合同纠纷：由被告住所地或合同履行地法院管辖

**注意事项**：
- 需要考虑案件主管、案件审级、案由类型等具体情形
- 特定案件可能由特定的仲裁委员会主管（仲裁主管的情形下应提交仲裁申请书）

---

### 7. 签章与日期

**格式**：
```

                                      具状人： 【原告签字并捺印】
                                      【日期】
```

**填写说明**：
- 右下角写"具状人："
- 右对齐
- 日期写"二〇二五年七月十三日"（用中文数字）
- 日期右对齐，与"具状人："对齐

**注意事项**：
- 自然人：签字并捺印
- 法人或其他组织：加盖公章
- 诉状写好之后，按照人手一份的标准打印（也就是开庭时各方都需要有一份起诉状，包括法院、我方以及被告等诉讼主体）

## 注意事项

### 格式要求
- 标题居中
- 原告被告信息分段写，每项信息之间空格
- 诉讼请求用编号列出，每项末尾用分号，最后一项用句号
- 事实与理由分段清晰
- 管辖法院单独一行
- 签章日期右对齐

### 用语规范
- 使用书面语，避免口语化
- 用词准确，避免模糊表述
- 引用法律条文时，准确写出法律名称和条款

### 标点符号
- 句号、逗号、分号、冒号等标点符号使用正确
- 中英文标点符号区分使用

### 空行要求
- 各部分之间适当空行，使版面整洁
- 原告信息和被告信息之间空一行
- 被告信息和诉讼请求之间空一行
- 诉讼请求和事实与理由之间空一行
- 事实与理由和管辖法院之间空一行
