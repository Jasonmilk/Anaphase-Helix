## 标准格式

```
民事答辩状

答辩人：XXX，男，汉族，生于19XX年XX月XX日，住XX省XX市XX区XX路XX室XX号，身份证号：xxxxxx，联系电话：XXXXXX。
（释明：以上写明答辩人的姓名或名称等基本信息）

被答辩人：XXX，男，汉族，生于19XX年XX月XX日，住XX省XX市XX区XX路XX室XX号，身份证号：xxxxxx，联系电话：XXXXXX。

答辩人现就本案（案号：          ）提出以下答辩意见。

一、原告的诉讼请求无事实与法律依据，依法应予驳回。关于原告主张的XX事实，答辩人认为......（阐述事实和理由）

二、关于原告主张的XX问题，答辩人认为......（阐述法律适用分析）

综上所述，原告的诉讼请求缺乏事实和法律依据，请求法院依法驳回原告的诉讼请求，本案诉讼费用由原告承担。

此致
xxxxx人民法院
答辩人：

年月日
```

## 逐部分说明

### 1. 标题

**格式要求**：
- 居中写"民事答辩状"
- 字体：一般用宋体或楷体
- 位置：页面顶部居中

**示例**：
```
民事答辩状
```

---

### 2. 答辩人信息

**自然人格式**：
```
答辩人：XXX，男，汉族，生于19XX年XX月XX日，
住XX省XX市XX区XX路XX室XX号，身份证号：xxxxxx，联系电话：XXXXXX。
```

**释明**：以上写明答辩人的姓名或名称等基本信息

**填写说明**：
- 姓名：写身份证上的全名
- 性别：男/女
- 民族：汉族/其他民族
- 出生日期：生于19XX年XX月XX日
- 住址：填写身份证上的住址或实际送达地址
- 身份证号：18位身份证号码，必须准确无误
- 联系电话：可以联系的常用电话号码

**示例**：
```
答辩人：王五，男，汉族，生于1985年5月10日，
住北京市海淀区XX路XX号院X号楼X单元XXX室，
身份证号：11010519850510XXXX，联系电话：138-XXXX-XXXX。
```

---

**法人或其他组织格式**：
```
答辩人：XX科技有限公司，住所地：XX省XX市XX区XX路XX号。
法定代表人：张三，职务：董事长。
统一社会信用代码：91110101MA01234567。联系电话：13900139000。
```

**填写说明**：
- 名称：营业执照上的全称
- 住所地：营业执照上的住所地或实际办公地址
- 法定代表人：法定代表人的姓名和职务
- 统一社会信用代码：18位统一社会信用代码，必须准确无误
- 联系电话：公司联系电话或负责人联系电话

**释明**：被答辩人即起诉状中的原告

**示例**：

```
住北京市朝阳区XX大街XX小区X号楼XXX室，
身份证号：11010519781225XXXX，联系电话：139-XXXX-XXXX。
```

### 4. 答辩意见与事实理由

**格式要求**：
- **合并书写**：将答辩意见和事实与理由合并为一个部分，不分开表述
- 编号列出：一、二、三...
- 每项同时包含答辩意见和相应的事实理由
- 逐项回应原告的诉讼请求和事实陈述

**格式模板**：
```
一、原告的诉讼请求无事实与法律依据，依法应予驳回。关于原告主张的XX事实，答辩人认为......（阐述事实和理由）

二、关于原告主张的XX问题，答辩人认为......（阐述法律适用分析）
```

**常见表述**：

**1. 全部驳回**
```
一、原告的诉讼请求无事实与法律依据，依法应予驳回。原告在起诉状中称......，但事实是......，因此......

二、关于原告主张的XX问题，答辩人认为......
```

**2. 部分驳回**
```
一、依法驳回原告关于[具体请求]的诉讼请求，并依法确认截至本案庭审辩论终结前，[答辩人尚欠的具体金额]。关于原告主张的......，答辩人认为......

二、依法驳回原告关于[具体请求]的诉讼请求。原告称......，但......

三、关于原告主张的XX问题，答辩人认为......
```

---

### 5. 总结陈述

**格式**：
```
综上所述，答辩人不应承担相应责任，依法应当驳回XXX的诉讼请求。
```

或

```
基于上述事实与理由，为维护答辩人的合法权益，恳请贵院在查明事实的基础上，依法作出公正裁决：
```

---

### 6. 总结与答辩请求

**格式**：
```
综上所述，原告的诉讼请求缺乏事实和法律依据，请求法院依法驳回原告的诉讼请求，本案诉讼费用由原告承担。

此致
XXXXX人民法院
```

**填写说明**：
- 在事实与理由之后，写总结陈述
- 总结中必须包含答辩请求：驳回原告诉讼请求、诉讼费用由原告承担
- 例如："综上所述，原告的诉讼请求缺乏事实和法律依据，请求法院依法驳回原告的诉讼请求，本案诉讼费用由原告承担。"
- 例如："综上所述，答辩人不应承担相应责任，请求法院依法驳回原告的全部诉讼请求，本案诉讼费用由原告承担。"

### 7. 签名与日期

**格式**：
```
答辩人：【姓名】

年月日
```

**填写说明**：
- 答辩人：答辩人本人签名或盖章
- 日期：年月日

**示例**：
```
答辩人：王五

2025年10月30日
```

### 示例2：完整格式（民间借贷纠纷）

```
民事答辩状

答辩人（被告）：王五，男，汉族，生于1985年5月10日，
住北京市海淀区XX路XX号院X号楼X单元XXX室，
身份证号：11010519850510XXXX，联系电话：138-XXXX-XXXX。

被答辩人（原告）：赵六，男，汉族，生于1978年12月25日，
住北京市朝阳区XX大街XX小区X号楼XXX室，
身份证号：11010519781225XXXX，联系电话：139-XXXX-XXXX。

答辩人现就本案（案号：                                   ）提出以下答辩意见。

一、依法驳回被答辩人关于支付借款本金50万元的诉讼请求，并依法确认截至本案庭审辩论终结前，答辩人尚欠本金为32万元。答辩人承认于2020年1月15日向被答辩人借款人民币50万元的事实，但答辩人自2021年3月至2022年8月期间，通过银行转账及微信支付方式，分五笔向被答辩人累计偿还了人民币18万元。因此，截至目前，答辩人实际尚欠被答辩人的借款本金应为人民币32万元，而非其诉称的50万元。

二、依法驳回被答辩人关于支付高额利息及违约金的诉讼请求。关于借款本金：应以实际未还金额32万元为准。根据《中华人民共和国民法典》第五百六十一条及民间借贷相关司法解释，债务人部分履行债务的，债权债务关系在已履行范围内消灭。答辩人已偿还的18万元应予扣除，本案争议本金应依法核定为32万元。关于利息计算有误：即使按照原约定计算利息，被答辩人也未扣除已还本金部分，其利息计算方式错误，金额虚高。

三、关于诉讼时效问题。本案借款到期日为2021年1月15日。截至被答辩人起诉之日（2024年2月），已超过三年。在此期间，除2022年10月15日那次沟通外，被答辩人未能提供任何证据证明其在2021年1月16日至2024年2月期间向答辩人进行过有效催收，导致诉讼时效中断。因此，该笔借款（即使按原合同）已超过三年的普通诉讼时效期间。根据《中华人民共和国民法典》第一百八十八条，人民法院应驳回其诉讼请求。

综上所述，原告的诉讼请求缺乏事实和法律依据，请求法院依法驳回原告的诉讼请求，本案诉讼费用由原告承担。

此致
北京市XX区人民法院

答辩人（签名）：王五
2025年10月30日
```

## 注意事项

### 1. 格式规范

- 严格按照上述格式要求撰写
- 标题居中写"民事答辩状"
- 答辩人信息、被答辩人信息分段清晰
- 答辩意见与事实理由合并书写，逐项列明
- 签名与日期格式正确

### 2. 内容规范

- 逐项回应原告的诉讼请求和事实陈述
- 明确表明答辩人的态度
- 事实陈述要清楚、具体
- 法律依据要准确
- 证据引用要明确

### 3. 语言规范

- 用语规范，避免口语化
- 标点符号正确
- 空行适当，版面整洁
- 语言简洁明了，逻辑清晰

### 4. 特殊情况

**合并书写原则**：
答辩意见和事实与理由必须合并书写，每项编号同时包含答辩意见和相应的事实理由，不得分开表述。

**释明文字**：
格式模板中的"（释明：...）"是说明文字，在正式答辩状中不需要保留

**案号格式**：
案号格式为：(XXXX)民初XXXX号，严格按照法院实际案号填写

### 5. 与附件的对应关系

本格式文档严格遵循"2-答辩状格式.docx"附件的内容要求：
- 标题：民事答辩状
- 答辩人信息：姓名、性别、民族、出生日期、住址、身份证号、联系电话
- 被答辩人信息：姓名、性别、民族、出生日期、住址、身份证号、联系电话
- 答辩意见与事实理由：合并书写，逐项列明，每项包含意见和事实理由
- 总结陈述：综上所述，答辩人不应承担相应责任，依法应当驳回XXX的诉讼请求
- 此致：XXXXX人民法院
- 答辩人：【姓名】
- 日期：年月日
