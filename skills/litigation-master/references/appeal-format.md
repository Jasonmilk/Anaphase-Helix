# 上诉状格式模板

## 目录
- 格式结构
- 逐部分说明
- 格式示例
- 注意事项

## 格式结构

上诉状应按以下顺序排列：

1. 标题（居中）
2. 上诉人信息
3. 被上诉人信息
4. 原审当事人信息（如存在未上诉主体）
5. 上诉请求
6. 事实与理由
7. 管辖法院
8. 签章与日期

## 逐部分说明

### 1. 标题

**格式要求**：
- 居中写"民事上诉状"
- 字体：一般用宋体或楷体
- 位置：页面顶部居中

**示例**：
```
民事上诉状
```

---

### 2. 上诉人信息

**自然人格式**：
```
上诉人：【姓名】，【性别】，【民族】，【出生日期】出生，
住【住址】，公民身份号码：【身份证号码】。
联系电话：【电话号码】

（系一审原告/被告/第三人）
```

**填写说明**：
- 姓名：写身份证上的全名
- 性别：男/女
- 民族：汉族/其他民族
- 出生日期：XXXX年XX月XX日
- 住址：写身份证上的住址，或实际送达地址
- 身份证号码：18位身份证号码
- 联系电话：可联系的联系电话
- 身份地位：必须注明上诉人在一审中的诉讼地位（原告、被告、第三人）

**法人或其他组织格式**：
```
上诉人：【名称】，住所地：【住所地址】。
法定代表人：【姓名】，职务：【职务】。
统一社会信用代码：【统一社会信用代码】。
联系电话：【电话号码】

（系一审原告/被告/第三人）
```

**填写说明**：
- 名称：营业执照上的全称
- 住所地：营业执照上的住所地
- 法定代表人：法定代表人的姓名
- 职务：法定代表人的职务（如董事长、经理等）
- 统一社会信用代码：18位统一社会信用代码
- 联系电话：可联系的联系电话
- 身份地位：必须注明上诉人在一审中的诉讼地位（原告、被告、第三人）

---

### 3. 被上诉人信息

**格式**：同上诉人信息格式

**自然人格式**：
```
被上诉人：【姓名】，【性别】，【民族】，【出生日期】出生，
住【住址】，公民身份号码：【身份证号码】。
联系电话：【电话号码】

（系一审原告/被告/第三人）
```

**法人或其他组织格式**：
```
被上诉人：【名称】，住所地：【住所地址】。
法定代表人：【姓名】，职务：【职务】。
统一社会信用代码：【统一社会信用代码】。
联系电话：【电话号码】

（系一审原告/被告/第三人）
```

**注意事项**：
- 上诉人和被上诉人的格式要保持一致
- 必须注明被上诉人在一审中的诉讼地位（原告、被告、第三人）
- 若有多个被上诉人，分别列出

---

### 4. 原审当事人信息（如存在未上诉主体）

**适用情况**：
- 当存在未提起上诉的当事人时，需要在本部分列明该当事人信息
- 未上诉主体是指在一审中参与诉讼但未提起上诉的当事人

**自然人格式**：
```
原审原告/原审被告/原审第三人：【姓名】，【性别】，【民族】，【出生日期】出生，
住【住址】，公民身份号码：【身份证号码】。
联系电话：【电话号码】

```

**法人或其他组织格式**：
```
原审原告/原审被告/原审第三人：【名称】，住所地：【住所地址】。
法定代表人：【姓名】，职务：【职务】。
统一社会信用代码：【统一社会信用代码】。
联系电话：【电话号码】

```

**填写说明**：
- 使用"原审原告"、"原审被告"、"原审第三人"的称谓
- 必须准确注明该当事人在一审中的诉讼地位
- 格式要求与上诉人、被上诉人信息保持一致
- 如有多个未上诉主体，分别列出

**注意事项**：
- 注明"原审"身份，以区别于上诉人和被上诉人
- 本部分仅在存在未上诉主体时才需要
- 如所有当事人都提起了上诉，则无需本部分

---

### 5. 上诉请求

**格式**：
```
上诉请求：

1. 撤销XX省XX市XX区人民法院（20XX）XX民初字第XX号民事判决；
2. 依法改判【具体改判内容】；
3. 本案一、二审诉讼费用由被上诉人承担。
```

**填写说明**：

1. **第一项请求**：
   - 格式：撤销XX省XX市XX区人民法院（20XX）XX民初字第XX号民事判决
   - 必须准确写明一审法院的名称、案号
   - 案号格式：（年份）法院代字民初字第编号
   - 示例：撤销北京市朝阳区人民法院（2024）京0105民初12345号民事判决

2. **第二项请求**：
   - 格式：依法改判【具体改判内容】
   - 必须具体明确，最好具体到可以直接执行的程度
   - 示例：
     - 依法改判被上诉人向上诉人返还借款本金100,000元；
     - 依法改判被上诉人向上诉人支付利息1670.56元（以本金100,000元为基数，按照中国人民银行授权全国银行间同业拆借中心发布的一年期贷款市场报价利率(LPR)标准，自2025年1月1日计算至被上诉人清偿完毕之日止，暂计至2025年7月13日为1670.56元）；
     - 依法改判驳回被上诉人的全部诉讼请求；
     - 依法改判支持上诉人的全部诉讼请求

3. **第三项请求**：
   - 格式：本案一、二审诉讼费用由被上诉人承担
   - 包括一审、二审的诉讼费、保全费等程序性费用

**注意事项**：
- 上诉请求必须具体明确，不得模糊不清
- 上诉请求不能超出一审诉讼请求的范围
- 涉及金额的必须具体到数额
- 涉及解除合同/协议时，必须明确写明希望解除的时间点
  - 格式：请求确认XXX合同/协议于XX年XX月XX日解除

---

### 6. 事实与理由

**格式要求**：
- 简洁清晰地陈述上诉理由
- 围绕上诉请求展开
- 不要事无巨细地罗列所有事实
- 法律依据要写在事实与理由里面，作为主张的依据，不要单独列出

**基本结构**：
```
事实与理由：

【第一段：简述一审判决结果】
XX省XX市XX区人民法院于20XX年XX月XX日作出的（20XX）XX民初字第XX号民事判决，【判决结果】，该判决认定事实错误/适用法律错误/程序违法，现依法提起上诉。

【第二段：明确指出一审判决的错误】
一审判决存在以下错误：

【第三段：逐项论证一审判决的错误】
1. 【错误类型一】
   【论证该错误的具体表现和理由】

2. 【错误类型二】
   【论证该错误的具体表现和理由】

【第四段：引用法律依据和证据】
根据【法律名称】【具体条款】之规定，【法律条文内容】。上诉人提供的【证据名称】可以证明【证明目的】。

【第五段：总结】
综上所述，一审判决【错误类型】，应予撤销。为维护上诉人的合法权益，特依法提起上诉，望二审法院查清事实，依法改判。
```

**填写要点**：

1. **一审判决错误类型**：
   - 认定事实错误
   - 适用法律错误
   - 程序违法
   - 认定事实不清
   - 遗漏重要事实
   - 证据不足

2. **论证方法**：
   - 对比一审判决认定的事实与实际事实
   - 指出一审判决对法律的错误理解或适用
   - 引用证据证明一审判决的事实认定错误
   - 引用法律条文论证一审判决的法律适用错误

3. **避免内容**：
   - 不要在事实与理由中罗列证据目录
   - 不要在事实与理由中单独列出"法律依据"部分
   - 不要在一审已经提出的问题上纠缠，除非一审判决处理错误

**示例结构**：
```
事实与理由：

北京市朝阳区人民法院于2025年5月20日作出的（2025）京0105民初12345号民事判决，判令上诉人向被上诉人返还借款本金100,000元并支付利息，该判决认定事实错误，现依法提起上诉。

一审判决存在以下错误：

一、一审判决认定双方存在民间借贷关系，属认定事实错误。
上诉人与被上诉人之间不存在民间借贷关系，而是【真实法律关系】。根据上诉人提供的【证据名称】可以证明，双方系【真实法律关系】。一审判决仅凭被上诉人的陈述，未全面审查案件事实，错误认定双方存在民间借贷关系。

二、一审判决适用法律错误。
一审判决依据《中华人民共和国民法典》第六百六十七条之规定认定双方构成民间借贷关系，但该条款适用于借款合同关系，不适用于本案【真实法律关系】。根据【相关法律】之规定，【法律条文内容】。

综上所述，一审判决认定事实错误、适用法律错误，应予撤销。为维护上诉人的合法权益，特依法提起上诉，望二审法院查清事实，依法改判。
```

### 7. 管辖法院

**格式要求**：
- 写明具体法院名称：XX省XX市XX中级人民法院
- 根据一审法院的级别确定二审法院
- 不需要展开论述管辖权问题

**确定方法**：
- 基层人民法院（XX区人民法院）→ 中级人民法院（XX市中级人民法院）
- 中级人民法院（XX市中级人民法院）→ 高级人民法院（XX省高级人民法院）
- 高级人民法院（XX省高级人民法院）→ 最高人民法院

**填写格式**：
```
此致
XX省XX市XX中级人民法院
```

**示例**：
```
此致
北京市第二中级人民法院
```

**注意事项**：
- 不要长篇大论论证管辖权
- 不要在管辖法院部分展开论述
- 只需写明二审法院名称即可

---

### 8. 签章与日期

**格式**：
```
上诉人：【上诉人名称】
二〇二五年七月十三日
```

**填写说明**：
- 右下角写："上诉人："（如有多个上诉人，分别写"上诉人1："、"上诉人2："等）
- 如有代理人，可以在上诉人下方写"代理人："并签字
- 右下角写明日期（用中文数字）
- 日期格式：二〇二五年七月十三日

**示例**：
```
上诉人：张三
二〇二五年七月十三日
```

或

```
上诉人：张三
代理人：李四（律师）
二〇二五年七月十三日
```

## 格式示例

### 完整示例（民间借贷纠纷）

```
民事上诉状

上诉人：张三，男，汉族，1990年1月1日出生，
住北京市朝阳区XX路XX号，公民身份号码：110101199001011234。
联系电话：13800138000

（系一审被告）

被上诉人：李四，男，汉族，1992年5月10日出生，
住北京市海淀区XX路XX号，公民身份号码：110108199205105678。
联系电话：13900139000

（系一审原告）

上诉请求：

1. 撤销北京市朝阳区人民法院（2025）京0105民初12345号民事判决；
2. 依法改判驳回被上诉人的全部诉讼请求；
3. 本案一、二审诉讼费用由被上诉人承担。

事实与理由：

北京市朝阳区人民法院于2025年5月20日作出的（2025）京0105民初12345号民事判决，判令上诉人向被上诉人返还借款本金100,000元并支付利息，该判决认定事实错误，现依法提起上诉。

一审判决存在以下错误：

一、一审判决认定双方存在民间借贷关系，属认定事实错误。
上诉人与被上诉人之间不存在民间借贷关系，而是赠与关系。根据上诉人提供的微信聊天记录可以证明，被上诉人多次表示"不用还"、"当作我送你的"等，足以证明双方系赠与关系。一审判决仅凭被上诉人的陈述，未全面审查案件事实，错误认定双方存在民间借贷关系。

二、一审判决适用法律错误。
一审判决依据《中华人民共和国民法典》第六百六十七条之规定认定双方构成民间借贷关系，但该条款适用于借款合同关系，不适用于本案赠与关系。根据《中华人民共和国民法典》第六百五十七条之规定，赠与合同是赠与人将自己的财产无偿给予受赠人，受赠人表示接受赠与的合同。本案中，上诉人将款项无偿给予被上诉人，被上诉人表示接受，双方已形成赠与关系，不适用借贷关系的相关法律规定。

综上所述，一审判决认定事实错误、适用法律错误，应予撤销。为维护上诉人的合法权益，特依法提起上诉，望二审法院查清事实，依法改判。

此致
北京市第三中级人民法院

上诉人：张三
二〇二五年七月十三日
```

## 注意事项

### 核心原则

1. **严格格式控制**
   - 上诉状必须严格按照上述格式起草
   - 不要增加格式要求以外的内容
   - 例如：不要在上诉状中加入证据目录、重要提示等格式要求以外的内容

2. **上诉请求必须具体明确**
   - 必须写明撤销一审法院的名称和案号
   - 改判请求必须具体明确，最好具体到可以直接执行的程度
   - 涉及金额的必须具体到数额
   - 涉及解除合同/协议时，必须明确写明希望解除的时间点

3. **事实与理由简洁明了**
   - 不要事无巨细地将所有意见观点及事实罗列殆尽
   - 上诉状的目的在于启动二审程序，应尽量简单、明确
   - 围绕一审判决的错误展开论述
   - 不要在一审已经提出的问题上纠缠，除非一审判决处理错误

4. **称呼一致**
   - 上诉人与被上诉人的称呼要保持一致
   - 不要让本来方便表述的称呼使整篇上诉状变得混乱

5. **隐藏火力点**
   - 诉讼要循序渐进，开头王炸不可取
   - 不要在上诉状中把全部意见都暴露出来
   - 避免被上诉人针对己方观点和证据进行相应准备

6. **多写多错**
   - 上诉状中可能出现的事实性描述可能对己方不利
   - 不要描述与案件无关的事实
   - 避免出现描述的事实与上诉请求矛盾

### 上诉状与起诉状的区别

1. **当事人称谓**：上诉状称"上诉人"和"被上诉人"，起诉状称"原告"和"被告"
2. **诉讼地位**：上诉状必须注明当事人在一审中的诉讼地位（原告/被告/第三人）
3. **上诉请求**：上诉状的第一项请求必须是"撤销XX法院XX号民事判决"
4. **事实与理由**：上诉状应围绕一审判决的错误展开，而不是陈述全部事实
5. **管辖法院**：上诉状的管辖法院是二审法院（中级人民法院以上）

### 上诉的注意事项

1. **上诉期限**：
   - 对判决提起上诉的期限为15日
   - 对裁定提起上诉的期限为10日
   - 从收到判决书/裁定书之日起计算

2. **上诉法院**：
   - 向一审法院的上一级人民法院提起上诉
   - 可以通过一审法院递交上诉状

3. **上诉范围**：
   - 上诉请求不能超出一审诉讼请求的范围
   - 可以在一审诉讼请求范围内变更具体内容

4. **新的证据**：
   - 二审程序中原则上不允许提交新证据
   - 如确有新证据，需说明为何在一审未能提交

### 书写规范

- 标题居中
- 上诉人、被上诉人信息分段写
- 上诉请求用编号列出
- 事实与理由分段清晰
- 用语规范，避免口语化
- 标点符号正确
- 空行适当，版面整洁

### 法律依据引用规范

- 法律依据应当写在"事实与理由"部分，作为主张的依据
- 不要在上诉状中单独列出"法律依据"部分
- 引用法律条文时，准确写明法律名称、条款编号
- 例如："根据《中华人民共和国民法典》第六百六十七条之规定"
