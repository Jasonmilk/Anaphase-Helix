## 法律关系确定方法

### 重要性

确定法律关系是草拟起诉状的关键步骤：

1. **确定案件性质**：明确纠纷的法律属性，是民事纠纷、行政纠纷还是其他性质
2. **确定案由**：根据法律关系选择正确的案由
3. **确定诉讼请求**：不同的法律关系对应不同的诉讼请求
4. **确定法律依据**：不同的法律关系适用不同的法律法规

### 确定方法

1. **分析争议内容**
   - 双方争议的焦点是什么
   - 争议涉及的权利义务关系是什么

2. **对照《民事案由规定》**
   - 结合最高法发布的《民事案由规定》
   - 在复杂的法律关系中确定诉讼所需用的法律关系
   - 常见的法律关系：买卖合同纠纷、借款合同纠纷、建设工程施工合同纠纷等

3. **确定主要法律关系**
   - 若存在多个法律关系，确定主要法律关系
   - 以主要法律关系确定案由

### 注意事项

- 首先，需要查清案件的实体法律关系是否为民事法律关系
- 其次，根据民法理论来确定属于哪种民事法律关系
- 可以结合《民事案由规定》来确定具体案由

## 民间借贷纠纷

### 法律关系定义

民间借贷纠纷是指自然人、法人、其他组织之间及其相互之间进行资金融通的行为产生的纠纷。

### 主要争议点

1. **借款是否实际发生**
   - 是否存在借款事实
   - 借款是否已经交付

2. **借款金额**
   - 借款本金数额
   - 是否有预先扣除利息的情形

3. **利率约定**
   - 是否约定利率
   - 约定的利率是否超过法律保护上限
   - 逾期利率约定

4. **还款期限**
   - 是否约定还款期限
   - 是否已经到期

5. **还款情况**
   - 已还金额
   - 还款时间
   - 还款性质（本金还是利息）

6. **诉讼时效**
   - 是否在诉讼时效期间内
   - 是否有诉讼时效中断、中止情形

### 常见诉讼请求

1. 请求依法判令被告向原告返还借款本金XX元；
2. 请求依法判令被告向原告支付借款利息XX元（以本金XX元为基数，按照XX利率标准，自XX年XX月XX日计算至被告清偿完毕之日止，暂计至XX年XX月XX日为XX元）；
3. 请求依法判令被告承担本案诉讼费、保全费等各项费用。

### 法律依据

1. 《中华人民共和国民法典》第六百六十七条至第六百八十条
2. 《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》
3. 《中华人民共和国民事诉讼法》

## 买卖合同纠纷

### 法律关系定义

买卖合同纠纷是指出卖人转移标的物的所有权于买受人，买受人支付价款的合同产生的纠纷。

### 主要争议点

1. **合同是否成立**
   - 是否存在有效的买卖合同
   - 合同形式是否符合要求

2. **标的物**
   - 标的物的数量
   - 标的物的质量
   - 标的物的规格型号

3. **价款**
   - 价款金额
   - 价款支付方式
   - 价款支付时间

4. **交付**
   - 交付时间
   - 交付地点
   - 交付方式

5. **违约**
   - 哪一方违约
   - 违约的具体行为
   - 违约造成的损失

### 常见诉讼请求

1. 请求依法判令被告向原告支付货款XX元；
2. 请求依法判令被告向原告支付逾期付款违约金XX元（以未付货款XX元为基数，按照XX利率标准，自XX年XX月XX日计算至被告实际支付之日止，暂计至XX年XX月XX日为XX元）；
3. 请求依法判令被告承担本案诉讼费。

### 法律依据

1. 《中华人民共和国民法典》第五百九十五条至第六百四十六条
2. 《中华人民共和国民事诉讼法》

## 侵权责任纠纷

### 法律关系定义

侵权责任纠纷是指行为人因过错侵害他人民事权益，或者法律规定应当承担侵权责任时，产生的纠纷。

### 主要争议点

1. **侵权行为**
   - 是否存在侵权行为
   - 侵权行为的具体内容

2. **损害后果**
   - 是否存在损害
   - 损害的范围和程度
   - 损害的金额

3. **因果关系**
   - 侵权行为与损害后果之间是否存在因果关系

4. **过错**
   - 行为人是否有过错
   - 过错的程度

5. **免责事由**
   - 是否存在法定免责事由
   - 是否存在约定免责事由

### 常见诉讼请求

1. 请求依法判令被告停止侵害原告XX权益的行为；
2. 请求依法判令被告赔偿原告经济损失XX元；
3. 请求依法判令被告赔偿原告精神损害抚慰金XX元（如涉及）；
4. 请求依法判令被告承担本案诉讼费、鉴定费等各项费用。

### 法律依据

1. 《中华人民共和国民法典》第一千一百六十五条至第一千一百九十八条
2. 《中华人民共和国民事诉讼法》

## 租赁合同纠纷

### 法律关系定义

租赁合同纠纷是指出租人将租赁物交付承租人使用、收益，承租人支付租金的合同产生的纠纷。

### 主要争议点

1. **合同是否成立**
   - 是否存在有效的租赁合同
   - 合同形式是否符合要求

2. **租赁物**
   - 租赁物的状态
   - 租赁物的使用情况

3. **租金**
   - 租金数额
   - 租金支付方式
   - 租金支付时间

4. **租赁期限**
   - 租赁期限的长短
   - 租赁期限是否届满

5. **维修责任**
   - 租赁物损坏的责任承担
   - 维修费用承担

6. **违约**
   - 哪一方违约
   - 违约的具体行为
   - 违约造成的损失

### 常见诉讼请求

1. 请求依法判令被告向原告支付租金XX元；
2. 请求依法判令被告向原告支付逾期付款违约金XX元；
3. 请求依法判令被告腾退租赁房屋（或其他租赁物）；
4. 请求依法判令被告承担本案诉讼费。

### 法律依据

1. 《中华人民共和国民法典》第七百零三条至第七百三十四条
2. 《中华人民共和国民事诉讼法》

## 劳动争议纠纷

### 法律关系定义

劳动争议纠纷是指劳动者与用人单位之间因劳动权利义务发生的纠纷。

### 主要争议点

1. **劳动关系**
   - 是否存在劳动关系
   - 劳动关系的起止时间

2. **工资报酬**
   - 工资标准
   - 工资数额
   - 加班工资

3. **社会保险**
   - 是否缴纳社会保险
   - 社会保险缴纳基数

4. **劳动合同**
   - 是否签订书面劳动合同
   - 劳动合同的内容

5. **解除或终止**
   - 解除或终止的原因
   - 是否合法

6. **经济补偿**
   - 是否应支付经济补偿
   - 经济补偿的数额

### 常见诉讼请求

1. 请求依法判令被告向原告支付工资XX元；
2. 请求依法判令被告向原告支付加班工资XX元；
3. 请求依法判令被告向原告支付经济补偿金XX元；
4. 请求依法判令被告为原告补缴社会保险；
5. 请求依法判令被告承担本案诉讼费用。

### 法律依据

1. 《中华人民共和国劳动法》
2. 《中华人民共和国劳动合同法》
3. 《中华人民共和国劳动争议调解仲裁法》
4. 《中华人民共和国民事诉讼法》

**注意事项**：
- 劳动争议案件应当先申请劳动仲裁，对仲裁裁决不服的，可以向人民法院提起诉讼
- 但追索劳动报酬、工伤医疗费、经济补偿或者赔偿金，不超过当地月最低工资标准十二个月金额的争议除外

## 其他常见案由

### 服务合同纠纷

- 服务内容是否符合约定
- 服务费用是否支付
- 服务质量是否符合要求

### 建设工程合同纠纷

- 工程款是否支付
- 工程质量是否合格
- 工程是否竣工验收

### 交通事故责任纠纷

- 交通事故责任认定
- 损害赔偿范围和数额
- 保险理赔情况

### 产品责任纠纷

- 产品是否存在缺陷
- 损害是否由产品缺陷造成
- 责任主体是谁

### 医疗损害责任纠纷

- 医疗行为是否存在过错
- 医疗行为与损害后果的因果关系
- 损害赔偿范围和数额

## 案由确定注意事项

1. **准确确定案由**
   - 案由是案件的核心，必须准确
   - 错误的案由可能导致诉讼请求不被支持

2. **案由与诉讼请求一致**
   - 诉讼请求必须与案由相匹配
   - 避免诉讼请求与案由不符

3. **参考《民事案由规定》**
   - 《民事案由规定》是确定案由的权威依据
   - 可以在最高人民法院官网查询最新版本

4. **复杂案件的案由确定**
   - 存在多个法律关系时，以主要法律关系确定案由
   - 可以咨询专业律师确定案由
