## 收集原则

在草拟民事诉讼文书前，必须向用户收集以下信息。信息收集应遵循以下原则：

1. **全面性**：尽可能收集与案件相关的所有信息
2. **准确性**：确保收集的信息真实准确，特别是身份信息
3. **针对性**：根据案件类型收集必要信息，避免无关信息
4. **可证明性**：收集的信息应有证据支持

## 原告信息

### 自然人

必须收集的信息：

1. **姓名**
   - 填写身份证上的全名
   - 确认姓名书写是否正确
   - 确认是否曾用名或改名

2. **性别**
   - 男/女

3. **民族**
   - 汉族/其他民族

4. **出生日期**
   - XXXX年XX月XX日
   - 与身份证保持一致

5. **住址**
   - 填写身份证上的住址
   - 或填写实际送达地址（若与身份证住址不同）
   - 需要具体到门牌号

6. **公民身份号码**
   - 18位身份证号码
   - 必须准确无误

7. **联系电话**
   - 可以联系的常用电话号码
   - 建议提供备用电话

### 法人或其他组织

必须收集的信息：

1. **名称**
   - 营业执照上的全称
   - 确认名称书写是否正确

2. **住所地**
   - 营业执照上的住所地
   - 或实际办公地址（若与营业执照住所地不同）

3. **法定代表人**
   - 法定代表人的姓名
   - 法定代表人的职务（如董事长、经理等）

4. **统一社会信用代码**
   - 18位统一社会信用代码
   - 必须准确无误

5. **联系电话**
   - 公司联系电话
   - 负责人联系电话

## 案情基本事实

必须收集的案情信息：

1. **事件发生时间**
   - 具体日期或时间范围
   - 重要时间节点（如合同签订时间、违约时间等）

2. **事件发生地点**
   - 具体地点（如XX市XX区XX路XX号）

3. **事件经过**
   - 详细描述事件的全过程
   - 包括双方的行为和互动
   - 争议产生的原因和经过

4. **双方形成的法律关系**
   - 借贷关系、买卖关系、租赁关系、侵权关系等
   - 法律关系的性质和内容

5. **违约或侵权事实**
   - 被告的具体违约或侵权行为
   - 违约或侵权行为的持续时间和状态

6. **损失情况**（如有）
   - 原告遭受的损失
   - 损失的具体金额或情况

**注意事项**：
- 此处的基本事实并不是委托人原告方所陈述的事实，而是根据现有证据材料可以还原和支持的基本事实
- 案情事实应有证据支持
- 避免主观臆断和推测

## 证据材料清单

必须收集的证据信息：

1. **证据清单**
   - 列举所有相关证据
   - 包括证据名称和数量

2. **证据类型**
   - 书证（合同、借条、收据等）
   - 物证
   - 视听资料
   - 电子数据（聊天记录、转账记录等）
   - 证人证言
   - 鉴定意见
   - 勘验笔录

3. **证据的证明目的**
   - 每份证据证明什么事实
   - 证据与争议焦点的关联性

4. **证据的来源**
   - 证据的获取方式
   - 证据的形成时间

**示例**：

| 证据名称 | 证据来源 | 证明目的 |
|---------|---------|---------|
| 借款合同 | 原被告双方签署 | 证明双方存在借贷关系及借款金额 |
| 银行转账凭证 | 银行开具 | 证明借款已实际交付 |
| 微信聊天记录 | 微信导出 | 证明被告承诺还款期限及催收记录 |

## 诉讼请求

必须收集的诉讼请求信息：

1. **具体诉求内容**
   - 明确原告希望法院判令被告做什么
   - 包括返还财产、支付款项、停止侵害等

2. **金额计算方式**
   - 如果涉及金额，需要明确的计算方式
   - 包括本金、利息、违约金等
   - 需要提供计算基数、计算标准、计算期间

3. **执行方式**
   - 希望如何执行判决
   - 包括支付方式、履行期限等

4. **程序性请求**
   - 诉讼费用承担
   - 保全费用承担

**示例**：

1. 请求依法判令被告向原告返还借款本金100,000元；
2. 请求依法判令被告向原告支付借款利息1670.56元（以本金100,000元为基数，按照中国人民银行授权全国银行间同业拆借中心发布的一年期贷款市场报价利率(LPR)标准，自2025年1月1日计算至被告清偿完毕之日止，暂计至2025年7月13日为1670.56元）；
3. 请求依法判令被告承担本案诉讼费、保全费等各项费用。

## 其他相关信息

根据案件类型，可能需要收集的其他信息：

1. **合同约定**（如有）
   - 合同名称
   - 合同签订时间
   - 合同主要条款
   - 违约责任约定

2. **还款期限**（借贷纠纷）
   - 约定的还款期限
   - 是否有展期约定

3. **违约条款**（合同纠纷）
   - 违约责任条款
   - 违约金计算方式

4. **双方沟通记录**
   - 催收记录
   - 协商记录
   - 承诺记录

5. **其他证明材料**
   - 户籍证明
   - 婚姻证明
   - 营业执照
   - 组织机构代码证

## 起诉状特殊收集要求

对于起草起诉状，除上述信息外，还需特别注意：

1. **尽可能找全法律关系主体**
   - 充分思考案件中的法律关系
   - 尽可能把被告拉满
   - 排查要点：
     - 合同关系：除直接相对方外，是否有担保人、保证人、连带责任人？
     - 侵权关系：除直接侵权人外，是否有其他共同侵权人、雇主责任、监护人责任等？
     - 侵权关系：如涉及机动车事故，需排查车主、驾驶人、保险公司等责任主体
     - 婚姻家庭：涉及共同债务、共同财产时，是否需要将配偶列为共同被告？
     - 继承纠纷：是否遗漏其他继承人？
     - 公司纠纷：是否需要将股东、董事等列为被告？

2. **共同诉讼的原告**
   - 是否有其他共同权益人需要列为共同原告？
   - 如共同所有权人、共同债权人等

## 答辩状特殊收集要求

对于起草答辩状，除上述信息外，还需特别注意：

1. **起诉状内容**
   - 原告信息
   - 被告信息（即答辩人）
   - 诉讼请求（逐项列出）
   - 案由
   - 事实与理由
   - 管辖法院

2. **答辩意见和抗辩理由**
   - 对诉讼请求的意见：同意、部分同意、不同意
   - 对事实陈述的意见：承认、否认、部分承认
   - 抗辩理由和依据
   - 反驳观点和证据

3. **答辩请求**
   - 请求法院驳回原告的诉讼请求
   - 其他答辩请求

## 上诉状特殊收集要求

对于起草上诉状，除上述信息外，还需特别注意：

1. **一审判决信息**
   - 一审法院名称：XX省XX市XX区人民法院
   - 案号：（20XX）XX民初字第XX号
   - 判决日期：20XX年XX月XX日
   - 判决结果：判决的主要内容
   - 一审诉讼请求：原告的诉讼请求
   - 一审认定事实：一审判决认定的事实
   - 一审适用法律：一审判决适用的法律条文

2. **上诉人一审诉讼地位**
   - 一审原告
   - 一审被告
   - 一审第三人

3. **被上诉人一审诉讼地位**
   - 一审原告
   - 一审被告
   - 一审第三人

4. **上诉请求**
   - 对一审判决不服的理由
   - 希望二审法院如何改判
   - 不能超出一审诉讼请求的范围

5. **一审判决的错误**
   - 认定事实错误
   - 认定事实不清
   - 适用法律错误
   - 程序违法
   - 其他错误

6. **上诉期限**
   - 判决书送达之日起15日内
   - 是否在上诉期限内

7. **新证据**（如有）
   - 一审未能提交的新证据
   - 说明为何在一审未能提交
