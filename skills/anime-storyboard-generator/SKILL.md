# 动漫分镜脚本生成器

## 任务目标
- 本 Skill 用于：将用户提供的剧本或小说原文转换为动漫分镜制作所需的各类内容
- 能力包含：
  - 分析剧本提取角色信息并生成角色形象
  - 基于角色形象生成AI绘画提示词
  - 提取场景并生成场景描述和绘图提示词
  - 将剧本转换为结构化的Sora视频分镜提示词
  - 生成表格化的分镜脚本提示词
- 触发条件：
  - 用户输入"这是一段剧本"、"分析这段小说"等明确意图
  - 用户提到"生成角色"、"制作分镜"等关键词
  - 用户需要将文本内容转换为视觉化呈现

## 操作步骤

### 第一步：识别用户需求
当用户输入剧本或小说原文时，判断用户需求是否明确：

**明确需求的判定标准**：
- 用户直接说明需要生成哪些内容（如"生成角色形象和场景"）
- 用户使用特定术语（如"需要Sora分镜"、"制作分镜脚本"）
- 用户上下文已明确目标

**不明确需求的场景**：
- 用户仅提供剧本/小说原文，未说明需要什么
- 用户仅说"分析这段内容"
- 用户需求模糊或表述不清

### 第二步：询问用户需求（无论需求是否明确）

**强制要求**：无论用户是否明确说明了需求，智能体都必须先询问用户需要生成什么内容，不能直接生成。

**询问内容**：

```
我已收到您的剧本/小说原文。请告诉我您需要生成哪些内容（可多选）：

1. 角色形象（角色名称、外貌、性格、小传）
2. 角色提示词（需先有角色形象，用于AI绘画）
3. 场景提示词（场景描述和绘图指令，纯环境场景）
4. Sora分镜提示词（视频分镜，每个分镜含0-3秒、3-7秒、7-10秒三个时间段）
5. 分镜提示词（表格化分镜脚本）

您可以选择其中一项或多项，我将按照您的要求生成对应内容。

例如：请生成角色形象和场景提示词
```

**重要原则**：
- ⚠️ **绝对禁止**：直接生成所有内容（角色形象、角色提示词、场景提示词、Sora分镜提示词、分镜提示词全部生成）
- ⚠️ **绝对禁止**：即使用户说了"生成角色"，也不应该生成其他内容
- ✅ **必须执行**：先询问用户需要什么，等用户明确回复后再生成
- ✅ **可以执行**：如果用户已经明确说明需要什么（如"请生成角色形象和Sora分镜"），可以直接复述确认后生成

**询问后的处理**：
- 如果用户回复了具体需求（如"生成角色形象和场景提示词"），按照需求生成对应内容
- 如果用户回复模糊（如"都生成"、"全部"），需再次确认具体指哪些内容
- 如果用户选择"角色提示词"但未提供角色形象，需询问是否需要先生成角色形象

### 第三步：生成内容（用户明确需求后）

#### 3.1 角色形象
分析剧本中出现的角色，提取以下信息：

**必需字段**：
- 角色名称
- 外貌：根据文本描述或合理推断
- 职业/身份：在故事中的角色定位
- 性格：基于行为、语言、心理活动分析
- 角色小传：背景、动机、关键事件、与主线的关系

**生成原则**：
- 优先提取原文中的直接描述
- 对未明确描述的外貌进行合理推断（符合时代背景和角色定位）
- 性格分析需结合行为和对话
- 小传需体现角色在故事中的作用和意义

#### 3.2 角色提示词
基于用户提供的角色形象（或先执行3.1生成角色形象），生成AI绘画提示词。

**必需要素**：
- 年龄、性别
- 五官特征（眼睛、脸型等）
- 发型、发色
- 服饰（符合时代背景和角色身份）
- 配饰（饰品、道具等）
- 表情神态
- 画质要求（8k、高分辨率、大师级画作等）
- 风格细节（光影层次、精致的面部细节等）

**格式示例**：
```
[角色名称]：
青年女性，低垂顺从的黑色杏眼，乌黑长发梳成温婉的随云髻，插着一支素雅的珍珠步摇，身穿淡青色立领对襟刺绣长袄，下着月白色百迭裙，手腕佩戴通透的翡翠玉镯，脚踩精致的苏绣软底布鞋，高分辨率，极其详细，大师级画作，8k画质，精致的面部细节，光影层次丰富。
```

#### 3.3 场景提示词
分析剧本中的关键场景，生成场景描述和绘图指令。

**核心原则**：
- **绝对禁止**：绘图指令中包含任何人物
- 绘图指令必须是**纯环境场景**（empty room/scenery only）
- 只描述场景的空间、光线、氛围、陈设、细节
- 画面描述可以有故事感，但绘图指令必须无人物

**必需要素**：
- 场景名称及序号
- 画面描述：详细说明场景的空间、光线、氛围、细节（可以提及故事背景）
- 绘图指令：
  - **必须是空场景**（empty/scenery only/no people）
  - 场景的空间结构（室内/室外）
  - 光线、色彩、材质
  - 氛围和情绪
  - 技术参数（分辨率、风格等）
  - 宽高比（--ar 16:9）
  - 版本参数（--v 6.0）

**绘图指令禁止内容**：
- ❌ 任何人物（man, woman, person, character, figure等）
- ❌ 人物的任何部位（face, hand, body等）
- ❌ 任何动作（sitting, standing, walking等）
- ❌ 任何衣物或配饰
- ❌ 任何指向人物的描述（silhouette, shadow of person等）

**绘图指令允许内容**：
- ✅ 空间结构（interior, exterior, room, hall, garden等）

#### 3.4 Sora分镜提示词
将剧本转换为结构化的视频分镜提示词。

**核心原则**：
- 每个分镜必须包含完整的时间分段（0-3秒、3-7秒、7-10秒）
- 景别和运镜必须多样化，避免重复使用相同的景别和运镜组合
- 根据剧本内容和情绪变化，动态调整景别和运镜方式
- 时间段之间要有逻辑递进，画面内容要连贯

**景别选择规则**：
- **开场/转场**：使用远景或全景，展示环境和空间关系
- **对话场景**：使用中景或近景，展现人物互动和表情
- **情绪高潮**：使用特写，突出人物内心状态和关键细节
- **动作场景**：使用中景配合快速运镜，增强动感
- **内心独白**：使用特写或大特写，聚焦人物细微表情
- **悬念营造**：使用远景推至中景，或从特写拉至中景

**运镜选择规则**：
- **推进**：强调细节、情绪递进、聚焦重点
- **拉远**：展示环境、释放紧张、转场
- **摇镜**：跟随人物移动、扫描场景
- **俯仰**：展示高低差、改变视角
- **晃动**：混乱场景、主观视角、惊悚氛围
- **固定**：冷静观察、客观陈述、稳定对话
- **旋转**：戏剧化效果、环视环境

**强制要求**：
- 每个分镜必须包含3个时间段：0-3秒、3-7秒、7-10秒
- 每个时间段都要独立描述画面、镜头、音效、情绪、对话
- 相邻分镜的景别要有变化，不能连续使用相同景别
- 运镜方式要多样化，同一分镜的不同时间段可以使用不同运镜
- 3个时间段的画面要有递进关系，不能重复描述相同内容

**格式要求**：JSON数组，每个元素为一个分镜

**必需字段**：
- 分镜序号：数字，从1开始
- sora提示词：包含以下内容
  - 角色：当前分镜出现的角色（注明外貌状态）
  - 时间分段：[X-Y秒]，每个分段独立描述
  - 镜头：景别（中景/特写/近景/全景等）+ 镜头运动（固定/推进/拉远/摇晃等）
  - 音效/音乐：环境音、背景音乐、台词等
  - 情绪/氛围：当前场景的情绪基调
  - 旁白/对话：台词或内心独白

**生成原则**：
- 每个分镜固定包含3个时间段：0-3秒、3-7秒、7-10秒
- 镜头语言要体现叙事逻辑（推进→高潮→舒缓等）
- 音效和情绪要配合画面内容
- 参考模板中的JSON结构
- **绝对禁止**：只生成1个时间段，或者所有分镜使用相同的景别和运镜

#### 3.5 分镜提示词
将剧本转换为表格化的分镜脚本，便于理解和使用。

**核心原则**：
- 景别要多样化，根据场景内容选择合适的景别
- 运镜要配合内容，避免所有镜头都是固定镜头
- 时长要根据内容密度调整，重要内容时长可稍长
- 相邻镜头的景别要有变化，避免重复

**景别选择规则**：
- 开场/转场：远景（2-3秒）
- 对话场景：中景（1.5-2秒）
- 情绪表达：近景/特写（1-2秒）
- 动作场景：中景（1-2秒）
- 细节强调：特写（1秒）
- 环境展示：全景（2-3秒）

**运镜选择规则**：
- 推进：聚焦人物、强调细节
- 拉远：展示环境、释放情绪
- 切镜：快速切换、节奏紧凑
- 摇镜：跟随人物、扫描场景
- 俯拍：权威视角、俯视人物
- 仰拍：弱小视角、增强气势
- 晃动：混乱场景、主观视角
- 跟拍：人物移动、沉浸感
- 推拉镜：远近变换、动态效果
- 旋转：戏剧效果、环视环境

**强制要求**：
- 相邻镜头的景别必须变化，不能连续使用相同景别
- 运镜方式要多样化，不能所有镜头都是固定镜头
- 时长要根据内容调整，不能所有镜头都是相同时长

- **Sora分镜的景别和运镜必须多样化，不能所有分镜都是中景固定**
- **场景提示词的绘图指令必须包含关键词：empty / scenery only / no people**
- **场景提示词的绘图指令绝对禁止任何人物、人物部位、人物动作、人物衣物**
- 分镜提示词的表格内容要具体可执行，便于AI视频生成
- 充分利用智能体的文本理解和创作能力，避免为简单任务编写脚本
- 所有生成的内容都要基于用户提供的剧本/小说原文，避免偏离原作设定

## 使用示例

### 示例1：用户输入剧本（无论是否明确需求）

**用户输入**：
```
这是一段古装剧剧本：
[剧本内容]
请生成角色形象和场景提示词
```

**智能体响应**（强制询问，不直接生成）：
```
我已收到您的剧本/小说原文。请告诉我您需要生成哪些内容（可多选）：

1. 角色形象（角色名称、外貌、性格、小传）
2. 角色提示词（需先有角色形象，用于AI绘画）
3. 场景提示词（场景描述和绘图指令，纯环境场景）
4. Sora分镜提示词（视频分镜，每个分镜含0-3秒、3-7秒、7-10秒三个时间段）
5. 分镜提示词（表格化分镜脚本）

您可以选择其中一项或多项，我将按照您的要求生成对应内容。

例如：请生成角色形象和场景提示词
```
