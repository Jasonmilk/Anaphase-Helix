# 镜头语言规则

本文档提供详细的镜头语言选择规则，帮助智能体在生成分镜时选择合适的景别和运镜方式。

## 景别选择规则

### 远景（Long Shot）
**作用**：展示环境、交代场景、建立空间关系

**使用场景**：
- 开场镜头，交代故事发生的地点
- 转场时连接不同场景
- 展现大规模场景（战争、游行、自然灾害等）
- 表现人物的渺小与环境的对比

**示例**：
- 开场：侯府全景，展示深宅大院的压迫感
- 转场：从京城远景切到侯府
- 战争：战场全景，展现两军对垒

### 全景（Full Shot）
**作用**：展现人物全身姿态和周围环境的关系

**使用场景**：
- 人物出场，展示整体造型
- 场景交代，展示人物与环境的互动
- 动作场景，展现人物的完整动作
- 转场，连接不同空间

**示例**：
- 沈晚瑜站在回廊中，展现她的孤身一人
- 陆砚礼在房间中痛苦打滚，展现完整的动作
- 人物穿过花园，展现环境的移动

### 中景（Medium Shot）
**作用**：展现人物上半身，适合对话和普通叙事

**使用场景**：
- 对话场景，展现人物的互动
- 普通叙事，平衡人物和环境
- 人物表情变化，展现情绪波动
- 多人场景，展现人物关系

**示例**：
- 陆砚礼和沈晚瑜对话
- 侯老夫人训斥沈晚瑜
- 多人聚集的场景

### 近景（Medium Close-up）
**作用**：聚焦人物面部表情和上半身

**使用场景**：
- 情绪表达，展现人物的内心状态
- 重要对话，强调台词的分量
- 人物反应，捕捉细微的表情变化
- 心理活动，展现人物的情绪波动

**示例**：
- 沈晚瑜面露为难的神色
- 陆砚礼痛苦的表情
- 侯老夫人严厉的目光

### 特写（Close-up）
**作用**：突出某个细节或强烈情绪

**使用场景**：
- 情绪高潮，强化情感表达
- 关键细节，强调重要道具或动作
- 人物眼神，传递内心活动
- 系统提示，突出特殊效果

**示例**：
- 沈晚瑜瞪大的眼睛
- 陆砚礼痛苦扭曲的脸
- 系统文字的特写
- 手部动作（攥裙摆、绞手帕）

### 大特写（Extreme Close-up）
**作用**：极近距离展示微小细节

**使用场景**：
- 瞳孔变化，展现震惊
- 眼泪、汗水，强化情绪
- 道具细节，强调重要性
- 极致情绪，展现人物内心的剧烈波动

**示例**：
- 沈晚瑜眼角的泪珠
- 陆砚礼额头上的青筋
- 系统文字的细节

## 运镜选择规则

### 固定镜头（Static）
**特点**：摄像机静止不动

**使用场景**：
- 冷静观察，客观陈述
- 稳定对话，展现人物关系
- 环境交代，展现空间
- 悬念营造，等待突发事件

**示例**：
- 对话场景，双方中景固定
- 房间全景，交代环境
- 等待暴风雨前的宁静

### 推镜（Dolly In）
**特点**：摄像机向主体推进

**使用场景**：
- 强调细节，聚焦重要元素
- 情绪递进，展现情感变化
- 悬念营造，逐步揭示真相
- 人物聚焦，引导观众关注

**示例**：
- 从中景推进到沈晚瑜的脸部特写
- 推进到系统文字
- 推进到关键道具

### 拉镜（Dolly Out）
**特点**：摄像机远离主体

**使用场景**：
- 展示环境，释放紧张感
- 转场，连接不同场景
- 孤独感，展现人物的孤立
- 释放情绪，缓解紧张气氛

**示例**：
- 从沈晚瑜脸部拉到房间全景
- 从特写拉到远景
- 从人物拉到环境

### 摇镜（Pan）
**特点**：摄像机水平转动

**使用场景**：
- 跟随人物移动
- 扫描场景，展示环境
- 人物互动，展现关系
- 转场，平滑过渡

**示例**：
- 摇镜头跟随沈晚瑜走过回廊
- 扫描房间，展示陈设
- 在两人对话时摇镜

### 俯镜（Tilt）
**特点**：摄像机垂直转动

**使用场景**：
- 展示高低差
- 从上到下，俯视人物
- 从下到上，仰视人物
- 展现建筑的层次

**示例**：
- 从天花板俯视痛苦中的陆砚礼
- 从沈晚瑜脚下仰到脸部
- 展示侯府建筑的宏伟

### 晃动镜头（Handheld）
**特点**：模拟手持摄像机的晃动

**使用场景**：
- 混乱场景，体现失控
- 主观视角，增强代入感
- 惊悚氛围，营造紧张感
- 动作场景，增强动感

**示例**：
- 沈晚瑜受到惊吓的视角
- 陆砚礼痛苦挣扎的场景
- 混乱的打斗场面

### 跟拍（Tracking Shot）
**特点**：摄像机跟随移动的主体

**使用场景**：
- 人物移动，展现行进过程
- 跟随主角，增强代入感
- 转场，平滑过渡
- 动作场景，展现动态

**示例**：
- 跟随沈晚瑜穿过回廊
- 跟随人物跑动
- 跟随人物进入房间

### 旋转镜头（Orbit）
**特点**：围绕主体旋转拍摄

**使用场景**：
- 戏剧化效果，增强冲击力
- 环视环境，展示360度空间
- 人物关系，展现互动
- 强化情绪，营造氛围

**示例**：
- 围绕沈晚瑜旋转，展现她的孤立
- 环视房间，展示环境
- 围绕关键道具旋转

### 推拉镜（Dolly Zoom）
**特点**：摄像机移动同时变焦，产生透视变化

**使用场景**：
- 戏剧化效果，视觉冲击
- 情绪突变，营造不安
- 悬念营造，突出异常
- 梦境/幻觉效果

**示例**：
- 沈晚瑜意识到系统存在的瞬间
- 陆砚礼谎言成真时的视觉冲击
- 回忆与现实交替

## 常见场景的镜头组合

### 开场场景
**组合**：远景固定 → 中景推进 → 中景摇镜

**效果**：
1. 远景交代环境，建立空间关系
2. 中景推进聚焦主体，引导观众关注
3. 中景摇镜跟随人物，带入故事

**示例**：
- 侯府远景固定 → 推进到沈晚瑜在回廊中 → 摇镜头跟随她走向婚房

### 对话场景
**组合**：中景固定 → 近景切镜 → 特写拉远

**效果**：
1. 中景固定展示整体对话
2. 近景切镜聚焦说话者
3. 特写拉远展现听者反应

**示例**：
- 陆砚礼和沈晚瑜对话（中景）→ 陆砚礼说话（近景）→ 沈晚瑜反应（特写拉远）

### 情绪爆发场景
**组合**：近景突发 → 手持摇晃 → 特写固定

**效果**：
1. 近景突发展示事件开始
2. 手持摇晃营造混乱感
3. 特写固定聚焦人物情绪

**示例**：
- 陆砚礼突然惨叫（近景）→ 他在床上打滚（手持摇晃）→ 痛苦表情（特写）

### 转场场景
**组合**：全景固定 → 中景推进 → 中景拉远

**效果**：
1. 全景固定交代环境
2. 中景推进引导过渡
3. 中景拉远释放紧张，进入新场景

**示例**：
- 老夫人房中全景 → 推进到门口 → 沈晚瑜离开（拉远）

### 悬疑场景
**组合**：特写推进 → 近景俯拍 → 中景摇镜

**效果**：
1. 特写推进制造悬念
2. 近景俯拍展现权威或压迫
3. 中景摇镜释放紧张

**示例**：
- 系统文字特写 → 侯老夫人俯视沈晚瑜 → 摇镜头扫描房间

### 回忆场景
**组合**：中景固定 → 特写推进 → 特写拉远（带滤镜）

**效果**：
1. 中景固定建立回忆场景
2. 特写推进聚焦关键瞬间
3. 特写拉远释放情绪，返回现实（带滤镜）

**示例**：
- 沈府花园中景 → 暖玉特写 → 拉远（暖色调滤镜）

## 避免重复的技巧

### 景别多样化
**技巧**：确保相邻镜头使用不同景别

**规则**：
- 不能连续两个镜头都是中景
- 特写后不要立即用特写，先用中景或近景过渡
- 远景和特写交替使用，创造节奏感

**示例**：
- 错误：中景 → 中景 → 中景
- 正确：中景 → 近景 → 特写 → 中景 → 全景

### 运镜多样化
**技巧**：确保运镜方式丰富，避免单调

**规则**：
- 不能所有镜头都是固定镜头
- 同一种运镜方式不要连续使用超过3次
- 运镜速度要有快慢变化

**示例**：
- 错误：固定 → 固定 → 固定
- 正确：固定 → 推进 → 摇镜 → 晃动 → 拉远

### 时长多样化
**技巧**：根据内容密度调整时长

**规则**：
- 重要内容时长稍长（2-3秒）
- 快节奏场景时长较短（1-1.5秒）
- 转场镜头适中（2秒）
- 不能所有镜头都是相同时长

**示例**：
- 错误：1s → 1s → 1s → 1s
- 正确：2s → 1.5s → 3s → 1s → 2s

### 镜头语言组合
**技巧**：景别和运镜要配合，创造丰富的视觉节奏

**规则**：
- 中景 + 固定：稳定对话
- 特写 + 推进：情绪递进
- 近景 + 晃动：混乱场景
- 全景 + 拉远：转场

**示例**：
- 分镜1：中景固定（对话）
- 分镜2：特写推进（情绪递进）
- 分镜3：近景摇晃（混乱）
- 分镜4：全景拉远（转场）
- 分镜5：中景摇镜（环境扫描）

### 时间段递进
**技巧**：同一分镜的3个时间段要有递进关系

**规则**：
- 0-3秒：建立场景或事件开始
- 3-7秒：事件发展或情绪递进
- 7-10秒：事件结果或释放紧张

**示例**：
- 0-3秒：陆砚礼说话（中景固定）
- 3-7秒：沈晚瑜反应（特写推进）
- 7-10秒：系统文字出现（特写拉远）

## 总结

遵循以上规则，可以生成多样化、富有节奏感的分镜：

1. **景别多样化**：至少包含远景、全景、中景、近景、特写5种
2. **运镜多样化**：至少包含固定、推进、拉远、摇镜、切镜5种
3. **时长多样化**：根据内容调整，1-3秒不等
4. **组合多样化**：景别和运镜要合理搭配
5. **递进关系**：同一分镜的3个时间段要有逻辑递进

避免所有镜头都是"中景固定"，避免所有镜头时长相同，这是生成高质量分镜的关键。
