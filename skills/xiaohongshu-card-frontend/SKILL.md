# 智能小红书卡片生成及一键打包下载技能

## 任务目标
本 Skill 用于将文章内容转换为精美卡片合集，支持6种主题模板、用户自定义样式和一键打包下载：
- **智能分配卡片类型**：根据文章内容和数据自动分配合适的卡片类型，不强制使用全部10种
- 10种卡片类型：封面卡、列表卡、饼图卡、柱状图卡、高亮卡、对比卡、统计卡、排名卡、流程卡、总结卡
- 6种主题模板：精简明亮主题、黑金金融主题、Apple钛金灰主题、赛博极客主题、节日庆典主题、马卡龙主题
- 极光/粒子背景效果：使用Canvas API程序化生成
- 数据可视化：饼图、柱状图
- 在线预览：实时预览所有卡片效果
- 一键下载：批量导出为ZIP文件

触发条件：用户需要将文章内容转换为社交媒体分享卡片时。

## 使用方式

**三步流程**：撰写文案 → 用户确认 → 选择主题生成

### 第一步：撰写图文文案
1. **用户提供文章内容或话题**
   - 如果用户提供的只是少量线索或简单话题（如"AI在医疗领域的应用"、"2025年iPhone新机发布"等），智能体应先使用 web search 搜集相关资料，再基于搜集到的资料撰写文案
   - 如果用户已经提供完整的文章内容或详细资料，则直接基于提供的内容撰写文案，无需搜索
2. **智能体根据内容撰写完整的图文文案文档**，生成 Markdown 格式文件供用户查看
3. **文案文档结构**：
   - **封面部分**：标题、副标题、作者、标签
   - **内容卡片**：根据内容类型分配合适的卡片类型（列表/图表/对比/高亮等）
   - **每张卡片包含**：
     - 卡片标题
     - 卡片副标题
     - 卡片内容（数据、列表、对比等）
     - **卡片总结**（除封面和结尾总结外，每张卡片必须包含一句总结）
   - **结尾总结**：核心观点总结、页脚
   - 文案一定要精简！否则容易溢出！

4. **请用户确认文档并列出全部主题供选择**
  - **精简明亮主题**（fresh-theme.html）：适用于知识科普、数据分享、通用内容
  - **黑金金融主题**（finance-theme.html）：适用于金融、投资、数据报告类内容
  - **Apple钛金灰主题**（apple-theme.html）：适用于产品、设计、极简风格内容
  - **赛博极客主题**（geek-theme.html）：适用于科技、编程、极客文化、赛博朋克风格内容
  - **节日庆典主题**（festival-theme.html）：适用于春节、节日庆典、营销活动、节日祝福内容
  - **马卡龙主题**（macaron-theme.html）：适用于生活、美食、旅行、情感分享等温馨风格内容

5. **一定要要求用户确认，并选择一个主题模板才继续！！**

### 第二步：生成卡片并下载
1. **智能体基于选定的主题模板生成全新的 HTML 文件**
2. **智能体在生成的 HTML 文件中定义卡片数据结构（const cards 数组）**
3. **智能体根据用户要求定制卡片样式（颜色、字体、布局等，如有需要）**
4. **用户打开 HTML 文件，预览卡片效果**
5. **用户点击下载按钮，获取 ZIP 文件**


## 卡片类型分配规则

**重要**：智能体根据文章内容和数据自动分配合适的卡片类型，不强制使用全部10种：

### 10种卡片类型
1. **封面卡（cover）**：文章必须有，用于展示标题和概述
2. **总结卡（summary）**：文章必须有，用于总结核心观点
3. **列表卡（list）**：用于展示列表内容，如步骤、要点、建议等，注意高度，不要溢出！
4. **饼图卡（chart-pie）**：用于展示数据占比，如百分比、份额等
5. **柱状图卡（chart-comp）**：用于展示数据对比，如不同类别的数据比较
6. **高亮卡（highlight）**：用于突出显示关键数据和描述
7. **对比卡（vs）**：用于展示正反对比或不同观点的比较
8. **统计卡（stat-card）**：用于展示统计数据和标签
9. **排名卡（list-rank）**：用于展示排名列表，如TOP榜单、排序数据等
10. **流程卡（flow）**：用于展示流程步骤或操作顺序

**核心原则**：
- 卡片类型和数量根据实际内容决定，避免硬凑
- 除封面和结尾总结卡外，每个内容卡片都必须包含一句总结
- 柱状图的宽高要合理，必须约束在卡片内，不要溢出
- 卡片要时刻注意高度控制，不要溢出

## 卡片数据结构

智能体基于选定的主题模板生成全新的 HTML 文件，并定义卡片数据结构：

```javascript
const cards = [
  {
    type: 'cover',           // 卡片类型：cover/list/chart-pie/chart-comp/highlight/vs/stat-card/list-rank/summary
    title: "卡片标题",
    subtitle: "卡片副标题",
    iconName: "activity",    // 图标名称（Lucide Icons）
    items: [                 // 列表卡片的内容
      { label: "标签", value: "值", desc: "描述" }
    ],
    data: [                  // 图表数据
      { label: "类别", value: 30, color: "#FFD700" }
    ],
    mainStat: "189%",         // 高亮卡片的主数据
    mainStatDesc: "描述",
    subStats: [
      { label: "标签", value: "67%" }
    ],
    left: { label: "左侧", value: "42%", color: "text-amber-400" },
    right: { label: "右侧", value: "18%", color: "text-red-400" },
    desc: "描述文字",
    stat: "78%",             // 统计卡片数据
    statLabel: "标签",
    text: "总结内容",
    footer: "页脚",
    tags: ["#标签1", "#标签2"],
    author: "作者",
    bgSeed: 1,               // 背景随机种子
    accent: "#FFD700"        // 强调色
  }
];
```
注意列表项超过4项的要缩小列表项内的y轴padding，以及列表项的行距防止高度溢出

## 样式定制

**重要**：智能体支持按用户要求灵活定制卡片样式，不限于预设模板：

### 列表卡片高度控制示例
当列表项超过3项时，需要缩小列表项的间距以防止高度溢出。以下是通用的优化方案：

**正常情况（≤3项）**：
```javascript
list: d => `<ul class="space-y-4">${d.items.map(i => {
    return `<li class="p-4 simple-bg rounded-lg border-l-4 border-l-orange-400">
        <div class="flex justify-between items-center mb-1">
            <div class="text-xs text-slate-500 font-medium uppercase tracking-widest">${i.label}</div>
            ${i.value ? `<span class="text-base font-bold text-pink-500">${i.value}</span>` : ''}
        </div>
        ${i.desc ? `<div class="text-sm text-slate-700 leading-snug mt-1">${i.desc}</div>` : ''}
    </li>`;
}).join('')}</ul>`
```

**高度优化（>3项）**：
```javascript
list: d => `<ul class="space-y-1.5">${d.items.map(i => {
    return `<li class="p-2 simple-bg rounded-lg flex items-center gap-2.5">
        <div class="w-1.5 h-1.5 rounded-full flex-shrink-0 bg-orange-400"></div>
        <div class="flex-1">
            <div class="flex justify-between items-center mb-0.5">
                <span class="text-xs font-bold text-slate-900">${i.label}</span>
                <span class="text-xs font-black text-pink-500">${i.value || ''}</span>
            </div>
            ${i.desc ? `<div class="text-[10px] text-slate-600 leading-tight">${i.desc}</div>` : ''}
        </div>
    </li>`;
}).join('')}</ul>`
```

**优化要点详解**：

1. **列表项间距**：`space-y-4` → `space-y-1.5`（极大减小列表项之间的垂直间距）

2. **内边距**：`p-4` → `p-2`（减小每个列表项的内边距）

3. **左侧指示器**：`border-l-4` → `w-1.5 h-1.5 rounded-full`（从左边框改为小圆形指示器，节省空间）

4. **标题值间距**：`mb-1` → `mb-0.5`（减小标题与值的间距）

5. **描述文字**：`mt-1` → 嵌入在标题下方（移除单独的间距）

6. **文字大小统一调整**：
   - 标题：`text-xs` → `text-xs`（保持不变）
   - 值：`text-base` → `text-xs`（减小约25%）
   - 描述：`text-sm` → `text-[10px]`（减小约37%）

7. **间距控制**：添加 `gap-2.5`（减小元素之间的间距）

8. **行高控制**：`leading-tight`（控制描述文字的行高，避免占用过多高度）

**核心优化思路**：
- 使用小圆形指示器替代粗左边框，节省水平空间
- 极大减小各项间距（`space-y-1.5`），确保4项以上也能完整显示
- 统一缩小所有文字尺寸，但保持视觉层次
- 控制行高，避免描述文字占用过多高度


### 定制方式
1. **用户提供具体要求**：如"要蓝白色调"、"圆角大一点"、"去掉阴影"等
2. **智能体直接修改 CSS 和数据**：在 HTML 模板中调整对应的样式
3. **智能体更新颜色变量**：修改主题的配色方案
4. **智能体调整卡片样式**：修改 `const cards` 数组中的 `accent`、`color` 等字段

## 图片处理与容错

**重要**：跨域图片的处理和容错机制：

### 图片处理流程
1. **用户提供图片URL**
2. **智能体尝试预加载并转换为Base64**：
   ```javascript
   async function preloadImage() {
       try {
           const response = await fetch(imageUrl);
           const blob = await response.blob();
           return new Promise((resolve) => {
               const reader = new FileReader();
               reader.onloadend = () => resolve(reader.result);
               reader.readAsDataURL(blob);
           });
       } catch (error) {
           console.error('预加载图片失败:', error);
           return imageUrl; // 降级到原始URL
       }
   }
   ```
3. **使用Base64图片**：转换成功后在卡片中使用


### 最佳实践
- **优先使用Base64**：尽可能将图片转换为Base64，避免跨域问题
- **提供替代方案**：如果图片无法加载，提供文字描述或占位符
- **测试图片URL**：在生成卡片前测试图片URL是否可访问
- **处理超时**：设置合理的超时时间，避免长时间等待
