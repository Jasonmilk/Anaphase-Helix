本 Skill 旨在指导模型针对单一公司，系统性地开展产品/技术与金融基本面的综合分析，并最终产出一份结构化的研究报告。

## 适用场景与目标

当需要对一个公司进行深入的基本面分析时，可以触发此 Skill。分析的核心是结合其产品/技术实力与财务健康状况，评估其市场地位和未来潜力。

最终产出应为一份结构化报告，至少包含以下部分：

*   **公司概览**：核心业务、市场定位与发展简史。
*   **产品/技术要点**：关键产品、技术路线、竞争壁垒与创新能力。
*   **金融基本面**：核心财务指标、盈利能力、现金流状况与资本结构。
*   **市场与竞争**：目标市场分析、竞争格局与公司护城河。
*   **催化与风险**：潜在的增长驱动因素与可能面临的内外部风险。
*   **结论**：综合上述分析，给出关于公司价值和前景的总结性判断。

## 时间范围与时效性

在分析中，任何相对时间的表述（如“过去两周”、“本月”、“今年”）都需要基于当前系统时间（2026-01-29）转换为精确的日期区间，以确保分析的准确性。

示例如下：

| 相对时间表达 | 解析后日期范围 (基于 2026-01-29) |
| :--- | :--- |
| 过去两周 | `2026-01-15` 至 `2026-01-29` |
| 本月 | `2026-01-01` 至 `2026-01-29` |
| 今年 | `2026-01-01` 至 `2026-01-29` |

## 工具使用策略与顺序

为高效、全面地收集信息，建议遵循以下工具使用策略：

1.  **并行初步探索**：首选 `general_search` 工具，以 2–3 个并行的关键词（不超过 3 个）启动搜索，分别覆盖公司的**产品/技术**、**财务状况**和**市场竞争**等不同侧面。避免对同一主题进行重复搜索。
2.  **深度内容获取**：对于搜索结果中摘要信息有价值、可能包含深入洞察的链接，使用 `web.fetch` 工具进行全文阅读。请注意，`web.fetch` 适合解析网页和文档（doc/ppt/excel/txt/markdown/pdf），但无法处理音视频内容。
3.  **补充专业信息**：
    *   当需要深入了解其技术细节或有学术论文支撑时，补充使用 `scholar_search`。
    *   当需要获取公司产品、设施或关键人物的实体图片时，使用 `image_search`。
    *   若已有参考图片并希望寻找其来源或相似内容，可使用 `visual_search`。
4.  **应对访问障碍**：如果在访问网页时遇到登录墙、人机验证等交互障碍，可使用浏览器工具组中的 `open_url_in_browser`，并通过 `AskHumanToControlBrowser` 请求用户介入协助。

## 数据源优先级建议

为保证分析的准确性和权威性，建议优先从以下渠道获取信息，并注意交叉验证：

1.  **官方文件与监管渠道**：公司官网（特别是投资者关系页面）、官方新闻稿、提交给监管机构的文件（如美国 SEC EDGAR 数据库中的 10-K, 10-Q, 8-K, S-1 文件）。
2.  **权威商业数据库**：Crunchbase, PitchBook 等，用于查询融资历史、公司架构等结构化数据。
3.  **头部财经媒体与行业报告**：信誉良好的主流媒体（如 Bloomberg, Reuters）和知名研究机构发布的行业分析报告。
4.  **专业数据库**：对于特定行业，查询专利数据库（如 USPTO）或临床试验注册网站（如 FDA, ClinicalTrials.gov）。

如果遇到付费墙，应在报告中予以说明，并积极寻找其他可替代的免费信源。

## 财务基本面分析要点

财务分析应聚焦于评估公司的盈利质量、增长潜力和财务健康状况：

*   **收入与利润**：分析收入增速、毛利率、经营利润率的变化趋势。
*   **现金流**：关注经营性现金流是否健康，以及自由现金流状况。
*   **资本结构**：评估现金储备、债务水平与资本支出计划。
*   **单位经济模型 (Unit Economics)**：估算客户获客成本 (CAC) 与生命周期价值 (LTV)，判断商业模式的可持续性。
*   **人力资本**：通过 LinkedIn、公司官网等渠道交叉验证员工规模与关键人才的变动情况。

## 产品/技术与市场分析要点

此部分旨在评估公司的核心竞争力与市场地位：

*   **技术与壁垒**：探究其技术路线的独特性、专利布局和技术护城河。
*   **监管与合规**：识别公司所处行业面临的关键监管要求与合规风险。
*   **商业模式**：分析其收入模式、销售渠道和客户群体。
*   **市场规模与格局**：评估目标市场的规模 (TAM/SAM/SOM)，识别主要竞争对手并进行差异化分析。
*   **定价与毛利**：研究其产品定价策略及其对毛利率的影响。

## 交叉佐证与可信度

所有信息均需经过审慎评估。根据 `references/scoring_standard.md` 中的标准，从权威性、时效性、交叉佐证、原始性和专业性五个维度对信息来源进行评分。当信息出现冲突时，必须在报告中清晰地标注分歧点，并说明为核实信息所尝试的路径（如再次检索、反向查询、查找一手文件等）。

## 输出规格与交付建议

最终交付的报告应清晰、结构化，便于阅读和决策参考。

*   **结构化摘要**：在报告开头提供一份精炼的摘要，总结核心发现。
*   **要点表格**：在适当位置使用表格来呈现关键数据对比（如财务指标、竞品分析）。
*   **来源清单**：在报告末尾附上所有引用的信息来源及其 URL。
*   **审慎措辞**：对所有不确定的信息或预测性陈述，使用“预计”、“可能”、“据分析”等谨慎措-辞。

建议采用结构化的 Markdown 文本格式进行输出。

## 错误处理与注意事项

*   **避免冗余工作**：在搜索前规划好关键词，避免对已获取的信息进行不必要的重复搜索。
*   **精确使用工具**：`image_search` 用于搜索实体图片，不应用于搜索抽象的示意图或图表。
*   **中立客观**：对未经证实的主张或传言，保持中立立场，不作定性判断。
*   **记录限制**：当因访问受限（如付费墙）而无法获取关键信息时，应在报告中记录此限制并说明已尝试的替代方案。
