# 问题类型与工具选择提示

本文件旨在根据不同的分析类型，提供工具选择和关键词设计的建议，以提升信息检索的效率和精准度。

## 常见分析类型与策略

| 分析类型 | 核心诉求 | 工具选择建议 | 关键词拆分提示 |
| :--- | :--- | :--- | :--- |
| **公司概览** | 快速了解公司的核心业务、历史沿革和市场定位。 | `general_search` 为主，可辅以 `web.fetch` 阅读公司官网的“关于我们”页面。 | **主公司名/别称** + “是做什么的” / “公司介绍” / “发展历史”。 |
| **产品/技术分析** | 深入探究产品的技术细节、创新点和竞争优势。 | `general_search` 查找评测文章和技术白皮书；`scholar_search` 查找相关专利和学术论文；`image_search` 查看产品外观和设计。 | **主公司名** + **核心产品/技术名**（如“Tesla Autopilot”）；**技术名** + “技术原理解析” / “专利” / “评测”。 |
| **财务基本面分析** | 获取和解读公司的财务数据，评估其盈利能力和健康状况。 | `general_search` 查找财报公告、投资者关系简报和财经新闻；`web.fetch` 精读 SEC 文件（10-K, 10-Q）。 | **主公司名/股票代码** + “财报” / “income statement” / “revenue growth” / “毛利率” / “现金流”。 |
| **市场与竞争分析** | 识别主要竞争对手，分析市场格局和公司的差异化优势。 | `general_search` 查找行业报告、市场份额数据和竞品对比分析。 | **主公司名** + “竞争对手” / “vs” / “alternatives”；**行业名** + “市场份额” / “market share” / “竞争格局”。 |
| **监管与合规调查** | 了解公司所面临的法律法规、政策风险和潜在诉讼。 | `general_search` 查找相关新闻、监管机构（如 FDA, SEC）的公告和法律文件。 | **主公司名** + **监管机构名**（如 “FDA approval”） / “诉讼” / “反垄断” / “监管”。 |
| **资本市场动向** | 追踪公司的融资历史、股东结构和分析师评级。 | `general_search` 查找 Crunchbase/PitchBook 页面、新闻稿和分析师报告。 | **主公司名** + “融资” / “funding” / “investors” / “analyst rating” / “股价”。 |

## 关键词设计原则

*   **精确与扩展结合**：使用“公司全称 + 股票代码”确保精确，同时使用“公司别称/核心产品名”进行扩展搜索。
*   **使用专业术语**：在搜索财务或技术信息时，使用行业标准术语（如 "EBITDA", "churn rate", "SoC"）能获得更专业的结果。
*   **限定来源与时间**：如果工具支持，可尝试使用 `site:` 操作符将搜索范围限定在特定网站（如 `site:sec.gov`），或添加年份来筛选信息。
*   **多语言搜索**：对于跨国公司，尝试使用英文或其他相关语言的关键词进行搜索，以获取更全面的信息。
