# 信息来源与结论评分参考

本文件旨在提供一套评估信息来源可信度与观点强度的参考标准，以确保分析结论的严谨性与客观性。

## 来源可信度评分参考 (0–5 分)

评估信息来源时，可从以下五个维度进行综合考量：

| 维度 | 评分参考 | 说明 |
| :--- | :--- | :--- |
| **权威性** | 5: 官方文件/监管机构公告<br>4: 顶级权威财经媒体<br>3: 知名行业研究机构/主流媒体<br>2: 有影响力的行业专家/分析师<br>1: 普通媒体/自媒体<br>0: 匿名来源/论坛帖子 | 衡量信息发布者的公信力和背景。官方和监管机构发布的一手信息拥有最高优先级。 |
| **时效性** | 5: 完全在分析的时间窗口内<br>3: 部分在时间窗口内，或作为背景参考<br>1: 明显过时，参考价值低 | 评估信息是否反映了最新的情况。对于财报等周期性数据，时效性至关重要。 |
| **交叉佐证** | 5: 被 3 个以上独立的权威来源证实<br>3: 被 1-2 个独立来源证实<br>1: 孤立信息，无其他来源佐证<br>0: 与其他权威来源存在明确冲突 | 检验信息是否能从多个不相关的渠道得到相互印证，这是排除错误或偏见信息的关键。 |
| **原始性** | 5: 一手信息（如公司财报、官方新闻稿、专利文件）<br>3: 二手信息，但清晰引用并链接了一手来源<br>2: 综合报道或转述，未提供一手来源<br>1: 多次转述或来源不明 | 判断信息是来自事件的直接源头，还是经过了解读和加工。一手信息最可靠。 |
| **专业性** | 5: 由具备深厚行业知识的顶尖专家/机构发布<br>3: 由具备相关知识背景的从业者或分析师发布<br>1: 非专业人士的个人评论或看法<br>0: 内容明显缺乏专业常识 | 评估信息发布者在相关领域的专业水平。专业的技术分析或财务解读优于宽泛的评论。 |

## 综合可信度与冲突处理

*   **综合评定**:
    *   **高可信度**: 通常指在权威性、原始性上得分高，并得到交叉佐证的信息（例如，多家顶级媒体引用的 SEC 文件）。
    *   **中等可信度**: 可能是权威来源的观点性陈述，或有一定佐证但非一手的信息（例如，行业分析师基于财报的解读）。
    *   **低可信度**: 通常是孤立的、来源不明或专业性差的信息（例如，论坛上的匿名爆料）。

*   **观点强度合成示例**:
    *   **强观点**: 基于多个高可信度数据源（如财报、官方公告）得出的分析结论。
    *   **弱观点**: 基于单一中等可信度来源（如一篇分析师评论）或传闻形成的推测。

*   **冲突信息处理策略**:
    1.  **标注分歧**: 当多个可信度相当的来源提供的信息相互矛盾时，必须在报告中明确指出分歧所在，并分别陈述各方观点及其依据。
    2.  **追溯源头**: 优先采纳更接近一手的、权威性更高的来源。
    3.  **降低结论性语气**: 在最终结论中，对存在争议的部分使用“尚不明确”、“存在两种可能”等审慎措辞，避免做出绝对化判断。
