# 模板格式化规范

## 概述

本文档定义了日报和周报模板中占位符的格式化要求，确保生成的 PDF 报告中不会出现原始的占位符符号（如 `[YYYY-MM-DD]`、`\n` 等），而是用实际数据填充。

## 占位符使用规范

### 占位符定义

占位符用于标记需要替换为实际数据的位置，格式为 `[占位符名称]`。

**示例**:
- `[YYYY-MM-DD]` - 日期
- `[价格]` - 价格数值
- `[百分比]` - 百分比
- `[事件名称]` - 事件描述
- `[因子]` - 影响因子

### 占位符替换规则

#### 时间格式

**日期占位符**:
- `[YYYY-MM-DD]` → 替换为实际日期，如 `2026-01-30`
- `[YYYY-MM]` → 替换为年份和月份，如 `2026-01`
- `[月份]` → 替换为月份名称，如 `1月` 或 `January`

**时间占位符**:
- `[HH:MM]` → 替换为时间，如 `10:30`
- `[HH:MM 北京时间]` → 替换为带时区的时间，如 `10:30 北京时间`

**时间戳占位符**:
- `[YYYY-MM-DD HH:MM 北京时间]` → 替换为完整时间戳，如 `2026-01-30 10:30 北京时间`
- `[YYYY-MM-DD HH:MM 北京时间 / UTC]` → 替换为双时区时间，如 `2026-01-30 10:30 北京时间 / 02:30 UTC`

#### 数值格式

**价格占位符**:
- `[价格]` → 替换为价格数值，如 `2050.50`
- `$[价格]` → 替换为美元价格，如 `$2050.50`
- `¥[价格]` → 替换为人民币价格，如 `¥480.50`

**百分比占位符**:
- `[百分比]%` → 替换为百分比，如 `1.5%`
- `+/-[百分比]%` → 替换为带符号的百分比，如 `+1.5%` 或 `-0.8%`

**变动占位符**:
- `[+/-]$[变动金额]` → 替换为美元变动，如 `+$20.50` 或 `-$15.30`
- `[+/-]¥[变动金额]` → 替换为人民币变动，如 `+¥5.20` 或 `-¥3.80`
- `[+/-]%` → 替换为百分比变动，如 `+1.5%` 或 `-0.8%`
- `[+/-]bp` → 替换为基点变动，如 `+5bp` 或 `-3bp`
- `[+/-]吨` → 替换为吨位变动，如 `+2.5吨` 或 `-1.2吨`
- `[+/-][变动]` → 替换为通用变动，如 `+3.2` 或 `-1.8`

**数值占位符**:
- `[数值]` → 替换为数值，如 `103.5`
- `[变动]` → 替换为变动值，如 `+0.5` 或 `-0.3`
- `[bp]` → 替换为基点，如 `5bp`
- `[吨]` → 替换为吨，如 `850吨`
- `[手]` → 替换为手数，如 `1500手`

#### 文本占位符

**事件占位符**:
- `[事件名称]` → 替换为事件名称，如 `美联储FOMC会议`
- `[事件描述]` → 替换为事件描述，如 `美联储宣布维持利率不变`

**因子占位符**:
- `[因子名称]` → 替换为因子名称，如 `利率/实际利率`
- `[因子]` → 替换为因子简称，如 `利率`

**方向占位符**:
- `[↑/↓/→]` → 替换为方向箭头，如 `↑`、`↓` 或 `→`

**评级占位符**:
- `[高/中/低]` → 替换为评级，如 `高`、`中` 或 `低`
- `[短/中/长期]` → 替换为时间跨度，如 `短期`、`中期` 或 `长期`
- `[⏰/⏳/📅/📆]` → 替换为时效性标记，如 `⏰`、`⏳`、`📅` 或 `📆`
- `[✅/⚠️/❓]` → 替换为确定性标记，如 `✅`、`⚠️` 或 `❓`
- `[🔴/🟡/🟢]` → 替换为重要性标记，如 `🔴`、`🟡` 或 `🟢`

**评分占位符**:
- `[+2/+1/0/-1/-2]` → 替换为评分，如 `+2`、`+1`、`0`、`-1` 或 `-2`

**分析占位符**:
- `[简要说明]` → 替换为简要说明文本
- `[详细说明]` → 替换为详细说明文本
- `[分析]` → 替换为分析文本
- `[描述]` → 替换为描述文本
- `[数据或事件]` → 替换为数据或事件描述

**周数占位符**:
- `[周[X]]` → 替换为具体周数，如 `周一`、`周二` 等
- `[X.XX%]` → 替换为具体百分比，如 `1.5%`

**概率占位符**:
- `[XX.X%]` → 替换为概率，如 `65.5%`

**利率占位符**:
- `[X.XX% - X.XX%]` → 替换为利率区间，如 `5.25% - 5.50%`

**季度占位符**:
- `[YYYY年Q季度]` → 替换为季度，如 `2026年Q1`

### 表格占位符处理

表格中的占位符需要逐一替换，确保表格完整性。

**示例表格**:
```
| 时间 | 事件 | 影响因子 | 影响方向 | 时效性 | 确定性 |
|------|------|---------|---------|--------|--------|
| [HH:MM 北京时间] | [事件描述] | [因子名称] | [↑/↓/→] | [⏰/⏳/📅/📆] | [✅/⚠️/❓] |
```

**替换后**:
```
| 时间 | 事件 | 影响因子 | 影响方向 | 时效性 | 确定性 |
|------|------|---------|---------|--------|--------|
| 10:30 北京时间 | 美联储FOMC会议 | 利率 | ↑ | ⏰ | ✅ |
```

### 特殊符号处理

#### 换行符 `\n`

**问题**: Markdown 源文件中的 `\n` 符号在转换为 PDF 时可能显示为字面字符。

**解决方案**:
1. **不使用 `\n` 符号**: 在模板中直接使用真实的换行
2. **Markdown 换行**: 使用两个空格加换行（`  \n`）或两个换行符
3. **PDF 生成时处理**: 在 PDF 生成代码中识别并转换 `\n` 为实际换行

**推荐做法**:
- 模板中不使用 `\n` 符号
- 直接使用 Markdown 的段落分隔（空行）
- 列表项直接换行

**示例**:
```
❌ 错误:
- 事件1: [描述]\n- 事件2: [描述]

✅ 正确:
- 事件1: [描述]
- 事件2: [描述]
```

#### 其他特殊字符

**箭头符号**:
- `↑` `↓` `→` - 直接使用，无需转义

**星号符号**:
- `⭐⭐⭐⭐⭐` - 直接使用，无需转义

**时区符号**:
- `北京时间` / `UTC` - 直接使用

**货币符号**:
- `$` `¥` - 直接使用，无需转义

**百分比符号**:
- `%` - 直接使用，无需转义

### 条件占位符处理

某些内容可能存在或不存在，需要条件性处理。

#### 示例：周度统计
```
**周度统计**:
- 最大单日涨幅: [+X.XX%] (周[X])
- 最大单日跌幅: [-X.XX%] (周[X])
- 波动率: [X.XX%]
- 成交量: [数值] (环比 [+/-]%)
```

**处理规则**:
- 如果数据存在，替换占位符
- 如果数据不存在，标注"暂无数据"或"N/A"
- 或者删除该行（如果是可选内容）

### 多语言占位符

模板支持中英文双语，需要处理语言占位符。

**示例**:
```
## 一、市场概览 (Market Overview)
```

**处理规则**:
- 中文标题保持不变
- 英文标题保持不变
- 不需要替换

### 数据来源占位符

**示例**:
```
*数据来源: [具体来源]*
```

**替换后**:
```
*数据来源: 美联储官网、上海黄金交易所*
```

**处理规则**:
- 列出实际使用的数据源
- 多个来源用"、"分隔
- 或者用"、"连接

## 格式化实现要求

### 生成流程

1. **读取模板**: 从模板文件读取原始内容
2. **收集数据**: 根据报告类型收集所有需要的数据
3. **替换占位符**: 按照替换规则逐一替换所有占位符
4. **验证完整性**: 检查是否还有未替换的占位符
5. **生成 Markdown**: 生成完整的 Markdown 内容
6. **转换 PDF**: 将 Markdown 转换为 PDF

### 实现提示

**Python 实现示例**:
```python
import re

def replace_placeholders(template, data):
    """替换模板中的占位符"""
    result = template
    
    # 替换日期
    result = result.replace('[YYYY-MM-DD]', data['date'])
    
    # 替换价格
    result = result.replace('[价格]', str(data['price']))
    
    # 替换百分比
    result = result.replace('[百分比]', data['percentage'])
    
    # 替换事件
    result = result.replace('[事件描述]', data['event'])
    
    # 处理特殊字符
    result = result.replace('\\n', '\n')  # 将 \n 转为实际换行
    
    # 验证是否还有未替换的占位符
    unreplaced = re.findall(r'\[[^\]]+\]', result)
    if unreplaced:
        print(f"警告：仍有未替换的占位符: {unreplaced}")
    
    return result
```

### 错误处理

**未替换的占位符**:
- 如果检测到未替换的占位符，应该：
  1. 记录警告日志
  2. 决定是保持原样还是替换为默认值（如"N/A"、"暂无数据"）

**数据缺失**:
- 如果某些数据无法获取：
  1. 使用"N/A"或"暂无数据"替换
  2. 或者在模板中标注"如无...则删除"

**格式错误**:
- 如果数据格式不符合预期：
  1. 尝试格式化（如数字保留2位小数）
  2. 记录错误日志
  3. 使用默认值或跳过

## 注意事项

1. **占位符一致性**: 确保所有模板使用相同的占位符格式
2. **数据完整性**: 收集所有必要数据，避免缺失
3. **格式验证**: 替换后验证格式是否正确
4. **特殊字符**: 注意特殊字符的转义和处理
5. **换行处理**: 确保换行符正确转换，避免字面 `\n` 出现
6. **语言支持**: 确保中文字符正确显示
7. **PDF 转换**: 测试 PDF 转换后的显示效果
