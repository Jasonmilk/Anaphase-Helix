# PDF输出格式规范

## 概述

黄金市场日报和周报均以 PDF 格式输出，确保报告的专业性、可读性和可分享性。本文档定义了 PDF 生成的格式规范和实现要求。

## 输出格式要求

### 文件格式
- **格式**: PDF (Portable Document Format)
- **编码**: UTF-8
- **语言**: 中文（可根据用户需求提供英文版）

### 文件命名规范

**日报**:
```
黄金市场日报_YYYY-MM-DD.pdf
Gold Market Daily Report_YYYY-MM-DD.pdf
```

**周报**:
```
黄金市场周报_YYYY-MM-DD.pdf
Gold Market Weekly Report_YYYY-MM-DD.pdf
```

说明：
- 日期使用报告生成日期
- 支持中英文双语命名

## 页面布局规范

### 页面设置
- **纸张大小**: A4 (210mm × 297mm)
- **页边距**:
  - 上: 25mm
  - 下: 25mm
  - 左: 25mm
  - 右: 25mm
- **页眉**: 无页眉
- **页脚**: 无页脚（无蓝色横线）

### 字体规范
- **中文字体**: 思源黑体、微软雅黑或宋体
- **英文字体**: Arial、Helvetica 或 Times New Roman
- **字号**:
  - 标题: 18-24pt
  - 二级标题: 14-16pt
  - 三级标题: 12-14pt
  - 正文: 10-12pt
  - 表格内容: 9-10pt

### 颜色规范
- **主标题**: 深蓝色 (#1F4E79)
- **二级标题**: 深灰色 (#404040)
- **正文**: 黑色 (#000000)
- **表格表头**: 浅灰色背景 (#F0F0F0)
- **强调文字**: 深蓝色或红色

## PDF 生成要求

### 内容生成流程

1. **收集数据**: 根据报告类型收集相关数据
2. **填写模板**: 使用 Markdown 或 HTML 格式填写报告内容
3. **转换为 PDF**: 将内容转换为 PDF 格式
4. **质量检查**: 检查格式、内容和完整性
5. **输出文件**: 生成最终的 PDF 文件

### PDF 生成工具推荐

**Python 实现方案**:

```python
# 方案1: 使用 ReportLab（推荐用于专业格式）
from reportlab.lib.pagesizes import A4
from reportlab.lib.units import mm
from reportlab.pdfgen import canvas
from reportlab.lib.styles import getSampleStyleSheet
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Table

# 创建PDF文档
doc = SimpleDocTemplate(
    "output.pdf",
    pagesize=A4,
    leftMargin=25*mm,
    rightMargin=25*mm,
    topMargin=25*mm,
    bottomMargin=25*mm,
    showFooter=False,  # 无页脚
    showHeader=False   # 无页眉
)

# 方案2: 使用 WeasyPrint（支持 HTML/CSS）
import weasyprint

html_content = """
<!DOCTYPE html>
<html>
<head>
    <style>
        @page {
            size: A4;
            margin: 25mm;
        }
        body {
            font-family: "Microsoft YaHei", Arial, sans-serif;
            font-size: 12pt;
        }
    </style>
</head>
<body>
    <!-- 报告内容 -->
</body>
</html>
"""

weasyprint.HTML(string=html_content).write_pdf("output.pdf")
```

**智能体实现说明**:
- 智能体生成 Markdown 格式的报告内容
- 使用 PDF 生成工具将 Markdown 转换为 PDF
- 或者使用智能体的原生 PDF 生成能力（如果可用）

### 页面元素规范

#### 标题
- 主标题：居中、加粗、深蓝色
- 副标题：居中、常规字体、深灰色
- 日期信息：居右、小字号、灰色

#### 表格
- 表头：浅灰色背景、加粗、居中
- 边框：1pt 灰色实线
- 行高：单倍行距或 1.2 倍
- 对齐：数字右对齐，文本左对齐或居中

#### 特殊符号
- 箭头：↑ ↓ →
- 星级：⭐⭐⭐⭐⭐
- 时间标记：⏰ ⏳ 📅 📆
- 确定性标记：✅ ⚠️ ❓
- 重要性：🔴 🟡 🟢

#### 图表（可选）
- 折线图：金价走势
- 柱状图：数据对比
- 饼图：权重分布
- 图表应清晰标注标题、轴标签和图例

### 页眉页脚设置

**页眉**:
- 不设置页眉

**页脚**:
- 不设置页脚
- **特别要求**：删除每页底部的蓝色横线（如有）
- 不显示页码
- 不显示任何装饰性元素

## 内容质量要求

### 准确性
- 所有数据必须有明确来源
- 时间戳必须包含时区信息
- 数据必须标注时间点

### 完整性
- 所有章节都必须有内容
- 无数据时需说明原因
- 必须包含免责声明

### 一致性
- 使用统一的术语和符号
- 保持格式一致
- 风格统一

### 专业性
- 使用客观、中性的语言
- 避免情绪化表达
- 遵守合规要求

## 注意事项

1. **文件大小**: PDF 文件大小应控制在合理范围内（建议 < 5MB）
2. **兼容性**: PDF 应兼容主流 PDF 阅读器
3. **打印友好**: 考虑打印需求，确保黑白打印清晰可读
4. **版本控制**: 在文件名或文档中注明版本号
5. **水印**: 可选添加"内部资料"或"仅供参考"水印
6. **页脚横线**: 必须删除每页底部的蓝色横线（如有）

## 实现提示

对于智能体实现：
1. 优先使用 Markdown 格式生成报告内容
2. 使用成熟的 PDF 生成库进行转换
3. 确保 PDF 生成过程中的中文支持
4. 测试生成的 PDF 文件可正常打开和阅读
5. 考虑添加目录和页码提升可读性（但不要在页脚显示）
6. 确保无页眉页脚，特别是无蓝色横线
