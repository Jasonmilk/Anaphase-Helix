# 三因子模型详解

## 模型概述

本模型基于三个核心因子分析黄金价格的影响因素，提供客观信息分析，不做综合评分或最终判断。

### 核心原则

1. **提供信息，不做判断** - 只呈现各因子独立影响，不给出综合评分
2. **三因子独立分析** - 每个因子独立评估，不进行加权计算
3. **交互效应说明** - 分析因子之间的协同/对冲效应
4. **用户自行综合** - 用户基于各因子分析自行做出综合判断

## 核心因子

### 因子1: 实际利率 ⭐⭐⭐⭐⭐

#### 定义
实际利率 = 名义利率 - 通胀预期

**推荐指标**：10年期TIPS收益率（Treasury Inflation-Protected Securities）

#### 影响机制

**核心逻辑**：实际利率是持有黄金的机会成本

```
实际利率 ↑ → 持有黄金机会成本 ↑ → 黄金吸引力 ↓ → 金价 ↓
实际利率 ↓ → 持有黄金机会成本 ↓ → 黄金吸引力 ↑ → 金价 ↑
```

**传导路径**：
1. 实际利率上升 → 持有生息资产（如债券）更有吸引力
2. 黄金不产生利息 → 相对吸引力下降
3. 投资者减少黄金配置 → 金价下跌

#### 数据来源

**主要指标**：
- 10年期TIPS收益率（每日）
- 5年期TIPS收益率（每日）
- 盈亏平衡通胀率（每日）

**辅助指标**：
- 联邦基金利率（FOMC决议）
- CPI数据（月度）
- PCE数据（月度）
- 美联储点阵图（季度）

**数据源**：
- 美国财政部：https://home.treasury.gov/
- FRED：https://fred.stlouisfed.org/
- 美联储：https://www.federalreserve.gov/

#### 分析要点

**影响方向判断**：
- 实际利率下降 → 利多金价
- 实际利率上升 → 利空金价
- 实际利率持平 → 中性

**影响强度评估**：
- 变化幅度 > 50个基点 → 强影响
- 变化幅度 20-50个基点 → 中等影响
- 变化幅度 < 20个基点 → 弱影响

**关键观察点**：
- 美联储政策转向信号
- 通胀预期变化
- 名义利率与通胀的相对变化
- FOMC会议声明和点阵图

#### 历史相关性

**历史规律**（仅供参考）：
- 2020-2021年：实际利率深度负值 → 金价创历史新高
- 2022年：实际利率快速上升 → 金价大幅回调
- 2023-2024年：实际利率高位震荡 → 金价震荡

**重要提示**：历史表现不代表未来结果

### 因子2: 央行购金 ⭐⭐⭐⭐⭐

#### 定义
全球央行（特别是新兴市场央行）购买黄金作为外汇储备的行为

#### 影响机制

**核心逻辑**：央行购金提供长期稳定的需求支撑

```
央行购金 ↑ → 黄金需求 ↑ → 供需关系改善 → 金价 ↑
央行购金 ↓ → 黄金需求 ↓ → 供需关系恶化 → 金价 ↓
```

**传导路径**：
1. 央行增持黄金 → 市场需求增加
2. 黄金供应相对有限 → 供需失衡
3. 价格上涨 → 金价上升

#### 购金动机

**储备多元化**：
- 减少对单一货币（特别是美元）的依赖
- 分散外汇储备风险
- 提高储备资产的稳定性

**去美元化**：
- 地缘政治考量
- 减少美元资产占比
- 增强货币主权

**避险需求**：
- 应对全球经济不确定性
- 防范金融系统风险
- 保值增值需求

#### 数据来源

**主要数据**：
- 全球央行净购金量（季度）- 世界黄金协会
- 各国央行黄金储备（月度）- IMF
- 中国央行黄金储备（月度）- 中国人民银行

**重点关注央行**：
- 中国人民银行（PBOC）
- 俄罗斯央行
- 土耳其央行
- 印度储备银行
- 波兰央行
- 新加坡金融管理局

**数据源**：
- 世界黄金协会：https://www.gold.org/
- IMF：https://www.imf.org/
- 各国央行官网

#### 分析要点

**影响方向判断**：
- 央行净购金增加 → 利多金价
- 央行净购金减少 → 利空金价
- 央行购金持平 → 中性

**影响强度评估**：
- 季度净购金 > 200吨 → 强影响
- 季度净购金 100-200吨 → 中等影响
- 季度净购金 < 100吨 → 弱影响

**关键观察点**：
- 世界黄金协会季度报告
- 中国央行月度储备公告
- 新兴市场央行储备变化
- 地缘政治事件对购金行为的影响

#### 历史趋势

**长期趋势**（仅供参考）：
- 2010年前：央行净售金
- 2010-2020年：央行转为净购金
- 2020年至今：购金力度持续增强

**重要提示**：历史表现不代表未来结果

### 因子3: 系统性风险 ⭐⭐⭐⭐

#### 定义
全球金融市场的不确定性和恐慌程度，包括地缘政治风险、金融系统风险、经济衰退风险

#### 影响机制

**核心逻辑**：系统性风险驱动避险需求

```
系统性风险 ↑ → 避险需求 ↑ → 黄金需求 ↑ → 金价 ↑
系统性风险 ↓ → 避险需求 ↓ → 黄金需求 ↓ → 金价 ↓
```

**传导路径**：
1. 风险事件发生 → 市场恐慌情绪上升
2. 投资者寻求避险资产 → 黄金作为传统避险资产
3. 避险资金流入黄金 → 金价上涨

#### 风险类型

**地缘政治风险**：
- 军事冲突（中东、俄乌、台海等）
- 政治危机
- 贸易战
- 国际关系紧张

**金融系统风险**：
- 银行危机
- 流动性危机
- 债务危机
- 股市崩盘

**经济衰退风险**：
- 经济增长放缓
- 就业市场恶化
- 通胀失控
- 政策失误

#### 衡量指标

**主要指标**：
- VIX指数（恐慌指数）
- 黄金波动率指数
- 避险资金流向

**辅助指标**：
- TED spread（银行间信用风险）
- 公司债收益率利差
- 股市波动率

#### 数据来源

**数据源**：
- CBOE：https://www.cboe.com/
- Reuters
- Bloomberg
- 各大财经媒体

#### 分析要点

**影响方向判断**：
- 系统性风险上升 → 利多金价
- 系统性风险下降 → 利空金价
- 风险平稳 → 中性

**影响强度评估**：
- 全球性危机（如2008金融危机）→ 极强影响
- 区域性冲突 → 中等到强影响
- 政治不确定性 → 弱到中等影响

**关键观察点**：
- VIX指数突破关键点位
- 重大地缘事件进展
- 银行和金融系统稳定性
- 经济数据意外恶化

#### 历史相关性

**历史规律**（仅供参考）：
- 2008年金融危机：系统性风险飙升 → 金价从800美元涨至1200美元
- 2020年疫情：VIX指数飙升 → 金价从1500美元涨至2000美元
- 2022年俄乌冲突：地缘风险上升 → 金价从1800美元涨至2070美元

**重要提示**：历史表现不代表未来结果

## 因子交互效应

### 协同效应（同向强化）

1. **实际利率下降 + 央行购金增加**
   - 效果：双重利多，金价支撑强劲
   - 示例：2020年疫情期间

2. **实际利率下降 + 系统性风险上升**
   - 效果：机会成本降低 + 避险需求增强
   - 示例：2008年金融危机后期

3. **央行购金增加 + 系统性风险上升**
   - 效果：长期需求 + 短期避险需求
   - 示例：2022年俄乌冲突期间

### 对冲效应（反向抵消）

1. **实际利率上升 + 央行购金增加**
   - 效果：机会成本上升 vs 需求支撑
   - 结果：金价可能震荡或小幅波动

2. **实际利率下降 + 系统性风险下降**
   - 效果：利多因素 vs 避险需求减弱
   - 结果：金价可能温和上涨

3. **央行购金减少 + 系统性风险上升**
   - 效果：长期需求减弱 vs 短期避险需求
   - 结果：金价可能短期上涨但缺乏持续性

## 市场环境识别

### 正常环境
- **特征**：经济平稳增长，通胀温和，地缘政治稳定
- **因子表现**：实际利率主导，央行购金稳定，系统性风险低
- **金价特征**：波动较小，主要跟随实际利率

### 危机环境
- **特征**：金融危机、经济衰退、地缘冲突
- **因子表现**：系统性风险主导，避险需求激增
- **金价特征**：快速上涨，波动加大

### 政策转向环境
- **特征**：货币政策重大转向（加息/降息周期）
- **因子表现**：实际利率预期变化主导
- **金价特征**：趋势性变化，方向明确

- 短期因子交互效应

### 周报分析重点
- 周度因子变化趋势
- 历史同期对比
- 中期因子交互效应

### 月报分析重点
- 月度因子深度分析
- 长期历史对比
- 结构性变化识别

## 使用说明

1. **独立分析每个因子**：不要预设立场，客观评估每个因子的影响
2. **识别因子交互**：注意因子之间的协同或对冲效应
3. **评估影响强度**：区分强、中、弱影响，合理分配注意力
4. **提供客观信息**：只做信息呈现和机制解释，不做价格预测
5. **用户自行判断**：让用户基于各因子分析自行做出综合决策
