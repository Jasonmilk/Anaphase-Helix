# 重要时间日程信息源

## 概述

重要时间日程是黄金市场分析的关键组成部分，直接影响投资者对金价的预期和交易决策。本文档定义了允许使用的时间日程信息源，以及如何在日报和周报中使用这些信息。

## 允许的信息源

### 1. 美联储日程

**官方地址**: https://www.federalreserve.gov/newsevents/calendar.htm

**包含内容**:
- FOMC会议日期和时间
- 美联储主席和官员讲话
- 重要经济数据发布时间
- 货币政策报告发布
- 其他重要活动和声明

**使用方式**: 使用 WebFetch 工具获取最新日程

**关键信息类型**:
- FOMC利率决议
- 点阵图发布
- 经济预测摘要(SEP)
- 美联储主席新闻发布会
- 重要官员讲话

### 2. 美国劳工局就业数据发布日程

**官方地址**: https://www.bls.gov/schedule/2026/home.htm

**包含内容**:
- 非农就业数据(NFP)发布时间
- 失业率数据发布时间
- JOLTS职位空缺数据
- 其他劳动力市场数据

**使用方式**: 使用 WebFetch 工具获取最新日程

**关键信息类型**:
- 非农就业人数变化
- 失业率
- 平均时薪
- 劳动参与率

### 3. 美国CPI发布日程

**官方地址**: https://www.bls.gov/schedule/2026/home.htm

**包含内容**:
- CPI数据发布时间
- 核心CPI数据
- PCE数据(需从其他源获取)
- 其他通胀相关数据

**使用方式**: 使用 WebFetch 工具获取最新日程

**关键信息类型**:
- CPI月率/年率
- 核心CPI月率/年率
- CPI分类数据
- 环比/同比变化

## 重要性评级

### 🔴 高影响力事件

必须重点提醒的事件：
- FOMC利率决议
- 非农就业数据
- CPI通胀数据
- 美联储主席重要讲话
- 点阵图和经济预测发布

### 🟡 中等影响力事件

需要提醒的事件：
- 核心CPI数据
- PCE数据
- 非农数据之外的劳动力市场数据
- 美联储其他官员讲话
- 其他央行决议(欧洲央行、英国央行等)

### 🟢 低影响力事件

可选提醒的事件：
- 次要经济数据
- 常规官员讲话
- 其他央行次要会议

## 在报告中的应用

### 日报中的使用

**位置**: "二、重要时间日程提醒"章节

**内容要求**:
- 列出未来7天内的高影响力事件
- 标注北京时间(北京时间)
- 说明预期影响(利多/利空/中性)
- 提供数据来源链接

**示例格式**:
```
## 二、重要时间日程提醒 (Upcoming Key Events)

### 🔴 近期高影响力事件

| 时间 (北京时间) | 事件 | 影响因子 | 预期影响 |
|------------|------|---------|----------|
| 2026-02-05 21:00 | 美联储主席讲话 | 利率 | 中性 |
| 2026-02-07 21:30 | 非农就业数据 | 利率 | 待观察 |
| 2026-02-14 21:30 | CPI通胀数据 | 利率 | 待观察 |

**数据来源**:
- 美联储日程: https://www.federalreserve.gov/newsevents/calendar.htm
- 美国劳工局就业数据发布日程: https://www.bls.gov/schedule/2026/home.htm
- 美国CPI发布日程: https://www.bls.gov/schedule/2026/home.htm

**重要提醒**:
- 上述重要信息公布可能显著影响金价，请提前做好风险准备
- 建议在关键数据发布前调整仓位或对冲风险
- 关注市场预期与实际值的差异对金价的冲击

**本周重点关注**:
- FOMC会议（2月5日）
- 非农数据（2月7日）
- CPI数据（2月14日）
```

### 周报中的使用

**位置**: "二、重要时间日程提醒"章节

**内容要求**:
- 列出下周的重要事件
- 列出本月剩余的重要时间节点
- 标注高影响力事件
- 说明长期关注点

**示例格式**:

## 数据获取策略

### WebFetch 使用

**获取美联储日程**:
```
URL: https://www.federalreserve.gov/newsevents/calendar.htm
Prompt: "提取未来30天内的重要日程，包括FOMC会议、美联储主席和官员的讲话、重要经济数据发布时间。返回格式：日期(北京时间)、事件名称、影响力评级。"
```

**获取劳工局日程**:
```
URL: https://www.bls.gov/schedule/2026/home.htm
Prompt: "提取未来30天内的重要数据发布日程，特别是非农就业数据、失业率、CPI通胀数据的发布时间。返回格式：日期(北京时间)、数据名称、影响力评级。"
```

### WebSearch 备选

如果 WebFetch 失败，使用 WebSearch:
```
Query: "美联储 FOMC 会议日程 2026"
Query: "非农就业数据发布时间 2026"
Query: "美国CPI数据发布时间 2026"
```

## 注意事项

1. **时间转换**: 所有时间必须转换为北京时间(北京时间)
   - 美国东部时间(ET) + 13小时 = 北京时间(冬季)
   - 美国东部时间(ET) + 12小时 = 北京时间(夏季)

2. **影响评估**: 对于尚未发生的事件，使用"待观察"或基于市场预期评估
   - 避免预测具体影响方向
   - 说明市场普遍预期

3. **更新频率**:
   - 日报：每日更新，列出未来7天的重要事件
   - 周报：每周更新，列出下周和本月的重要事件

4. **合规要求**:
   - 仅使用官方白名单信息源
   - 不预测数据结果
   - 提醒投资者关注实际值与预期的差异
   - 强调风险管理的重要性

5. **格式规范**:
   - 使用表格清晰展示
   - 标注影响力评级(🔴/🟡/🟢)
   - 提供数据来源链接
   - 包含风险提示说明
