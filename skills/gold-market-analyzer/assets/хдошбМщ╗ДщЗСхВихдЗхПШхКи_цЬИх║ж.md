# 央行黄金储备变动表（月度）

本文档为**主要央行/官方机构黄金储备**的**月度环比变动**（单位：**吨**）。
- **增加**：`+数量`
- **减少**：`-数量`
- **无变动**：`0`

时间自 **2000 年 1 月**至**最近可得**（约 2025 年 12 月）。**行**为各月，**列**为各国。数据由《全球主要央行黄金储备_月度.md》对应序列计算得出。

---

## 一、数据说明

| 项目 | 说明 |
|------|------|
| **含义** | 当月黄金储备较上月的变动量（吨） |
| **正数** | 净增持（购金等） |
| **负数** | 净减持（售金等） |
| **0** | 当月与上月持平 |
| **首月** | 2000-01 无上月基准，表中以 — 表示 |
| **2025 年 2–12 月** | 已按 WGC/央行等公开报道填入月度变动（+增/－减/0 无变动），无报道的为 0 |
